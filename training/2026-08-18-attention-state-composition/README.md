# OLEANDER Training — Attention-State Composition

Date: 2026-08-18

## Training question

How should a multi-layer visual system preserve all required information without letting map, explanation, controls, evidence and brand compete with the real project object at the same moment?

## Reused knowledge

- Notion `CH01｜项目问题与机会｜Current Material`: `S0 LANDSCAPE/BODY → S1 PROMPT → S2 REVEAL`; `SERVICE / RETURN > ROUTE > OBSERVATION > EXPLANATION > MEMORY > SHARE`.
- Notion `KN-METHOD-INFOVIZ-ABSTRACTION-BUDGET-001`: abstraction/detail must follow user task rather than aesthetic simplification.
- Notion `FW-DESIGN-VISUAL-COMM-001`: information hierarchy remains a visual-communication responsibility.
- GitHub `oleander-story-and-board`: one primary claim + one primary visual, evidence-first, authority-preserving presentation.

## Practice

A synthetic Qingjiang-like landscape proxy was kept constant. Variant A shows explanation, map/status and controls simultaneously. Variant B redistributes visual responsibility across S0/S1/S2 while keeping Return persistent.

### Crit

- A / all layers visible: **REJECT**. Correct information is present, but the landscape is no longer the unambiguous first-read.
- v1 state-budget board: **REVISE** because the available renderer produced missing-glyph boxes in Chinese labels; typography quality failed even though hierarchy logic worked.
- v2 state-budget board: **KEEP FOR TRAINING**. Typography renders cleanly; S0/S1/S2 each have a distinct attention owner; required information is delayed rather than deleted.

## Failure knowledge

1. Information completeness does not equal hierarchy quality.
2. Minimalism by deletion is not an acceptable repair when content is required.
3. A state change that only changes opacity/color is not a visual-responsibility change.
4. Typography/render failures are Design Crit failures even when the interaction/content logic is correct.
5. Return/service/safety are persistent recovery layers, not optional decorative controls.

## Skill delta

Updated `oleander-story-and-board` with an **Attention-state composition gate** and default review chain:

`ATTENTION OWNER → SUPPORT LAYERS → SUPPRESSED LAYERS → RECOVERY → EVIDENCE BOUNDARY → FIRST-READ / NEAR-READ`

## Transfer

Applicable to landscape interpretation, museum/exhibition interfaces, product onboarding, map drill-down, web chapters, presentation sequences and spatial-digital hybrids. Not a substitute for dense analytical dashboards where simultaneous comparison is the actual task, and not evidence of field validity or user comprehension.
