# GUI CP4 Supplement Protocol

若 CP2 已经由 headless provider 关闭，GUI provider 只需：
- 打开同一 definition SHA256；
- 展示 `PV_BASE / PV_GRAFT / PV_FLATTEN / PV_TRANSPOSE / PV_ADVERSE`；
- 保存 Grasshopper canvas；
- 保存 Rhino viewport（若定义输出几何）；
- 保持 adverse mismatch 可见；
- 通过 Occlusion / Legibility / sink↔viewer correspondence 审查。

GUI supplement 不需要重做离线 Data Tree 方法研究。
