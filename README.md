# Design｜Oleander 刘旋

产品、CMF、品牌与文化体验设计作品集。

我关注设计对象与人、材料、空间和文化之间的关系，并通过研究、视觉系统、原型与体验路径，把抽象判断转化为可以理解、使用和验证的设计成果。

## 设计方向

- 产品设计：用户研究、竞品分析、场景定义、建模与原型
- CMF 设计：色彩、材料、表面工艺、趋势研究与样板表达
- 品牌设计：定位、视觉识别、编辑系统与传播触点
- 空间体验：服务路径、导视、材料氛围与商业空间叙事
- 设计研究：证据整理、关系分析、动态数据可视化与项目复盘

## 精选项目

### 忘也 Daylily｜都市疗愈商业空间

以都市人群的短时恢复需求为起点，完成从市场研究、受众分析和品牌定位，到 VIS、CMF、物料触点与空间体验的完整设计。

核心命题不是制造一种统一的“疗愈审美”，而是让每个人都能以自己的节奏靠近、停留、感知，并把片刻恢复带回日常。

**职责**：Research / Strategy / Brand / CMF / VIS / Space  
**状态**：作品集项目，网页案例整理中

### OPPO Reno 系列 CMF 提案｜The Light Collection

围绕品牌基因、光影体验和趋势验证，构建系列化色彩、材料、表面工艺与图纹转译方案。

**职责**：CMF Research / Color / Material / Finish

### Oleander 设计实践

Oleander 把项目视为“关系研究”，以六阶段方法组织工作：

1. Read：阅读对象原有的关系
2. Locate：定位断点与责任
3. Translate：把研究转化为生成规则
4. Form：形成品牌、产品、空间或传播触点
5. Test：用证据检查设计是否成立
6. Revise：记录变化、限制与下一轮判断
