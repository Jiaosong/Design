# v3.3 Photography Calibration — Round 3 gate criteria

All four gates are visual/presentation gates only. They are not material, optical, manufacturing, thermal, electrical, safety, compliance or production validation.

## 1. Housing highlight
PASS only if the PC+ABS candidate body reads with a controlled broad-to-narrow studio reflection sweep that reveals the side curvature and upper shoulder without becoming glossy car paint, clay-flat, or banded/faceted.

## 2. Diffuser volume
PASS only if the formed diffuser reads as a three-dimensional opal volume with legible edge thickness / formed curvature and restrained internal glow; it must not read as a flat warm disc, transparent glass, or blown-out emissive plate.

## 3. Metal knob reflection
PASS only if the knob reads as satin metal with at least one controlled bright reflection and one darker opposing value region while retaining cylindrical form; it must not read as brown/black plastic, chrome mirror, or featureless gray.

## 4. Contact shadow falloff
PASS only if the product appears grounded by a compact dark contact core that transitions into a soft low-density falloff without a visible rectangular shadow plate, halo, floating gap, or frame-obscuring foreground geometry.

## Lock rule
`FINAL HERO / CMF RENDER LOCK` may be set only when all four gates receive human visual PASS from screenshots rendered in a recorded WebGL environment. Until then: `UNLOCKED`.
