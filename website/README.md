# OLEANDER Website Prototype — Tactile Interaction v2

本版本重点强化 **Paper Weave Field（纸上织场）** 与 **Relationship Reading（关系阅读）** 的可感知交互。

## 直接运行

打开 `index.html`。页面不依赖外部字体、图片或第三方 JavaScript 库。

也可以直接打开同级交付中的 `oleander-prototype-v2-standalone.html`，该文件已内嵌全部 CSS 和 JavaScript。

## 新增纸质语言

- 多层纸张纤维、局部颗粒与光线响应
- 纸层阴影、压痕、折线、翘角与轻微毛边
- Paper Fragment 节点与开放纸张边界
- 可按压按钮、纸卡抬升与触摸反馈
- 深色 Contact 页面中的墨色纸面与压印层

## 新增交互

- 首页关系织场：连接 / 松开、关系密度调节
- Relationship Reading：Original / Current / Intended 状态切换
- 关系张力调节：同步改变线型与节点距离
- 证据层抽屉：显示来源、限制与可信度
- Selected Evidence：逐项展开证据层
- Translation Logic：点击应用卡查看生成规则
- Experience Formation：切换用户角色与触点职责
- Project Index：关系 / 实践 / 档案模式
- Practice：六阶段方法切换并关联项目证据
- Contact：五步关系说明、验证、本地草稿及模拟提交

## 无障碍

- 主要交互均支持键盘 Enter / Space
- 状态不只通过颜色表达
- 支持 `prefers-reduced-motion`
- 保留原生焦点、表单标签和状态说明

## 上线前需要替换

- 专业邮箱、LinkedIn 与 CV
- Contact 表单后端与隐私政策
