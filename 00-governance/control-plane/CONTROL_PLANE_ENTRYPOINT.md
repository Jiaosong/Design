# OLEANDER Control Plane Entrypoint

For executable project-control checks, use:

```bash
python 00-governance/control-plane/control_plane.py check <project-control-card.json>
```

This entrypoint is subordinate to current governance and compiles existing rules into execution. It does not redefine Knowledge Architecture, Application Mapping, Project Axis, Case Axis, delivery priority, evidence levels, Artifact Review, Post-Generation Review, PAP, Rights, Reality, Engineering, Human Test or project-specific contracts.

It also compiles the global default `NO COMPRESSION / NO LOSS / RESTRUCTURE WITHOUT INFORMATION LOSS` policy into the existing Control Card. For `problem_layer=Architecture`, a `preservation_review` is required. Existing objects must be explicitly accounted for through separate `concept_state / presentation_state / truth_evidence_state` plus an action and reason. Compression, page count, cleaner presentation, shorter Web/film, less text or minimalism cannot be the sole reason for DEMOTE/CUT. The schema forbids applying any fixed global chapter count; C04's 12-layer architecture remains C04-specific.

A PASS means only that the supplied card is structurally valid, no current namespace collision was detected, the gate profile was resolved, CB-01 did not block continuation, and any Architecture-layer preservation contract satisfied the machine no-loss checks. It is not a design-quality, evidence, physical, rights, engineering, human-test, promotion or release approval.
