## 1｜Why this process exists

Interior design is not decoration applied after architecture, and it is not proven by a polished render, material board or FF&E list. It coordinates human activity, spatial sequence, enclosure, finishes, fittings, furniture/equipment, lighting/acoustic intent, building-services interfaces, safety/accessibility, procurement, mockups, construction administration, handover and in-use performance.

Canonical chain:

```text
STRATEGIC / APPOINTMENT BASIS
→ USER / OPERATION / INTERIOR BRIEF
→ CONCEPT + EXPERIENCE / MATERIAL DIRECTION
→ SPATIAL COORDINATION + ROOM / FF&E SYSTEM
→ TECHNICAL INTERIOR DESIGN
→ PROCUREMENT / PRODUCTION / SUBMITTALS
→ CONSTRUCTION ADMINISTRATION + MOCKUP / INSTALLATION READBACK
→ HANDOVER / SNAGGING / FF&E CLOSE
→ USE / POST-OCCUPANCY EVALUATION
```

Hard boundaries:

```text
BEAUTIFUL RENDER ≠ BUILDABLE INTERIOR
MATERIAL SAMPLE ≠ INSTALLED SYSTEM PERFORMANCE
PRODUCT DATASHEET ≠ ROOM / PROJECT COMPLIANCE
FF&E SELECTED ≠ PROCURED / DELIVERED / INSTALLED / WARRANTED
CLASH-FREE CEILING ≠ USABLE / MAINTAINABLE CEILING
INTERIOR PASS ≠ FIRE / ACCESSIBILITY / MEP / ELECTRICAL / STATUTORY PASS
MOCKUP APPROVED ≠ ALL INSTALLED WORK CONFORMS
HANDOVER ≠ POST-OCCUPANCY PERFORMANCE
INTERIOR PROCESS PASS ≠ DESIGN KEEP
```

## 3｜Trigger

Trigger the Interior Design process when the project makes material claims about:

- interior spatial experience, hierarchy, sequence, privacy or supervision;
- room planning beyond architectural gross programme;
- interior partitions, ceilings, floors, wall systems or finish build-ups;
- fixed joinery, casework or custom interior elements;
- FF&E selection, specification, sourcing or procurement responsibility;
- product/equipment interfaces affecting human use;
- reflected ceiling, lighting, acoustics, controls or service-terminal integration;
- interior accessibility / inclusive-use interfaces;
- fire/life-safety material, compartment, door, lining or egress interfaces;
- material health / emissions / durability / cleaning / hygiene claims;
- interior mockups / samples / prototypes;
- specialist fabrication / shop drawings / submittals;
- construction contract administration, site review, snagging or handover;
- interior post-occupancy performance.

Do not trigger a completed professional claim merely because a render, moodboard or furniture list exists.

## 5｜Cross-cutting Interior control objects

### 5.1 Interior Design Brief / User–Activity–Experience Matrix

Record actors, activities, temporal states, privacy/supervision, storage, furniture/equipment, human clearances, sensory targets, maintainability and operational states.

### 5.2 Interior Responsibility / Schedule of Services

Allocate responsibility for architecture/interior boundaries, partitions, ceilings, finishes, joinery, FF&E, decorative/specialist lighting, acoustics, signage/graphics where assigned, equipment, accessibility, fire interfaces, MEP terminals/controls, product sourcing, procurement, contract administration, mockups, snagging and handover.

### 5.3 Room / FF&E / Product Interface Register

Track `ROOM → ACTIVITY → BODY/CLEARANCE → FF&E/EQUIPMENT → SERVICES → LIGHT/ACOUSTIC → FIRE/ACCESS → MATERIAL/FINISH → MAINTENANCE/REPLACEMENT → STATUS`.

### 5.4 Material / Finish / Sample Register

For each material/system preserve identity, location, build-up, substrate, finish, edge/joint, slip/cleaning/wear/health/fire/wet-use constraints as applicable, sample/mockup state, source/version and change trigger.

### 5.5 Procurement / Commercial Role Register

BIID guidance distinguishes design/specification from sourcing/supplying/procurement responsibilities. Record whether the designer acts as adviser/agent/principal or does not procure; record fee/discount/rebate/conflict disclosures and warranties/returns/delivery risks according to actual contract and law.

### 5.6 Mockup / Sample / Benchmark Register

Critical room, joinery, finish, lighting, acoustic, accessibility or interface claims may require physical samples, prototypes or 1:1 mockups. Record exact scope, approved benchmark and what the sample does **not** prove.

---

### 5.7 Reflected Ceiling / Service Coordination Register

Track by room/zone:
`CEILING TYPE / HEIGHT / DATUM → GRID / PANEL / BAFFLE LOGIC → LIGHTING → SPRINKLER / DETECTOR / DIFFUSER / GRILLE / SPEAKER / SENSOR / ACCESS PANEL → SWITCHING / CONTROL ZONE → MAINTENANCE ACCESS → COORDINATION STATUS`.

A visually clean RCP is not coordinated if service terminals, access or controls are unresolved.

### 5.8 Door / Opening / Hardware Coordination Register

Track:
`DOOR/OPENING ID → PARTITION/WALL TYPE → SIZE/SWING → FIRE/SMOKE/ACOUSTIC REQUIREMENT → FRAME/GLAZING → HARDWARE SET → ACCESS CONTROL → CLEARANCE/ACCESSIBILITY → THRESHOLD → FINISH → POWER/LOW-VOLTAGE INTERFACE → STATUS`.

Interior may coordinate these objects only within its actual appointment; fire, accessibility, security and hardware specialist authority remain separate where applicable.

### 5.9 Finish / Substrate / Transition Register

Track:
`FINISH ID → LOCATION → SUBSTRATE/BUILD-UP → PREPARATION → ADHESIVE/FIXING → EDGE/JOINT/TRANSITION → WET/SLIP/CLEANING/WEAR/HEALTH/FIRE CONSTRAINTS → SAMPLE/MOCKUP → MAINTENANCE → SUBSTITUTION STATE`.

A finish schedule that names only color/product is incomplete for consequential construction use.

### 5.10 Joinery / Millwork Production Register

Track:
`JOINERY ID → USE/LOAD → PLAN/ELEVATION/SECTION → SUBSTRATE/CORE → FACE/EDGE → HARDWARE/FITTING → STRUCTURAL SUPPORT/ANCHORAGE → POWER/DATA/MEP → TOLERANCE/CLEARANCE → FABRICATION SUBMITTAL → SAMPLE/MOCKUP → INSTALL/ADJUSTMENT → SERVICE/REPLACEMENT`.

### 5.11 FF&E / Equipment Procurement and Logistics Register

Track:
`ITEM ID → ROOM/USE → DIMENSION/CLEARANCE → PERFORMANCE → FINISH/UPHOLSTERY → POWER/DATA/PLUMBING NEED → QUANTITY → SUPPLIER → LEAD TIME → APPROVAL → PURCHASE/CLIENT-SUPPLIED STATUS → DELIVERY/STORAGE → INSTALL → WARRANTY/SPARE/REPLACEMENT`.

Selected is not ordered; ordered is not delivered; delivered is not installed; installed is not accepted.

### 5.12 Submittal / Sample / Mockup / Substitution Release Register

For every consequential submittal:
`SUBMITTAL ID → GOVERNING DRAWING/SPEC/SCHEDULE → WHAT IS BEING VERIFIED → SOURCE/PRODUCT IDENTITY → DEVIATIONS → AFFECTED INTERFACES → SAMPLE/MOCKUP REQUIRED → REVIEW DISPOSITION → RELEASE/REVISE/REJECT → UPDATED CURRENT REFERENCES`.

A submittal review must not silently redesign outside the reviewer's authority.

### 5.13 Interior QA/QC Matrix

Before issue:
- plan ↔ RCP ↔ elevation ↔ section ↔ detail consistency;
- room/finish/door/hardware/FF&E schedules ↔ drawing tags;
- dimensions ↔ clearances ↔ furniture/equipment;
- partition/door/ceiling ↔ fire/acoustic/accessibility requirements;
- lighting/MEP devices ↔ coordinated ceiling/wall locations;
- joinery ↔ services/structure/maintenance;
- wet-area finishes ↔ waterproofing/drainage;
- material/product identity ↔ current evidence;
- revision cloud/change register ↔ affected sheets/schedules/specs.

### 5.14 Closeout / Asset / O&M Register

Track:
`OBJECT/SYSTEM → AS-BUILT/RECORD REF → WARRANTY → O&M/CARE → CLEANING → SPARES → KEY/ACCESS/CONTROL → TRAINING → DEFECT/PUNCH STATUS → ASSET TAG/DATA → OWNER/FM ACCEPTANCE → OPEN ITEM`.

## 6｜ID-PW0 — Strategic Definition

**Question:** What interior-design scope, value, reuse constraints and professional/commercial responsibilities materially affect the strategic decision?

Work includes high-level interior scope, retained/existing asset implications, operational constraints, procurement route implications, major specialist triggers and information gaps.

**Native outputs:** strategic interior constraints/opportunities note; survey/investigation need list; initial responsibility and procurement-role map.

**Does not prove:** concept quality, technical buildability, material compliance or procurement completion.

## 7｜ID-PW1 — Preparation and Briefing

**Question:** Is there a sufficiently complete interior brief and appointment boundary to begin concept work without inventing user, operational or procurement assumptions?

Develop:
- user/activity/experience brief;
- room-level performance/operation requirements;
- current existing-condition/survey needs;
- Interior Responsibility / Schedule of Services;
- project material/product evidence requirements;
- FF&E/procurement-role boundary;
- mockup/sample strategy;
- accessibility/fire/MEP/lighting/acoustic interface requirements.

**Native outputs:** Interior Design Brief; User–Activity–Experience Matrix; responsibility matrix; survey register; initial room/FF&E interface register; procurement role statement.

**Does not prove:** selected concept, detailed room layout, material/system performance or procurement authority beyond appointment.

## 8｜ID-PW2 — Concept Design

**Question:** Which interior concept credibly resolves user activity, spatial character, material logic and cross-professional constraints?

Concept work must compare controlled alternatives for:
- spatial sequence/hierarchy;
- partitions/openings/transparency/privacy;
- furniture/equipment organization;
- material/colour/light/acoustic direction;
- ceiling/lighting/services integration concept;
- fixed joinery strategy;
- accessibility/fire/maintenance consequences;
- cost/procurement/lead-time implications;
- retained/reused material or furniture where applicable.

**Native outputs:** concept plans/sections; experience/sequence diagrams; material/finish concept; FF&E concept; reflected-ceiling/service intent; concept sample palette; option comparison/decision record.

**Does not prove:** technical construction, final product selection, fire/accessibility compliance, acoustic/lighting performance or installed finish.

## 9｜ID-PW3 — Spatial Coordination

**Question:** Are room geometry, furniture/equipment, ceiling/service zones, interfaces and human-use clearances coordinated enough for other disciplines to rely on the interior spatial state?

Coordinate:
- room dimensions and clear zones;
- partitions/doors/reveals/thresholds;
- furniture/equipment and service connections;
- ceilings, access panels, terminals, sprinklers/detectors and lighting;
- wet-area build-ups and drainage/waterproofing interfaces;
- storage, cleaning and maintenance routes;
- acoustic separations;
- accessibility manoeuvre/transfer/approach zones;
- fire/life-safety boundaries;
- structural supports/openings for interior elements;
- joinery/equipment installation/replacement paths.

**Native outputs:** coordinated interior plans/sections/elevations/RCP; room data; FF&E/equipment layouts; door/opening/hardware coordination; ceiling/service coordination register; interface details/register; updated finish/sample/material schedules; preliminary joinery/equipment production zones.

**Required coordination readback:** plan/RCP/elevation/section must describe one room geometry; ceiling heights and service devices must agree; doors/furniture/equipment must retain use and maintenance clearances; joinery/equipment installation/replacement path must be visible.

**Exit:** in-claim MAJOR/CRITICAL interior interfaces meet required Integration maturity.

**Does not prove:** final detailing, fabrication information, procurement/delivery or field installation.

## 10｜ID-PW4 — Technical Design

**Question:** Is the interior design technically resolved at the declared responsibility boundary so specialists, suppliers and construction can produce the intended interior without hidden interface assumptions?

Develop:
- technical plans/sections/elevations/RCP;
- partition/lining/ceiling/floor/wet-area build-ups;
- doors/ironmongery interfaces where assigned;
- joinery/fixed furniture details;
- finish schedules and transition/joint/edge details;
- FF&E/equipment specifications;
- lighting/control/acoustic interface details where assigned;
- accessibility/fire/MEP/product compliance interfaces;
- maintenance/replacement access;
- sample/mockup specifications;
- specialist/fabricator performance requirements;
- procurement packages and long-lead decisions where in scope.

**Native outputs:** technical interior drawing/model set; room/finish/door/joinery/FF&E schedules as applicable; specifications; product/interface register; compliance evidence refs; mockup/sample requirements; technical review record.

### ID-PW4 practitioner release chains

#### RCP / ceiling-service release

`ROOM/ZONE → CEILING DATUM/TYPE → LIGHTING + FIRE + HVAC + AV + SENSOR + ACCESS DEVICES → CONTROL/SWITCHING → ACCESS/MAINTENANCE → TAG/SCHEDULE → CONSULTANT COORDINATION → RELEASE`.

Release requires:
- no unexplained device overlap;
- access panels and serviceable equipment remain reachable;
- ceiling heights/transitions match sections/elevations;
- fixture/device tags resolve to current schedule/specification;
- reflected plans and consultant drawings are reconciled at the current interface maturity.

#### Joinery / millwork release

`DESIGN INTENT → DIMENSIONED PLAN/ELEVATION/SECTION → MATERIAL/CORE/EDGE → HARDWARE → SUPPORT/ANCHORAGE → SERVICE PENETRATION → TOLERANCE → FABRICATION REQUIREMENT → SHOP-DRAWING REVIEW BASIS`.

A hero elevation cannot substitute for fabrication-defining section/detail logic.

#### Door / hardware release

`DOOR TAG → DOOR/FRAME/GLAZING → RATING/ACOUSTIC → HARDWARE SET → ACCESS CONTROL/POWER → CLEARANCE → THRESHOLD/FINISH → SCHEDULE/SPEC → CONSULTANT/AHJ INTERFACE`.

#### Finish release

`FINISH TAG → SUBSTRATE/BUILD-UP → EDGE/JOINT/TRANSITION → INSTALLATION REQUIREMENT → SAMPLE/MOCKUP → PERFORMANCE EVIDENCE → MAINTENANCE → SCHEDULE/SPEC`.

#### FF&E / equipment release

`ITEM TAG → ROOM/USE/CLEARANCE → PERFORMANCE → SERVICES → QUANTITY → PROCUREMENT ROLE → LEAD TIME → DELIVERY/INSTALLATION → WARRANTY/REPLACEMENT`.

**Hard REVISE:** visual intent conflicts with code/fire/accessibility/MEP; unbuildable joints; inaccessible equipment; unresolved RCP/device collision; missing door/hardware/finish schedule coordination; product selection lacks required evidence; schedule/model/drawing contradiction; material sample substituted without reopen.

**Does not prove:** shop/fabrication completeness, delivered product identity, installation conformity or statutory approval.

## 11｜ID-PW5 — Manufacturing and Construction / Procurement / Administration

**Question:** Do specialist production information, procured products and installed work preserve the approved interior intent and professional requirements?

Work includes, as appointed:
- shop/fabrication/submittal review;
- samples and 1:1 mockups;
- procurement/sourcing administration;
- product substitution review;
- site/design queries and change control;
- construction-contract administration where appointed;
- inspection/site review within actual scope;
- coordination of joinery, finishes, FF&E, lighting/MEP terminals and specialist systems;
- defect/nonconformity review;
- delivery/storage/protection/installation sequencing issues.

**Native outputs:** submittal/sample/mockup register; approved benchmark refs; procurement status; site-review records; change/nonconformity decisions; updated drawings/schedules; installation evidence where observed.

### ID-PW5 submittal / substitution release rule

For each consequential submittal or substitution:

`GOVERNING CURRENT → PROPOSED PRODUCT/FABRICATION → DECLARED DEVIATIONS → DESIGN ROLE/PERFORMANCE → INTERFACE IMPACT → SAMPLE/MOCKUP → PROFESSIONAL/SPECIALIST DISPOSITION → RELEASE STATE → CURRENT DOCUMENT UPDATE`.

Allowed review outcomes should remain explicit, for example `RELEASE / RELEASE_WITH_LISTED_CORRECTIONS / REVISE_RESUBMIT / REJECT / HOLD`, subordinate to the actual contract/appointment vocabulary.

“Similar appearance” does not establish equivalent fire, acoustic, accessibility, durability, cleaning, fit, warranty, lead-time or maintenance performance.

### ID-PW5 site-observation boundary

A field note records:
`DATE/TIME → LOCATION → OBSERVED SCOPE → REFERENCE CURRENT → OBSERVED CONDITION → VARIANCE → RESPONSIBLE PARTY → DISPOSITION/NEXT ACTION`.

One observed room/item does not prove all identical work.

A site observation only proves the observed scope/time/location.

**Does not prove:** universal workmanship, concealed conditions, all delivered items or unobserved installation conformity.

## 12｜ID-PW6 — Handover

**Question:** Is the interior delivered with defects, FF&E/product status, maintenance information and unresolved items visible enough for responsible handover?

Work includes snagging/defects according to appointment, FF&E/product reconciliation, warranties/asset information where assigned, care/cleaning/maintenance information, sample/finish benchmark retention, replacement/spares information and unresolved-item transfer.

**Native outputs:** interior handover/snagging record; current FF&E/finish/product schedules; warranty/O&M refs; outstanding-items register; record information according to responsibility; asset/serial/tag data where in scope; spare/attic-stock/key/control/training status where applicable.

**Closeout readback:** compare issued/current intent → installed/record condition → punch/defect → warranty/O&M/maintenance → owner/FM responsibility. Handover remains HOLD where a material installed object cannot be identified, operated, maintained, replaced or linked to its governing record within the appointed claim.

**Does not prove:** future material performance, absence of latent defects or user satisfaction.

## 13｜ID-PW7 — Use / Post-Occupancy Evaluation

**Question:** What does actual use reveal about interior usability, comfort, durability, maintenance, material ageing and operational fit?

Evaluate, where in scope:
- actual room/furniture use and crowding;
- accessibility/inclusive-use failures;
- lighting/acoustic/thermal/service interaction complaints;
- finish wear, staining, slip, cleaning and maintenance;
- furniture/joinery failure;
- storage and equipment-fit problems;
- operational changes and adaptations;
- user/FM feedback;
- designed-vs-used spatial states.

**Native outputs:** POE/in-use interior review; defect/wear/maintenance evidence; corrective-action register; bounded G9 lesson candidates.

Each use-stage assessment closes only its observation scope/time.

**Does not prove:** universal user preference, indefinite future performance or transferable design rules without Knowledge validation.

## 19｜Adversarial failure attacks

Reject or HOLD when any applicable condition occurs:

1. RCP is visually tidy but consultant devices/access panels are missing or collided.
2. Ceiling device positions exist but fixture/control tags do not resolve to a current schedule/spec.
3. Millwork is shown only in elevation/render with no section, substrate, support, hardware, service or tolerance logic.
4. Door schedule, plan swing, hardware/access-control requirement and clearance disagree.
5. Finish schedule names a product/color but omits substrate, transition, wet/slip/fire/cleaning requirements material to the claim.
6. FF&E “selected” is treated as procured/delivered/installed/accepted.
7. Long-lead or custom item lacks procurement/logistics consequence.
8. Product datasheet is treated as room/system compliance.
9. Mockup/sample approval is generalized to all installed work.
10. Shop drawing review silently redesigns beyond reviewer authority.
11. Substitution is accepted on visual similarity without performance/interface review.
12. Site observation generalizes one observed location to universal conformity.
13. Field variance is fixed in the field but not propagated to current drawings/schedules/specs.
14. Punch closeout is declared while material O&M/warranty/asset/open items remain unresolved.
15. Render/material board is used as technical Interior PASS.
16. Interior PASS is used as fire/accessibility/MEP/acoustic/statutory PASS.
17. Schedule/model/detail contradictions are hidden by presentation output.
18. Maintenance/replacement access is lost even though geometry “fits.”
19. A new material/interface change leaves prior review current without impact analysis.
