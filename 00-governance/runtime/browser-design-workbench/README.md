# OLEANDER Browser Design Workbench v0.1

Status: CANDIDATE SHARED_REPO_RUNTIME
Parent: OLEANDER Cloud-Free Project Profile v1.0
Role: browser-native execution surface; not a new METHOD, Skill, Gate, or Design Authority.

## Purpose
Provide a reusable, no-local-install, no-paid-dependency browser workbench that any OLEANDER conversation can copy into a project and edit through GitHub. It exists to reduce dependence on limited free SaaS files such as Figma Starter team files.

## Execution surface
`SHARED_REPO_RUNTIME` by default. When the active conversation exposes GitHub write capability, source mutation is `AGENT_EXECUTABLE`; actual browser visual readback remains required before any design verdict.

## What it covers
- Web/UI responsive frame production and readback staging.
- Editable SVG / graphic / packaging / POP composition staging.
- Data-viz / diagram SVG or HTML staging.
- Existing-image composition and non-destructive CSS treatment previews.
- Existing glTF/GLB / Three.js presentation shells when a project supplies the actual geometry.
- Desktop/tablet/mobile viewport checks, grid overlay, grayscale check, outline check, and zoom.

## What it does not cover
- New professional BIM/CAD geometry.
- Class-A / manufacturing CAD.
- High-end from-zero architectural CGI.
- Supplier prepress/RIP/physical proof.
- Engineering approval or field acceptance.

## Project use
1. Resolve Type Brief + Required Native Output.
2. Copy `workbench.html` into the project candidate folder or reference it as a runtime scaffold.
3. Replace only the `#design-root` content / linked project asset source.
4. Keep project Source Authority outside this runtime.
5. Open actual page at required viewport sizes.
6. Run Evidence Gate + independent Design Quality Gate.
7. Persist only material project delta; do not fork this runtime per project unless runtime behavior itself changes.

## SaaS boundary
Figma / Penpot / Photopea / SketchUp Web may remain optional adapters. None is required for Current project continuity. Figma Starter team-space file limits make it unsuitable as the global OLEANDER Current design store; Drafts are not used as cross-conversation authority.

## Core rule
`SHARED WORKBENCH EXISTS ≠ PROJECT DESIGN PASS`.
