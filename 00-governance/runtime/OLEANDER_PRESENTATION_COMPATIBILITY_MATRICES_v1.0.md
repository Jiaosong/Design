# OLEANDER Presentation Compatibility Matrices v1.0

Status: **DRAFT GOVERNANCE EXTENSION / PRIORITY P10**. Binds the existing `OLEANDER_PROJECT_PRESENTATION_LAYER_v1.0` and `OLEANDER_PRESENTATION_STYLE_TECHNIQUE_SYSTEM_v1.0`. It does not create a house style, does not override Project/Knowledge truth, and does not make aesthetics machine-approvable.

## 1. Purpose

The existing Presentation Style & Technique System defines observable Style axes, 14 candidate Style Profiles and bounded technique IDs. This contract answers three practical questions:

1. **Which technique families are normally compatible with each Style Profile?**
2. **How must a Style Profile adapt to different media/read conditions?**
3. **How much truth-risk does each presentation transformation introduce when it touches evidence/source-bound material?**

Core rule:

`STYLE × TECHNIQUE × MEDIUM × SOURCE TRUTH → PRESENTATION PROJECTION → TARGET-CONDITION READBACK`.

No compatible style/technique combination can raise upstream claim/evidence/design/field/professional ceilings.

## 2. Matrix codes

Use:

- `PREFERRED (P)` — normally aligned with the style/medium problem and low translation cost;
- `ALLOWED (A)` — compatible when it answers a real communication problem;
- `CONDITIONAL (C)` — requires explicit reason, source/evidence boundary, or extra readback;
- `AVOID (V)` — usually weak/conflicting; use only with strong project-specific justification;
- `FORBIDDEN (F)` — violates a hard truth/accessibility/authority condition for the stated use.

These codes are **routing priors**, not aesthetic scores. Actual target-condition readback still decides quality.

### Family routing rules

- `PREFERRED` never means mandatory. Use minimum sufficient techniques.
- `AVOID` may become legal if the current Decision Question explicitly requires it and readback proves improvement.
- For S01/S04/S12, `DIAG` cannot be stylized into decorative abstraction that weakens exact relations.
- For S06/S13/S14, any evidence-bearing source must remain separately recoverable from atmospheric/synthetic layers.
- For S10, low density is legal only when truthful content is genuinely sparse; do not delete required proof to preserve “minimalism”.

## 7. Medium-specific mandatory adaptations

### BOARD
Must pass:
- far read: primary subject/claim recognizable;
- mid read: argument sequence and major evidence relations;
- near read: captions/sources/technical details;
- no required critical meaning only at near-read scale;
- authoritative plan/map/model geometry not distorted to fit layout.

### LIVE_DECK
Must define:
`AUDIENCE QUESTION → PRIMARY CLAIM/DECISION → PRIMARY PROOF → SPOKEN CONTEXT → NEXT STEP`.

Rules:
- live-reading density differs from report density;
- full narration should not compete with visual proof unless explicitly reading-first;
- support/appendix preserves depth without cluttering essential path;
- static export must remain semantically understandable when progressive reveal is used.

### READING_PDF_REPORT
Must preserve:
- reading order;
- continuous text measure;
- figure/source proximity;
- cross-reference integrity;
- full-page + reading-scale + detail-scale readback;
- printable/static truth independent of hover/motion.

### EDITORIAL_PUBLICATION
Must test:
- full sequence/contact sheet;
- page/spread roles;
- section rhythm/pacing;
- single-page integrity;
- binding/trim/material production conditions;
- caption/folio/credit system.

### WEB_CASE_STUDY
Must test:
- semantic/visual reading order;
- responsive recomposition, not proportional shrink;
- source assets/crops at real breakpoints;
- keyboard/touch/accessibility as applicable;
- reduced-motion/static equivalent for essential content;
- no hover-only essential proof.

### MOBILE
Must prioritize:
- single-column/limited-width clarity;
- touch target and interaction affordance;
- role redistribution rather than scaled desktop;
- longest bilingual string stress;
- no dense atlas behavior unless progressive/filterable depth remains usable.

### DASHBOARD
Must prioritize:
- current state/action/evidence over atmosphere;
- semantic/data encoding with redundant critical-state channels;
- filter/state provenance;
- timestamp/freshness/uncertainty visibility;
- stable comparison scales where comparison is intended.

### EXHIBITION
Must test:
- far/mid/near hierarchy;
- physical circulation and viewing angle;
- lighting/glare/material contrast;
- mounting/edge/maintenance/safety constraints;
- accessibility and alternate reading channel as applicable;
- local detail cannot rescue weak far-read identity.

### FILM_VIDEO
Must preserve:
- frame-level hierarchy at playback size;
- source/synthetic distinction;
- temporal/camera transformations that do not invent spatial continuity;
- readable duration for text/data;
- captions/audio alternatives when required;
- still-frame/source recovery for critical proof when necessary.

### VI_BRAND_MANUAL
Operational rules must be visibly represented:
- logo/master geometry;
- clearspace/influence bounds;
- minimum-size threshold specimen;
- actual color/type specimens;
- misuse examples where needed;
- effect-off/flat geometry authority for material effects;
- no invented dimensions merely for page completeness.

### TECHNICAL_REVIEW_SHEET
Must prioritize:
- exact IDs/revisions/configuration;
- unambiguous annotations;
- dimensions/units/tolerances where applicable;
- claim → requirement → evidence trace;
- source/condition/limitations;
- no atmospheric stylization that impairs verification.

## 8. Truth-risk classes

### E0 — SEMANTICALLY_NEUTRAL_OR_LOW_RISK
Layout/typography/navigation/relational operations that do not materially alter source evidence meaning when correctly used.

Typical:
`C01–C04/C06/C08–C13, P04/P06, T01–T08/T10, D04/D06/D07/D10–D12, M02/M07, X02–X09, F01/F03–F05/F07/F08`.

E0 still requires source fidelity and readback. A low-risk technique can be misused.

### E1 — BOUNDED_PRESENTATION_DERIVATIVE
Crop/mask/annotation/sequence/view transformation that can legitimately focus or clarify but changes what is immediately visible.

Typical:
`C05/C07/C14/C15, P01–P03/P05/P07/P08, I01/I03–I09/I11/I12, T09, D01–D03/D05/D08/D09, M01/M03/M05/M06/M08, X01, F02/F06`.

Requirements when source/evidence-bearing:
- preserve upstream source identity;
- record transformation;
- protect claim-bearing region;
- state omissions when material;
- maintain recovery path to source;
- target-condition readback.

### E2 — INTERPRETIVE_DERIVATIVE
Transformation creates a composite/interpretive relation not directly present in one source state.

Current explicit examples:
- `I10 COLLAGE_COMPOSITE`;
- `M04 MATCHED_MORPH`;
- `M09 LOOPING_AMBIENT_MOTION` when used as atmosphere/interpretation;
- any strong compositing, reconstruction, heavy retouch or abstracted synthesis that exceeds bounded E1 transformation.

Requirements:
- label as interpretive derivative;
- list constituent sources;
- do not use as sole empirical/technical/field proof;
- bind any factual claim to underlying E0/E1/source evidence;
- disclose what relation is interpretation rather than observation.

### E3 — SYNTHETIC_OR_SPECULATIVE
Generated/speculative content whose depicted state is not an observation of the project/source.

Examples:
- AI/generated scene;
- speculative future condition;
- invented atmospheric reconstruction;
- synthetic persona/participant output;
- unbuilt scene presented as possible future rather than Current design evidence.

Requirements:
- persistent `SYNTHETIC / SPECULATIVE / DOES_NOT_PROVE` status;
- cannot serve as field, empirical participant, installed-condition or technical proof;
- project/design authority must come from separate source objects;
- no crop/color/layout treatment may erase the disclosure.

## 9. Technique × Evidence-Risk Matrix

| Technique group | Default risk | Evidence-bearing use | Required protection |
|---|---|---|---|
| Dominance/grid/whitespace/layout | E0 | Allowed | must not hide mandatory caveat/source/negative evidence |
| Matched comparison | E0–E1 | Preferred | same scale/condition or disclose mismatch |
| Crop/mask/cutout/ghost | E1 | Conditional | source identity + protected region + omission boundary |
| Annotation overlay | E1 | Preferred for explanation | distinguish annotation from source pixels/data |
| Overview/detail/magnification | E1 | Preferred | preserve same-source/version relation |
| Documentary full-frame | E0 | Preferred | preserve context; ordinary color correction bounded |
| Tonal/monochrome unification | E1 | Conditional | cannot obscure material color/state if claim depends on it |
| Collage/composite | E2 | Support/interpretive | constituent sources + interpretation label; not sole proof |
| Diagram abstraction | E0–E1 | Allowed/Preferred | relation must be source-resolvable; no invented causality |
| Trade-off/causal flow | E1 | Conditional | distinguish observed dependency from inferred causation |
| Morph/spatial transform | E1–E2 | Conditional | cannot imply geometric/spatial continuity not present in source |
| Ambient/cinematic atmosphere | E2 | Support only for factual claims | no factual promotion; preserve separate proof layer |
| Interaction filter/toggle | E0 | Allowed | filter state/provenance visible; no selective hiding of contradictory data |
| Material finish/foil/emboss | E0 presentation risk | Allowed | finish cannot substitute for operational rule/content/evidence |
| Synthetic/generated image/scene | E3 | Forbidden as empirical proof | permanent disclosure + separate authoritative source |

## 10. Risk escalation overrides

Default technique risk is overridden upward when:

- a source-bearing image is materially retouched/reconstructed;
- crop removes contradictory/contextual information relevant to claim;
- color transformation changes a material/state claim;
- animation interpolates nonexistent intermediate geometry/state;
- diagram adds unsupported causal arrows or quantities;
- comparison uses unmatched scale/time/configuration without disclosure;
- generative fill changes source-bearing geometry/content;
- audience cannot recover whether a visual is observed, derived, modeled or synthetic.

Use the highest applicable risk class.

## 11. Evidence-native carrier priority

Choose primary presentation carrier by claim/task/evidence fit, not house style.

Examples:
- spatial exactness → plan/section/model/readback may outrank atmospheric render;
- trend/comparison → chart/matrix may outrank image;
- material tactile claim → actual sample/macro/source data may outrank generic render;
- user journey → observed route/behavior evidence may outrank decorative diagram;
- legal/specification claim → precise text/table/source locator may legitimately be first-read proof.

`BIG IMAGE ≠ DEFAULT PRIMARY CARRIER`.

## 12. Accessibility and semantic redundancy

Across all Styles:

- color cannot be sole carrier of critical meaning;
- motion cannot be sole carrier of critical meaning;
- essential information cannot require hover alone;
- reading/semantic order should remain coherent when visual order changes;
- reduced-motion/static alternative must preserve essential state where motion is used;
- text/background contrast and type size must follow the applicable medium/accessibility requirements rather than aesthetic profile;
- physical exhibitions must consider viewing distance, glare, reach and alternate access where relevant.

Accessibility requirement overrides Style preference.

## 13. Bilingual adaptation

Bilingual presentation is not “duplicate the second language at smaller size”.

For each View Unit resolve:
- semantic role pairing;
- hierarchy parity;
- line-break/length stress;
- CJK/Latin punctuation and numeral/unit behavior;
- whether one language is primary for the audience, without deleting required semantic parity;
- caption/source labels in both languages when the formal body requires them.

Use `T08 BILINGUAL_ROLE_PAIRING` or equivalent role logic, not literal typographic mirroring.

## 14. Style combination rules

Multiple Style Profiles may be combined only when roles are explicit.

Preferred pattern:

`BASE STYLE + LOCAL ROLE STYLE + MEDIUM ADAPTATION`.

Examples:
- S03 Civic base + S04 Atlas evidence section;
- S05 Hero Portfolio base + S01 Technical proof page;
- S09 Brand Expressive base + S12 Data analytical dashboard inset;
- S02 Editorial publication + S08 tactile material chapter.

Avoid:
- equal mixing of 3+ styles with no ownership;
- using S13 atmosphere to cover weak S01 technical evidence;
- using S10 minimalism to remove mandatory S04/S12 evidence;
- using S09 brand styling to recolor semantic data without preserving code/legend meaning.

## 15. Style consistency vs page-role variation

Consistency means shared grammar, not identical pages.

A presentation system may vary:
- density;
- dominant carrier;
- image scale;
- evidence visibility;
- pace;
- motion/interaction;
- page/surface role.

But should preserve the intended project grammar through a controlled subset of:
- alignment anchors;
- type roles;
- spacing rhythm;
- color semantics;
- source/caption logic;
- motif behavior;
- edge/crop grammar;
- navigation/ID system.

## 16. Target-condition readback matrix

| Medium | Mandatory readbacks |
|---|---|
| Board | far + mid + near + whole-frame |
| Live deck | full slide at playback size + sequence + static export |
| PDF report | full page + normal reading + detail + print/static |
| Publication | contact sheet + representative roles + page/spread + production proof |
| Web | target desktop + narrow/mobile + keyboard/touch states + reduced motion where applicable |
| Mobile | narrow viewport + longest strings + touch + scroll/reentry |
| Dashboard | default + high-risk states + filters + freshness/uncertainty + small-screen if supported |
| Exhibition | far/mid/near + route/view angle + material/light/glare + physical accessibility |
| Film | playback size + representative stills + text-duration + captions/audio path |
| VI manual | actual specimens + threshold/fail examples + print/digital target size |
| Technical sheet | full sheet + normal detail + critical dimension/source read |

## 17. Promotion / release gate

A presentation Style/Technique set may become `CURRENT_FOR_SCOPE` only when:

- audience/objective/medium are explicit;
- upstream source objects are Current enough for the intended claim;
- style axes are resolved enough to reproduce the grammar;
- technique set addresses named communication problems;
- E1/E2/E3 derivatives are disclosed correctly;
- accessibility/rights/production constraints are satisfied or bounded;
- actual target-condition readback passes applicable Visual/Project review;
- no technique hides contradiction, uncertainty or claim boundary;
- release claim ceiling does not exceed source claim ceiling.

## 18. Validator floor

- `PRES-COMP-001` style label alone cannot satisfy Style Profile;
- `PRES-COMP-002` Style×Technique matrix is routing guidance, not automatic quality approval;
- `PRES-MED-001` medium adaptation requirements override literal cross-media consistency;
- `PRES-MED-002` desktop/print composition cannot be merely scaled into mobile/other medium when roles materially change;
- `TRUTH-001` every material derivative has E0–E3 truth-risk class;
- `TRUTH-002` E1 source-bearing derivative preserves source identity/transformation/omission boundary;
- `TRUTH-003` E2 interpretive derivative cannot be sole empirical/technical/field proof;
- `TRUTH-004` E3 synthetic/speculative cannot serve as empirical participant/field/installed proof;
- `TRUTH-005` risk escalation applies when technique materially changes claim-bearing context;
- `A11Y-001` Style cannot override critical semantic redundancy/accessibility requirement;
- `BIL-001` bilingual role pairing cannot demote required semantic parity;
- `READ-001` Technique KEEP requires target-condition readback;
- `READ-002` motion/interaction essential meaning requires static/reduced-motion equivalent where applicable;
- `REL-001` Presentation release cannot exceed upstream source claim ceiling;
- `STYLE-001` multiple styles require explicit base/local-role ownership;
- `STYLE-002` finish/atmosphere cannot compensate for missing evidence or information hierarchy.

## 19. P10 closure condition

P10 is sufficiently refined for draft review when Style×Technique, Style×Medium and Technique×Evidence-Risk matrices are explicit; accessibility/bilingual/static/physical adaptation rules are bound; and presentation release requires actual target-condition readback without modifying upstream truth authority.
