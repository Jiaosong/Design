# Session Kernel v0.2 Practical Trial

The trial tests visible co-design behavior and runtime safety. A loadable Skill that only explains governance is not enough.

## Minimum real round

1. Resolve a bounded real decision object.
2. Produce 2+ materially distinct editable/native alternatives when the question is open.
3. Inspect actual artifacts and repair observable non-value defects.
4. Show mechanism difference, strongest benefit/risk and sensitive unknown.
5. Obtain actual option/object-referenced Human steering.
6. Make a second-round editable/native delta from that steer.
7. Read the second round back.
8. Keep session/design/professional/review/persistence/promotion states separate.

## Kernel regressions

- generic `继续` never becomes `DEFER/SELECT`;
- `只读继续` is `RESUME + READ_ONLY`;
- auto-advance stops at a real Human value choice;
- affective rejection yields hypotheses, not durable taste;
- ambiguous `就按这个` asks one referent question;
- unambiguous `就按这个` may bind to the one active object;
- MIX requires two parents;
- explicit DEFER requires a pending decision;
- second-round claim fails without actual steer or actual readback;
- stale authority/checkpoint blocks authority-sensitive mutation;
- presentation recency never replaces native authority;
- missing native surface may allow bounded truthful prototype but blocks native-completion claim;
- multi-Human conflict follows scoped rights;
- OPEN professional process cannot award professional PASS;
- uninstalling the plugin does not remove project state/checkpoint/native authority.

## Cross-domain

Run spatial, digital/HCD and physical-product work through the same interaction kernel while preserving distinct process/native/readback contracts. If one domain's professional process is genuinely OPEN, the trial must show that OPEN state rather than invent a universal process.
