# Human–AI Co-Design Model v0.2

This is the visible operating model for the Session Kernel. It is not a new authority/state/professional-stage/persistence layer.

## One architecture, three views

`HUMAN ↔ SESSION KERNEL ↔ AI`

read through:

1. **Co-Design Experience** — framing, exploration, critique, steering, designer development;
2. **Professional & Making** — authentic professional process, editable/native making, simulation/readback;
3. **Governance & Continuity** — authority, Project State, evidence, continuation, permissions, review, persistence and Promotion.

The three views project the same OLEANDER Current architecture. They do not create parallel state or authority.

## Two coupled kernels

Design: `UNDERSTAND → EXPLORE → MAKE → LOOK → CRITIQUE → STEER → LEARN`.

Runtime: `RESOLVE → RESUME → ROUTE → GUARD → HANDOFF → REPORT`.

The first is what the user experiences. The second protects truth/continuity.

## Option graph

Alternatives are branches, not cards with different styling. A comparable option records a mechanism signature, parent refs, artifact refs, locked invariants, strongest benefit/risk and sensitive unknowns under one comparison world.

Cosmetic duplicates do not count. Preserve rejected/deferred branches. MIX preserves both/all parents. Baseline/no-change/OFF is a valid branch when causally meaningful.

## Human action levels

`FEEDBACK_SIGNAL ≠ ITERATION_STEER ≠ DESIGN_DECISION ≠ DESIGN_KEEP ≠ PROMOTION_DECISION`.

Explicit `DESIGN_DECISION / DESIGN_KEEP / PROMOTION_DECISION` statements are preserved and routed to existing OLEANDER authorities. They are not applied as iteration steering and do not grant this Session Kernel project/review/promotion authority.

Only actual `SELECT / MODIFY / MIX / REJECT / REOPEN / DEFER` bound to the current decision object may control the next design round. Generic continuation is not steering. Affective feedback creates hypotheses, not permanent taste.

## Learning

Track separately:

- artifact learning;
- designer learning;
- system-evolution evidence.

Designer learning may alter explanatory support, not authority. Only system-evolution evidence may enter existing G9/Evolution governance.
