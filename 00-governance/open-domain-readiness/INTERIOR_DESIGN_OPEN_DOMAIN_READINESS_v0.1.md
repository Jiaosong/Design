# OLEANDER Interior Design — OPEN Domain Readiness v0.1

**Status:** `DOMAIN PROCESS OPEN / PROFESSIONAL SCOPE VERIFIED / NO CANDIDATE PROCESS YET / NO PROJECT EXERCISE / NO PROMOTION`

**Domain:** Interior Design

**Authority position:** subordinate to OLEANDER Current Architecture Map, Professional Domain Process Contract, Cross-Disciplinary Integration, Architecture / MEP / Structural / Fire-Life-Safety / Accessibility / Acoustics / Procurement authorities, and the responsible Interior Design professional when appointed.

**Purpose:** define the minimum professional execution-depth floor that a future Interior Design R-E process must satisfy before OLEANDER may claim an authentic Interior professional process.

This is deliberately **not** a Candidate process. Current repository evidence does not contain a qualifying Interior project exercise with RCP, finishes, joinery/millwork, FF&E, hardware/acoustic coordination and construction-stage readback.

---

## 1｜Why this readiness dossier exists

Current OLEANDER already contains:
- Architecture professional development;
- MEP professional development;
- Structural professional development;
- Design Process;
- visual / web / 3D / artifact execution;
- spatial-experience project work.

But current repository search found no project case with an authoritative Interior professional artifact chain such as:

- reflected ceiling plan;
- finish plan / finish schedule;
- partition / wall type package;
- millwork / joinery / casework drawings;
- FF&E schedule / procurement logic;
- interior elevations;
- door / hardware coordination;
- room data sheets;
- acoustic treatment coordination;
- interior life-safety / accessibility documentation;
- construction submittal / mockup / closeout readback.

Therefore:

`SPATIAL DESIGN PROJECT ≠ INTERIOR PROFESSIONAL PROJECT EXERCISE`.

A future Candidate process must not be created merely because a project contains “indoor space”.

## 3｜Professional trigger

A future Interior Design process is materially triggered when a project claims professional resolution of one or more:

- interior programming / occupancy/use requirements;
- interior space planning;
- interior partitions / room configuration;
- interior code / life-safety coordination;
- accessible interior routes, clearances and reach/use conditions;
- interior finish systems;
- FF&E specification / procurement;
- millwork / joinery / casework;
- interior doors / hardware coordination;
- reflected ceiling and ceiling-system coordination;
- interior lighting interface;
- interior acoustic treatment/interface;
- interior signage/wayfinding interface;
- interior equipment/appliance coordination;
- interior power/data/AV/device coordination;
- interior details/specifications/schedules;
- construction administration, submittal/mockup review and closeout.

Not triggered by:
- atmosphere render only;
- exhibition board showing rooms without technical claims;
- conceptual “spatial experience” with explicit exclusion of interior professional resolution;
- furniture/finish moodboard with no professional specification claim.

## 4｜Minimum continuous technical threads

Any future Candidate process must carry these threads continuously.

### IDT-01 Existing Conditions / Survey / Base Authority

Track:
- existing walls/columns/slabs/openings;
- ceiling heights/plenums;
- existing services;
- existing finishes;
- existing doors/hardware;
- hazardous material / demolition constraints;
- datum / field-measure state;
- landlord/base-building authority.

Rule:

`AS-BUILT DRAWING ≠ FIELD-VERIFIED EXISTING CONDITION`.

### IDT-02 Program / Occupancy / Use / Adjacency

Track:
- user groups;
- occupancy/use;
- room functions;
- capacities;
- equipment;
- privacy;
- security;
- adjacencies;
- operations;
- maintenance;
- future flexibility.

### IDT-03 Space Planning / Clearances / Accessibility

Track:
- circulation;
- door clearances;
- transfer/approach zones;
- furniture/equipment clearances;
- accessible routes;
- reach/use;
- turning;
- thresholds;
- pinch/conflict zones;

- fire ratings;

## 8｜Professional HOLD conditions

Future Interior professional PASS must HOLD when materially applicable and unresolved:

- existing conditions used as dimensional truth without authority;
- room/use capacity conflicts with code/life-safety/accessibility;
- space plan lacks required clearances;
- RCP conflicts with MEP/fire/lighting/service access;
- finish system lacks substrate/transition/performance relation;
- millwork lacks support/fixing/service/tolerance logic;
- FF&E lacks size/access/power/procurement relation;
- door/hardware conflicts with accessibility/fire/security;
- acoustic claim lacks system continuity/specialist evidence;
- material sample/moodboard is substituted for technical specification;
- product substitution changes performance without disposition;
- shop drawing is treated as designer-authored truth without review;
- render/elevation beauty is used as construction-document PASS;
- site observation is extrapolated beyond observed scope;
- installation completion is treated as closeout without defects/record/O&M/warranty evidence.

## 10｜Interface owner boundary

Interior Design may own or co-own design intent and documentation but must not absorb:

### Architecture
- shell/building architecture;
- primary envelope;
- building code authority where assigned elsewhere;
- major circulation/core/building systems.

### Structural
- structural capacity;
- anchorage/foundation beyond delegated detail scope.

### MEP
- HVAC/plumbing/electrical engineering;
- load/circuit/flow calculations;
- system performance.

### Fire/Life Safety
- formal fire strategy / statutory approval.

### Accessibility
- formal accessibility review/certification where separately appointed.

### Lighting
- professional photometric/controls/commissioning claims when separate Lighting owner exists.

### Acoustics
- acoustic engineering/testing beyond Interior scope.

### Security/AV/IT
- specialist systems.

### Procurement/Contractor
- means/methods;
- shop/fabrication responsibility;
- procurement authority.
