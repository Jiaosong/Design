## Full-resource sequential carrier gate

Use this gate when a reviewed/current source resource must remain complete but the carrier cannot show all supporting explanation, states or technical depth at once.

Core rule:

`FULL RESOURCE → BOUNDED FOCUS → SEQUENTIAL SUPPORT → RETURN TO FULL RESOURCE`

The solution is **not** a 2×2 card wall of crops and it is not a new mini-resource for every state. Preserve source identity first, then sequence the reading.

### 1. Resource identity lock

Before styling, record:

- `RESOURCE_ID`
- `RESOURCE_SOURCE / SOURCE_VERSION`
- `FULL_FRAME_ASPECT`
- `CROP_AUTHORITY`
- `REQUIRED_CONTEXT`
- `STATE_SET`
- `DOES_NOT_PROVE`

If Current Authority says `NO CROP`, use `contain` / full-frame presentation. If the complete source cannot remain legible in one viewport, use sequential full-frame presentation, carousel, step-through or page-by-page progression rather than shrinking several complete resources into equal cards.

### 2. State continuity

Across CLEAN / BODY / ASSEMBLY / SERVICE or equivalent states:

- the same source frame remains recoverable and identifiable;
- state changes may add bounded focus, veil, annotation, hotspot or peripheral reading rails;
- state changes may not replace the source with a crop that becomes the new primary resource;
- focus overlays must not alter authoritative geometry or hide required context;
- supporting detail may move outside the resource stage, but Technical Proof remains visible/readable when it is required by project authority.

### 3. No-compression rule

`NO COMPRESSION / NO LOSS` does not mean every state must appear simultaneously.

Allowed:
- sequential full-frame views;
- horizontal scroll-snap of complete frames;
- carousel with one complete resource visible at a time;
- bounded focus inside a persistent full-frame stage;
- progressive disclosure that preserves all information across the sequence.

Blocked:
- shrinking complete technical/resources until body text, nodes or dimensions become metadata;
- crop walls where each state removes different context;
- replacing the current source with an extracted detail while still calling it the same resource;
- using a new explanatory diagram merely because the original/current resource is dense;
- `cover` cropping where Current Authority requires complete-frame preservation.

### 4. Failure-seeking tests

Run all applicable tests on actual pixels:

1. `FULL-FRAME` — every state can recover the complete source without reloading a different source object.
2. `STATE-IDENTITY` — remove labels; the same resource remains identifiable across states.
3. `CROP-ATTACK` — intentionally crop to each focus; reject if crop changes the claim, loses context or creates a new apparent resource.
4. `COMPRESSION-ATTACK` — intentionally place all states in equal cards; reject if legibility/hierarchy collapses.
5. `RETURN-TO-WHOLE` — from any focused state, the user can return to the complete resource without ambiguity.
6. `SUPPORT-CONTINUITY` — information deferred from the first viewport is still present later in the sequence; nothing is silently deleted for simplicity.
7. `NATIVE-CARRIER` — review desktop/mobile/native target pixels; do not infer legibility from enlarged artboards.

### 5. Hard failures

`REVISE / REJECT` when any of the following occurs:

- the state switch replaces the complete resource with a crop or derivative and the user cannot recover the original frame;
- multiple crops are presented as if they were independent source objects;
- card-wall compression preserves artifact count but destroys design readability;
- a focus state becomes visually stronger than the source and turns Technical Proof/support into a second hero without decision need;
- a sequential presentation drops information rather than deferring it;
- a new vector/AI explanatory substitute is introduced while a current reviewed resource already carries the required information;
- one breakpoint uses `cover`/crop despite a no-crop authority requirement.

### 6. Review record

Record:

- `RESOURCE_ID`
- `CARRIER_TYPE`
- `FULL_FRAME_VISIBLE`
- `STATE_SET`
- `FOCUS_METHOD`
- `CROP_USED`
- `COMPRESSION_USED`
- `RETURN_TO_WHOLE`
- `SUPPORT_CONTINUITY`
- `NATIVE_READBACK`
- `DOES_NOT_PROVE`

Promotion test:

> Step through every state: the full source frame must remain recoverable and identifiable; focus may deepen reading but may not become a replacement crop.

## Image-processing operator routing
