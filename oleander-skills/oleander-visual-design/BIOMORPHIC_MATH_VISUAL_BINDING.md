## 1. Trigger

Use for visual systems described as biomorphic, organic, streamlined, cellular, skeletal, vascular, branching, shell-like, growth-driven, mathematically generated, Voronoi, reaction–diffusion, topology-inspired, minimal-surface-inspired, fractal-like, or bio-futurist.

## 2. Visual grammar sources

Translate mechanisms/relations rather than copying nature silhouettes:

- skeletal hierarchy → primary / secondary / terminal strokes or masses;
- growth gradient → controlled scale, density, spacing or thickness gradient;
- branching → hierarchy, direction and junction rules;
- segmentation → repeated modules with controlled differentiation;
- bilateral/radial/helical symmetry → transformation grammar;
- controlled asymmetry → directional focus, motion or functional exception;
- field direction → line/texture/orientation flow;
- cellular partition → region hierarchy and adjacency;
- tension/compression → visual stretch, contraction and mass distribution;
- surface differentiation → role-specific texture/material zones.

## 3. Streamlined visual language

A visual system may communicate speed/flow through:

- elongated proportion;
- continuous directional curves;
- controlled taper;
- curvature acceleration/deceleration;
- section/mass progression;
- directional whitespace;
- highlight/gradient flow when the medium supports it.

If no fluid-performance evidence exists, label the route `STREAMLINED VISUAL LANGUAGE`, not aerodynamic/hydrodynamic optimization.

## 4. Biomorphic visual boundary

A fish outline, leaf vein, shell spiral, bone lattice, cell/Voronoi pattern or skin texture may be a visual source.

It becomes a biomimicry claim only when the upstream Biomimicry method provides sourced function/mechanism abstraction and evaluation.

Use labels deliberately:

- `BIOMORPHIC VISUAL` — formal resemblance / nature-derived visual grammar;
- `BIO-INSPIRED` — source relationship stated but function not necessarily emulated;
- `BIOMIMETIC` — only with mechanism/function evidence.

## 5. Mathematical pattern boundary

Do not use mathematical vocabulary as decoration.

- Voronoi → spatial partition rule, not automatic cell biology;
- reaction–diffusion → pattern-generation model, not automatic biological mechanism;
- topology → connectivity/holes/global relation, not “complex geometry” synonym;
- symmetry/group → invariance/repetition rule, not generic balance;
- fractal/self-similar → scale relation only when actually present;
- golden ratio/Fibonacci → optional chosen proportion/generator only, never universal beauty proof.

## 6. Visual evaluation

Check the output without its explanatory label:

`REMOVE WORDS LIKE BIO / ORGANIC / MATH / STREAMLINED → DOES THE FORM SYSTEM STILL SHOW A COHERENT RELATION?`

Review:

- dominant mass and first read;
- hierarchy of primary/secondary/tertiary form;
- direction/tension;
- repetition versus variation;
- symmetry versus controlled asymmetry;
- local density and global breathing space;
- figure-ground and silhouette;
- material/texture role separation;
- whether the pattern is carrying structure or merely filling empty space.

## 7. Anti-patterns

Reject:

- generic Voronoi overlay as “biomimicry”;
- random curves as “organic”;
- mirrored blobs as “biological symmetry”;
- fake scientific diagrams used only to justify a chosen style;
- one golden spiral placed over a composition as proof of quality;
- topology-optimization render used as a visual texture without acknowledging its actual engineering context;
- equal-weight biological motifs with no hierarchy or functional/semantic role.

## 8. Required handoff

When the visual system derives from a biological/mathematical rule, retain:

- upstream rule/mechanism identity;
- visual variables actually translated;
- deliberate departures from the source rule;
- what is visual-only;
- what physical/biological claim remains HOLD;
- actual target-size visual readback.

`VISUAL COHERENCE ≠ BIOLOGICAL TRUTH ≠ MATHEMATICAL OPTIMUM ≠ PERFORMANCE PASS`.
