# Gate deepening

The existing Design Process Reference decomposition gate now requires:

## A. Source mechanism encoding

Record:
- source object/revision/source strength;
- problem/function solved;
- actors/objects/states;
- hierarchy/sequence/interaction;
- causal/functional mechanism;
- enabling conditions;
- failure/limitation;
- source-specific identity that must not transfer.

Carrier:

`SOURCE ELEMENT → SOURCE ROLE → RELATION / MECHANISM → CONSEQUENCE → CONDITION / LIMIT`.

## B. Independent target encoding

Record target:
- actor/object;
- need/function;
- context;
- relations;
- hard constraints;
- unknowns;
- authority;
- claim ceiling.

Critical rule:

`DO NOT REWRITE THE TARGET TO MAKE THE REFERENCE FIT`.

## C. Correspondence map

Record:

`mapping_id / source_relation / source_role / target_relation / target_role / correspondence_type / evidence_or_reason / required_mutation / mismatch / authority_boundary / test`.

Correspondence types:
- RELATIONAL;
- FUNCTIONAL;
- CAUSAL;
- BEHAVIORAL;
- ATTRIBUTIONAL_ONLY;
- NO_CORRESPONDENCE.

Attributional resemblance cannot stand in for a structural analogy claim.

## D. Mismatch ledger

State:
- MATCH;
- PARTIAL;
- NONE;
- CONFLICT.

Mandatory attacks:
1. surface-similarity trap;
2. source-condition loss;
3. authority leakage;
4. role inversion;
5. scale/regime shift;
6. interface mismatch;
7. state mismatch;
8. identity carryover.

`NO TARGET COUNTERPART → DO NOT FORCE A MAPPING`.

## E. Abstract strategy

When useful:

`ABSTRACT STRATEGY = FUNCTION / RELATION / MECHANISM / CONDITIONS / FAILURE BOUNDARY`.

Source-domain nouns and identity should be removed before cross-domain transfer.

## F. Project-native mutation

A project mutation must derive:
- content;
- geometry;
- sequence;
- material;
- interaction;
- carrier

from project Current authority rather than copying the source artifact.

## G. Matched artifact / readback

Full gate:

`REFERENCE → SOURCE MECHANISM → TARGET PROBLEM → CORRESPONDENCE MAP → MISMATCH LEDGER → PROJECT-NATIVE MUTATIONS → MATCHED ARTIFACTS → ACTUAL READBACK → KEEP / REVISE / REJECT / HOLD`.

Readback asks:
- can the design explain itself without naming/showing the reference?
- does the relation survive style removal?
- did source identity/rights/performance leak?
- did mismatch create a new evidence/professional requirement?
- is the artifact stronger for the target Decision Question rather than merely more reference-like?

# Failure regressions

Added to Design Process Golden corpus:

## SK-DES-029 — superficial similarity

Source and target share appearance but not actors/load/task/failure relations.

Required:
- separate ATTRIBUTIONAL_ONLY from relational/causal mapping;
- reject false analogy.

## SK-DES-030 — source-condition loss

Source success depends on staffing/connectivity/controlled environment absent in target.

Required:
- expose missing conditions;
- mutate or reject/hold.

## SK-DES-031 — authority leakage

Reference has tested structure/accessibility/user outcomes.

Required:
- mechanism may transfer;
- PASS states do not.

## SK-DES-032 — identity carryover

Copy changes words/colors but keeps branded/signature composition/geometry/icon/sequence.

Required:
- abstract mechanism;
- project-native mutation;
- reject reference-dependent identity.
