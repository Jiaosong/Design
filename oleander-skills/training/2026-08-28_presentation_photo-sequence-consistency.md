# PRESENTATION Practice Evidence — Photo Sequence Consistency

Status: PRACTICE_EVIDENCE / REAL-PHOTO SAME-SOURCE / NO PROJECT WRITE / NOT ACTIVE
Mode: TRAINING_MODE

## GAP
Same-project photo sequence consistency: individually polished frames can drift in exposure / color cast / tonal family and read like different projects. The opposite failure is literal identical treatment and equal visual mass, which flattens full / mid / detail roles.

## SOURCE
Professional calibration: Vitra official Lounge Chair product presentation. The same product identity is maintained across overview / inspiration, Details and Production imagery while image scale and informational role change.

Training source: one real, non-generated source photograph, source-locked across all full / mid / detail derivatives. No compositing, no generative fill.

## ARTIFACT
Editable HTML/CSS sequence study + real Chromium desktop/mobile readback + thumbnail / grayscale / contact sheet + tone readback.

## A/B
- A — each frame optimized independently with different exposure / color-cast decisions.
- B1 — one shared global grade, but all three frames receive equal visual mass.
- B2 — one shared tone/color family + only bounded local exposure compensation + role-specific image scale.

## READBACK
A visibly jumps between dark-neutral, bright-warm and dark-cool frames at contact-sheet distance. B1 is coherent but reads as three comparable alternatives. B2 gives the full view first-read ownership while mid/detail operate as supporting evidence; grayscale preserves the progression.

## FAILURE / ROOT CAUSE
Sequence consistency was first treated as per-image beauty, then as identical grading/equal sizing. Both ignore sequence role: the first causes family drift; the second causes semantic flattening.

## REPAIR / RETEST
Lock global tonal/color family first. Permit only small role-bound exposure corrections that do not alter material/site facts. Assign scale by full → mid → detail duty. Retest as contact sheet, desktop/mobile sequence and grayscale rather than approving frames individually.

## TRANSFER RULE
`LOCK SEQUENCE TONE FAMILY → ASSIGN IMAGE ROLE → ALLOW BOUNDED LOCAL EXPOSURE COMPENSATION → SCALE BY ROLE → RETEST CONTACT SHEET / GRAYSCALE`

`SEQUENCE CONSISTENCY ≠ IDENTICAL EDIT / EQUAL SIZE`
