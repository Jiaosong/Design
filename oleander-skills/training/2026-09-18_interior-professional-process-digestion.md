# Practitioner-depth additions

The historical candidate was not discarded.

The material additions are:

## 1. RCP / ceiling-service coordination

Explicit object chain:

`CEILING TYPE/HEIGHT/DATUM → LIGHTING → SPRINKLER/DETECTOR → DIFFUSER/GRILLE → AV/SPEAKER/SENSOR → ACCESS PANEL → SWITCHING/CONTROL → MAINTENANCE ACCESS → TAG/SCHEDULE → CONSULTANT COORDINATION`.

Aesthetic cleanliness is not coordination evidence.

## 2. Door / opening / hardware coordination

`DOOR ID → PARTITION/WALL → SIZE/SWING → FIRE/SMOKE/ACOUSTIC → FRAME/GLAZING → HARDWARE SET → ACCESS CONTROL → CLEARANCE → THRESHOLD → FINISH → POWER/LOW-VOLTAGE → STATUS`.

## 3. Finish / substrate / transition

`FINISH ID → LOCATION → SUBSTRATE/BUILD-UP → PREPARATION → FIXING/ADHESIVE → EDGE/JOINT/TRANSITION → PERFORMANCE → SAMPLE/MOCKUP → MAINTENANCE → SUBSTITUTION`.

Product/color-only finish schedules are insufficient for consequential technical use.

## 4. Joinery / millwork production

`JOINERY ID → USE/LOAD → PLAN/ELEVATION/SECTION → CORE/FACE/EDGE → HARDWARE → SUPPORT/ANCHORAGE → SERVICES → TOLERANCE → FABRICATION SUBMITTAL → INSTALL/ADJUSTMENT → SERVICE/REPLACEMENT`.

## 5. FF&E / equipment logistics

`ITEM → ROOM/USE → DIMENSION/CLEARANCE → PERFORMANCE → SERVICES → QUANTITY → SUPPLIER → LEAD TIME → APPROVAL → PURCHASE STATUS → DELIVERY/STORAGE → INSTALL → WARRANTY/REPLACEMENT`.

`SELECTED ≠ PROCURED ≠ DELIVERED ≠ INSTALLED ≠ ACCEPTED`.

## 6. Submittal / sample / mockup / substitution

`SUBMITTAL → GOVERNING CURRENT → PRODUCT/FABRICATION IDENTITY → DEVIATIONS → PERFORMANCE/INTERFACE IMPACT → SAMPLE/MOCKUP → DISPOSITION → RELEASE STATE → CURRENT UPDATE`.

“Looks similar” is not substitution equivalence.

## 7. QA/QC matrix

Before issue, reconcile:
- plan ↔ RCP ↔ elevation ↔ section ↔ detail;
- tags ↔ room/finish/door/hardware/FF&E/equipment schedules;
- dimensions ↔ clearances ↔ FF&E;
- fire/acoustic/accessibility ↔ partition/door/ceiling;
- lighting/MEP devices ↔ ceiling/wall geometry;
- joinery ↔ structure/services/maintenance;
- wet finishes ↔ waterproofing/drainage;
- product identity ↔ current evidence;
- change register ↔ affected documents.

## 8. Site observation

Every observation is bounded by:
`DATE/TIME → LOCATION → OBSERVED SCOPE → CURRENT REF → OBSERVED CONDITION → VARIANCE → OWNER → NEXT ACTION`.

No single site observation may become universal installed-work truth.

## 9. Closeout / asset / O&M

`OBJECT/SYSTEM → RECORD REF → WARRANTY → O&M/CARE → SPARES → KEY/CONTROL → TRAINING → PUNCH STATUS → ASSET/TAG → FM ACCEPTANCE → OPEN ITEM`.

Handover does not close if a material object cannot be identified, operated, maintained, replaced or traced to its governing record within the claim.
