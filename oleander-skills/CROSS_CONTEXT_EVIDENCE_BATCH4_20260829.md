## Transfer rules retained

### Content / Microcopy

`CLARITY / CONCISION` remains desirable, but when an action is destructive or materially consequential:

`CONSEQUENCE LEGIBILITY > FIXED LABEL LENGTH`.

This does not justify gratuitously long labels; it rejects a universal length cap when the cap would hide system truth.

### Packaging

Where distribution performance is material:

`STRUCTURAL CONCEPT → DISTRIBUTION HAZARD / TEST AUTHORITY → PHYSICAL TEST → FAILURE EVIDENCE → STRUCTURE REVISION → PRODUCTION HANDOFF`.

No test sequence/intensity, board specification or certification mark may be invented by the design extension.

### Physical signage

Where repeated route choices occur, use functional journey states when helpful:

`JOURNEY START → DECISION → CONFIRMATION → DESTINATION`.

These are sequencing roles, not a mandatory four-sign visual taxonomy.

### Data table

Add to the precision/unit/missingness discipline:

`COMPARABILITY STATE / METHOD STATE → WHETHER DIRECT COMPARISON IS LEGITIMATE`.

A well-formatted number may still be incomparable to another number.

### Editorial publication

For multi-document/change-heavy publications:

`PUBLICATION MANIFEST → DOCUMENT ORDER → STYLE SOURCE → NUMBERING / CROSS-REFERENCE AUTHORITY → DOCUMENTS → EXPORT`.

Synchronization or export success is not Design Quality, content truth or accessibility proof.
