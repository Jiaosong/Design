# OLEANDER Image Set Curation Extension

Status: `CANDIDATE EXTENSION / IMAGE-ART-DIRECTION`

Use when several real photographs, screenshots, scans or other source images compete for the same page/sequence roles and the problem is selection/cohesion before final crop/grade execution.

## Core principle

`SOURCE AUTHORITY → CANDIDATE SET → ROLE / CLAIM FIT → PLACEMENT FIT → CROSS-SET RELATION → KEEP / CUT REASONS → BOUNDED TREATMENT → SEQUENCE READBACK`.

A coherent image set is not created by forcing every source into the same visual condition. Selection must preserve evidence, source identity and the strongest project-specific relation.

## Candidate-set gate

Review candidates together at approximately their intended display roles rather than only as isolated full-size images.

For each candidate record:

- source/master identity and rights/authority state;
- intended slot/role;
- claim-bearing content and protected regions;
- native scale/aspect/crop tolerance;
- placement fit, including text/image conflict where relevant;
- source-native light/color/material conditions that must remain truthful;
- whether the image strengthens or weakens the sequence when adjacent to the other selected sources;
- KEEP / SUPPORT / CUT / HOLD decision with one concrete reason.

A cut list is evidence of selection reasoning, not proof that a rejected image is aesthetically bad in every context.

## Cohesion hierarchy

Use this priority order when trade-offs appear:

1. source/evidence truth;
2. project claim and semantic role;
3. placement/readability fit;
4. cross-set rhythm and continuity;
5. optional tonal/texture normalization.

Do not demote a uniquely necessary proof merely because its native lighting differs from atmosphere images. Instead change role, adjacency, crop, field treatment or surrounding layout when possible.

`COHESION ≠ SOURCE NORMALIZATION`.

## Bounded consistency variables

Potentially coordinate only the variables the sources safely share, such as:

- role and scale hierarchy;
- crop rhythm;
- negative-space behavior;
- edge/field treatment;
- contrast range where factual interpretation is not altered;
- sequence alternation among whole / mid / detail views;
- optional grain/texture treatment when it does not change evidence interpretation.

Do not impose one universal white balance, LUT, light key, camera angle or crop behavior when native conditions carry factual or narrative meaning.

## Stock/generic-image attack

When candidate imagery is sourced from general libraries or feels generic, diagnose the problem by relation rather than by a universal taste rule.

Check whether the candidate:

- depicts a literal cliché instead of the actual project relation;
- looks staged in a way that conflicts with the brief;
- has no usable project-specific detail;
- creates false context or false scale;
- competes with stronger source-grounded imagery;
- exists only because a layout slot needed filling.

Candid, asymmetric, warm, cool, documentary, polished, centered or staged imagery are not intrinsically KEEP/REJECT categories. Their suitability depends on the current project and evidence role.

## Placement readback

For final candidates, verify at the actual target relation:

- exact/representative aspect ratio;
- focal/claim region survives crop;
- text safe region remains usable when text is actually required;
- thumbnail/far read does not invert the intended sequence;
- mobile/alternate crop retains the required object/relation;
- neighboring images do not flatten all frames to equal visual mass.

## Rejected external defaults

The following are not OLEANDER defaults:

- a fixed color-temperature band;
- one mandatory high-key/low-key treatment;
- fixed candidate-count or rejection quotas;
- universal preference for candid over posed, asymmetric over centered, or environmental over isolated;
- a requirement that the strongest single image be removed solely because it differs visually;
- a shared LUT/white balance applied regardless of source meaning.

## Required output

Return:

- candidate-set inventory;
- role/placement map;
- KEEP / SUPPORT / CUT / HOLD reasons;
- preserved truth/color/light boundaries;
- selected sequence;
- bounded treatment notes;
- actual placement/thumbnail/near/mobile readback when applicable;
- unresolved rights/source limitations.

## Candidate boundary

This extension improves curation traceability and cross-set judgment. It does not search for images, grant licensing rights or override source truth. `SET COHESION ≠ BRAND PASS ≠ EVIDENCE PASS`.
