Observed project action: the P02 railing intervention was repaired around a lean/rest use relation rather than being read as a generic seat or decorative board.

Current project carrier explicitly keeps:

### C04 J02｜moving-context attention budget

Observed project action: a real editable journey carrier was materialized for boat / water-scale experience. The design gives first visual authority to continuous landscape relations and pushes directional/light/deep information later, with `PHONE-DOWN FIRST` and LIGHT/OFF digital states.

Bounded learning:
- in moving or low-attention contexts, attention availability is a design constraint, not a presentation afterthought;
- first decide what must remain continuously perceptible without interaction, then route optional information to later/lower-attention states;
- if an interaction requires sustained looking-down, repeated tapping, or task completion before the experience works, test whether the interaction belongs in that moving context at all;
- `more content` is not equivalent to `more experience depth` when the carrier competes with the primary environment.

Provenance status: `PROJECT_LEARNING_EVIDENCE / REAL EDITABLE ARTIFACT / HISTORICAL SKILL_USAGE_TRACE NOT ESTABLISHED / PROJECT-SPECIFIC / CROSS-CONTEXT VALIDATION NOT YET ESTABLISHED`.

1. `SCENE / ROUTE / BODY RELATION BEFORE LOCAL OBJECT POLISH` when the object changes circulation or bodily use.
