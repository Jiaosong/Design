### C04 P01｜scene-fit + footfall relation

Observed project action: the existing P01 physical concept was repaired in the editable SVG to restore scene-fit / footfall relation instead of treating the component as an isolated object.

Bounded learning:
- physical intervention design must test `OBJECT + BODY + PATH + EXISTING SITE RELATION`, not object geometry alone;
- a locally coherent component can still be wrong if it pushes the user into circulation conflict, creates a false use cue, or ignores the scene role;
- scene/use relation is upstream of cosmetic detailing when it materially changes whether the object belongs in the place.

Status: `PROJECT_USAGE_EVIDENCE / DESIGN REPAIR PERFORMED / INDEPENDENT CROSS-CONTEXT VALIDATION NOT YET ESTABLISHED`.

### C04 P02｜lean-rest body relation

Observed project action: the P02 railing intervention was repaired around a lean/rest use relation rather than being read as a generic seat or a decorative board.

Current project carrier explicitly keeps:
- body-contact surface;
- reversible clamp logic;
- isolation/buffer layer;
- drainage/cleaning path;
- independent replacement/service intent;
- `CONCEPT / NTS / FIELD OPEN / NOT FOR CONSTRUCTION` boundary;
- no assumption that an existing railing is verified to carry new load.

Bounded learning:
- define use-posture identity before form polish: `LEAN / PERCH / SIT / SUPPORT` are not interchangeable labels;
- human figures must expose body/contact/force/path relation, not act as decorative scale props;
- an existing base/substrate is not automatically load or installation authority;
- when the design depends on an existing site element, separate `DESIGN RELATION` from `FIELD / ENGINEERING VERIFICATION`.

Status: `PROJECT_USAGE_EVIDENCE / BOUNDED DESIGN LOGIC / FIELD + ENGINEERING HOLD`.

### C04 J02｜moving-context attention budget

Observed project action: a real editable journey carrier was materialized for boat / water-scale experience. The design deliberately gives first visual authority to continuous landscape relations and pushes directional/light/deep information later, with `PHONE-DOWN FIRST` and LIGHT/OFF digital states.

Bounded learning:
- in moving or low-attention contexts, attention availability is a design constraint, not a presentation afterthought;
- first decide what must remain continuously perceptible without interaction, then route optional information to later/lower-attention states;
- if an interaction requires sustained looking-down, repeated tapping or completion of a task before the experience works, test whether the interaction belongs in that moving context at all;
- `more content` is not equivalent to `more experience depth` when the carrier competes with the primary environment.

Status: `PROJECT_USAGE_EVIDENCE / REAL EDITABLE ARTIFACT / PROJECT-SPECIFIC / CROSS-CONTEXT VALIDATION NOT YET ESTABLISHED`.

## Transferable candidate rules

These remain bounded candidates until materially different contexts confirm them:

1. `SCENE / ROUTE / BODY RELATION BEFORE LOCAL OBJECT POLISH` when the object changes circulation or bodily use.
2. `USE-POSTURE IDENTITY BEFORE FORM DETAIL` for body-contact physical interventions.
3. `EXISTING BASE ≠ LOAD / FIELD AUTHORITY` unless separately verified.
4. `ATTENTION BUDGET → INFORMATION / INTERACTION DEPTH` in moving or low-attention contexts.
