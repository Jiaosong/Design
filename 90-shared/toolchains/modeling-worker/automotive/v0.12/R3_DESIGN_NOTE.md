# E3 R3｜Coupled Semantic Surface Network｜Design Note

Status: `RE-ENTER / WORKING_SOURCE / MACHINE NOT RUN / HUMAN NOT RUN / PAP BLOCKED / PROMOTION BLOCKED`

## Decision Question

Can the v0.12 relationship-driven compiler preserve genuinely distinct hood/cabin, shoulder/rear-haunch, lower-body and termination masses when those masses are authored as separate but coupled Surface Source families with independent Profile and Plan-view Primary Curve authority and relationship-specific continuity targets?

## Why R3 exists

R2 proved that independent source keys, analytic C2 compilation and sampled fairness are not sufficient for perceptual volume independence. Human Project/Visual review retained R2 as method evidence but rejected the application form because:

- Side still reads as one dominant central mound;
- Top remains weakly articulated;
- rear-haunch is source-independent but not perceptually independent;
- lower-body remains passive;
- terminations remain demonstration boundaries;
- blanket longitudinal C2 over-smooths relationships that require different design character.

R3 therefore changes the **application Surface Source topology**, not the generic E1/E2 method evidence.

## R3 source families

1. `SURF-UPPER` — hood / cowl / cabin upper mass.
2. `SURF-SIDE` — belt / shoulder / rear-haunch side mass.
3. `SURF-LOWER` — lower-body / rocker counter-tension.
4. `SURF-FRONT-TERM` — independent front continuation volume.
5. `SURF-REAR-TERM` — independent rear continuation volume.

The first three families are authored from distinct Profile and Plan-view Primary Curves. They may share declared boundary curves, but they do not share one global control cage or one blanket longitudinal continuity assumption.

## Relationship-specific continuity classes

R3 supports only claims that can be measured by the benchmark:

- `G0` — boundary position coincidence.
- `G1` — boundary tangent-plane / normal-angle agreement proxy.
- `G2_PROXY` — G1 plus bounded mean-curvature difference at the boundary.
- `CURVATURE_RATE` — bounded local curvature-rate proxy through the transition region.
- `INTENTIONAL_BOUNDARY` — position relationship is explicit but no smooth-continuity claim is made.

`G2_PROXY` is deliberately not called production Class-A G2. Human Zebra/reflection review remains mandatory.

## Primary Curve authority

Profile and plan-view curves are separate authority objects. A side silhouette edit is not allowed to silently rewrite plan-view shoulder trajectory, and a plan-view rear-haunch edit is not allowed to silently lift the cabin profile.

Minimum curve roles:

- `PROFILE-UPPER-CENTER`
- `PROFILE-SHOULDER-HEIGHT`
- `PROFILE-LOWER-ROCKER`
- `PLAN-UPPER-WIDTH`
- `PLAN-SHOULDER`
- `PLAN-ROCKER`
- `PLAN-FRONT-TERM`
- `PLAN-REAR-TERM`

## Fail-closed R3 Machine QA

R3 Machine PASS requires all of:

1. source-family ownership is disjoint except explicitly declared shared boundary curves;
2. Profile and Plan-view curve ownership are distinct;
3. every declared boundary relation is evaluated under its own continuity class;
4. interior fairness passes per Surface Source family;
5. semantic edits alter only declared source objects;
6. semantic edits produce working-fidelity geometric effect;
7. plan-view trajectory metrics change when plan-view semantic controls are edited;
8. silhouette derivative / inflection metrics remain bounded under profile edits;
9. derived execution topology is generated only after Surface Source compilation;
10. machine PASS only opens Human Project/Visual QA.
