## Human Project / Visual review｜REVISE

The R2 artifact was reviewed directly against the R1 baseline from the same run using Hero / Side / Top / Zebra and the five R2 semantic Side variants.

### 1. Side silhouette still reads as one dominant mound

R2 is cleaner and more controllable than R1, but the primary side reading remains a single central crown falling continuously toward both ends.

The intended sequence

`hood/cowl → cabin → rear-haunch → termination`

is still not legible as a hierarchy of coupled but distinct low-frequency masses.

The cabin crown remains too close to the dominant global peak. Hood/cowl changes mostly alter the approach to that peak rather than establishing a separately controlled front volume. Rear-haunch changes alter the rear slope but do not produce a clear haunch mass.

### 2. Plan-view hierarchy remains weak

The R2 Top view remains close to a long rectangular / weakly tapered envelope. Front, cabin/shoulder and rear mass do not establish sufficiently different plan-view trajectories.

This reveals a structural limitation: the station-jet chain controls vertical and transverse section roles, but it still lacks independent **plan-view Primary Curve authority** for shoulder, belt, rocker and termination trajectories.

### 3. Rear-haunch is controllable but not yet a distinct volume

The new Rear-Haunch control is source-disjoint and machine-legible, which is an architectural improvement over R1. Human review nevertheless reads it primarily as a change in the common shell's rear slope rather than an independently authored rear mass.

`source-key independence != perceptual volume independence`.

### 4. Lower-body control remains subordinate

The Lower-Body variant is measurable and fair, but the base form still lacks a strong lower-body / rocker counter-tension against the upper shoulder/cabin mass. The side continues to read as a top surface plus a relatively passive lower edge.

### 5. Terminations remain open-boundary demonstrations, not resolved volumes

Front and rear ends still read as abrupt open boundaries / planar end conditions in Side and Top. They no longer depend on mesh-cap topology, which is a method improvement, but they are not yet convincing continuation volumes.

### 6. Zebra continuity passes, reflection organization does not yet pass the application bar

No obvious seam break is visible at the shared station seams, consistent with the machine C2 evidence. However the R2 Zebra view shows strong reflection compression / looping around the central cabin crown and toward the terminal zones.

The current fairness proxies successfully reject local differential discontinuity but do not fully measure **reflection-field organization, curvature-direction coupling or highlight acceleration at application scale**.

Therefore:

`C2 + sampled fairness PASS != application reflection-quality PASS`.
