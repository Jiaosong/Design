## Machine failure evidence

### A. Boundary relationship proxy failure

Source construction shares exact boundary positions, but one-sided numerical normal evaluation reported:

- `SURF-UPPER ↔ SURF-SIDE`: approximately `0.1553°` against `0.10°` runtime proxy;
- `SURF-SIDE ↔ SURF-LOWER`: approximately `0.3059°` against `0.15°` runtime proxy.

Front and rear continuation seams passed their declared runtime normal proxy.

The shared Hermite source tangent policy is analytically the relationship authority. Therefore R3.1 must distinguish **source-level tangent-plane authority** from finite-difference runtime representation evidence rather than relaxing the declared relationship.

### B. Current fairness metric conflates different surface zones

The first R3 machine implementation uses raw adjacent-grid normal angle as a universal fairness check. This metric is sample-spacing dependent and was applied equally to:

- broad low-frequency interior;
- shoulder / rocker character bands;
- front/rear continuation zones;
- far boundaries explicitly declared `INTENTIONAL_BOUNDARY`.

Observed maxima:

- `SURF-UPPER`: ~`43.19°`;
- `SURF-SIDE`: ~`52.63°`;
- `SURF-LOWER`: ~`6.73°`;
- `SURF-FRONT-TERM`: ~`79.89°`;
- `SURF-REAR-TERM`: ~`60.93°`.

The maxima concentrate near character / far-boundary zones rather than the broad interior. Denser private diagnostic sampling reduces the same raw adjacent-angle number substantially, confirming that this metric cannot be used as a resolution-independent global fairness authority.

This does **not** mean the geometry is acceptable: the same artifact visually and physically shows genuinely concentrated curvature near shoulder/rocker transitions and termination collapse. R3.1 therefore revises both the metric semantics and the source geometry.

### C. Actual geometry still requires revision

R3 improves layer separation over R2, but working-fidelity evidence still shows:

- shoulder and rocker turns are too concentrated;
- front termination has a notch/pinch and collapses too quickly;
- rear termination also collapses sharply;
- Zebra/reflection proxy shows concentrated curls around character bands and terminal zones.

These are real source-geometry problems and cannot be dismissed as measurement artifacts.

### D. Lower-Body semantic QA logic is incomplete

`LOWER-BODY` changes `PROFILE-ROCKER` and `PLAN-ROCKER`, but the current profile domain-effect detector only compares metrics derived from `PROFILE-UPPER-CENTER`. The edit is exact but the domain-effect check can incorrectly report no profile effect.

R3.1 must evaluate the **actual edited Primary Curve authority**, not a hard-coded upper-center metric.

The current Lower-Body maximum surface displacement is also only ~`0.01695 m`, below the `0.025 m` working-fidelity minimum. Its semantic amplitude must be increased while preserving the new fairness contract.

## Root cause

`R3 architecture direction = RETAIN`

Do not revert to R2. Do not densify the execution mesh as a solution. Do not lower the quality bar by simply increasing sample density or widening existing thresholds.

## R3.1 allowed correction

### QA semantics

Split machine evidence into:

1. **Source Relationship Authority** — analytic/shared boundary position and tangent-plane construction;
2. **Runtime Boundary Representation** — finite-difference position/normal proxy recorded separately;
3. **Broad Interior Fairness** — distance-normalized / zone-scoped evidence away from declared character bands;
4. **Character-Band QA** — monotonic normal turning, no fold/degeneracy, bounded curvature concentration / minimum-radius proxy;
5. **Intentional Boundary QA** — non-degenerate and explicit, but not misreported as broad-surface fairness;
6. **Reflection Organization Proxy** — retained as a supplemental machine signal and always followed by Human Zebra review.

### Geometry

- broaden shoulder and rocker transitions;
- reduce front/rear termination collapse by increasing termination width retention and vertical continuation;
- strengthen Lower-Body semantic edit above the working-fidelity minimum;
- retain Profile/Plan authority separation and five-family architecture.

### Semantic QA

Domain-effect checks must derive from the specific edited curve/family IDs. A `PROFILE-ROCKER` edit must be measured against the rocker profile, not only the upper-center profile.
