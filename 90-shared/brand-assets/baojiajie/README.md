## BJ-PORTRAIT-LOCK-01｜Licensed Portrait Asset Lock

Status: **HARD GATE / ALL BAOJIAJIE VISUAL OUTPUTS**

User-uploaded and user-confirmed licensed endorser / human photographs are `LOCKED SOURCE ASSET`s. They are not AI-generatable design material.

### Immutable human content

Unless the user explicitly authorizes a specific exception, do not alter:

- face or facial features;
- expression;
- makeup;
- hairstyle or any hair-strand position;
- clothing;
- pose, action, gesture or hand position;
- body proportions;
- silhouette / contour;
- internal relative geometry of the human image;
- any human pixels through generative redraw, inpainting, replacement or retouching.

### Allowed operations only

- uniform whole-layer scaling;
- whole-layer translation / placement;
- crop;
- occlusion by other layout elements;
- non-generative masking that only hides source pixels;
- ordinary layer compositing.

Do not warp, liquify, perspective-transform the person, reconstruct cropped body parts, extend the portrait with generative fill, relight/repaint the person, face-swap, retouch, change makeup/hair/clothes, or regenerate the person.

### Required production workflow

`GENERATE / DESIGN ALL NON-HUMAN CONTENT → HUMAN-FREE QA → COMPOSITE ORIGINAL LICENSED PORTRAIT AS LOCKED LAYER → FINAL QA`

The licensed portrait should normally be inserted only after AI image generation is complete. If a generation step can reinterpret or redraw the human subject, the portrait must not be included in that generation step.

### QA Gate

Before promotion or delivery:

- `PORTRAIT SOURCE AUTHORITY = PASS`
- `HUMAN LAYER CONTENT MODIFICATION = NONE`
- `ALLOWED TRANSFORM ONLY = PASS`

If the composition conflicts with the locked portrait, revise the composition — not the person.

This rule applies to jump cards / hang tags, packaging, posters, e-commerce pages, key visuals, social content, web assets, video stills and all later Baojiajie visual outputs.
