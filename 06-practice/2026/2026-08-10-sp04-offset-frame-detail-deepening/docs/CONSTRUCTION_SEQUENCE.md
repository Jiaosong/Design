# C | Offset Frame — construction sequence

1. **P / survey** — confirm structural rough opening, tolerances, substrate condition and actual frame system.
2. **H / prepare sill fall** — form a smooth outward-sloping rough-opening substrate at sill.
3. **E / water control** — connect W04 into the opening with a compatible sill-pan / liquid or formable flashing; maintain backdam and jamb end-dam logic.
4. **H / reveal thermal return** — install the reveal insulation return without interrupting the waterproof liner.
5. **P / set frame** — place frame plumb/level/square on durable support blocks; frame fixing follows manufacturer + structural design.
6. **E / jamb + head flashing** — jamb waterproofing laps over sill system; head waterproofing laps over jambs and returns to W04.
7. **H/P / middle joint** — install low-expansion foam or compatible insulation in the frame-to-opening joint; this is not the primary air seal.
8. **E / interior air seal** — form one continuous interior airtight perimeter connection frame → rough-opening liner/control layer.
9. **P / exterior closure** — complete jamb/head weather closure and sill capping without blocking sill drainage.
10. **P / verification** — inspect membrane corners/end dams, frame anchorage, drainage outlets; perform project-required air/water testing if specified.
