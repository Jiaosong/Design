## DESIGN QUESTION / INPUTS / CONSTRAINTS / E-I-A-D
Question:
Can a threshold make a branch decision legible *before* the circulation conflict point, even with signage removed?

Inputs / constraints:
- synthetic NTS circulation only;
- two outgoing directions;
- one opposing-flow adverse condition;
- no dimensions or capacity claims;
- no project/site/egress/accessibility/structure authority.

EVIDENCE:
Two paths branch only at one opening.

INFERENCE:
Users must approach the conflict point before deciding direction.

ASSUMPTION / ATTACK:
Opposing flow would amplify crossing / backtracking if the choice remains late.

DESIGN CONSEQUENCE:
Move the choice threshold upstream and use spatial form to pre-separate flows.

## TRANSFER RULE
When a spatial design consequence is meant to change behavior, place the form intervention where the behavioral decision must occur — not where a landmark is visually convenient.

A threshold can be a causal device only if removing signage still leaves its intended sequence legible.

## BOUNDARY
Applicable to:
- circulation branches;
- approach/entry thresholds;
- queue/service splits;
- museum/travel routing;
- spatial products/interfaces where compression/release changes choice timing.

Not sufficient for:
- fire egress;
- statutory accessibility;
- crowd-capacity sizing;
- real wayfinding validation;
- structural design;
- field-measured behavior.
