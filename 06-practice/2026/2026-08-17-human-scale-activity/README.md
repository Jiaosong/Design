## Learning object
Lina Bo Bardi / SESC Pompéia, 1977 drawing set. Instituto Bardi archive records multiple `Corte`, interior perspectives and a flow diagram for the project.

## Visible Fact / Design Inference / Transfer Rule
- Visible Fact: people appear within ramps, platforms and activity spaces across the drawing set.
- Design Inference: human figures can communicate use, movement and spatial occupation in addition to nominal scale.
- Transfer Rule: `BODY SCALE → ACTION → SPATIAL INTERFACE → FLOW / PAUSE / MAINTENANCE`.

A correct-height standing silhouette repeated everywhere can still be visually weak evidence if it communicates no action.

## Real C04 transfer
A relational section A/B uses the same abstract geometry and same figure count:
- A: generic standing figures; scale is visible but behavior is absent.
- B: MOVE / OBSERVE / MAINTAIN figures tied to path, sightline and service interface.

Boundary: `NOT SITE GEOMETRY / NTS / FIELD OPEN`. No new C04 dimension, route, platform, railing, accessibility or structural fact is introduced.

## Visual readback
- 1600×1000 near-read: B creates three distinct body-space relationships without increasing figure count.
- 480×300 distance-read: A reduces to decorative scale markers; B retains behavioral differentiation.

## Candidate rule fields
- Problem: figures used as decorative scale stickers.
- Trigger: section/model contains people but program/use remains unreadable.
- Inputs: authoritative geometry + known program role + bounded user action.
- Visible Symptoms: identical standing silhouettes; no relationship to path, edge, view, control or service point.
- Cause: scale figure treated as an icon rather than body-space evidence.
- Technique: assign each figure one spatial verb and bind pose/placement to a real interface.
- Parameters / Conditions: use only actions supported by project evidence; figure count does not need to increase.
- Aesthetic Judgment: figures should reinforce spatial reading instead of becoming decorative entourage.
- Verification: hide figures and record what information disappears.
- Failure Condition: pose implies unsupported access, maintenance, safety, accessibility or operation.
- Counterexample: a technically correct standing silhouette that adds only height comparison should REVISE when a behavioral role is needed.
- Transfer Boundary: never invent activities to make drawings look lively.
