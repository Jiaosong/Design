## Status

`EXECUTION CANDIDATE / STACKED ON MODELING WORKER v0.13 / MACHINE GATE REQUIRED / NO DESIGN PROMOTION`

## Why this optimization exists

The merged Blender Surface System v1.20.0 already centralizes F1 diagnostic materials, Broad / Strip / Grazing lighting and render execution. Modeling Worker v0.13 already keeps six sparse Blender-native Source objects as `WORKING_SOURCE` and treats dense meshes as `DERIVED_EXECUTION_NOT_AUTHORITY`.

The remaining integration weakness is at the boundary between those systems:

- the Surface System can render a supplied object, but it does not own a reusable Source-context snapshot contract;
- diagnostic material assignment is safe only when the caller remembers to target disposable derived geometry;
- the Source digest is currently generated by the project worker rather than by a reusable Surface System adapter;
- a future project could accidentally run a diagnostic material mutation on an authoritative or project-owned object.

v1.21 adds the missing reusable boundary instead of adding another texture/noise family. The stacked branch also adds an explicit Modeling Worker v0.13 binding consumed by the Blender smoke test, so this is not a parallel, uncalled helper.

## New capability

`Blender-native Source Authority → deterministic snapshot → diagnostic proxy → Surface diagnostic material/rig → before/after Source gate`

### Source snapshot

The adapter captures:

- object identity and Blender type;
- world transform;
- custom properties;
- NURBS/Bezier control geometry for Curve Source objects;
- mesh vertices/edges/polygons when Mesh is explicitly used as a Source;
- EMPTY transform/display state and relation properties.

The canonical snapshot is hashed with SHA-256 over normalized, key-sorted JSON.

For the current Modeling Worker benchmark the expected Source set remains:

- `OL_SRC_GRIP_AXIS`
- `OL_SRC_PALM_PROFILE`
- `OL_SRC_THUMB_SIDE_PLAN`
- `OL_SRC_OPPOSITE_SIDE_PLAN`
- `OL_SRC_LOWER_RETURN_PROFILE`
- `OL_SRC_INTERFACE_DECK_BOUNDARY`

No seventh Source family is introduced.

### Non-destructive diagnostic proxy

The adapter creates an evaluated mesh copy tagged:

`DERIVED_DIAGNOSTIC_NOT_AUTHORITY`

Diagnostic material-slot clearing is permitted only on that proxy. The reusable API refuses diagnostic material mutation on any object that lacks the proxy role.

Each proxy stores the Source snapshot SHA that existed when the proxy was created.

### Fail-closed Source gate

Every diagnostic session can record a Source snapshot before and after the diagnostic operation. A changed digest raises an error.

A controlled native Source edit is expected to change the digest; restoration must return to the original digest. This distinguishes legitimate editable Source work from accidental mutation during rendering.

## Modeling Worker bridge

`G1_SURFACE_SOURCE_CONTEXT_BINDING_v1.json` binds the existing v0.13 Source collection and six object identities to the v1.21 adapter while retaining `MODELING_WORKER_v0.13` as Source owner. The binding explicitly keeps the v1.20 F1 render runtime as the parent render engine and requires all new Source-aware diagnostics to pass through a non-authoritative proxy.

Historical v1.20 direct-derived render evidence remains provenance; it is not rewritten retroactively.

## R4.5.1 compatibility

The snapshot intentionally includes Source custom properties, including the currently authorized sparse parameter:

`termination_cap_pole_curvature_scale`

The Surface System may read and bind this parameter but does not own it and cannot promote it. Modeling Worker remains Source Authority owner.

## Review separation

Passing CI establishes only:

`DETERMINISTIC SOURCE READBACK / NON-DESTRUCTIVE DIAGNOSTIC BINDING / BLENDER 5.2 EXECUTION`

It does not establish:

- professional surface-form quality;
- Candidate or Canonical promotion;
- Class-A continuity;
- ergonomic comfort;
- engineering CAD;
- manufacturing/tooling;
- physical CMF/material truth;
- Release.

Visual quality remains an independent downstream gate using actual Broad / Strip / Grazing / Zebra evidence on the real project geometry.
