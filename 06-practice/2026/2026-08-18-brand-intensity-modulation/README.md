# 2026-08-18 Brand Intensity Modulation

Status: **KEEP FOR TRAINING / reusable gate candidate**

## Project trigger
Current C04 architecture v3.2 requires Brand to operate at medium-appropriate strength: FULL for communication/cover, LIGHT for App/map/content, TRACE in field/service, and OFF where landscape/body attention must dominate. The same authority also prohibits Brand from gaining route, landscape, safety, field, geometry or engineering authority.

## Existing-first
No new framework or standalone Brand Skill is created. This round reuses `oleander-story-and-board` and adds one bounded gate to it.

Recent training was checked before selection. This round does not repeat page rhythm, joint legibility, activity-bearing human scale, route-state semantics, map-label collision, bilingual hierarchy, endorsement hierarchy, long-form orientation, or physical reassurance.

## Training question
Can one identity system remain recognisably coherent while its visual authority changes across media?

## Practice
The same synthetic Qingjiang Stone Book river/folio grammar is tested in four attention regimes:

- `FULL` — cover / communication / opening; identity owns first-read.
- `LIGHT` — App / map / content; task owns first-read and identity confirms context.
- `TRACE` — field / service / reassurance; only a small recognisable token remains.
- `OFF` — landscape / body attention / view; decorative brand graphics leave the primary attention field.

A rejected comparison repeats the FULL treatment across all four media to demonstrate that constant loudness is not a valid definition of consistency.

## Design Crit

### v1 — REVISE
The hierarchy concept was valid, but rendered Chinese identity text fell back to tofu boxes and the TRACE token was slightly too prominent. Export success did not count as typography or design PASS.

### v2 — REVISE
CJK rendering was repaired with `Noto Serif CJK SC`, and TRACE amplitude was reduced. However, two internal explanatory micro-labels had weak contrast against the artwork and competed with the specimen.

### v3 — KEEP FOR TRAINING
Removed low-contrast internal annotations, moved the mode definition to one shared legend, and produced a 600 px distance-read derivative. FULL > LIGHT > TRACE > OFF remains perceptible without relying on the explanatory labels.

## Failure knowledge
- Constant logo size / contrast / frequency across media creates repetition, not coherent brand architecture.
- `LIGHT` is not a smaller FULL lockup if it still dominates the task.
- `TRACE` is not a tiny billboard; it should reassure, not interpret.
- `OFF` is a legitimate designed state when landscape, body, safety, route or technical proof must dominate.
- Brand recognisability must survive modulation; disappearing into generic styling is also a failure.
- Render/export PASS does not prove typography, hierarchy, trademark approval or Brand Design PASS.

## Transfer rule
`ATTENTION TASK → BRAND STRENGTH → AUTHORISED IDENTITY GRAMMAR → DISTANCE READ → MEDIUM MATRIX CRIT`

## Transfer boundary
This practice uses synthetic vector grammar only. It is not a trace or replacement of current/legacy Qingjiang logo artwork, does not establish trademark rights, and does not promote C04 Brand Design.

## Cross-project reuse
Applicable to parent/sub-brand systems, experience brands, retail families, digital/physical service systems, exhibition identities, destination brands and any project where one identity appears across media with different attention demands.

Not a fit for true equal co-branding, legally prescribed constant lockups, or safety/traffic systems whose mandatory sign standards override brand modulation.
