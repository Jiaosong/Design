## TRANSFER RULE
**A design-to-validation handoff must transfer the relation that must survive, the unknown that threatens it, and the return contract — while leaving validation method authority downstream.**

The minimal causal handoff is:

`OBJECT / DESIGN MASTER → INVARIANT → UNKNOWN / VALIDATION QUESTION → VALIDATOR-OWNED METHOD → PASS|REVISE|HOLD + EVIDENCE REF → AFFECTED DESIGN REPAIR`

## BOUNDARY
Applicable to:
- spatial/architectural design → engineering/field validation;
- product form → ergonomics/mechanism/manufacturing validation;
- UI/interaction → runtime/accessibility validation;
- data/visual design → source/measurement validation;
- production artwork → supplier/preflight validation.

Not sufficient for:
- choosing engineering methods;
- code interpretation;
- structural sizing;
- accessibility certification;
- legal compliance;
- field acceptance;
- supplier approval.
