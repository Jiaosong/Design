## Failure knowledge
- A list of individually good rules is not a system.
- Shared vocabulary does not reveal priority or conflict.
- A network diagram can be logically correct and still fail if edges cross first-read text.
- Conflict resolution must name contextual ownership; otherwise layout or novelty decides accidentally.
- Pattern Network PASS does not prove each medium or project artifact is professionally finished.
