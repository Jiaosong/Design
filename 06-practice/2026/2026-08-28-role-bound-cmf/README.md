## DESIGN QUESTION / INPUTS / CONSTRAINTS / E-I-A-D
Question:
Can grip, moving control and protected shell remain functionally distinguishable after hue is removed, with CMF reinforcing rather than creating those roles?

Inputs:
- synthetic hand-tool body;
- three part roles: `GRIP / MOVING CONTROL / PROTECTED SHELL`;
- wet glove / contamination / low-light / repeated-cleaning adverse conditions.

Constraints:
- no real material specification;
- no friction coefficient;
- no stain/chemical resistance;
- no ergonomic or manufacturing validation.

EVIDENCE:
The three zones have different contact and interaction roles.

INFERENCE:
One uniform finish can flatten those differences; maximum contrast can also create false interaction hierarchy.

ADVERSE CONDITIONS:
wet glove / contamination / low light / repeated cleaning.

DESIGN CONSEQUENCE:
Assign surface role first; choose color, value, texture and finish only after the part-role hierarchy is clear.

### A / REJECT — ONE PREMIUM FINISH
All parts share one dark glossy finish. Visual consistency is high, but grip/control/shell semantics collapse.

### B / KEEP candidate — ROLE-BOUND CMF
- Grip: coarse ribs, low visual reflection, tactile priority.
- Control: bounded contrast plus explicit travel/stop geometry, interaction priority.
- Shell: low texture, visually quiet, cleanable-role cue; does not borrow grip semantics.

### C / REVISE — MAXIMUM CONTRAST
Every part is strongly differentiated; the shell competes visually with the control and every zone appears actionable.

## A/B / ATTACKS
1. `COLOR-OFF`: remove hue/chroma; role hierarchy must survive.
2. `LABEL-OFF`: remove role labels; form + surface rhythm must still distinguish grip/control/shell.
3. `WET`: grip/control cannot depend on gloss or fine decorative texture.
4. `CONTAMINATION`: shell should not acquire false grip semantics from decorative microtexture.
5. `LOW-LIGHT / GRAYSCALE`: visual priority cannot rely on hue alone.
6. `ROLE-OFF`: maximum contrast cannot make every component look like the primary interaction point.

## ACTUAL READBACK
Initial full-size readback exposed a real presentation defect in B: the three role-description lines were compressed into one dense horizontal band, reducing near-read clarity and making the functional distinction look like metadata.

## FAILURE / ROOT CAUSE
Two failures were confirmed:
1. **Design failure:** `visual consistency ≠ role consistency`; a single premium finish can flatten functional zones.
2. **Representation failure:** a correct role model loses force if role evidence is compressed into low-priority text.

## TRANSFER RULE
`ROLE → REQUIRED CONTACT / INTERACTION BEHAVIOR → FORM/SURFACE ROLE → CMF REINFORCEMENT`

CMF is valid design evidence only when removing hue and labels leaves the underlying part-role hierarchy intact.

Uniformity is not automatically coherence; contrast is not automatically usability.
