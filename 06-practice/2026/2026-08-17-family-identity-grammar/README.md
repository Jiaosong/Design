# 2026-08-17 Brand System — Family Identity Grammar

Status: **CANDIDATE / project transfer practice complete / broader validation pending**

## Learning object
Pentagram × MIT Media Lab visual identity, 2014.

Visible fact: Pentagram states that the Media Lab identity retained an underlying seven-by-seven grid and extended that same grid to 23 research groups, producing an interrelated glyph family that combines a fixed Lab identity with differentiated group identities.

Design inference: a family system does not require every member to share the same composition. It needs a small set of invariant relationships that remain recognizable while meaningful differences are allowed inside those boundaries.

Transfer rule: **FIXED GRAMMAR + BOUNDED VARIATION**. Lock 3–5 relations before styling variants. `SAME TEMPLATE != FAMILY`; `EVERY SKU REINVENTED != FAMILY`.

## Baojiajie project transfer
Target: 100×100 mm retail jump-card family for 欧科棉 / XF01 肥皂拖把 / 七彩高弹胶棉.

Locked Baojiajie Logo and licensed portrait pixels are intentionally not embedded or altered. Only reserved anchor zones are represented.

A = three individually designed posters with unrelated grids, headline locations, information density and brand-blue roles.

B = four shared relations: Logo anchor, portrait reserve, claim datum and brand-blue proof rail. Product-specific differences remain distinct: 欧科棉 uses an absorbency arc, XF01 uses an action geometry, 七彩高弹胶棉 uses a material/color rhythm.

## Review rule
**Family Grammar Review**: hide product names and test whether the set still reads as one family; hide accent colors and test whether individual SKU roles are still distinguishable. Both must pass.

## Failure condition / counterexample
A set can look polished and consistent because every card uses the same rounded rectangle, typeface and token palette, yet still be `REVISE` if each SKU has no product-specific identity beyond swapping color/name. Conversely, three strong standalone posters remain `REVISE` if the viewer must relearn the brand each time.

## Transfer boundary
Do not copy MIT Media Lab glyphs, seven-by-seven geometry, Helvetica treatment or trade dress into Baojiajie. The transferable method is the relationship between invariant grammar and bounded variation.
