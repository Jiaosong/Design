## DESIGN QUESTION / INPUTS / CONSTRAINTS / E-I-A-D
Question: If returned equipment must be checked before re-entering verified stock, does that state distinction visibly change adjacency, thresholds and path ownership?

Inputs: synthetic equipment-library service; pickup flow; return flow; check/hold; verified clean stock; damaged-item adverse state.

Constraints: NTS; no real queue capacity; no hygiene protocol; no staffing count; no accessibility/egress/architecture authority.

EVIDENCE: Returned items must pass a check before re-entering borrowable stock.

INFERENCE: If return, check and pickup share one service point, `unchecked` and `verified clean` become spatially ambiguous.

ADVERSE CONDITION: Peak simultaneous return + pickup; damaged item discovered.

DESIGN CONSEQUENCE: Move triage upstream; keep unchecked/damaged states outside verified clean stock; let pickup bypass the check/hold sequence.

## A/B / ATTACK
1. `LABEL/SIGNAGE-OFF`: remove labels and signs; state distinctions must survive spatially.
2. `PEAK`: simultaneous pickup and return; check activity must not occupy pickup path.
3. `DAMAGED ITEM`: damaged state must gain a spatially bounded hold/quarantine path.
4. `TRIAGE DELETION`: delete upstream triage; if damaged/unchecked items can directly approach clean stock, the state boundary is not spatially robust.
5. `STAFF-CROSSING`: inspection/staff movement cannot rely on crossing the primary pickup path.
6. `GRAYSCALE`: service-state hierarchy cannot depend on color alone.

## TRANSFER RULE
`SERVICE STATE → ALLOWED NEXT ACTION → REQUIRED ADJACENCY / SEPARATION → THRESHOLD → PATH OWNERSHIP`

A service blueprint becomes spatial design only when a meaningful state difference changes at least one of: adjacency; sequence; threshold; path ownership; storage/hold boundary. Better signage alone is not equivalent.

## BOUNDARY
Applicable to equipment lending/returns, repair intake, clean/dirty service chains, cloakroom/item check, service counters with verification before release, and backstage/frontstage transitions where state affects access.

Not sufficient for hygiene regulation, infection control, real queue/capacity sizing, staffing, accessibility/egress, inventory correctness, or architecture/engineering approval.
