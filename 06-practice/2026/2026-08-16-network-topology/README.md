# 2026-08-16 | Information Design / L5 | Topology First, Geography Explicit

Status: CANDIDATE / POST-REVIEW PASS FOR SYNTHETIC PRACTICE ONLY

## Learning object
Harry Beck's London Underground diagram, using Transport for London and London Transport Museum as evidence sources.

## Candidate rule
When the primary task is route choice, branch recognition, interchange recognition and return recognition, schematic topology may outrank geographic-looking coordinate geometry. Geographic facts that affect decisions — distance, slope, terrain, orientation, closure, risk — must remain explicit in a separate evidence/geographic layer.

## A/B
- `before_geographic_noise.svg`: identical topology with irregular geographic-looking coordinates.
- `after_topology_first.svg`: identical nodes, edges, route identities and labels; coordinate geometry only is regularized into horizontal and 45-degree segments.

First After draft was rejected during visual readback because two lines were described as 45 degrees but were not. Coordinates were corrected and rerendered before this record.

## C04 transfer boundary
This practice borrows C04-style node labels only for transfer testing. It is NOT C04 geography, distance, slope, survey or route authority. For C04, maintain two distinct outputs: topology/service/Return diagram and geographic/evidence map. Thirteen Imprints remain optional content, not 13 forced route stops.
