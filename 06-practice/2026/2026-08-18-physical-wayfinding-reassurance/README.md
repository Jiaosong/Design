# OLEANDER Practice — Physical Wayfinding Reassurance

Training ID: `OLEANDER-TRN-2026-08-18-PHYSICAL-WAYFINDING`

## Trigger

Qingjiang requires a no-phone journey in which route and return remain understandable without GPS or a continuous digital overlay. Existing OLEANDER reusable skills did not contain a physical-wayfinding role hierarchy.

## Training question

How should physical route cues divide responsibility between decision, reassurance, interpretation, and return so the landscape/path remains first-read rather than becoming a sequence of repeated information boards?

## External calibration

- NPS Harpers Ferry Center, *Wayside Exhibit Design*: start with the site; the landscape is the original object and the wayside is its caption.
- NPS, *Wayside Exhibit Evaluation Checklist*: waysides should relate directly to the landscape, remain legible, and be visually unobtrusive to park resources.
- U.S. Access Board, ADA signs guidance: where applicable, visual signs require legible visual characters, non-glare finish assumptions, and strong figure/ground contrast. Tactile/Braille scope is separate and must be verified for the actual sign type and jurisdiction.

## Practice iterations

- `v1 REJECT`: decision, reassurance, interpretation, and return all became similarly large upright boards. The route was still present, but repeated sign objects became the dominant system.
- `v2 REVISE`: role hierarchy was introduced and reassurance became compact, but interpretation and return still read too much like repeated upright panels.
- `v3 REVISE`: interpretation became a low-profile wayside tied to a view/story intersection and return became an operational blade; rendered reopen exposed a decision-marker accent stripe wider than its body and a crowded role label.
- `v4 KEEP FOR TRAINING`: repaired the decision marker and retained the improved physical hierarchy.

## Extracted rule

`DECISION → REASSURANCE → optional INTERPRETATION → RETURN / SERVICE`

Each cue answers the smallest necessary question at the place it arises. Reassurance is not another interpretive board. Interpretation appears only where a story intersects a specific view/object. Return/service remains operationally explicit. Landscape and path retain first-read ownership.

## Truth boundary

This is an NTS relative-scale calibration. It does not establish Qingjiang site dimensions, mounting heights, materials, foundations, drainage, tactile/Braille scope, code compliance, field visibility, maintenance access, or engineering approval.

## Cross-project transfer

Applicable to scenic trails, exhibitions, museums, campuses, landscape routes, hospitality, public-realm projects, and other journeys that must continue without a phone. Not a substitute for road-traffic-sign systems, emergency-egress codes, accessible-sign standards, or field placement studies.
