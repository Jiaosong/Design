## Question
Does equal modular structure create clarity, or can it erase the first-read thesis?

## Reference
- Josef Müller-Brockmann, Tonhalle Zürich concert posters, MoMA collection.
- Museum für Gestaltung Zürich: Müller-Brockmann poster practice follows strict functional criteria while still producing varied, dynamic compositions.

## Controlled exercise
Same 1600×1000 canvas, same 12-column guide, same labels and narrative sequence.

- `before_equal_modules.svg`: three equal frames, near-equal visual weight.
- `after_dominant_field.svg`: R06 Landscape First becomes the dominant field; R06 Relation Reveal and R13 Return Closure remain subordinate evidence.

Only dominance/grouping is intentionally changed. No project image assets are invented or embedded.

## Candidate rule
`GRID CREATES RELATIONAL ORDER; DOMINANCE CREATES FIRST-READ.`

Do not confuse equal modules with clarity. If a page is tidy but the viewer cannot identify the unique thesis at distance-read, default to `REVISE`.

## Counterexample
A 2/3 dominant frame is still wrong when the content inside is not the actual narrative/evidence priority, or when subordinate technical evidence becomes unreadable. Area difference is not hierarchy by itself.
