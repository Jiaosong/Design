# OLEANDER Training — Mixed-media Evidence Roles

## Training question

How should source-grounded landscape, model/axon, and technical node drawings share one presentation surface without a derivative model becoming a false project authority?

## Existing methods reused

- `oleander-story-and-board`: existing mature design / evidence first.
- `oleander-3d-pipeline`: model outputs remain derived from one authoritative model.
- Current C04 direction: real landscape remains primary; models prove space and relationship rather than replacing landscape.

## Practice artifact

`mixed_media_evidence_roles_v2.svg` is an editable 1920×1080 calibration board. It uses abstract vector geometry only and does not claim to reproduce C04 pixels or field geometry.

The left specimen intentionally demonstrates MODEL-FIRST failure. The right specimen assigns explicit medium roles:

- landscape: experienced field / first read;
- model: relative spatial relation / scale logic;
- node: support / construction logic at near read.

Each right-hand medium also carries a `PROVES / DOES NOT PROVE` boundary.

## Design Crit

### v1 — REVISE

The right-hand hierarchy was directionally correct, but the model remained too large and the evidence boundaries were mostly implicit. A viewer could understand hierarchy but still over-read what each medium proved.

### v2 — KEEP FOR TRAINING

Repairs:

1. Added adjacent `PROVES / DOES NOT PROVE` statements to every medium.
2. Reduced the model footprint so it supports rather than competes with the landscape.
3. Increased node width so technical proof remains readable after visual subordination.
4. Preserved one first-read authority while retaining all supporting information.

### Gate results

- First visual gate: PASS — landscape is the first read in the KEEP candidate.
- Composition: PASS — one experiential field, one model support field, one near-read node field.
- Proportion/hierarchy: PASS after v2 repair.
- Typography: PASS for calibration; labels remain subordinate to visuals.
- Material/spatial realism: N/A / HOLD — abstract calibration only.
- Scale: relative only; no measured dimensions claimed.
- Node readability: PASS after v2 repair.
- Interaction: N/A.
- Narrative: PASS — `experience → relation → support` is explicit.
- Professional completion: KEEP FOR TRAINING, not project promotion.

## Failure knowledge

- A cleaner derivative can accidentally become a stronger visual authority than the source it explains.
- `Model PASS` does not mean `Landscape/Field PASS`.
- Reducing a model to SUPPORT must not make its spatial logic unreadable.
- Evidence boundaries that matter to interpretation should sit next to the visual, not only in a distant source note.
- Mixed-media hierarchy is semantic, not only geometric: two objects of different size can still communicate the wrong authority if their roles are unnamed.

## Transfer boundary

Reusable for spatial/landscape boards, architecture presentations, product/CMF pages, portfolio websites, reports, decks, and videos that mix real/source-grounded imagery with models, diagrams, renders, prototypes, or technical proof.

Not a substitute for field validation, engineering review, model geometry validation, or source-rights review. A geometric/technical decision page may intentionally promote a model or section to first read; that role change must be explicit.
