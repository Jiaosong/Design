# OLEANDER Training — Evidence-bound Figure Caption

## Training question

How should an OLEANDER figure keep its truth state attached to the visual without turning metadata into a competing dashboard?

## Repository gap reused

`oleander-story-and-board` already required captions to identify what/where/when/why, but did not require figure identity, evidence class, interpretation boundary, and claim-bearing relation to remain visually adjacent.

## Practice

A/B calibration using the same abstract R06-like landscape relation.

- A — `DETACHED CAPTION`: figure looks authoritative while `DOES NOT PROVE` reads like a remote legal footer. **REJECT**.
- B v1 — three-column evidence rail: truth state is adjacent, but metadata becomes a mini dashboard and competes with the figure. **REVISE**.
- B v2 — one compact evidence-bound caption: `figure_id + source class + claim + supports + does-not-prove + FIELD state` remain adjacent while landscape stays first-read. **KEEP FOR TRAINING**.

## Design Crit

- First visual gate: PASS in v2. Landscape and relation anchor remain first-read.
- Composition: PASS. Caption sits in the image object's near-read zone rather than forming a separate panel system.
- Proportion: PASS after v2 repair; metadata height reduced.
- Hierarchy: PASS. Primary figure > claim > support scope > limitation.
- Typography: PASS for calibration; limitation is visible without becoming hero text.
- Spatial/material realism: N/A; abstract vector calibration only.
- Scale: NTS / FIELD OPEN.
- Node/anchor legibility: PASS; the caption is explicitly tied to `RELATION ANCHOR`.
- Interaction: N/A.
- Narrative: PASS; figure semantics and evidence state are read as one object.
- Professional finish: KEEP for reusable training calibration, not project MAIN.

## Failure knowledge

1. Caption existence does not prove evidence binding.
2. A distant disclaimer can leave the visual over-authoritative even when the wording is technically correct.
3. Moving all metadata next to the figure can over-correct into a dashboard. Evidence communication still needs visual hierarchy.
4. If truth state changes interpretation, keep the decisive boundary adjacent and route only secondary detail elsewhere.
5. A claim-bearing detail should have an explicit visual relation to its caption through `figure_id`, local label, callout, or stable anchor.

## Transfer rule

`FIGURE → FIGURE_ID / SOURCE CLASS → CLAIM → SUPPORT SCOPE → DOES NOT PROVE → FIELD / TRUTH STATE`

Distance read: evidence metadata must not steal the hero role.

Near read: evidence class and interpretation boundary must be unambiguous.

## Boundary

This practice uses abstract vector geometry and no real C04 site pixels or field measurements. It does not alter C04 Authority, FIELD status, engineering status, or promotion state.
