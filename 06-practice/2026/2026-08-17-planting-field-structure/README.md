# Planting Field Structure First — 2026-08-17

Status: **CANDIDATE / POST-REVIEW PASS FOR PRACTICE**

## Question
How can a planting plan remain information-rich without reading as an equal-weight species scatter?

## Candidate rule
**FIELD STRUCTURE FIRST → SPECIES DETAIL SECOND.**

For concept/presentation planting drawings, establish three visual roles before increasing species-level detail:
1. `MATRIX / continuity`
2. `STRUCTURAL / rhythm`
3. `SEASONAL ACCENT / punctuation`

This is a compositional/graphic rule, not a horticultural prescription.

## Verification
A deterministic A/B used the same path geometry and identical mark count. Only the organization changed from equal scatter to role-based field structure. First-read and near-read were both reviewed.

The first export was rejected after visual readback because an invalid SVG vertical path command produced long unintended lines. The v2 geometry fixed the command and was re-rendered. Therefore `EXPORT SUCCESS + GRAPHIC GEOMETRY ERROR = DESIGN FAIL / REVISE` remains explicit.

## Transfer boundary
This practice does not prove species suitability, density, spacing, soil, moisture, sunlight, mature spread, ecological performance, maintenance cycle, or C04 field conditions. Do not copy High Line species or visual style without site evidence.

## OLEANDER transfer
C04 R02 vegetation: preserve source-grounded vegetation evidence, but avoid equal botanical-symbol fields. Test landscape field / structural vegetation / seasonal or interpretive accent hierarchy, then perform real project readback.
