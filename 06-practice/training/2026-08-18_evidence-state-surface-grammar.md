## Failure knowledge

1. **Polish flattening:** equal cards, equal borders and equal completion cues can visually upgrade a HOLD slot into apparently mature evidence even when the footnote is technically correct.
2. **Magnitude contamination:** opacity, mark length, area, route geometry or bar height cannot be casually reduced to mean lower evidence confidence when those channels already carry quantity or topology.
3. **Remote-label failure:** evidence state that exists only in paragraph text or a remote legend fails first-read truth.
4. **Proxy completion:** drawing a plausible map/chart mark inside a HOLD panel to preserve visual rhythm manufactures evidence.
5. **Opposite overcorrection:** provenance styling can become so strong that viewers read evidence status before the analytical question; evidence state is secondary unless it is itself the question.

## Repair method

- Separate `ANALYTICAL OBJECT` from `EVIDENCE STATE` before styling.
- Keep quantitative/spatial marks invariant.
- Put maturity on an orthogonal carrier: rail, boundary, slot, glyph, line pattern or explicit status token.
- Preserve HOLD/UNKNOWN slots without proxy values.
- Run `label-off evidence readback`: maturity must remain distinguishable without words.
- Run `state-off analytical readback`: remove provenance styling and confirm magnitude/topology remains unchanged.
- Run grayscale/compact readback so hue is not the only evidence-state channel.
