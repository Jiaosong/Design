## Failure knowledge
1. `No loss` does not mean `same order / same line count / same above-fold content`.
2. Global type shrink is not responsive recomposition; it transfers density cost to legibility.
3. Deleting evidence is not a valid density repair; defer/reorganize it instead.
4. Progressive disclosure must not hide safety/status/truth information that changes interpretation.
5. Shortening a title is invalid if it changes the claim; change measure/order before changing meaning.
6. Enlarged artboard review can hide mobile type failure; native-width readback is mandatory.
