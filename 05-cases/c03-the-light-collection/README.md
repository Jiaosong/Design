## 1｜项目是什么

「The Light Collection」是一项以 Reno 产品语境为背景的独立 CMF 概念研究。

重点探索：

- Color；
- Material；
- Finish；
- 光线与表面关系；
- 产品视觉表达；
- 概念如何进一步进入样品验证。

当前已经完成概念与视觉化，但还没有完成真实样品测试。

---

## 2｜为什么不能把“视觉化完成”写成“产品完成”

CMF 项目很容易出现一个典型误区：

> 渲染看起来成立 → 默认材料、工艺、颜色和量产效果也成立。

但真实 CMF 需要继续面对：

- 材料真实反射；
- 表面纹理；
- 颜色偏差；
- 工艺可行性；
- 触感；
- 不同光环境；
- 批次稳定性；
- 样品与屏幕显示差异。

因此当前状态明确保持：

> **PORTFOLIO CONCEPT / VISUALIZED / SAMPLE TEST PENDING**

## 4｜设计母语：把“光的时间感”转成 CMF 系列规则

现有项目不是先定四个颜色，再给它们补故事，而是从“光”作为共同母语出发。

当前概念把一天中不同的光感拆成四类表面状态：

- 晨光：柔和、低对比、轻暖；
- 暮色：温暖、带更明确的色温变化；
- 雾面：克制、低反射、柔化边界；
- 流动反射：具有方向性和更明显的动态光感。

项目试图把这些感受进一步转成可以讨论的 CMF 变量：

~~~text
Hue
+ Value / Lightness
+ Saturation
+ Transparency
+ Reflection
+ Texture Direction
~~~

也就是说，概念不是“给颜色命名”，而是建立一个可以从情绪语言进入材料与表面设计的规则系统。

---

## 5｜色彩系统：Palette as Time

现有色彩逻辑以低饱和中性色为基础，并引入：

- 暖金；
- 晨雾蓝；
- 暮光棕；
- 冷调银白／雾面方向。

已经存在的命名方向包括：

- `Morning Glow`；
- `Twilight Warmth`；
- `Mist Dance`。

项目同时记录了第四类“流动／冷光反射”方向，但当前公开文本没有给出一个稳定的独立系列名，因此这里不补造名称。

每个方向不只定义一个主色，而是要求至少考虑：

- 主色；
- 伴随色；
- 反射倾向；
- 材料参考；
- 光照条件下的变化范围。

这避免了概念板和真实产品表面之间完全脱节。

---

## 6｜Material & Finish：从 Mood 到可讨论工艺路径

当前设计把视觉意象拆成以下层次：

~~~text
Substrate
→ Base Color
→ Translucent Layer
→ Micro-texture
→ Local Reflection
~~~

这一结构的目的不是声称已经确定量产工艺，而是把“想要这种光感”改写成后续可以被样品、工艺和工程团队验证的语言。

现有设计关注：

- 基材关系；
- 底色；
- 半透明层；
- 微纹理；
- 局部反射；
- 纹理方向；
- 边缘反射；
- 冷暖与明暗在不同光源中的变化。

因此当前正确表述是：

> **Manufacturing discussion path exists; manufacturing proof does not.**

---

## 7｜系列化：One Language, Multiple Temperatures

当前输出被记录为：

> **Four-direction series proposal**

系列感主要来自共同规则：

- 相同或兼容的产品轮廓基础；
- 统一的反射逻辑；
- 相对细腻的触感方向；
- 同一“光”概念母语。

方向差异则主要来自：

- 冷暖；
- 明暗；
- 纹理密度；
- 透明度；
- 局部反射方式。

因此项目评价重点不是“哪一个颜色最好看”，而是：

> **四个方向是否既能被辨识为同一系列，又存在足够明确的体验差异。**

## 9｜下一阶段 Sample Validation 应该回答什么

现有公开文本已经明确下一步需要进入：

- 实体色板；
- 不同光源环境；
- 耐磨测试。

进一步来说，当前设计真正需要验证的是：

### Color
- 数字色与实体色差；
- 不同色温光源下的偏移；
- 低饱和色是否仍保持区分度。

### Material
- 透明／半透明关系是否可实现；
- 表面是否产生预期层次；
- 触感与视觉是否一致。

### Finish
- 微纹理方向是否真的改变光感；
- 局部反射是否过强或过弱；
- 边缘反射是否符合系列语言。

### Durability
- 耐磨后颜色与纹理如何变化；
- 表面处理是否容易出现不可接受的使用痕迹。

其中前三类是当前设计逻辑自然推导出的验证问题；具体测试参数、材料规格与工程阈值在现有仓库中尚未闭合，因此不能在这里伪造。

## 13｜Human–AI 协作价值

这个项目适合验证 AI 在 CMF 场景中的正确角色：

### AI 可以帮助
- 趋势与竞品资料整理；
- 色彩／材料方向发散；
- 方案比较；
- 视觉模拟；
- 表达结构；
- 测试计划整理。

### AI 不能替代
- 实际材料样品；
- 工艺验证；
- 真实颜色测量；
- 触感判断；
- 量产与工程验证。

这体现了 OLEANDER 的一个重要边界：

> **Simulation ≠ Physical Validation**
