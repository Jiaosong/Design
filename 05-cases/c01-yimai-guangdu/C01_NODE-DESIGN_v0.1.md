# C01｜一脉广渡｜各节点设计 v0.1

Status: `PROPOSAL / SITE VALIDATION REQUIRED`
Evidence: `E2 unchanged`
Date: `2026-08-11`

## Purpose

This file marks the transition from evidence preflight into node-level design prototyping. It does **not** claim site validation, implementation approval, heritage approval, fixed dimensions, capacity, fire-safety clearance, property rights, or installation permission.

The node system is designed as a sequence of **relationship behaviors**, not a set of scenic objects. Information is separated into `FACT / SOURCE CLAIM / LOCAL NARRATIVE / DESIGN QUESTION / UNKNOWN`. Physical intervention follows a reversible-first hierarchy: digital → handheld → movable independent media → temporary non-contact media → fixed installation deferred.

Main reading sequence:

`enter village → environment & production → ritual order & education → family memory → everyday life → shared intangible-heritage practice`

Mountain route remains a seasonal / conditional extension rather than a default main-loop requirement.

## 01｜Village entrance / 广渡启卷处

**Relation:** visitor → rules, route and evidence state → enters a living village rather than a completed scenic zone.

**Behavior:** arrive → locate self → identify available route → read minimum village rules → choose main/extension route → open 寻脉册 → carry first question onward.

**v0.1 media:** digital entry page, route status, public/living/reservation/closed-space legend, lightweight handheld booklet.

**Rejection condition:** if no safe stopping point exists, move the entry experience to pre-arrival digital reading + lightweight on-route confirmation.

## 02｜大公殿 / 田园水口课堂

**Relation:** historic building + water-mouth + stream + fields + production explain how environment supports village life.

**Behavior:** read the setting at distance → find water/field/road/building relations → choose one environmental clue → judge its role → read minimal source context → record one environmental conclusion.

**v0.1 media:** mountain-water-field-building observation card; layered mobile map; production-boundary reading.

**Rejection condition:** if the building and water/field system are not continuously legible from public visitor space, split this into separate environment and building nodes.

## 03｜牌坊 / 礼序路径

The project must not treat “the archway” as one abstract object. v0.1 preserves three objects: P1 上马石, P2 八股厅前, P3 大爿地.

### C1｜single-object deep reading

`approach → first noticing → choose one physical clue → separate I see / source says / I infer / I do not know → form one question`

Output: one four-column evidence card + one revised judgment.

### C2｜three-object comparison

Compare P1/P2/P3 by figure, location, material/ornament clues, public naming and surrounding relationship. The goal is not memorization but identification of similarities, differences, source conflicts and unknowns.

### P1

Lead C1 object + C2 starting candidate. If stopping is unsafe, move deep reading away from the object or onto digital media.

### P2

Transition role: `ritual order → education`. It should be read together with 八股厅. If there is no natural/safe spatial continuity, retain only cognitive/digital continuity.

### P3

Evidence-incomplete comparison object. Missing evidence must remain visible. If ordinary visitors cannot find or publicly access it, `NOT FOUND / INACCESSIBLE` becomes a design result; no generated substitute image is allowed.

## 04｜八股厅 / 书香研学室

**Relation:** education tradition → observation, questioning, discussion, writing, revision → contemporary learning behavior.

**Behavior:** building reading → choose a question → small-group discussion → leave a judgment → compare with source → revise.

**v0.1:** dual-mode course system. If indoor use is possible, all furniture/media remain movable and non-invasive. If indoor use is impossible, the same course can migrate to nearby safe public space or digital/handheld form. `20–30 people` remains a planning hypothesis, not verified capacity.

**Rejection condition:** if stable community use would be disrupted, cancel dedicated classroom occupation and use community-priority + reserved/off-site learning.

## 05｜毛氏宗祠 / 一村记忆档案

**Relation:** lineage history + family memory + contemporary life → authorization, juxtaposition, revision and withdrawal → living public memory.

**Archive layers:** public facts / family-authorized material / parallel narratives / revision history.

**v0.1:** movable archive boxes, digital archive interface, rotating small archive window; no full-wall final narrative.

**Rejection condition:** without authorization and withdrawal mechanisms, only already-public and verifiable material can be displayed.

## 06｜八角井 / 生活水脉庭

**Relation:** well → water use / production / family labor / neighborhood exchange / maintenance → everyday life as culture without turning it into consumption spectacle.

**v0.1:** no wishing-well or photo-op treatment. Prioritize safety, resident circulation, low-position/handheld reading, and `past / present / unknown` separation.

Public official naming currently supports `广渡八角井`; other names remain source-specific aliases until closed by better evidence.

**Rejection condition:** if visitor stopping interferes with residents, convert to pass-through reading + later reflection.

## 07｜古巷民居 / 生活边界阅读 (working definition)

**Relation:** outside visitor → recognizes public / semi-public / private boundaries → learns how to walk through an inhabited village.

**Four states:** public passage / public short stop / explicit permission required / private-do-not-enter.

**v0.1:** boundary legend, mobile scenario cards, lightweight direction cues. Do not assume every household receives a sign; do not turn the lane into a commercialized visitor street.

**Rejection condition:** if a route depends on entering private courtyards or photographing residents, remove that segment from the public experience.

## 08｜手狮空间 / 非遗共创工坊

**Relation:** inheritor + learner + materials + embodied movement + group coordination → knowledge completed through shared practice, not spectator performance.

**v0.1:** mobile workshop model, not a fixed hall/stage assumption. `30 min / 60 min / half-day` remain course-architecture hypotheses.

Teaching content, who may teach, what can be public, commercial authorization and compensation must be reviewed by the inheritor / confirmed teachers. The design team does not invent a standard action syllabus.

**Rejection condition:** without inheritor review and authorization, this node may only present public background + reservation placeholder, not technical teaching.

## 09｜嵩峰山 / 山地延伸线路

**Relation:** mountain environment → season, risk, physical demand, production and ecological limits → visitor understands landscape as a governing system, not scenery.

**v0.1:** open/closed status, digital route card, exit logic, risk explanation.

**Rejection condition:** if ordinary visitors cannot safely identify the route without local-person dependence, keep it non-default / reservation-only.

## 10｜嵩峰寺 / 山线文化节点

**Relation:** religious/historic space + mountain setting + current-use rules → respectful reading rather than summit check-in.

**v0.1:** determine permitted mode of entry before cultural reading. If closed, public exterior/environmental reading must still allow route completion.

## Node interfaces

- entrance → 大公殿: `how do I enter? → why did the village form here?`
- 大公殿 → 牌坊: `environmental order → human ritual order`
- 牌坊 → 八股厅: `ritual order → learning`
- 八股厅 → 宗祠: `public education → family memory`
- 宗祠 → 八角井: `formal archive → everyday life`
- 八角井 → 古巷: `one living node → village-wide living boundaries`
- 古巷 → 手狮: `respecting other people's life → being permitted to participate`
- 手狮 → entrance/digital feedback: `participation → feedback and re-entry`

## Gate to v0.2

v0.2 requires the design to survive five tests:

1. each node has a genuinely different first reading unit;
2. each node causes an observable visitor action rather than passive reading;
3. each node output connects to the next node;
4. the mechanism still works after traditional decorative symbols are removed;
5. if site evidence contradicts the preflight assumption, the design has a clear downgrade, relocation or rejection path.

No evidence-level upgrade is claimed by this file.
