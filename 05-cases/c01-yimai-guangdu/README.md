# C01｜一脉广渡

**Design Research · Culture · Spatial**

「一脉广渡」是一项以文化研究与空间设计为主要维度的个人研究型设计提案。这个页面用于呈现项目如何从研究线索进入设计判断，并记录概念、空间关系、推演过程与当前证据边界。

它不是一个以“完成效果图”为终点的展示条目，而是一项持续整理中的设计研究：哪些判断来自已有资料，哪些仍属于设计推断，哪些结果还需要进一步验证，都应在项目记录中保持可区分。
