# C01｜一脉广渡

**Design Research · Culture · Spatial**

**Current public state:** `RESEARCH + PROPOSAL / EVIDENCE REVIEW`

---

## 1｜项目是什么

「一脉广渡」是一项以文化研究与空间设计为主要维度的个人研究型设计提案。

这个项目关注的不是“先做一个视觉概念，再补故事”，而是：

> **文化线索、对象证据、空间关系、使用路径和地方解释权，如何真正进入设计判断。**

项目当前仍处于研究与提案并行阶段，因此仓库刻意保留：

- 已有事实；
- 可支持判断；
- 设计推断；
- 缺失证据；
- 尚未执行的现场／参与者验证。

它不是一个以效果图完成度作为唯一终点的案例。

---

## 2｜为什么这个项目适合观察 OLEANDER

C01 是一个典型的“研究与设计不能分家”的长期项目。

它要求系统同时处理：

- 文化资料与公开来源；
- 空间对象与路径关系；
- 方案转译；
- 原型；
- Reality Gate；
- Human Test 前置条件；
- 证据不对称；
- 设计表达与事实边界。

因此它更适合验证：

**Evidence → Interpretation → Design Decision → Prototype → Validation**

而不是单纯验证生成质量。

---

## 3｜核心问题

当前最重要的问题不是“能否再设计一套导览”，因为公开资料已经表明广渡此前存在导览设施、调研与多轮高校规划设计介入。

更准确的问题是：

> **能否在既有系统之上，形成可追溯的证据分层、对象比较、自主问题、文化解释权与后续责任链？**

这个问题直接影响项目是否只是“重复做已有内容”，还是形成新的设计价值。

---

## 4｜整体体验结构：从“景点列表”转向“关系行为序列”

C01 当前不是把村庄拆成一组供游客打卡的景点，而是把节点定义为不同的**关系行为**。

主阅读序列为：

~~~text
进入村庄
→ 环境与生产
→ 礼序与教育
→ 家族记忆
→ 日常生活
→ 共同非遗实践
→ 反馈 / 再进入
~~~

山地线路被保留为**季节性 / 条件性扩展**，而不是默认主环必须完成的内容。

当前节点结构：

| Node | 工作名称 | 核心关系 | 当前介入方向 | 关键 HOLD |
|---|---|---|---|---|
| 01 | 广渡启卷处 | 游客 ↔ 路线 / 规则 / 证据状态 | 数字入口、路线状态、轻量手册 | 安全停留点 |
| 02 | 大公殿 / 田园水口课堂 | 建筑 + 水口 + 溪流 + 田地 + 生产 | 环境关系观察卡、分层地图 | 公共空间连续可读性 |
| 03 | 牌坊 / 礼序路径 | P1/P2/P3 独立对象 ↔ 礼序阅读 | C1 单对象深读、C2 三对象比较 | 身份映射、停留安全、证据不对称 |
| 04 | 八股厅 / 书香研学室 | 教育传统 ↔ 当代观察 / 提问 / 修订 | 可移动双模式课程 | 室内使用、容量、消防等 |
| 05 | 毛氏宗祠 / 一村记忆档案 | 家族记忆 ↔ 授权 / 修订 / 撤回 | 可移动档案盒、数字档案 | 授权与撤回机制 |
| 06 | 八角井 / 生活水脉庭 | 井 ↔ 日常用水 / 劳作 / 邻里 | 低位／手持阅读、过去/现在/未知 | 当前使用与停留冲突 |
| 07 | 古巷民居 / 生活边界阅读 | 访客 ↔ 公共 / 半公共 / 私密边界 | 四级边界图例、场景卡 | 居民共审、实际通行条件 |
| 08 | 手狮空间 / 非遗共创工坊 | 传承人 + 学习者 + 材料 + 身体动作 | 移动式工作坊、预约与权限接口 | 谁可教、公开范围、商业授权、报酬 |
| 09 | 嵩峰山 / 山地延伸线路 | 山地环境 ↔ 季节 / 风险 / 体能 | 路线状态、退出逻辑、风险说明 | 普通游客独立识路能力 |
| 10 | 嵩峰寺 / 山线文化节点 | 宗教／历史空间 ↔ 当下使用规则 | 先确认进入方式，再进行文化阅读 | 开放状态与使用规则 |

这套结构的核心不是“每个节点都做一个装置”，而是保证每个节点都有：

- 不同的第一阅读单位；
- 可观察的游客行动；
- 对下一节点有意义的输出；
- 在装饰符号被拿掉后仍成立的机制；
- 当现场证据推翻假设时，可以降级、迁移或取消。

## 5｜介入原则：Reversible-first

在场地、遗产、产权、运营和授权证据尚未闭合时，C01 的物理介入遵循：

~~~text
Digital
→ Handheld
→ Movable independent media
→ Temporary non-contact media
→ Fixed installation deferred
~~~

这意味着当前阶段优先验证**阅读关系和行为机制**，而不是提前制造固定设施。

例如：

- 如果入口没有安全停留点，入口体验可以迁移到到达前数字阅读 + 路上轻量确认；
- 如果八股厅不能稳定占用，课程可以迁移到附近安全公共空间或数字／手持形式；
- 如果游客停留影响八角井周边居民使用，节点应降级为经过式阅读；
- 如果古巷体验依赖进入私人庭院或拍摄居民，该路线段应直接移出公共体验；
- 如果手狮教学权限没有得到传承人／确认教师审核，只能保留公开背景与预约占位，不得自行编造标准动作课程。

## 6｜从 v0.1-A 到 v0.1-C：原型不是“做出来就算通过”

早期 v0.1-A 原型能够运行，但没有直接晋级，因为 adversarial review 暴露了测量污染问题：

1. booklet 可以用静默空白完成；
2. entry prototype 可以在没有明确路线／边界判断时导出；
3. C1 首屏提前暴露来源信息，污染第一反应；
4. C2 在自由比较前提前暴露对象身份与比较维度。

v0.1-B 因此引入：

- staged lock：提交后锁定早期答案；
- 时间戳与阶段时长；
- `ABSENT_EXPLICIT` / uncertainty / rejection 等明确空值状态；
- spontaneous first read 与 prompted evidence classification 分离；
- participant raw JSON 与 researcher coding 分离；
- C2 P1/P2 AB/BA 随机化；
- P3 缺失证据保持 `EVIDENCE GAP`。

v0.1-C 又把这套 node grammar 扩展到 N04–N08，并在回归中修复了手狮权限问题：不能强迫参与者选择“应付费劳动类别”，必须保留 `不确定 / 需传承人确认`。

当前结论仍只是：

> **DRY-RUN PASS / NODE-GRAMMAR REGRESSION PASS**

不是 Human Test PASS。

## 7｜P01–P06：项目如何从研究进入专业表达

当前 Representation Execution Plan 不要求六页采用同一种视觉风格，而要求它们来自**同一关系世界、同一证据边界**。

| Page family | 要回答的问题 | 当前重点 |
|---|---|---|
| P01 Village World | 项目进入的是怎样一个真实、有人居住的村庄世界？ | 关系级 master / axon，暂不伪造测绘精度 |
| P02 Relation Cuts | 哪些地方存在生活、访客、排水、阈值、村田边界冲突？ | Threshold / Lane / Well / Drainage / Edge / Resident-visitor cuts |
| P03 Intervention | 哪里真的需要介入，介入强度可以到哪里？ | Z0–Z4 intervention classes |
| P04 Experience | 一个真实体验如何发生？ | Arrival → Threshold → Reading → Everyday overlap → Hand Lion → Return |
| P05 Deep Nodes | 哪些关键节点需要真正深化？ | N01 Entry+Return / N07 Boundary / N08 Mobile Workshop |
| P06 Time & Operation | 同一空间在不同状态下怎么工作？ | ordinary / event / rain / night / permission OFF / maintenance withdrawal |

当前硬规则是：

> **SAME PROJECT ≠ SAME LOOK**

视觉方式由问题决定，但项目连续性必须来自对象 ID、证据语法、同一世界几何与来源绑定。

## 8｜当前真正的下一生产里程碑

当前项目不缺新的“方法论页面”。下一步更具体：

> **建立第一个 source-bound `C01-WORLD-REMOTE-RELATION` 世界关系资产，并完成 P01 / P02 readback。**

在现场尚未执行前，可以继续：

- source / GIS / image inventory；
- relation-level base world；
- confidence / current-change layer；
- P01 relation-world prototype；
- P02 relation-cut source binding；
- P03 Z0–Z4 overlay；
- P04 shot / scene contracts；
- P06 state contracts。

仍需 HOLD：

- 实测宽度、标高、坡度；
- 当前排水；
- 正式遗产保护边界；
- 固定介入几何；
- 无障碍／消防／容量；
- N08 真实 host / capacity；
- 夜间运营照明；
- 居民／传承人许可与共审；
- 现场表现。

`PENDING CAPTURE`

仍需要真实采集／确认，不能把缺失基线当成已完成。

### A1｜受控讲解
`KEEP AS CONTROL`

作为对照条件保留。

### B｜证据阅读
`KEEP`

继续作为核心验证路径。

### C1｜单坊深读
`KEEP / LOW-RISK SINGLE-OBJECT PATH`

适用于单对象、低风险的深读路径。

### C2｜多坊比较
`KEEP AS LEAD EXTENSION / EVIDENCE ASYMMETRY MUST REMAIN VISIBLE`

保留多对象比较，但不允许为了版式“看起来完整”而伪造对称证据。

## 6｜三牌坊证据边界

R04 进一步锁定：

- P1 / P2 / P3 必须独立处理；
- 官方记录中的通用名称 `广渡节孝牌坊` 不能在缺少正式对象映射时自动分配给其中某一座；
- P1 / P2 / P3 的图像证据当前并不对称；
- 缺失照片不能通过生成、误配或替换来“补齐”。

这类约束体现了 OLEANDER 的一个核心原则：

> **视觉完整性不能高于事实完整性。**

## 7｜Human–AI 协作在这里如何分工

### AI 适合承担
- 公开资料整理；
- 对象关系梳理；
- 方案比较；
- 原型结构；
- 测试材料准备；
- 证据冲突提示；
- 文档、图示与执行支持。

### Human 保留
- 文化解释权相关判断；
- 对象身份确认；
- 关键设计取舍；
- 是否进入现场／参与者验证；
- 最终专业判断与晋级决定。
