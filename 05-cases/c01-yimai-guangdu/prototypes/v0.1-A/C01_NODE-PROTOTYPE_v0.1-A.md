## Purpose

This round does not add more scenic-node concepts. It establishes four reusable prototype contracts that all later C01 nodes must inherit:

1. `《广渡寻脉册》` — cross-node record and revision tool;
2. `村口数字启卷` — entry, boundary and route-state interface;
3. `P1 / C1 单对象深读` — evidence-reading contract;
4. `P1/P2/P3 / C2 三坊比较` — comparative-reading contract with visible evidence asymmetry.

The prototypes remain Chinese-first. They are not final UI, public content, installation drawings or site evidence.

## Shared evidence syntax

All four prototypes distinguish:

- **事实** — currently supportable public fact;
- **来源叙述** — attributed source claim that may still require first-hand verification;
- **设计提问** — a question used to advance observation or verification, never a historical conclusion;
- **未知** — evidence gap, site condition not run, or object mapping not closed.

`地方口述` is not pre-populated in this round. It can enter later only with appropriate attribution, context and rights handling.

## Prototype 01｜《广渡寻脉册》

The booklet is not a stamp-collection or souvenir system. Each node produces one reusable output:

- 村口：路线选择 + 边界确认；
- 环境与生产：一条环境关系判断；
- P1 C1：一张四栏证据卡；
- C2：一条跨对象比较；
- 八股厅：一条被来源修订的学习判断；
- 宗祠：一条来源 / 权利判断；
- 八角井：过去 / 现在 / 未知；
- 古巷 / 手狮：边界判断 + 下一次参与需要谁许可。

Success is not measured by pages completed. The later test should ask whether the output can be reviewed, revised, compared or carried into the next node.

## Prototype 02｜村口数字启卷

First-reading question:

> 我现在进入的是谁的生活空间？

The interface must establish, before cultural storytelling:

- current location / arrival state;
- `公共通过 / 生活空间 / 预约 / 当前关闭`;
- main loop versus conditional mountain extension;
- three baseline behavior rules: do not assume private access, do not interfere with production/resident passage, and keep UNKNOWN visible.

If the site has no safe entry stopping point, this prototype downgrades to pre-arrival digital reading + lightweight route confirmation. It must not justify a fixed gateway installation.

## Prototype 03｜P1 / C1 单对象深读

Working object: `P1｜上马石 / 徐氏贞孝牌坊`.

Fixed sequence:

1. free first read before full story;
2. choose one visible clue;
3. classify into `我看到 / 来源说 / 我推测 / 我不知道`;
4. reveal minimal attributed source information;
5. state what changed in the participant's judgment;
6. leave one open question that cannot be answered immediately at the object.

Current source handling:

- official public material supports the existence of an object named `广渡贞孝牌坊` in regulatory inspection context;
- local/source material maps P1 to the 上马石 / 徐氏 object and supplies chronology/details as source claims;
- formal heritage ID, exact protection boundary, current stopping safety and full first-hand closure remain outside this prototype.

Candidate success conditions: at least one direct observation, a clear separation between observation and source claim, one explicit unknown, one explainable revision, and a final question more specific than “这是什么”.

## Prototype 04｜P1/P2/P3 / C2 三坊比较

First-reading question:

> 同类纪念对象为什么因人物、地点、物证与今天的解释权而产生不同意义？

Comparison dimensions are locked to:

- 人物；
- 位置；
- 物证；
- 来源；
- 解释权；
- 证据完整度。

Evidence asymmetry is intentional and must remain visible:

- P1 has relatively complete visual/source support;
- P2 has contextual village imagery but its formal one-to-one mapping with the generic official `广渡节孝牌坊` remains unresolved;
- P3 remains the weakest full-space record and its object-to-official-record mapping is UNKNOWN.

P3 must never be visually “completed” with P1/P2 imagery or generated imagery.

**C2 failure condition:** if the result only says that the three objects differ in size, color, ornament or appearance, and does not reach person/institution/location/source/interpretation-right differences, C2 fails.
