The current project does not need another research dashboard or a fixed visual template. It needs one credible village world that can survive repeated transformation into analysis, intervention, experience, technical-node and operational-state representations.

`CURRENT C01 AUTHORITY → REMOTE PROXY / CURRENT CHANGE EVIDENCE → RELATION-LEVEL WORLD → DECLARED REDRAW OPS → FIGURE-SPECIFIC NATIVE OUTPUT → ACTUAL READBACK → REVISE/HOLD → BOARD SELECTION`

This plan does **not** claim that the requested final figures have already been rendered. It defines the current executable work and the exact HOLD boundaries that prevent false precision.
