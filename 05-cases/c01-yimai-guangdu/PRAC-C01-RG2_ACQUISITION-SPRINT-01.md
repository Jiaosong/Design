## 3｜Acquisition Channel B｜最低成本本地代理采集

不要求专业摄影师。优先由村级联系人、当地志愿者或既有合作团队使用手机 + 卷尺/激光测距完成一次 30–45 分钟受控采集。

### 每座对象的强制三视段

#### S1｜Approach

- 从真实主要接近方向连续拍摄 20–40 秒；
- 从牌坊尚未可见开始，到牌坊成为第一阅读单元结束；
- 保留自然行走速度，不剪辑；
- 同时拍入道路、路缘/边沟、来车、行人、停车与遮挡；
- 记录首次看见牌坊的位置 GPS、朝向和时间。

#### S2｜Front + Read

- 正面完整对象静止视频 10–15 秒；
- 1 张完整正面、1 张题额、1 张典型浮雕/构件、1 张基座与道路交接；
- 记录拍摄距离、镜头倍率、是否需要站入车行空间才能看清；
- 不触摸、不攀爬、不在本体固定尺度物。

#### S3｜Pass / Leave

- 沿同一行走方向越过或绕过对象，连续 20–40 秒；
- 越过后回望一次；
- 记录背面、下一节点方向、道路连续性、停留位置与车辆冲突。

### 文件必须保留

原始视频和照片不得经微信压缩后作为唯一母本；至少保留原文件 EXIF / 创建时间。文件名固定：

`P{1|2|3}_YYYYMMDD_HHMM_S{1|2|3}_{approach|front|leave}_RAW.ext`

## 4｜Acquisition Channel C｜道路 + 人车冲突实测

### 路宽

每座对象至少测 5 个断面：

`A-20m / A-5m / OBJECT / L+5m / L+20m`

每断面记录：

- 硬化路面净宽；
- 可步行边缘宽度；
- 边沟/明沟宽度；
- 障碍物、墙体、护栏、台阶；
- 是否存在车辆会车余量；
- 测量工具、照片和读数同框。

### 人车冲突

首轮不是交通统计研究，而是安全 preflight。每座对象至少完成一个 15 分钟连续观察窗；若可行，再增加早 / 午 / 晚三个窗口。

每次只记录可见事实：

- 小客车 / 货车 / 摩托电动车 / 自行车 / 行人数量；
- 是否出现车辆与观察者争用同一净宽；
- 是否需要观察者后退、贴墙、跨沟或离开观察点；
- 停车是否遮挡对象或通行；
- 冲突发生时间戳及对应视频编号。

**不把 15 分钟结果外推为日交通量。**

## 5｜Acquisition Channel D｜排水、遮阴、停留

### 排水

每座对象记录：

- 道路横坡方向的可见判断；
- 明沟 / 暗管 / 过路管 / 无明显排水设施；
- 雨水入口、堵塞、破损；
- 青苔、泥沙线、冲刷、积水痕迹；
- 牌坊基座是否直接受道路径流影响。

如果不是雨天，只能记 `DRY-DAY OBSERVATION`，不能宣称“无积水问题”。

### 遮阴

首次先做可重复、低成本记录：同一观察点拍一张 360° 或四方向环境照片，并记录时间。条件允许时在 `09:00 / 12:00 / 15:00` 各重复一次；这是时点记录，不等于全年日照分析。

### 停留

不先套一个假定的“标准停留点”。直接记录：

- 实际可以站立而不进入车行流的位置；
- 该位置可容纳的大致人数；
- 是否阻断村民门口、生产、排水或通行；
- 从该点是否能完整阅读对象；
- 若没有安全停留位置，直接记录 `NO SAFE STOP OBSERVED`。

## 7｜Acquisition Channel F｜地方讲述者三角复核

地方复核不能只找一个“最懂的人”盖章。至少形成三个相互独立的来源角色：

### L1｜村级治理 / 当前现实

优先通过 2026 道路项目业主“广渡村集体经济组织”建立当前村级入口。重点确认：

- P1/P2/P3 当地叫法和位置；
- 2026 道路施工是否影响三座对象；
- 当前谁负责文保巡查 / 导览 / 接待；
- 哪些地点允许停留拍摄；
- 能否协调一次受控三视段采集。

### L2｜地方文化讲述 / 记忆

2025 潮新闻正文记录：作者毛长明由村干部 `毛樟屏` 陪同走访三座牌坊；三位女性及牌坊故事由退休老师 `毛井水`、村干部 `毛樟萍` 收集整理。来源内部存在 `毛樟屏 / 毛樟萍` 字形差异，**不得由 OLEANDER 自动判定为同一人或错别字**，需要村级确认身份与当前是否愿意参与复核。

Source: https://tidenews.com.cn/news.html?id=3064717

### L3｜既有研究 / 影像档案

衢州职业技术学院 2022–2024 广渡博士创新站已多次实地调研；2024 报道明确说团队制作宣传手册、宣传片和 13 个宣传视频，艺术设计学院教师何敬、付雪燕曾进入村内进行摄影与文创素材采集。因此应优先请求：

- 旧导览图、道路标、指示牌照片；
- 2022–2024 现场路线资料；

### 复核方式

每位讲述者独立回答后再并表，不先给“标准答案”。每条主张记录：

`claim → speaker role → first-hand / heard / document-based → confidence → conflicting claim → evidence requested → allow attribution?`

出现冲突时保留冲突，不用多数票消除差异。

## 9｜一次现场采集的最小“可过 Gate”包

只有以下全部满足，单个对象的 site-capture 才可从 `NOT RUN` 变为 `CAPTURED / REVIEW PENDING`：

- 同次 S1 / S2 / S3 原始视频；
- 至少 5 个道路断面实测；
- 1 个连续 15 分钟人车观察；
- 排水 / 基座 / 路缘完整照片；
- 遮阴时点 + 方位记录；
- 安全停留位置记录，或明确 `NO SAFE STOP OBSERVED`；
- GPS / 时间 / 朝向 / 采集者 / 设备信息；
- 现场没有触碰或固定介质到文物本体；
- 原始文件未被覆盖、压缩或二次导出作为唯一母本。

对象包通过后仍不等于 `APPROVED`，还需正式文保映射和地方 / 专业复核。
