## Why v0.1-A was not promoted directly

The v0.1-A prototypes were technically runnable but failed adversarial measurement review:

1. the relationship-reading booklet could be completed with silent blanks;
2. the entry prototype could export without an explicit route/boundary judgment;
3. C1 exposed source information on the initial page, allowing later information to contaminate first-read responses;
4. C2 exposed object identities and prompted comparison dimensions before a free comparison.

Therefore v0.1-A remains an early low-fidelity record, not the authoritative participant runner.

## v0.1-B｜Prototype Adversarial Dry-Run

### Measurement contract

- stage submission locks earlier responses;
- each stage records start/lock timestamps and duration;
- silent blanks are replaced by explicit states such as `ABSENT_EXPLICIT`, uncertainty, or explicit rejection;
- spontaneous first reading is separated from prompted evidence classification and facilitated relation probes;
- raw participant JSON remains separate from later researcher coding.

### C1 staged sequence

`SETUP → N0a → N0b → PK → B1 → S1 → C1 → NEXT`

- N0a/N0b: free first read and optional spontaneous question;
- B1: prompted evidence-boundary classification;
- S1: minimal source information only after earlier answers are locked;
- C1: facilitated relation probe, never coded as spontaneous emergence;
- NEXT: optional next verifier / source / node.

### C2 staged sequence

`SETUP → C2-0 → C2-1 → C2-2 → C2-3 → C2-4`

- C2-0: blind free comparison, no background, identity, or preset comparison framework;
- C2-1: location relationship;
- C2-2: object name/category;
- C2-3: minimal source claims;
- C2-4: P3 partial evidence + explicit `EVIDENCE GAP`.

P1/P2 display order is randomized AB/BA. P3 is never filled with another object's image or a generated full-view substitute.

### Recorded adversarial failure

The first regression run failed because the C2-0 instruction said that no name, date, **person**, location, or comparison dimension was provided. Mentioning “person” itself leaked a desired comparison dimension. The prompt was replaced with neutral wording: no background information, object identity, or preset comparison framework. The rerun passed.

### Image-rights boundary

Rights-pending project-source archway photographs are **not committed to this public repository**. v0.1-B binds P1/P2/P3 images locally at runtime through browser file inputs/Object URLs. Exported JSON does not include image bytes or local file paths.

### Dry-run result

- 5 pages × 3 viewport classes: no horizontal overflow / JS errors;
- C1 N0 does not reveal later source material;
- C2-0 does not reveal identity or preset dimensions;
- 40 fresh C2 sessions produced AB 21 / BA 19 in the final randomization stress run;
- explicit no-answer/uncertainty states replace silent blanks.

**Decision:** `DRY-RUN PASS` only.

## v0.1-C｜Node Grammar Expansion

The stable locked/reveal/revise/boundary grammar was expanded to N04–N08 without claiming site facts.

### N04｜八股厅

Tests a simulated availability branch: indoor candidate / unavailable or closed / unknown. The branch is a prototype condition, not a site claim. The learning mechanism must survive if the building cannot be occupied. Community use remains prior; real capacity, fire safety, opening hours and fixed installation remain unresolved.

### N05｜毛氏宗祠

Tests memory rights before exhibition. Family/publication scope, anonymity, revision, withdrawal, conflicting narratives, and cross-media synchronization are explicit actions. The system must execute a family's changed decision rather than persuade the family to keep content public.

### N06｜八角井

Separates historical source narrative, present-day site condition, `UNKNOWN`, and matters visitors should not decide. `广渡八角井` / `八卦井` naming differences remain source-attributed rather than designer-resolved. If stopping interferes with residents, the experience downgrades to pass-through reading / later review.

### N07｜古巷

Uses boundary scenarios before revealing the four-level rule. Options include public passage, short stop without obstruction, permission required, do-not-enter/do-not-shoot, and insufficient information. The prototype tests whether visitors revise their boundary judgment rather than whether they know a rule in advance.

### N08｜手狮

Tests the permission ladder: public visibility does not prove a fixed Guangdu teaching venue or stable course; performance ability does not automatically imply independent teaching authority; course authorization does not automatically grant brand/product commercialization rights. Teaching, review, commercial authorization, assistant labor, and downstream reuse are distinct labor/rights objects.

### Recorded N08 regression failure

The first v0.1-C regression forced participants to select at least one compensated-labor category and omitted an explicit `不确定 / 需传承人确认` branch. This contradicted the D03 inheritor-rights logic. The uncertainty branch was added and the regression was rerun successfully.

### Regression result

- N04–N08: 5 prototypes × 3 viewport classes;
- no horizontal overflow / JavaScript errors;
- N04 uses explicit simulated conditions;
- N05 establishes rights before display;
- N06 preserves UNKNOWN;
- N07 presents boundary scenarios before rules;
- N08 preserves inheritor confirmation and uncertainty.

**Decision:** `NODE-GRAMMAR REGRESSION PASS` only.
