# C01｜v0.2-R0.10–R0.11｜Human Comprehension + Physical QA Protocol

**Status:** `PROTOCOL ONLY`  
**Human Test:** `NOT RUN`  
**Physical Print / Real Device QA:** `NOT RUN`

## R0.10｜Controlled Human Comprehension

The first controlled run should test comprehension, not preference.

Questions:
1. Is the first reading a village object / behavior rather than a research system?
2. Is UNKNOWN understood as a legitimate state rather than a broken interface?
3. In R0-C02, can participants distinguish object difference from evidence-completeness difference?
4. In R0-C03, can pass-through / permission / no-entry be understood as valid outcomes?
5. After source material appears, can participants change, retain or become more uncertain without being forced to revise?

### Proposed first pilot

`5–8 ordinary adult readers` is a proposed controlled-pilot parameter only. It is not an executed sample.

### No-leading rules

- do not explain the Evidence Framework beforehand;
- do not tell participants that UNKNOWN is a desired answer;
- do not imply which archway is more important;
- do not correct premise rejection into a preferred interpretation;
- do not reveal source stories before the staged sequence permits it.

### Response coding

Runner:
`RESPONSE / ABSENT_EXPLICIT / UNCERTAIN / EXPLICIT_REJECTION`

Coding:
`ABSENT / SPONTANEOUS / PROMPTED_NA / AMBIGUOUS / EXPLICIT_REJECTION`

Only `SPONTANEOUS` receives depth 1–3.

These are participant-response states, not Evidence Type or Evidence Level.

## R0.11｜Physical Print / Device QA

### A5

- 148 × 210 mm;
- print at 100%;
- no fit-to-page;
- test at least one color and one grayscale condition.

Check:
- no trim/crop loss;
- body and secondary text remain readable;
- P3 gap is not mistaken for a print failure;
- R0-C03 passage void reads as behavioral space rather than unfinished layout;
- photo crop does not remove relevant contemporary context;
- writing areas are physically usable;
- internal metadata does not overtake first reading.

### Mobile

Minimum target viewports:
- 360×800
- 390×844
- 430×932

Before beta, run on real devices and check:
- virtual keyboard obstruction;
- 125–150% text zoom;
- outdoor / bright-light readability;
- one-hand scrolling and typing;
- no hover-only interaction;
- P3 partial and R0-C03 scenario states remain explicit.

## Promotion boundary

A successful controlled pilot can support only a limited claim of prototype comprehension under the tested conditions.

It does not establish:
- resident acceptance;
- inheritor authorization;
- heritage implementation feasibility;
- site suitability;
- real visitor behavior change;
- local operating viability.
