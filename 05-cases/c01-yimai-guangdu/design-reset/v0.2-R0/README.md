## Why this reset exists

The earlier v0.1-E visual/information system became too system-led. v0.2-R0 reverses the sequence:

`真实对象 / 行为 → 第一阅读 → 停留方式 → 问题 → 必要证据 → 媒介 → 视觉构成 → OLEANDER 后台治理`

OLEANDER governance remains authoritative in the background; public reading must grow from Guangdu's actual objects, contemporary context, evidence gaps, living boundaries and field conditions.
