# PRAC-C01-TRANS-ABC-001｜Participant Protocol v0.2

Verified: 2026-08-10

Status: `ADVERSARIAL-READY PROTOCOL / HUMAN TEST NOT RUN`

This protocol replaces the participant-facing prompts identified as leading in simulated adversarial Round 01. It does not replace the canonical Practice or claim real participant validation.

## Principle

`free response → evidence separation → optional disagreement/exit → optional question → optional continuation → researcher coding after submission`

A participant is allowed to say:

- `I do not know`;
- `my judgement did not change`;
- `I disagree with the premise`;
- `I have no further question`;
- `I do not want a next step`.

These are evidence, not incomplete forms.

## B v0.2｜Evidence Reading

### Participant stage 1 — unlabelled observation

Use the same Zhenxiao Archway photograph. Do not show named hotspots or labels such as `two-column / three-tier`, `inscription layer`, or `modern context` before response.

Ask:

1. `第一眼你注意到什么？`
2. `请只写照片里能直接看到的内容。`
3. `有没有你其实是以前就知道、而不是从照片看到的？`

### Participant stage 2 — source response

After one controlled source statement is shown:

4. `你的判断有没有变化？` → no change / changed / uncertain / reject comparison.
5. `如果变化，什么导致了变化？如果没变化，可留空。`
6. `有没有来源互相冲突，或你认为项目源可能不对？`

### Researcher coding after submission

Researcher may code:

`direct observation / source statement / inference / unknown / prior knowledge / source conflict / local correction`.

Do not insert those professional categories into the first free response.

## C v0.2｜Relation Hypothesis — photo-only

The photo-only prototype does **not** test approach/pass/leave behavior.

Ask:

1. `第一眼你注意到什么？`
2. `这张照片让你想到哪些人、行为、制度或生活情境？也可以写“没有”。`
3. `哪些只是你的猜测，不能从照片确定？`
4. `你还有想继续问的问题吗？` → yes / no / premise rejected / do not want to continue.
5. If yes: free question. If no: leave blank.
6. `如果你真想继续理解，你会去问谁或查什么？不继续也有效。`

Next-step options must include `不继续 / 无下一步` and free `其他`.

### Researcher coding after submission

Only after the response is locked, code whether the participant independently raised:

- person/biography;
- institution/norm;
- daily-life relation;
- evidence/source responsibility;
- local narrator or interpretive authority;
- conflict/rejection;
- maintenance/governance;
- voluntary continuation.

If a concept did not appear spontaneously, do not add it to the participant result.

## C2 v0.2｜Blind Comparison

### Phase 1 — participant blind comparison

Show two object photographs with neutral labels `Object A / Object B`.

Ask:

- `它们有哪些相同或不同？`
- `哪些差异你能从图像确认？哪些只是猜测？`
- `你会不会主动想看第三个对象？`

Do **not** show biography/location/institution/interpretation-right dimensions yet.

### Phase 2 — researcher matrix

After Phase 1 is locked, code spontaneous references to biography, location, material evidence, evidence gaps, institutions and governance/interpretation subjects.

The existing C2 research matrix remains a researcher instrument, not a participant prompt.
