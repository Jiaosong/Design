074 / CH14 / BRAND FOUNDATION / VISUAL REFERENCE

为什么叫
「清江石书」

清江是正文，旅程是阅读；品牌只负责让关系在需要时被看见。

“清江石书”不是给清江附加一个文化主题。清江决定真实主体，石决定时间与材料重量，书决定旅程如何被阅读。品牌不替代景观、路线、服务和现场 authority。

NAME / 01

名称本身就是责任分工

不是四个汉字的文化联想，而是三层稳定关系：真实主体 / 材料时间 / 阅读行为。

POSITION / 03

品牌定位与边界

保留 v5.2 的完整视觉语气，但只留下 P01 真正需要说明的边界；规范性的 Claim→Design 表移到后续视觉语言页。

  • 01连接真实景观、旅程、解释、服务与记忆。
  • 02阅读成为可选深度，而不是完成任务。
  • 03Web / App / Map / Physical 共享同一品牌语法。
  • 04Return / Service 在需要时压过品牌。

IS NOT / THEME PACKAGING

  • ×不是 13/13 强制打卡与完成度系统。
  • ×不是新的路线 / 地貌 / 运营 authority。
  • ×不是仿古纸墨、民族纹样或传统印章皮肤。
  • ×不是用 Logo 遮盖真实清江。
PRINCIPLES / 04

六条不可牺牲的品牌原则

继续保留 v5.2 的长页编辑结构，但不再重复解释品牌资产层级；资产治理移动到后续系统页。

01 / REAL QINGJIANG FIRST

真实清江先成立

景观、尺度、路线和现场不能被品牌效果替代。

02 / JOURNEY BEFORE EXPLANATION

先完成旅程，再增加解释

阅读只在需要时出现，不打断水上、空中、山中的连续体验。

03 / READING OPTIONAL

阅读是可选深度

R01–R13 不是 13 个必须完成的实体任务。

04 / RETURN FIRST

服务与回程先于品牌

关闭、未知、降级时，品牌主动降到 TRACE / OFF。

05 / MATERIAL WITHOUT NOSTALGIA

材料感不等于仿古

矿物、纸纤维、压印和墨密度来自工艺关系，不做古风皮肤。

06 / MEMORY WITHOUT COMPLETION

记忆不是完成度

保留 Trace 和再次识别，不设计积分、徽章和完成百分比。

ARCHITECTURE / 05

运营语境、体验身份与子系统

恩施大清江与清江石书不是同一层；Endorsement / co-brand authority 未正式成立前保持 HOLD。

EXPERIENCE IDENTITY / NOT OPERATOR AUTHORITY

清江石书拥有体验身份，不拥有运营、安全或路线 authority。Journey / Reading / Digital / Physical / Memory 共享身份语法，但分别服从自己的任务和媒介。

DEFINITION / 06

品牌定义

作为 P01 的收束，后续 Logo、综合色、字体和图形系统必须能回到这段定义。

清江石书是一套以真实清江为正文、以旅程为阅读行为、以可选解释为深度、以回程与记忆为闭合的体验身份系统。
QINGJIANG STONE BOOK IS AN EXPERIENCE IDENTITY THAT LETS THE LANDSCAPE REMAIN THE TEXT, THE JOURNEY BECOME THE READING, AND THE BRAND APPEAR ONLY WHEN IT ADDS CLARITY.
