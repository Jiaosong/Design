色彩角色
与完整色彩系统

颜色先服务阅读关系，再形成品牌识别：背景负责让内容安静，深色负责建立场，青色只连接清江关系，朱砂只在记忆与少量提示中出现。

清江石书不以“看见几个品牌色”作为识别目标。真正需要被识别的是：什么是背景、什么是路径与关系、什么只是支持信息、什么值得被记住。品牌色彩与运营状态色彩保持分离。

01 / COLOR SYSTEM

色彩角色

色彩先承担角色，再进入具体值。大面积场、身份色、支持色和记忆色拥有不同权重。

READ Role Before PaletteBOUNDARY 色彩比例是品牌当前的视觉权重，不是跨项目固定公式。
02 / COLOR SYSTEM

核心色彩

所有数字值集中在这里，方便数字产品和设计生产调用。

READ HEX / RGB / HSL / LAB / CMYK candidateBOUNDARY CMYK 与实体色必须通过生产 proof。
03 / COLOR SYSTEM

色阶

色阶服务层级和表面，不创造新的品牌身份色。

READ 100% core colors remain identity anchorsBOUNDARY Tints / shades are support values.
04 / COLOR SYSTEM

色彩组合

直接展示真实标题和文本组合，同时给数字对比比值作为参考。

READ Pairing = hierarchy + legibilityBOUNDARY Ratio 不是整套无障碍证明。
05 / COLOR SYSTEM

Logo 背景矩阵

先选择 Primary / Reverse / Holding Field；复杂背景不通过临时改色解决。

READ Background decides approved assetBOUNDARY High-noise landscape may require LIGHT / TRACE / OFF.
06 / COLOR SYSTEM

色彩与材质场

Gradient、纸纤维、墨密度、石粒分层管理，并保留 Effect-Off。

READ Flat → tonal → paper → ink → stoneBOUNDARY Filter / raster preview never owns geometry.
07 / COLOR SYSTEM

灰度与非色彩冗余

关闭色彩后，排版、形状、间距、标签仍然必须保留主要信息层级。

READ Color-off attack testBOUNDARY Critical meaning cannot depend on color alone.
08 / COLOR SYSTEM

品牌色 ≠ 状态色

P04 只定义品牌色彩；NORMAL / DEGRADED / CLOSED / UNKNOWN 由运营状态系统单独拥有。

READ Identity lane ≠ operational laneBOUNDARY P04 不擅自指定最终状态色值。
09 / COLOR SYSTEM

印刷与实体转换

RGB/HEX 到印刷和材料之间必须经过 proof，而不是数字照抄。

READ Digital → Print → CMFBOUNDARY Pantone 暂不指定；实体 limit sample 仍开放。
