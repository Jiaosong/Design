Typography System

不靠“书法感”制造文化，而是让中文、英文、数字、证据和留白在同一个阅读系统里各自承担正确的工作。

清江石书采用 Contemporary Editorial + Landscape Space：展示层有字形张力，正文层保持稳定阅读，技术层明确区分 ID / 数据 / 状态；品牌字标与编辑字体严格分离。

字体角色

先分 Display / Body / Latin / Technical / Bilingual，再决定具体字号和排版。

READ Role first, family secondBOUNDARY 官方字标始终由 P03 outlined master 拥有。
02 / TYPOGRAPHY

中文字符系统

宋体承担展示与编辑张力，黑体承担连续阅读和功能信息；不做仿古书法。

READ Display Serif + Functional SansBOUNDARY 中文正文 tracking = 0；大字展示只做极轻调整。
03 / TYPOGRAPHY

英文字符系统

Inter Display 与 Inter 分开承担展示和正文，大小写按语言角色工作。

READ Display / prose / short labelsBOUNDARY 英文正文不复制中文的尺度和字距。
04 / TYPOGRAPHY

数字 / 标点 / 符号

数字、单位、R-ID、状态和中英标点进入同一字符压力测试。

READ Editorial + technical character coverageBOUNDARY 最终字符集与授权仍需 release check。
05 / TYPOGRAPHY

字重与大小写

字重用于层级，大小写用于语言与系统语义；不能把 ALL CAPS 当万能风格。

READ Weight = hierarchy / Case = language logicBOUNDARY 官方英文 wordmark 不由字体重新打字。
06 / TYPOGRAPHY

字级系统

给出 Desktop / Mobile 当前 token，并明确响应式不是按比例缩小。

READ C04 web calibrationBOUNDARY A1、纸面、空间和可访问条件必须重新校准。
07 / TYPOGRAPHY

中英双语层级

中文保持第一阅读，英文承担解释与国际阅读；两套脚本不强求等权。

READ Chinese first-read / English second-readBOUNDARY 不强求相同行数、字距或居中方式。
08 / TYPOGRAPHY

正文行长与节奏

直接展示过宽正文与控制 reading band 的差别。

READ Measure before decorative hierarchyBOUNDARY 28–34 CJK / 58–66ch 仅为当前项目 calibration。
09 / TYPOGRAPHY

网格与构图

网格控制关系，不把页面变成等权卡片墙；Dominant Field 保持第一视觉。

READ Grid ≠ equal boxesBOUNDARY 留白属于阅读路径。
10 / TYPOGRAPHY

响应式与媒介

Desktop、Mobile、Print 是同一身份语法下的不同 typesetting instance。

READ Same grammar / different instanceBOUNDARY px 不直接换算 pt；印刷必须 proof。
11 / TYPOGRAPHY

错误用法

每一种常见排版错误都真实画出来，而不是只列禁用条款。

READ Rule → FigureBOUNDARY 不以“文化感 / 高级感 / 统一感”破坏可读性。
