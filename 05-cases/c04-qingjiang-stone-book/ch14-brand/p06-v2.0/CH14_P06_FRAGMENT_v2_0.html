图形语言
从地图中长出来

不是再画一条“像清江的线”，而是让已经成立的清江路线关系，同时成为品牌图形语言的来源。

ROUTE-03 保持唯一地图权威。LINE、TRACE、节点挂接和 Return 关系全部从它派生；Stone Seal 只负责身份锚点，PAGE 只负责打开阅读。品牌可以变轻、退场，但不能重新定义路线。
