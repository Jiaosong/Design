076 / CH14 / P03 / BRAND STANDARDS

标志 / 字标
与识别标准

先建立一个能被记住的身份，再把它变成任何第三方都能正确执行的规则。

Stone Seal 的几何、字标、组合关系、综合色版本、最小尺寸与生产边界形成同一套识别语法；在不同媒介中可以适配，但不能重新发明。

01 / BRAND STANDARDS

身份资产

先选择正确资产，再进入尺寸、背景和媒介适配。完整锁定组合不得被随意拆分。

READ Primary / Stacked / Wordmark / Mark / MicroBOUNDARY Micro 仍是候选，进入正式资产前需独立设计审查。
02 / BRAND STANDARDS

标志结构

Stone Seal 只保留三条稳定关系：Stone Mass、River Cut、Strata Trace。

READ Form logic before textureBOUNDARY 任何生产变化都不能破坏 River Cut 连续性和层理节奏。
03 / BRAND STANDARDS

标准制图

X 取中部石带高度，同一模块同时控制标志比例、Lockup 间距与安全空间。

READ X = middle stone band heightBOUNDARY 后台精确 bbox、B01–B08、间隙测量继续存在，但不进入公众 VI。
04 / BRAND STANDARDS

安全空间

只保留一条 exclusion-zone 规则，不再制造第二层“最大影响范围”。

READ 0.5X on all four sidesBOUNDARY 可以留更多空白；不能比 0.5X 更紧。
05 / BRAND STANDARDS

最小尺寸

用真实 native-pixel 样本表达什么时候必须切换资产，而不是把同一个 Logo 无限缩小。

READ Primary 240px / Mark 40px current minimumBOUNDARY Primary 低于 240px 进入 Mark；Mark 低于 40px 进入 Micro。Micro 仍需批准，实体尺寸需打样。
06 / BRAND STANDARDS

综合色版本

品牌通过批准版本适配背景，不通过临时改色解决冲突。

READ Ink / Bone · Reverse / Deep · MonoBOUNDARY Cinnabar 只做记忆与强调，不把整枚 Logo 染成朱砂。
07 / BRAND STANDARDS

错误用法

错误规则用真实当前资产直接表示，第三方一眼即可判断。

READ Recognition protectionBOUNDARY 禁止改 River Cut、增减层理、拉伸、旋转、任意改色和重新排字。
08 / BRAND STANDARDS

生产翻译

实体工艺统一从 Flat Geometry 出发，屏幕材质不作为生产依据。

READ Flat → physical processBOUNDARY 所有材料与工艺参数仍需实体 proof。
