CORE PROPOSITION / FIXED ASSET
NAME / 01

中文是第一身份，英文是第二接口

正式名称、Wordmark 英文、正文英文与错误写法必须分开，不允许触点自由变体。

DESIGN NOTE

为什么中文必须是第一身份

“清江石书”首先依赖中文语义建立“地点—材料—阅读”的关系，因此中文不只是翻译源，而是品牌命名本体。英文承担跨媒介识别、索引与国际化阅读，但不应反过来改变中文名称的节奏与含义。

使用边界

正式字标使用全大写英文；正文、说明与编辑语境使用 Title Case。内部缩写 QJ / C04 / CH14 只属于治理与制作层，不进入公众第一阅读。

FIXED VERBAL ASSETS / 02

四组固定品牌语句

这些句子是 Verbal Identity 的稳定资产，不是每个页面都重复出现的装饰口号。

WHY FIXED

固定语句不是广告口号集合

四组语句分别对应品牌命题、游程、系统出现方式与旅后记忆，它们共同构成 Verbal Identity 的稳定骨架。每组只在对应场景承担任务，不要求在所有页面同时出现。

英文目前的状态

英文用于当前设计原型与跨媒介验证，语义优先于修辞对仗。正式对外发布前仍应结合运营方、母语编辑与最终品牌注册语境复核，不把候选译法写成已获正式批准。

VOICE / 03

同一个品牌，不只有一种“品牌腔”

Landscape / Service / Reading / Memory 四种语气按任务分工。尤其 Service 必须压过诗性表达。

VOICE LOGIC

品牌不应该永远保持同一种“文艺腔”

Landscape 可以克制并保留停顿，Reading 可以增加关系和解释，Memory 可以留白；但 Service 必须直接、明确、可执行。语气的统一来自价值和句法，而不是所有句子都写成同一种诗性风格。

判断标准

如果语言会延迟用户理解安全、方向或回程动作，就必须降低品牌表达。服务场景的好文案首先是可用信息，其次才是品牌语言。

GRAMMAR / 04

句法先服从任务，再服从品牌

服务先写状态和动作；景观先观察；阅读才增加关系与证据；Memory 留下空间，不制造“完成”的压力。

SENTENCE MODEL

为什么要规定句法，而不只规定 Tone of Voice

“自然、克制、诗意”这类形容词无法稳定地产生可用文案。句法把不同任务拆成可执行顺序：服务先状态再动作，景观先观察再关系，阅读最后才进入证据和解释。

与证据边界的关系

当 FIELD=0、状态 UNKNOWN 或来源只能支持推断时，句子必须显式保留不确定性。语言系统不能通过更自信的措辞把推断升级成事实。

NAMING / 05

命名层级与公开身份

项目名、Journey、Reading、Memory 与内部文件 ID 使用不同命名规则。内部治理 ID 不进入公众品牌第一阅读。

NAMING SYSTEM

命名层级是为了减少认知竞争

体验身份、Journey、Reading、Memory 的名称各有任务，因此不需要每一层都重新创造一个“品牌名”。越靠近功能层，名称越短、越直接；越靠近记忆层，才允许更具编辑性的命名。

内部 ID 不等于品牌资产

R01–R13 可以作为阅读对象的稳定索引，但 C04、CH14、QJ 等治理编号只服务制作、版本与追踪。它们可以存在于技术层，不能抢公众命名的第一层级。

CASE / SYMBOL / 06

大小写、标点、数字与 ID 不留给每个页面自己决定

这里只规定 Verbal Identity 接口；完整字重、行距、字符集和排版 token 继续由 P05 Typography 展开。

EDITORIAL RULE

大小写与标点也是识别系统的一部分

全大写字标负责稳定识别，Title Case 负责正文可读性，系统短标签使用统一大写与斜杠。这样可以在 Web、地图、导视和技术图层之间保持同一种信息语法。

这一页不替代 Typography

P02 只定义语言层接口。字符覆盖、字重、行距、字号、字体 fallback 与中英混排细节仍由 P05 Typography System 负责，避免同一规范在不同页面重复维护。

TOUCHPOINT PROOF / 07

规范必须能变成真实一句话

同一品牌在 Service、Landscape、Optional Reading、Memory 四类触点中的成句效果。

PROOF OF USE

品牌语言必须在真实触点里成立

规范只有转成具体一句话才能被检验。这里用 Service、Landscape、Optional Reading 和 Memory 四类文本验证：信息密度、句长和诗性程度随着任务变化，但仍保持同一品牌判断。

后续如何继承

P07 的地图与信息系统使用 Service / System Label 语法，P08 的跨媒介应用则使用这套 Voice 与命名规则。任何新触点先判断任务类型，再选择语气，而不是从零写一套新风格。

PROHIBITED / 08

品牌语言必须有明确失败边界

禁用语言不是审美偏好；它直接防止旅游陈词、技术过度承诺、游戏化完成度和 FIELD=0 下的虚假确定性。

NO TOURISM CLICHÉ

秘境 / 仙境 / 打卡圣地

除非处于引用语境，不作为品牌默认语言。

NO TECH CLAIM

实时 / 精准 / 智能识别

没有系统 authority 时不得出现。

NO GAME COMPLETION

解锁 / 13/13 / 收集完成

十三印是可选阅读层，不做完成度。

NO FALSE CERTAINTY

已验证 / 已开放 / 可实施

FIELD=0 或 UNKNOWN 时不能写成确定状态。

NO BRAND POETRY IN SERVICE

沿着石书回到你的来路

服务状态必须 State → Action，不写品牌隐喻。

NO ETHNIC / ANTIQUE PASTICHE

秘境土家 / 古印 / 千年墨韵

不把地域文化压成可消费的视觉/语言标签。

FAILURE BOUNDARY

禁用清单的目的不是限制创作

它用来阻止品牌滑向最容易出现的陈词：文旅夸张、民族标签、科技过度承诺与游戏化完成度。品牌可以有情绪，但不能用情绪掩盖证据和功能。

不是绝对词典黑名单

某些词在引用、学术说明或真实来源语境中仍可能出现。禁用规则针对“品牌主动主张”的默认语言，不应机械删除原始史料、地名或合法引用。
