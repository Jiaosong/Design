这一轮不重新发明装置，也不把旧效果图直接当 Current。每个已有设计先保留其概念，再按最新场地证据、身体需求和展示质量决定：深化、竞争、待证据重入或仅保留记忆语法。

CURRENT DECISION低占用服务先行；大型装置只竞争一个真正需要的场景。

栏杆倚靠板进入高优先级支持；山体流体休憩与清风吟保持单点竞争；步步生光保留机制但当前 HOLD；清江旅记进入 Memory MAIN。

01 / SERVICE BODY SUPPORT

先让累的人有地方短暂停一下。

栏杆式可拆卸倚靠板不需要成为视觉 Hero。它的价值是把半坐、扶靠和短时恢复嵌进步行节奏，同时尽可能少占景观和通行空间。

02 / BODY FEEDBACK

步步生光：保留设计，不假装已经选址。

旧方案最有价值的不是“灯光造型”，而是身体经过以后留下一个很短的回应。较新的 Field-Evidence Protocol 尚未证明真实 Need，因此当前只保留机制与可测试原型资格。

03 / ONE-SITE COMPETITION

山体流体休憩和清风吟，不同时争做主角。

HOLD / SINGLE-SITE COMPETITION

山体流体休憩

如果真实场景确实需要更长停留，它用坐、靠、看和环境反射形成一个空间界面。必须证明它比普通休息更有价值，并解决眩光、温升、湿滑、维护和景观竞争。

VS
HOLD / WIND-SENSORY CANDIDATE

清风吟

只在有稳定而有价值的风关系时出现。核心不是风铃装饰，而是风引起低强度光/声变化与等待、书写；大风安全、噪声、耐久、维护仍需证据。

二者都必须与 C0「不介入」竞争。当前不凭空重画最终形态，等待原始形态 authority / 场地 Need 决定下一步效果图或模型深化。

04 / MEMORY MAIN

清江旅记：让“开卷—成书”真正有一个实体载体。

不做十三印盖章册。纸本在出发/到达时可以打开，在回程时保存路线、停留、问题、手写、画与照片；数字「我的石书」保存同一趟旅程的另一层记录。

05 / MEMORY GRAMMAR

每一种带走物，只保存一种现场变量。

清江一线、清江雾气、红花峰崽继续保留，但不为了“文创数量”扩张。没有足够原始形态 authority 的对象，只恢复其设计角色，不伪造最终产品造型。
