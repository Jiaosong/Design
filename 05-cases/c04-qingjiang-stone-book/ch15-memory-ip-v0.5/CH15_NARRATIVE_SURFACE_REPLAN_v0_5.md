## 1. CH15 single chapter question

> **旅程结束以后，什么继续存在？**

CH15 is the **memory consequence** of the real Qingjiang journey.

It explains how a real route, selected observations, optional reading, bodily traces and active records become personal memory — and only then how that memory may extend into cultural objects.

## 2. Chapter thesis

### Primary thesis

**真正留下来的，不是十三个完成项，而是游客真正经历、注意、选择和保存的那一部分清江。**

`PARTIAL IS COMPLETE` is not a slogan about incompleteness. It is the memory rule produced by the whole project:

`REAL JOURNEY → SELECTIVE ATTENTION → ACTIVE RECORD → PERSONAL MEMORY`

### Secondary thesis

A memory can have more than one carrier without becoming a synchronized task system:

`ONE JOURNEY → PAPER TRACE + DIGITAL REVISIT`

### Tertiary thesis

Cultural products are valid only when they can be traced back to a real journey relation:

`REAL EXPERIENCE → PERSONAL MEMORY → CULTURAL EXTENSION`

not:

`BRAND → SKU FAMILY → PURCHASE → COMPLETION`

## 4. New CH15 narrative architecture

CH15 is reorganized into **four content acts**. These are narrative acts, not automatic Web pages.

### ACT 1｜AFTER THE JOURNEY — Memory begins

**Question:** 游完以后，什么真的留下？

Core relation:
`RETURN / EXIT → RECOGNITION → SELECTIVE MEMORY`

Content:
- `PARTIAL IS COMPLETE`;
- memory comes from actual route, observation, optional reading and active record;
- blank / unread / unvisited remains blank rather than failed;
- one remembered scene, one sentence, one trace can already constitute a complete personal Qingjiang.

Project role:
- receives the journey from CH09–CH13;
- does not replay those chapters;
- establishes the emotional and conceptual turn from **experience** to **memory**.

Primary visual direction:
- a real/established journey recedes;
- a small number of retained traces remain;
- no KPI, no 04/07/11 as achievement score, no 13 nodes.

### ACT 2｜ONE JOURNEY, TWO TRACES — Physical + Digital memory

**Question:** 为什么同一次经历需要纸本与数字两种保存方式？

Core relation:
`ONE EVENT / ONE JOURNEY → PAPER TRACE ↔ DIGITAL REVISIT`

#### Physical carrier｜清江旅记
Meaning owned by CH15:
- body trace;
- fold / handwriting / route trace / photo / ticket / texture / blank;
- `OPEN → DURING → BECOME A BOOK`;
- no-phone continuity.

Do not turn into:
- 13-stamp task book;
- service-heavy paper map;
- generic stationery product page.

#### Digital carrier｜我的石书
Meaning owned by CH15:
- where I went;
- what I noticed;
- what I chose to read;
- what I saved;
- one sentence / image / sound when chosen;
- later re-find / rearrange / revisit;
- `BLANK ≠ FAILED`.

Do not turn into:
- another App chapter;
- multi-screen UI montage;
- completion dashboard.

#### The proof
Use one already-established journey event identity, e.g. `SC-R13-EXIT / LOOK BACK / RECOGNIZE`, to show:
- Paper preserves bodily/time traces;
- Digital preserves indexing/revisit;
- no sync dependency;
- neither medium is required for journey completion.

### ACT 3｜MEMORY GROWS — Cultural extension

**Question:** 个人记忆如何继续变成清江的文化载体，而不是景区商品货架？

Core genealogy:
`REAL QINGJIANG → PERSONAL MEMORY → MEMORY CARRIER → CULTURAL EXTENSION`

Hierarchy:
1. **MEMORY MAIN**
   - 清江旅记
   - 我的石书
2. **SELECTIVE CULTURAL EXTENSION**
   - 清风吟: `ON SITE → TAKE AWAY → REMEMBER`
   - 清江一线: line / route memory
   - 清江雾气: sensory-memory, evidence-sensitive
3. **OPTIONAL FAMILY / COMMUNICATION**
   - 红花峰崽: family/child observation layer; never adult-route mascot

Selection rule:
Every extension must answer at least one of:
- Which real route relation does it inherit?
- Which observation / bodily action / material / sentence / sensory relation does it retain?
- What memory behavior does it support after leaving?

If none can be answered, it stays HOLD or is not shown as a public main design.

Do not show:
- ecommerce grid;
- SKU matrix;
- price / cart / product readiness;
- invented material / production claims;
- a new ungrounded IP family.

### ACT 4｜THE BOUNDARY — Experience complete before purchase

**Question:** 文化延展到哪里必须停止？

Core rule:
`SELLABLE ≠ REQUIRED`

The following remain complete without purchase:
- route;
- observation;
- Return;
- optional reading;
- no-phone journey;
- personal memory.

CH15 should state the boundary but **not own the final project closure**.

Handoff:
- print specification / manufacturing / connection / maintenance → CH16;
- model / engineering / proof / FIELD matrix → CH17;
- selection / HOLD / evolution judgment → CH18;
- final Return / second recognition / project ending → CH19.
