# CH08-P01｜母系统：不是叠加更多层，而是控制谁在什么时候拥有主权

## Claim

**清江石书的总体策略不是“所有设计系统一起出现”，而是让正确的系统在正确时刻拥有主权，并允许其余系统完整但退后。**

总体优先关系：

`REAL QINGJIANG / ROUTE / BODY`  
`→ CURRENT DECISION / SERVICE / RETURN`  
`→ OPTIONAL OBSERVATION / READING`  
`→ DIGITAL / PHYSICAL SUPPORT WHEN EARNED`  
`→ BRAND TRACE`  
`→ MEMORY AFTER RETURN`

这不是固定视觉层级，而是动态 ownership。

## Decision

系统完整性来自 **CORRECT ABSENCE**：
- 索道移动时，Digital 可以 OFF；
- R13 通过时，READ / PLAY 可以 OFF；
- R06 稳定停留时，Relation Reveal 可以短时出现；
- Return / Unknown / Closed 时，Content 和 Brand 必须让位；
- 离场以后，Memory 才可以从配角变成主层。

## Knowledge basis

复用 `Earned Attention`：
`PRIMARY TASK / CURRENT DECISION > SUPPORTING CONTENT > CHROME / UTILITIES`。

迁移到 C04 后不是“UI 主任务”，而是：

`LANDSCAPE / BODY ENCOUNTER > CURRENT DECISION / RETURN > OPTIONAL RELATION > SUPPORT CARRIERS`。

## Interface

- CH09 提供 Route / Service / Return 的真实当前决策对象；
- CH10/11/13/14/15 只在 CH08 允许的注意力窗口中增强体验；
- CH08 不重新画第二套路线，也不创建第二套 App / Brand / Physical system。

## Limit

本页不证明真实注意力时长、疲劳阈值、运营窗口或安全优先级参数。

# CH08-P02｜Encounter Order：先遇见，再解释；解释必须从同一对象中长出来

## Claim

**PRIMARY ENCOUNTER BEFORE CONTEXT。**

当景观、身体或真实路线本身能承担第一主张时，解释不删除，但必须退出 first-read cone。

基本阅读顺序：

`ENCOUNTER → ORIENT → OPTIONAL QUESTION → RELATION REVEAL → WITHDRAW / CONTINUE`

不是：

`LABEL / UI / DEVICE → EXPLANATION → 再看景观`。

## Decision

### Same-source rule
`Landscape First → Relation Reveal` 必须使用同一 authoritative base source / geometry：
- 第一帧删掉说明文字后仍要读得出真实项目对象；
- 第二帧只增加会改变理解或决策的 bounded relation；
- Reveal 不得为了“讲清楚”重画地形、路线、视点或空间关系。

### Explanation deferral
解释可通过第二动作到达：
- 靠近；
- 主动打开；
- 停留；
- 翻面；
- 二次阅读。

“小牌子”不天然克制；只要高对比标题、QR、发光或 badge 抢第一视觉，仍然失败。

## Scene mapping

- R01：移动视点优先，Digital / long explanation 不进入第一阅读；
- R06：Landscape First → optional Relation Reveal → attention handoff back to landscape；
- R13：Body / aperture / exit / Return first，READ / PLAY OFF during passage。

这些 scene behavior 的完整说明归 CH12；CH08 只拥有 encounter-order contract。

## Limit

本页不授权新增标识家具、亭、平台、栏杆、开口、路线或构造。

# CH08-P03｜Freedom of Encounter：空间秩序不等于强制序列

## Claim

**SPATIAL ORDER ≠ FORCED SEQUENCE。**

真实清江可以有明确秩序，同时允许游客绕行、跳过、停留、返回、只看不读。

CH08 对 CH09 / CH10 的关系合同：

- `ROUTE-03` 拥有当前 route geometry / travel decision authority；
- R01–R13 是 optional / reorderable reading layer；
- Reading node 不得反向成为 Route checkpoint；
- `PARTIAL IS COMPLETE`：未读内容为空白，不是失败；
- Return 在任何分支都必须比 completion 更可读。

## Decision

秩序由以下关系建立，而不是由 01→13 progress 建立：
- topology；
- sightline / landscape cue；
- movement condition；
- return cue；
- optional anchor；
- memory continuity。

禁止：
- `13/13`；
- missed-imprint warning；
- unlock / scan / next-task gate；
- 把 route geometry 改成内容顺序；
- 用编号等权节点替代真实场地层级。

## Downstream boundary

- Quick / Deep / Family、S0 / S1 / S2 的详细阅读设计归 CH10 / CH11；
- BOAT / CABLE / WALK 的具体 travel logic 归 CH05 / CH09；
- CH08 只保证“选择自由不破坏路线清晰度”。

## Limit

不证明现场真实分支开放状态、绕行距离、坡度、时间、容量或无障碍连续性。

# CH08-P04｜Intervention Threshold：先改变关系，再决定是否需要新增媒介或物体

## Claim

**THRESHOLD = CHANGE IN RELATION, NOT AUTOMATICALLY A NEW OBJECT。**

设计介入不是因为“这里缺一个设计物”，而是在 Route / Body / Attention / Interpretation 出现真实缺口时才成立。

## Decision ladder

遇到一个体验问题，按以下顺序判断：

1. **现有 Landscape / Route 是否已经足够？**
2. **Service / Signage / Paper / Human 是否能解决？**
3. **只改变信息顺序或 encounter order 是否足够？**
4. **Digital reveal 是否真的能解释一个不可直接看见的关系？**
5. **Physical 是否存在不可由现有环境解决的身体需求？**
6. **新增 object 后，是否仍保持 landscape / body first？**

只有前一级无法解决时，才进入后一级。

## Physical / Sensory contract

用户原始 P02 / Fluid Rest / Qingfengyin 等设计对象继续是 ACTIVE C04 DESIGN SOURCE OBJECTS，但 CH08 不替它们做选型。

母系统只规定：
- Physical = response to body need, not product catalogue；
- P02 可作为短恢复支持，但不替代 safety railing；
- Fluid Rest 仍受 LOCATION / SITE fit；
- Qingfengyin 仍受 wind / ecology / sound / maintenance / location；
- HOLD / COMPETITION 不等于设计身份被删除。

具体设计、人体、材料、构造和 selection 归 CH13 / CH17 / CH18。

## Digital / Brand contract

同样地：
- Digital 只在需要提示、Reveal、记录、服务辅助时出现；
- Brand 只承担 recognition，不为了“统一”覆盖 Route / Safety / Landscape；
- 介入强度可以减少，但信息不能因“安静”而被删除。

## Limit

本页不把任何 Physical / Sensory candidate 提升为已定位、已建造或工程可实施状态。

# CH08-P05｜Three Independent State Axes：不要把“开放状态、内容强度、品牌存在感”混成一种颜色

## Claim

C04 至少有三套彼此独立的状态轴。它们可以同时变化，但语义不能互相借权威。

### Axis A｜Operational / Credibility State
`NORMAL / DEGRADED / CLOSED / UNKNOWN`

回答：**现在是否可靠地知道可以怎么走 / 怎么返回？**

Owner：Route / Service / Return。  
Rule：UNKNOWN 不得伪装为 OPEN；CLOSED 必须 hard stop。

### Axis B｜Content / Digital Intensity
`FULL / LIGHT / OFF`

回答：**当前注意力条件允许多少解释与数字介入？**

Owner：Digital / Reading experience。  
Rule：OFF 不代表系统失败，而可以是正确体验状态。

### Axis C｜Brand Presence
`FULL / LIGHT / TRACE / OFF`

回答：**当前媒介需要多少身份识别？**

Owner：CH14 Brand。  
Rule：Brand color / presence 不能替代 Operational state / safety semantics。

## Failure & Recovery

异常状态下，母系统执行：

`DETECT → INFORM → REDUCE LOAD → SAFE ALTERNATIVE → RETURN / HUMAN HELP → RECORD OPEN ITEM`

冗余链：

`LANDSCAPE + SIGNAGE + PAPER + HUMAN + DIGITAL`

任何单一技术失效都不能让“能否返回”失去答案。

## App relation

App v1.28 中的 `UNKNOWN fail-closed / Return Guard / Digital OFF / Offline Prep` 是本合同的下游实现之一，不是 CH08 的唯一载体。

## Limit

不证明真实实时接口、关闭机制、疏散程序、SOP 或现场安全条件。

# CH08-P06｜Authority & Handoff Matrix：每个载体只做它拥有语义权的事

## Claim

**SOURCE-CORRECT GEOMETRY ≠ FUNCTIONAL AUTHORITY。**  
**VISUAL CONSISTENCY ≠ SEMANTIC OWNERSHIP。**

同一条路线可以进入 Route、Brand、App、Board，但不同 carrier 拥有不同语义。

| Carrier / System | Owns | May Support | Must Not Impersonate |
|---|---|---|---|
| Landscape / Journey | first encounter, spatial/body reality | orientation cue | Brand / Digital world |
| Route / Service / Return | current decision, direction, fallback, recovery | journey reading | Thirteen Imprints / Brand trace |
| Thirteen Imprints | optional observation / interpretation | memory | route checkpoint / progress authority |
| Digital | prompt, reveal, record, service aid | route context | GPS truth / only Return / live status without source |
| Physical / Sensory | body support / bounded sensory event | pause / observation | landscape hero / safety system |
| Brand | recognition, language, cross-media continuity | trace route identity | direction, current position, live status, safety |
| Memory | post-return record / re-recognition | optional share | completion score |
| Technical Proof | how a relation may hold together | near-read evidence | landscape / experience hero |

## Semantic firewall

任何 route-derived graphic 使用前先声明 carrier role：
- `FUNCTIONAL_ROUTE`
- `IDENTITY_TRACE`
- `OPTIONAL_READING`

随后执行：
`SOURCE ROUTE → CARRIER ROLE → ALLOWED SEMANTICS → PROHIBITED SEMANTICS → FALSE-AFFORDANCE CHECK → RETURN/STATUS OWNERSHIP CHECK`。

Brand trace 不允许仅因为沿用 ROUTE-03 几何就加入：
- movement arrow；
- START HERE；
- current-position marker；
- live/open/closed semantics；
- only Return cue。

## Master handoff sequence

`ENCOUNTER`  
`→ ORIENT`  
`→ CHOOSE`  
`→ OBSERVE`  
`→ OPTIONAL REVEAL`  
`→ RECOVER / CONTINUE`  
`→ WITHDRAW / RETURN`  
`→ RECOGNIZE`  
`→ RECORD`

系统不是线性内容任务；每一步都允许提前 Return。

## Final chapter judgment

> **清江石书的“总体系统”不是一个覆盖景区的超级界面，而是一套不断决定“谁现在应该出现、谁应该退后、谁拥有下一步决策权”的体验编排。**

它的完成标准不是系统数量，而是：
- landscape 仍然先被看见；
- route / service / return 始终可判断；
- interpretation 永远可选；
- physical 只因身体需要出现；
- digital / brand 可以主动消失；
- memory 在离场后继续；
- technical proof 能说明但不替代体验；
- 异常与未知状态下仍能收束。
