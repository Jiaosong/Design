# CH08｜总体策略与体验系统｜v0.4 Master Design Strategy

Project: `PRJ-C04-QINGJIANG-SHISHU`  
Role: `MASTER DESIGN STRATEGY / MASTER INTEGRATION`。  
State: `AUTHORING SUCCESSOR / ARCHITECTURE + RELATION DEEPENING / NO SELF-KEEP / NO_PROMOTION`。

CH08 不重新拥有 CH09–CH15 的 Route、十三印、App、Physical、Brand 或 Memory；它负责回答一个更上位的问题：**真实清江的一次旅程应该怎样被组织，已有设计在什么条件下才有资格出现、何时退场、彼此怎样交接，以及哪些设计根本不应该增加。**

---

## 0｜MASTER THESIS｜清江石书的总体设计命题

> **同一条江，在不同尺度中被重新认识：先获得整体，再跨越关系，再进入身体；设计只在方向、理解、恢复或记忆出现真实缺口时介入。**

项目不是“十三印 + App + 装置 + 文创”的并列集合，而是一条由真实空间和身体变化驱动的体验：

`REAL QINGJIANG → ORIENT → MOVE / CROSS → WALK → NOTICE → CHOOSE / RECOVER → OPTIONAL READ → PASS → RETURN → RECOGNIZE → RECORD`

原始叙事层继续保留：

`开卷 → 换眼 → 寻页 → 写入 → 看懂 → 收束 → 成书`

两条线的关系必须保持：**叙事帮助理解体验，但不反向制造路线事实。**

### 原始“三次看江”命题的 authority 修正
原始设计中的 `水上建立整体 / 空中建立关系 / 山中建立身体尺度` 保留为项目最重要的体验命题之一，但不能把 Boat 误写成所有游客的 Universal Core。

因此 v0.4 将其解释为：

1. **WHOLE / TERRITORY SCALE｜先建立整体尺度**  
   水上游船是这一尺度最强的条件性体验之一；如果游客由道路或其他方式到达，也必须先通过真实江谷、两岸和宏观路线关系建立“我进入的是一条完整清江”的认识。
2. **RELATION SCALE｜跨江建立关系**  
   Cable 的价值不是增加互动，而是通过移动视点把江、两岸、峰林和南岸步行网络放进同一空间关系中。
3. **BODY SCALE｜山中进入身体尺度**  
   Walk 之后，坡度、足下、植被、岩壁、视线、停留、疲劳和恢复开始成为体验本身；十三印、Digital、Physical 只能在这一身体事实之后获得介入资格。

**设计目标不是让三种交通方式变成三项任务，而是让尺度转换本身成为理解清江的方法。**

## 1｜EXPERIENCE SPINE｜真实旅程母线

CH08 使用下列 operational spine 统筹体验，但不拥有路线几何：

`ARRIVAL → ORIENT → ACCESS / WHOLE-SCALE VIEW → CABLE / CROSS → WALK / DISCOVER → OBSERVE / RECOVER / CHOOSE → PASS → RETURN → LEAVE / MEMORY`

其中：
- `ROUTE-03 = LOCKED CURRENT`，真实移动决策归 CH09；
- Boat = `CONDITIONAL ACCESS / WATER-SCALE EXPERIENCE`；
- Cable = 关系转换的核心空间段；
- South-bank = 多分支 / 回环步行网络；
- R01–R13 = optional reading objects，不组成强制顺序；
- Return 可以从任何阶段提前发生。

### Journey Phase × Master Strategy Atlas

| Journey phase | 第一体验 / 第一阅读 | 当前需要解决的决定 | 允许出现的设计 | 应主动退场的设计 |
|---|---|---|---|---|
| ARRIVAL / 开卷 | 清江整体、到达关系 | 我怎么进入、怎么回来 | Route / Service / Paper / Journal opening / Digital orient | 深读、任务、强品牌 |
| ACCESS / WHOLE SCALE | 连续江谷、两岸、山水整体 | 通常无强决策；必要时确认下一段 | 低强度 Route / Service；Boat 若实际使用则以景观为主 | 十三印密集解释、实体 Hero、持续 App |
| CABLE / 换眼 | 移动视点与两岸关系 | 进入前确认；抵达后重新定向 | BEFORE/AFTER Route；中段 Landscape | 中段 Digital、长解释、Relation HUD、新装置 |
| WALK / 寻页 | 路径、身体、局部景观 | 继续 / 分支 / Return | Route；轻 Content cue；必要 Physical | 平均分布的知识点、强品牌 |
| OBSERVE / 看懂 | 同一真实场景的第二次观看 | 要不要读、要不要停 | 十三印 S1/S2；短时 Digital Reveal；必要身体支持 | 自动触发、进度、持续 Overlay |
| RECOVER | 身体恢复与重新获得观看能力 | 继续还是 Return | P02 / Service / Return；Fluid 仅在 site-fit 成立后 | 文化解释优先、任务化互动 |
| CHOOSE | 路线选择与不确定性 | 往哪走 / 是否返回 | Route/Return Touchpoint + Paper/Human/Digital support | 十三印、Brand 抢方向权 |
| PASS / 收束 | 足下、身体、空间压缩 | 通过 / 退出 | 必要 Route / Exit / Return | READ / PLAY / COLLECTION / 强 Digital / 新 Physical |
| RETURN | 重新获得方向与确定性 | 怎样结束探索并离场 | Route / Service / Paper / Human / Digital redundancy | 可选内容继续拉住游客 |
| LEAVE / 成书 | 再次认出刚经历的清江 | 留下什么 | Qingjiang Journal / My Book / Qingfengyin memory / optional extensions | completion pressure、13/13 |

这张 Atlas 的核心不是“每个阶段都要有触点”，而是明确 **哪个阶段设计必须少，哪个阶段才有资格增加深度。**

## 2｜DYNAMIC OWNERSHIP｜正常体验模式与 Override 决策模式

CH08 不再使用一条贯穿全程的固定优先链。项目至少有两个运行域。

### A｜NORMAL EXPERIENCE MODE
触发条件：路线状态可理解、没有强 Return 需求、身体能够继续、没有 CLOSED / UNKNOWN 决策冲突。

主次关系：

`LANDSCAPE / ROUTE / BODY → OPTIONAL OBSERVATION → OPTIONAL REVEAL → SUPPORTING DIGITAL / PHYSICAL → TRACE BRAND → MEMORY ACCUMULATION`

这里的目标是让真实清江保持第一阅读。

### B｜OVERRIDE DECISION MODE
触发条件包括：
- `CLOSED / UNKNOWN`；
- Return urgency 明显上升；
- 路线选择不确定；
- 疲劳 / ACCESS / RECOVER 需求上升；
- 需要人工服务或 no-phone fallback；
- 当前信息不足以支持继续探索。

此时优先级临时改为：

`CURRENT DECISION / SERVICE / RETURN → ROUTE → BODY SUPPORT → OPTIONAL CONTENT`

这里的 Service / Return 是**当前决策权**，不是全旅程永远压在 Landscape 之前。

### Conflict Arbitration｜只在需求冲突时使用
当多个系统同一时刻争夺注意力，按以下规则仲裁，而不是把它当成路线顺序：
1. 已知运营限制或 `UNKNOWN` 的可信度边界；
2. 当前 Route / Return 决策；
3. 身体通过 / 恢复需求；
4. 真实景观第一遇见；
5. 可选解释 / Reveal；
6. Brand / Memory 的附加表达。

**冲突解除后，应尽快回到 NORMAL EXPERIENCE MODE。**

## 3｜ENCOUNTER + FREEDOM｜先遇见，再解释；有秩序，不做完成链

### Primary Encounter Before Context
每一个真正值得阅读的场景先允许现实对象独立成立：

`REAL SCENE → NOTICE → OPTIONAL QUESTION → RELATION REVEAL → OPTIONAL EVIDENCE → WITHDRAW / CONTINUE`

Reveal 的作用是帮助游客**第二次看见同一个对象**，不是用解释取代第一次观看。

### Same-source Rule
Landscape First 与 Relation Reveal 必须使用同一 authoritative scene / geometry。第二层只能增加 bounded relation，不允许为了说明方便重画一套更漂亮但不真实的空间。

### Spatial Order ≠ Forced Sequence
R01–R13 是 Content Index，不是路线进度。

允许：
- 跳过；
- 倒序遇见；
- 只读少量；
- 不打开 App；
- 只观察不记录；
- 中途 Return。

禁止：
- 13/13；
- missed node；
- next mission；
- route-to-Rxx 的伪精确邻近；
- completion reward 反向控制旅行。

`PARTIAL IS COMPLETE` 是项目的体验自由，不是宣传语。

## 4｜BEHAVIOR CONDITION｜同一旅程中的六种设计条件

CH05 的六种体验条件直接进入 CH08 作为触点分配依据：

| Condition | 体验事实 | CH08 设计响应 | 明确禁止 |
|---|---|---|---|
| MOVE | 正常移动 | Route 清楚，Content 弱 | 沿路平均触发内容 |
| LOOK | 景观主动吸引注意 | Landscape first；最多轻 cue | Overlay / 长解释抢景 |
| OBSERVE | 稳定停留、比较 | 十三印 / Reveal 可有限出现 | STOP 自动等于 READ |
| RECOVER | 疲劳、等人、短休 | Physical / Service / Return 提升 | 强制文化内容 |
| CHOOSE | 分支或下一步不确定 | Route / Service 获得当前决策权 | Brand / Imprint 充当导航 |
| PASS | 足下和身体成为第一任务 | 内容退场；必要方向保留 | PLAY / READ / COLLECTION |

其中最重要的校正是：**STOP ≠ READ。** 游客停下可能只是累、等人、拍照或看景；任何系统不得自动把“停留”转译成“内容触发”。

## 5｜MINIMUM SUFFICIENT CARRIER｜按需求类型决定介入，不使用机械升级梯

CH08 不再规定 `Signage → Paper → Digital → Physical → New Object` 的固定顺序。不同问题拥有不同候选集。

### NEED A｜Decision / Route
问题：我在哪里、往哪里、能否继续、怎样 Return。

候选顺序不是媒介升级，而是**可信度与冗余组合**：
`ROUTE-03 → SITE SIGN / RETURN CUE → PAPER → HUMAN → DIGITAL SUPPORT`。

当真实现场存在决策缺口时，才允许 CH09 `Route / Return Physical Touchpoint Family` 成为新设计对象。

### NEED B｜Interpretation / Reading
问题：我已经看见了，但还没看懂一个关系。

优先：
`REAL SCENE → PROMPT → RELATION REVEAL → OPTIONAL EVIDENCE`。

默认不通过新增大型实体解释自然；Digital / Paper 只是可选深度载体。

### NEED C｜Body / Recovery
问题：身体需要靠、停、恢复或重新获得继续行走能力。

优先比较：
`NO INTERVENTION / EXISTING REST → P02 → FLUID REST only if long-rest site-fit is proven enough for design continuation`。

身体需求不需要先经过 Signage 或 Digital 才有资格进入 Physical。

### NEED D｜Sensory / Attention
问题：真实风、水、光、雾、声音或触感已经存在，但游客不容易意识到。

优先：
`EXISTING RESOURCE → NO DESIGN / TRACE / FRAME → QINGFENGYIN only if site + environmental fit merits it`。

不发展“一种感官一个装置”的产品体系。

### NEED E｜Memory
问题：旅程结束后，什么值得留下。

优先：
`QINGJIANG JOURNAL → MY BOOK → QINGFENGYIN MEMORY / SECONDARY EXTENSIONS`。

Memory 不能反向制造现场完成压力。

### New Object Admission Gate
任何未来新增 micro-intervention 必须同时回答：
1. 真实问题是否明确；
2. 现有环境 / 服务 / 已有设计为什么不足；
3. 为什么这个位置需要它，而不是“项目需要一个设计”；
4. 它对真实景观造成什么成本；
5. 是否可逆、可维护、可停用 / 替换；
6. 异常或失效时会发生什么；
7. 哪些关键条件仍属于 FIELD / ENGINEERING OPEN。

如果这些问题回答不成立，`NO DESIGN` 继续是正式方案。

## 7｜USER / USE-STATE MODIFIERS｜不同人得到不同深度，不得到不同清江

CH04 的七个变量进入 CH08，但不重新做 Persona：

| Modifier | 改变什么 | 不改变什么 |
|---|---|---|
| TIME AVAILABLE | 停留数量、阅读深度、Return 提前程度 | Route truth |
| STAMINA | RECOVER / Physical / Return 权重 | 景观与路线事实 |
| ATTENTION LOAD | Digital / Content 强度 | 当前真实场景 |
| READING INTENT | S0 / S1 / S2 深度 | 是否必须完成十三印：永远否 |
| DIGITAL RELIANCE | App / Paper / Human 比例 | 基础 Route / Return 必须成立 |
| COMPANION CONDITION | 共同观察、等待、Family action | 不生成儿童专属假路线 |
| RETURN URGENCY | 当前决策和服务权重 | 不制造“退出失败” |

### Combination Rule
多个状态同时出现时，**更紧迫的现实需求覆盖更深的可选体验**：
- DEEP reader + fatigue → 先 RECOVER / Return，再决定是否继续深读；
- FAMILY + PASS → 先完成身体通过，不触发亲子互动；
- HIGH reading intent + UNKNOWN → UNKNOWN 决策边界优先；
- LOW-DIGITAL + CHOOSE → Paper / Signage / Human 必须独立支持判断。

这不是一条固定优先链，而是冲突时的临时 arbitration。

## 8｜STATE SYSTEM｜三轴独立，异常时降低承诺

### Axis A｜Operational / Credibility
`NORMAL / DEGRADED / CLOSED / UNKNOWN`

### Axis B｜Content / Digital
`FULL / LIGHT / OFF`

### Axis C｜Brand Presence
`FULL / LIGHT / TRACE / OFF`

三轴不能借权：
- `Digital OFF ≠ CLOSED`；
- `Brand OFF ≠ abnormal`；
- `Brand color ≠ operational status color`；
- `UNKNOWN` 不能画成可自由进入的 OPEN。

### Typical combinations
- Cable mid-crossing：`NORMAL × OFF/minimal × TRACE/OFF`；
- R06 stable observation：`NORMAL × LIGHT / optional short FULL × TRACE`；
- R13 PASS：若运营状态已知且允许进入，则可为 `NORMAL × OFF × OFF/TRACE`；
- UNKNOWN at decision point：`UNKNOWN × OFF/LIGHT × TRACE`，先转入确认 / Return / Human help，而不是继续探索语言。

### Recovery grammar
`DETECT → INFORM → REDUCE LOAD → AUTHORIZED / VERIFIED ALTERNATIVE WHEN AVAILABLE → RETURN / HUMAN HELP → RECORD OPEN ITEM`

这里不宣称现场已经拥有经过验证的安全替代路线、应急疏散或实时运营接口；这些继续属于 FIELD / OPERATION / SAFETY OPEN。

## 9｜CROSS-SYSTEM HANDOFF｜媒介如何交接，而不是互相抢权

### Route → Imprint
前提：当前 Route 决策已经清楚，且游客进入 OBSERVE / stable attention。不能在 CHOOSE / PASS 时用内容覆盖路线。

### Imprint → Digital
只有用户主动需要更深关系时才进入 Reveal；Digital 不自动弹出完整解释。

### Digital → Landscape
Reveal 完成后必须允许 Withdraw，使注意力回到同一真实场景。成功的 Digital interaction 包含退出。

### Route → Physical
只有身体问题和场地条件共同成立时才进入 P02 / Fluid 等实体选型；Route 不为了“展示产品”经过装置。

### Physical → Landscape
身体被支持后的结果应是重新抬头、继续观看或继续行走，而不是让实体成为新目的地。

### Experience → Memory
Memory 从旅程中累积，但在 Return / Leave 后取得主导。清江旅记和 My Book 记录发生过的经历，不制造下一次现场 completion pressure。

### Brand → All carriers
Brand 提供识别和编辑语法，但不拥有：
`CURRENT POSITION / DIRECTION / RETURN / OPERATIONAL STATE / SAFETY AUTHORITY`。

### Paper / Human / Digital redundancy
这三者不是竞争谁“更先进”，而是在 no-phone / low-network / uncertainty 中共同保证基础判断不依赖单一技术。

---

## 10｜PROJECT PROOF BOUNDARY｜技术证明不进入游客实时载体矩阵

Technical Proof 独立于 visitor-facing experience system。

统一证明链：

`DESIGN CLAIM → DRAWING / MODEL / DETAIL / EVIDENCE → WHAT IT PROVES → DOES NOT PROVE → NEXT CHECK`

典型边界：
- ROUTE-03 / source map 可证明宏观关系，不证明测绘坐标、距离、坡度和实时状态；
- section / body diagram 可证明概念尺度关系，不证明现场适配；
- model / axon 可证明空间关系，不替代真实景观和设计源；
- connection detail 可解释构造意图，不证明结构批准；
- App runtime 可证明交互实现，不证明现场网络 / GPS / 服务可靠性；
- Brand application 可证明视觉语法，不取得功能 Wayfinding authority。

`R06 = FINISHED / FROZEN / NO REOPEN`：CH17 可继续解释 proof，但不能通过技术图重新设计 R06 experience。

### CH10｜Thirteen Imprints

- `REAL SCENE → NOTICE → QUESTION → RELATION → OPTIONAL EVIDENCE → EXIT`；

## 13｜MASTER JUDGMENT｜总体策略的最终判断

> **清江石书不是把更多设计叠加到清江上，而是设计“什么时候什么应该出现、什么时候什么必须消失”。**

它最终依靠五个关系成立：

1. **尺度关系**：整体 → 关系 → 身体；
2. **注意关系**：先遇见 → 再理解 → 可退出；
3. **行动关系**：Route / Return 永远不被内容替代；
4. **介入关系**：真实需要 → 最小充分载体 → 不必要则不设计；
5. **记忆关系**：经历先发生，记录随后形成，不以完成度定义价值。

因此项目的专业完成度不取决于是否把 App、十三印、P02、Fluid Rest、步步生光、清风吟、品牌和文创全部做得更显眼，而取决于：**每个已有设计是否只在真实清江需要它时出现，并能在不需要时可靠地退场。**

Truth boundary remains: `FIELD OBSERVED=0 / FIELD MEASURED=0 / G1F HOLD / NO_PROMOTION / NTS / NOT FOR CONSTRUCTION`。
