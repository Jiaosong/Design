CH08 is produced by **P Owner → multiple actual visual surfaces**, following the CH14 production model. The current 28-surface map is an authoring map, not a page-count quota.

`VISUAL PROPOSITION → EXPERIENCE EVIDENCE → RELATION EXPLANATION → STRATEGY RULE`

Hard production rules:
- real/current/mature C04 visual first;
- no strategy matrix as first read;
- a surface exists only when it has one primary claim + one primary visual;
- authoritative geometry is never redrawn for layout convenience;
- same-source reveal surfaces preserve identical base geometry;
- no-loss: older matrix/system pages remain provenance/backstage source, not deleted;
- no final Web PAGE-ID is invented during CH08 authoring.

## 3｜Review cadence

A P Owner may contain 2, 3, 6, 12 or more visual surfaces. Production stops only at meaningful quality gates, not after each minor edit.

`SOURCE LOCK → FIRST PIXELS → PIXEL CRIT → REPAIR → READBACK → ARTIFACT REVIEW → INDEPENDENT PROFESSIONAL DESIGN REVIEW`.

Producer pixel review is not Professional Design Review. CI/manifest/hash existence is not Design PASS.
