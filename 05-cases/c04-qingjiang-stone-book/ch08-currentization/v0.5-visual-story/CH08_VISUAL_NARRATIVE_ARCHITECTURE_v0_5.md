## 0｜CORRECTION｜CH08 不是“四页总体策略”

本版修正此前将 CH08 压缩为少量系统页 / 策略矩阵页的叙事错误。

硬规则：

`CHAPTER ≠ PAGE COUNT`  
`P OWNER ≠ ONE PAGE`  
`SURFACE ≠ FINAL WEB PAGE-ID`  
`MATRIX ≠ FIRST READ`  
`REAL / MATURE PROJECT VISUAL FIRST`

CH14 已经建立了正确的生产模型：一个 P Owner 可以拥有 Hero、specimen、detail、comparison、proof、misuse、production 等多个实际展示 surface。CH08 同样采用这一模型。

因此 CH08 的四个叙事动作：

`视觉命题 → 体验证据 → 关系解释 → 策略规则`

是**阅读逻辑**，不是 4 页、4 个 P Owner 或 4 个 Web screen。

CH08 v0.4 的策略内容继续保留为内容 authority；本 v0.5 只重构它如何被观看和理解，不改写 ROUTE-03、R01–R13、App、Physical、Brand、Memory、Engineering 或 Field authority。

## 1｜FRONTSTAGE THESIS｜先让人经历清江，再让策略出现

CH08 的第一阅读必须是：

> **同一条江，在不同尺度中被重新认识。先获得整体，跨越关系，进入身体；设计只在方向、理解、恢复或记忆真正出现缺口时介入。**

前台顺序：

`REAL QINGJIANG / PROJECT VISUAL → HUMAN EXPERIENCE → SAME-SOURCE RELATION → DESIGN CONSEQUENCE → RULE`

不得反转为：

`RULE → MATRIX → EXPLANATION → DECORATIVE IMAGE`

整体阅读必须让观众先感到尺度发生变化，再理解为何项目形成这些策略。

## 2｜SURFACE MODEL｜9 个 P Owner，28 个候选展示 surface

以下数量是 **authoring surface map**，不是最终页数合同。Web 可连续滚动；展板、书册、Deck 可按媒介重新分页，但不得为了“整齐”合并掉具有独立视觉命题的 surface。

**S01 / HERO — 一条完整清江**  
Primary claim: 清江先作为真实整体成立，设计退后。

**S02 / THREE WAYS OF SEEING — 水上 / 空中 / 山中**  
Primary claim: BOAT / CABLE / WALK 的价值不是交通清单，而是视点与身体尺度转换。  
Primary visual: 三段真实已处理 journey imagery / authoritative journey visual，允许不同来源并列，但每段必须保留 source owner。

**S03 / EXPERIENCE SPINE AS JOURNEY — 从进入到离开**  
Primary claim: `ORIENT → MOVE/CROSS → WALK → NOTICE → CHOOSE/RECOVER → OPTIONAL READ → RETURN → RECORD` 是一段旅行，不是一张流程图。  
Primary visual: Master Journey currentized visual；文字只作节奏标记。

### P02｜WHOLE / TERRITORY｜先获得整体

**S06 / DESIGN WITHDRAWS AT WHOLE SCALE**

## 4｜VISUAL BINDING RULES

每个 CH08 surface 必须登记：

`SURFACE_ID / PRIMARY_CLAIM / PRIMARY_VISUAL / SOURCE_OWNER / SOURCE_VERSION / TRUTH_STATE / PRESENTATION_ONLY_CHANGE / REVEAL_LAYER / DOES_NOT_PROVE / REVIEW_STATE`

规则：

1. `STRONGEST EXISTING MATURE VISUAL FIRST`；找不到才允许新建候选。
2. 已有照片、currentized image、render、map、drawing、model proof、UI specimen 不因旧页面版式弱而被删除；可重新裁切、分镜、调权重、加 bounded overlay。
3. Spatial / Route / Model geometry 不为版式方便重画。
4. `Landscape First → Relation Reveal` 必须 same-source；R06 是 CH08 的核心示范对。
5. AI-assisted conceptual visualization 必须保留其 truth label，不能通过 CH08 编排变成 site photo / field proof。
6. 抽象矩阵只能证明规则结构，不能取代体验证据。
7. 一张图不能同时承担“情绪 Hero + 路线事实 + 工程证明 + 状态运营”四种 authority；必要时拆成多个 surface。

## 5｜PRESENTATION RHYTHM

CH08 的视觉节奏按以下方式控制：

`FULL-BLEED / QUIET → SEQUENCE → SAME-SOURCE PAIR → DETAIL → DECISION SCENE → OBJECT-IN-CONTEXT → PROOF → QUIET CLOSURE`

而不是连续出现等宽卡片、四象限、矩阵和 dashboard。

建议前 2/3 surface 中，Primary Visual 占据主要视域；规则文本只在观众已经看到对应证据之后出现。

最终是否为 18、22、28 或更多实际 Web/Book surfaces，由素材质量和独立 Design Review 决定，不由整齐页数决定。
