## 3｜PAGE-TYPE QUALITY RULE

`PROJECT / ANALYSIS / AUDIENCE / PRINCIPLE / METHOD / SYSTEM / SCENE / DETAIL / TECHNICAL / PROCESS / CLOSURE`.

- ANALYSIS = `evidence/observation → finding → design consequence`
