- `G1R PASS` supports research-grade macro route, cableway, selected view relations, operating behavior and selected scientific/context claims.
- Remote evidence remains `Reported / Compared / Inferred` according to source type; it never becomes `Observed / Measured by OLEANDER`.

### Implementation hold

`G1F Field / Professional Survey = NOT AVAILABLE / IMPLEMENTATION HOLD`.

The following remain blocked from implementation claims:

- exact node GPS / elevation;
- trail widths / steps / slopes / platform dimensions;
- exact current signage naming;
- lux / network / GPS drift / AR stability;
- crowd dwell ratios;
- structural / foundation / drainage / electrical design for physical interventions;
- final operation, maintenance and construction authority.

## 6｜Design Rules Retained

- `LANDSCAPE FIRST`.
- `ROUTE AUTHORITY > CHAPTER AUTHORITY`.
- `FACT / LOCAL NARRATIVE / DESIGN READING` must remain distinguishable.
- `OFFLINE-FIRST / MANUAL-LOCATION / PHONE-IN PHONE-OUT`.
- `PARTIAL IS COMPLETE`.
- `清江十三印` is an editorial/personal memory structure, not a mandatory 13-stop completion system.
- S0/S1 dominate; S2 is reserved for relationships that genuinely need Reveal.
- `SERVICE / RETURN > ROUTE > OBSERVATION > EXPLANATION > MEMORY > SHARE`.
- no fake real-time service data;
- no GPS auto-trigger or AR dependency before field evidence;
- no game HUD, rarity, reward or 13/13 completion logic.
