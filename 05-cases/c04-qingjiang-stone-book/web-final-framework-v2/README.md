## What this changes

This is a real successor to `web-full-asset-recomposition-v1`, not another framework memo.

The old Web correctly restored much of the C04 universe, but its public structure still compressed or weakened three permanent systems and used several temporary render substitutes:

- Audience existed mainly inside R06 copy instead of as an independent designed chapter;
- Technical Proof was absorbed into scene/physical explanation instead of remaining a visible but secondary system;
- Visual / Motion remained implicit rather than having a real public carrier;
- App presentation relied heavily on simulated phone composition instead of consuming the merged portable App/Game Map artifact;
- several real-Qingjiang raster bindings existed only in the portable/Drive production package, while GitHub source used unresolved local paths.

v2 corrects those issues without deleting the valid content of v1.

## Key editorial decisions

1. **Real Qingjiang first.** Hero, R06 and Return use explicit QJ-D v1.1 Drive bindings. No generic AI replacement is created.
2. **Journey before content sovereignty.** BOAT / CABLE / WALK / RETURN define movement; R01–R13 do not own the route.
3. **App is a primary outcome.** The Web embeds the merged portable App/Game Map artifact rather than treating digital as a state-machine diagram.
4. **R01–R13 stay complete.** Exposure is selective; existence is not reduced.
5. **R06 and R13 remain different scene rhythms.** R06 opens/recover/compare; R13 compresses/body-first/return.
6. **Audience is restored as an independent system.** The rejected PR #155 equal-text-ladder pixels are not reused. v2 uses a same-scene body/attention/depth progression.
7. **Physical is not C23.** P01/P02 are consumed from merged SVG carriers; Fluid Rest and Qingfengyin remain visible as source-bound conditional design families without silently promoting unmerged PR pixels.
8. **Memory remains physical + digital.** M01 journal and App/My Book are shown as complementary, with `partial is complete` and no 13/13 closure.
9. **Technical Proof is visible, but secondary.** C22/C23/SEC-A/R06-node logic supports spatial credibility and never replaces landscape or body experience.
10. **Visual/Motion is restored.** QJ-D visual family and 86s film lineage receive a public chapter; motion remains `RE-EDIT`, not falsely Final.
11. **Return is independent.** It remains the final closure and an always-available rail through earlier sections.
