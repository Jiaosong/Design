# CH10｜十三印内容与互动系统｜v0.4 Reorganized Reading System

**Role:** 十三印不是 13 个站，而是一个可变阅读系统。CH10 拥有内容/互动语法，不拥有路线、App IA、Physical 或 Memory 实施。

## 01｜核心重组
- `十三印 = EDITORIAL IDENTITY / VARIABLE READING SYSTEM`，不是 runtime completion count。
- 当前研究级结构从“13 个等权 R 项”调整为：**Core 8 + Companion Pool + Trip Subset**。
- Core 8：R01 / R02 / R05 / R06 / R07 / R09 / R12 / R13。
- R03/R04/R08/R10/R11 保留 R-ID provenance，但降为 `COMPANION / PROVISIONAL / MERGE / OFF` 可变角色。
- 许愿台／板栗树可作为更强的真实行为 Companion；巨帆启航保持 Route Hinge / CH09 主权。

## 02｜每一印必须回答的 13 个设计字段
`R-ID / TIER / REAL SCENE / CONTENT ROLE / EVIDENCE STATE / WHAT TO NOTICE / OBSERVABILITY / ACTION / DEPTH / PROMPT GATE / OPTIONAL REVEAL / FAILURE-RECOVERY / EXIT-MEMORY`。
载体和物理介入另加 `CARRIER / INTERVENTION LEVEL / OWNER / DOES-NOT-PROVE`。

## 03｜Core 8
### R01｜越江视域｜红岩嘴｜CORE
- **Scene:** 索道移动视点 / 越江开卷
- **Notice:** 江水、岩壁、峰林在移动中怎样改变前后、遮挡与尺度关系
- **Action / depth:** `LOOK / PASS` / `S0 → S1`
- **Prompt:** 先别找景点名，看江水、岩壁和峰林怎样在移动中改变关系。
- **Reveal:** 默认无；离开后可补读“移动视点如何改变空间关系”
- **Recovery / Exit:** 网络/定位/内容失败均不影响观看；UNKNOWN/CLOSED 服从 Service/Return；屏幕退场 → 继续看 → 到站后再记录
- **Memory:** 一页越江开卷；记录“我在移动中看见了什么变化”
- **Boundary:** 不证明连续真实 cabin POV、GPS、实时索道状态或精确距离

### R02｜生长页｜华中第一藤｜CONDITIONAL CORE
- **Scene:** 植物 / 岩壁与路径附近的近身体尺度
- **Notice:** 藤本与周围岩面、树体、支撑和高度方向的关系；先看生长方式，不先背物种知识
- **Action / depth:** `LOOK / TRACE` / `S1 → S2`
- **Prompt:** 先沿着它看一遍：从哪里开始，向哪里生长，又依靠了什么？
- **Reveal:** 可选：已核验的植物身份 / 生长策略；未核验字段明确 OPEN
- **Recovery / Exit:** 疲劳/拥堵时跳过；BOTANY 未关闭时只保留观察，不输出物种结论；继续行走；不要求保存
- **Memory:** 一条“生长轨迹”观察或照片，可留白
- **Boundary:** 不证明植物年龄、物种诊断或现场生态因果

### R05｜峰林视域｜红花石林｜CORE VIEW
- **Scene:** 开阔峰林观察
- **Notice:** 峰体的高低、疏密、前后层次；若画面确有江面，再读峰—江关系
- **Action / depth:** `LOOK / COMPARE / WAIT` / `S0 → S1`
- **Prompt:** 先看峰体的高低、疏密和前后层次怎么变化。
- **Reveal:** 仅当当前 source 同时包含所需对象时增加关系说明；不画假江面/假天气
- **Recovery / Exit:** 雾/拥堵/疲劳可只看或直接通过；不存在“错过”；继续观看或行走
- **Memory:** “我记住的一组峰形”；不要求拍照
- **Boundary:** 不证明晴雾同机位差异、精确距离或地质成因

### R06｜河谷页｜观景平台＋多级阶地／不对称河谷｜CORE COMPOSITE / SCIENCE HERO
- **Scene:** 开阔停留 / 河谷与阶地观察
- **Notice:** 先看河谷两侧是否同样陡/同样展开，阶地和路径关系在哪里更明显
- **Action / depth:** `LOOK / COMPARE / RECOVER` / `S0 → S2+DEEP`
- **Prompt:** 先不看解释：河谷两侧看起来一样吗？你能找到层级变化最明显的一侧吗？
- **Reveal:** 同一 authoritative base 上增加 bounded relation；可选 2D 剖面/轮廓；FACT / INFERENCE / OPEN 分层
- **Recovery / Exit:** 疲劳→RECOVER；拥堵→缩短为 S0；Digital OFF→Landscape remains; Return always interrupts；WITHDRAW → 景观恢复主权 → CONTINUE / RETURN
- **Memory:** 记录“我原来没注意到的河谷关系”
- **Boundary:** 不证明现场尺寸、坡度、平台安全、科里奥利单因或施工可实施性

### R07｜象形页｜仓禀峰／仓廪峰｜CORE / NAME OPEN
- **Scene:** 可辨山形 / 命名对象
- **Notice:** 先看轮廓和体量，再看“仓”的联想从哪里产生
- **Action / depth:** `LOOK / FRAME / TRACE` / `S1 → S2`
- **Prompt:** 先看轮廓，再猜：它为什么会被叫作“仓”？
- **Reveal:** 名称来源/字形状态；明确“仓禀峰”当前第一方优先、“仓廪峰”保留 legacy provenance
- **Recovery / Exit:** 视点/标牌 OPEN 时不冻结唯一现场字形；内容可跳过；回到山形
- **Memory:** 保留“我先看到的形状 / 后看到的名字”
- **Boundary:** 不证明地质成因、古代功能或现场标牌最终字形

### R09｜回声页｜盐水女神峰｜CORE / CULTURE REVIEW
- **Scene:** 自然对象 + 地方叙事回声
- **Notice:** 先观察轮廓、方位或与周边峰体的关系，再进入地方叙事
- **Action / depth:** `LOOK / LISTEN / TRACE` / `S1 → S2+DEEP`
- **Prompt:** 先把它当作一座山看：什么轮廓让你开始产生“人物”的联想？
- **Reveal:** FACT / LOCAL NARRATIVE / DESIGN READING 三栏；Deep 可追文本传统与来源
- **Recovery / Exit:** 嘈杂/团队/低注意力 → 只保留 S0/S1；无音频也成立；故事结束后回到眼前山体
- **Memory:** 可记录“山形和故事在我脑中怎样重叠”
- **Boundary:** 不证明古代事件发生于现代命名峰或神话为历史事实

### R12｜望山页｜廪君峰｜CORE
- **Scene:** 观景关系较强的自然对象 + 地方叙事
- **Notice:** 山体轮廓、与周边峰体/视域的关系；再看“廪君”命名如何改变观看
- **Action / depth:** `LOOK / FRAME / LISTEN` / `S1 → S2+DEEP`
- **Prompt:** 先把名字忘掉：这座峰最让你记住的是哪一段轮廓？
- **Reveal:** FACT / LOCAL NARRATIVE / DESIGN READING；Deep 追溯早期文本传统
- **Recovery / Exit:** 低注意力/返程紧迫 → 只保留观察；故事可旅后补读；回到景观 → 继续 / Return
- **Memory:** 把“轮廓 + 一个词”留进石书
- **Boundary:** 不证明古代事件发生位置或传说为地质事实

### R13｜归缝页｜一线天｜CORE / BODY CLOSURE
- **Scene:** 空间收束 / 身体通过 / 离开后回望
- **Notice:** 身体感知空间从收束到重新打开；通过后再回望
- **Action / depth:** `PASS / LOOK BACK / RETURN` / `S0 → S1 AFTER PASS`
- **Prompt:** 进入前：先通过。离开后：如果愿意，再回头看一眼。
- **Reveal:** PASS 中无 Reveal；REOPEN 后可出现“刚才空间关系”短读
- **Recovery / Exit:** UNKNOWN/CLOSED/拥堵/身体不适 → ROUTE/RETURN/HUMAN HELP only；LOOK BACK / RETURN / continue; no completion animation
- **Memory:** 记住“收束→打开”的身体变化；旅后成页
- **Boundary:** 不证明安全净宽、照度、无障碍、现场视点或施工条件

## 04｜Companion / Provisional R-IDs
### R03｜天书候选｜铁券天书｜COMPANION / PROVISIONAL
- **Activation:** HOLD UNTIL visible object/frame is source-bound; no generic prompt
- **Interaction:** `LOOK / FRAME / COMPARE` / `OFF → S1`
- **If active:** 先看可见的边界、纹理或轮廓，再比较命名是否真的来自眼前形态
- **If not supported:** 对象不可辨/关闭/拥堵 → OFF；不为凑十三页补内容
- **Boundary:** 不证明岩性、年代、形成机制或命名唯一来源

### R04｜象形候选｜母子相望／母子峰｜COMPANION / PROVISIONAL
- **Activation:** 只有当同一画面中两个对象均清楚可见时启用
- **Interaction:** `LOOK / COMPARE / FRAME` / `OFF → S1`
- **If active:** 两个可辨轮廓的大小、间距、朝向与相互遮挡
- **If not supported:** 视点不成立 → OFF；不要求为了阅读停在不安全/拥堵位置
- **Boundary:** 不证明地质关系、人物故事发生地或固定最佳视点

### R08｜天书候选｜文山天书｜COMPANION / MERGE PROVISIONAL
- **Activation:** HOLD UNTIL source-bound frame exists
- **Interaction:** `LOOK / FRAME` / `OFF → S1`
- **If active:** 只有可辨的形态/纹理才值得进入；否则保持空白
- **If not supported:** 证据/视点不足 → OFF / SUBSTITUTE
- **Boundary:** 不证明具体地质机制或命名事实链

### R10｜天书候选｜绝壁天书｜COMPANION / MERGE PROVISIONAL
- **Activation:** HOLD UNTIL exact source-bound object is visible
- **Interaction:** `LOOK / FRAME` / `OFF → S1`
- **If active:** 只阅读当前可见的表面、边界、纹理；不套用区域地质结论
- **If not supported:** 证据不足 → OFF，不用区域资料冒充节点事实
- **Boundary:** 不证明节点岩性、时代、成因

### R11｜裂隙候选｜金石为开｜COMPANION / PROVISIONAL / SAFETY OPEN
- **Activation:** Safety/route pressure > content. 未确认安全停留条件时只 PASS / OFF
- **Interaction:** `LOOK / PASS` / `OFF → S1`
- **If active:** 可见裂隙、开合、光线或边界关系；只在安全可停/可看的前提下
- **If not supported:** 拥堵/湿滑/UNKNOWN/CLOSED → CONTENT OFF, ROUTE/RETURN ONLY
- **Boundary:** 不证明安全、净宽、防滑、可停留、地质裂隙成因

## 05｜Companion Pool competition
### 许愿台／板栗树｜OPTIONAL BEHAVIOR ANCHOR
- Evidence: 官方报道记录许愿行为与约20m板栗树；具体运营/现场状态仍需 current check
- Why: 真实行为节点，能把“人如何在景区留下愿望/记忆”作为观察，而不是再造祈愿装置
- Interaction: `LOOK / NOTICE / REMEMBER`
- Ownership: CH10 optional reading; CH15 memory if recorded
- Warning: 避免商业祈愿化、奖励化或伪民俗

### 巨帆启航｜ROUTE HINGE / NOT CORE
- Evidence: 路线节奏/方向价值高于独立深读价值
- Why: 更适合作为方向、节奏、章节过渡，不应为了凑十三页升级为内容 Hero
- Interaction: `ORIENT / PASS`
- Ownership: CH09 primary; CH10 may reference only if editorially useful
- Warning: 不得让 Companion 反向拥有路线主权

### 天书组页｜R03+R08+R10｜MERGED COMPANION FAMILY
- Evidence: 三个命名对象均为 provisional，且独特阅读价值高度重复
- Why: 用一个“人如何把石壁读成文字”的方法页，按真实可见对象替换内容，避免三次重复同一种解释
- Interaction: `LOOK / FRAME / COMPARE`
- Ownership: CH10
- Warning: 任何具体 Prompt 都必须通过 Prompt↔Media semantic binding

## 06｜Depth × state
- `S0 = LANDSCAPE/BODY`: 0–10s research target; prompt then withdraw.
- `S1 = PROMPT/RECOGNITION`: 15–45s; one-screen by default.
- `S2 = RELATION/REVEAL`: mainly R06; only where relation needs explanation.
- `DEEP = EVIDENCE/TRAVEL-AFTER`: user-initiated, not onsite default.
- Quick / Deep / Family / Low-Stamina are state modifiers, not identities or levels.

## 07｜Interaction contract
`ENCOUNTER → ORIENT → OBSERVE → OPTIONAL PROMPT → OPTIONAL REVEAL → WITHDRAW / CONTINUE → REMEMBER`.
Any step may yield to `RECOVER / RETURN / HUMAN HELP`.

## 08｜Hard prohibitions
`NO 13/13 / NO UNLOCK / NO MISSED WARNING / NO REWARD / NO FORCED ORDER / NO PROMPT OVERREACH / NO EVIDENCE-MANUFACTURING OVERLAY / NO NEW PHYSICAL OBJECT BY DEFAULT`.

## 09｜Truth boundary
`FIELD OBSERVED=0 / FIELD MEASURED=0 / G1F HOLD / NO_PROMOTION / NTS / NOT GPS / NOT FOR CONSTRUCTION`.
