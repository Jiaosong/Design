## 5｜Physical Body-Use contract

Every Physical object promoted to MAIN must answer, visually and technically:

`BODY STATE → APPROACH → BODY ACTION → DESIGN RESPONSE/SUPPORT → DURATION → EXIT / CONTINUE`

Examples:
- P02 lean-rest: fatigue → approach edge-safe support → lean/half-rest → body support + view → short recovery → continue/return.
- P01 Step-Light: walking → pass through → no deliberate target action required → short local light response → 1.5–3 s prototype fade → continue; fault/day/maintenance = OFF.

## 6｜Return + Memory closure

Target closure is not `finish all content`. It is:

`RETURN → RECOGNITION → RECORD → TAKE AWAY`

- RETURN: choose route/transport/service homeward.
- RECOGNITION: see again the river, peaks, cable or paths that were just experienced.
- RECORD: My Book / Qingjiang Journal stores only selected scenes, actions, notes, photos or revisit intent.
- TAKE AWAY: paper / digital / selective cultural product extends one remembered variable, not a compulsory souvenir set.
