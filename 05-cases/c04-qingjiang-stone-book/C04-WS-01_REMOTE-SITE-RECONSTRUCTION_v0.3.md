# C04 Remote Site Reconstruction v0.3

**Project:** C04｜清江石书｜红花峰林十三印  
**Stage:** `G1 REMOTE EVIDENCE / PROVISIONAL DESIGN`  
**Purpose:** 在无法现场踏勘的条件下，以官方官网、运营方、政府资料、用户提供的导游词与全景导览图、公开完整游览序列进行远程场地重建；任何尺寸、安全、结构、网络、施工许可均不由网络推断替代。

## 1｜Remote Evidence Levels

- `R1｜REMOTE OFFICIAL VERIFIED`：景区官网、运营方、政府直接确认。
- `R2｜REMOTE TRIANGULATED`：内部导游词／导览图 + 公开路线／运营报道等至少两类来源相互吻合。
- `R3｜REMOTE INFERRED`：由空间拓扑推断，仅允许支持设计探索。
- `F｜FIELD ONLY`：尺寸、安全、坡度、路面、网络、结构、维护和施工批准等。

## 2｜Macro Access Chain

官方 2025 景区攻略明确红花峰林采用索道往返，并支持两种主要进入方式：

`浑水河码头 → 云坛口旅游码头 → 跨江索道 → 红花峰林游步道 → 索道回程`

或：

`自驾 → 云坛口旅游码头 → 跨江索道 → 红花峰林游步道 → 索道回程`

2026 运营资料继续确认云坛口码头、跨江索道与游步道为现行基础设施；索道同时承担游客观景与两岸居民跨江通行功能。

## 3｜Micro Route Reconstruction — R2 Current Route Candidate

用户提供的红花峰林全景导览图与公开完整游览序列可形成一致的环线骨架：

`索道上站 → 华中第一藤 → 清江之吻／铁券天书／一帆风顺等上部脊线节点 → 文人问礼 → 红花点赞／红花火炬 → 游客休息区 → 母子相望／母子峰 → 驼峰山 → 红花石林支线／远眺 → 红花山神／采药翁 → 多级阶地·不对称河谷 → 红花幺妹／红花少女 → 红花大佛 → 仓廪峰／仓禀峰 → 文山天书 → 盐水女神峰 → 绝壁天书 → 金石为开 → 仙灵洞 → 廪君峰 → 一线天 → 索道上站`

该顺序并非官方逐点路线文本，因此等级为 `R2`；但与导览图的空间拓扑高度一致，可作为无法现场踏勘条件下的 Provisional Route Baseline。

## 4｜RC-01 Reclassification

旧导游词与当前公开游览序列之间的主要冲突，更可能是同一环线的不同游览方向／不同版本讲解顺序，而不是红花石林与河谷观察区的真实位置矛盾。

`RC-01: BLOCKING` → `DIRECTION / VERSION CONFLICT`

正式体验不再依赖旧导游词的编号顺序。

## 5｜Red Flower Stone Forest Reclassification

运营方明确写明：游客乘索道可眺望红花石林；全景导览图又将红花石林画在下部游步道附近的支线／景观位置，而公开完整步行序列没有把它列为必要停留点。

因此：

`红花石林 = LANDSCAPE HERO / VIEW OBJECT / OPTIONAL SPUR`

它可以形成数字印记，但不要求游客进入石林内部，也不新增大型设施。

## 6｜P/T and Finale

- P/T 具体露头退出 13 个核心节点，保留 `Research Archive / HOLD`。
- 铁券天书不再承担固定“最后一印”；导览图把它放在上部脊线。
- 终章改为功能槽位 `CLOSURE SLOT`，由真实回到索道前的节点承担。
