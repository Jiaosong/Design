082 / CH15 / P01 / MEMORY
PARTIAL IS COMPLETE · RETURN FIRST · NO COMPLETION SCORE
RETURN → RECOGNITION → RECORD → TAKE AWAY

走过以后，
留下几页清江。

记忆不是“完成十三印”的奖品。回程之后，游客只带走自己愿意留下的那几页；未读、跳过和空白都仍然是完整旅程的一部分。

CH15 只处理离场后的延续：纸本、数字记录与选择性记忆物。路线、安全、服务和现场第一阅读仍由前序系统拥有。

083 / CH15 / P02 / PHYSICAL MEMORY HERO
ODI-02 · EXISTING MATURE DESIGN FIRST · FIELD OPEN

《清江旅记》
保存身体留下的痕迹。

纸本不是任务册，也不是 App 的打印版。它让手写、折痕、画、贴附与路线痕迹独立存在，即使没有网络、账户或手机，记忆仍能成立。

写一句话，不要求解释完整。
折让页角、折线成为旅程的材料证据。
画记录视线、风、水与空间关系。
留白没打开的页不补齐，不伪造完整。
现有成熟资产直接 currentize： physical-memory-currentization-v1.2 / M01_qingjiang_journal_v1_2.svg。A5 / 32pp 等仅为设计测试值；纸张、装订、耐湿和量产仍需样件验证。

085 / CH15 / P04 / PHYSICAL × DIGITAL
COMPLEMENTARY · NO SYNC DEPENDENCY

纸本与数字：
互补，不互相备份。

SELLABLE ≠ REQUIRED · NO BUNDLING TO ROUTE / 13-OF-13
