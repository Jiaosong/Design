## 2. Technical minimum

- hero long edge: `>=4000 px` preferred; `>=2400 px` fallback;
- retain original file when possible, including RAW/HEIC/TIFF/JPEG source;
- no heavy tourism filter or baked brand tint;

- keep horizontal and vertical options; at least one frame should survive a `9:16` safe crop;
- exact GPS is not required for this design acquisition gate; a defensible location/view description is required.

## 3. Priority-0 shot list

### `R05-H01` — 红花石林 / S0 / REQUIRED

Goal: the photograph itself must carry the peak-forest first reading.

- broad peak-forest contour;
- at least three readable depth layers where possible;
- vegetation-to-rock proportion remains legible;
- cable cabin / tourists do not become hero subjects;
- maintain both 16:9 and 9:16-safe composition options.

Recommended `R05-H02`: medium relation image for contour/rhythm mark construction.

Failure: isolated generic peak, excessive saturation, heavy haze effect, non-Red-Flower-Peak-Forest substitution.

### `R01-H01` — 红岩嘴 / S1 / REQUIRED

Goal: show cross-river / moving-view relation, not an isolated rock photograph.

- Qingjiang must appear;
- bare-rock edge must be legible;
- viewpoint should make the cable/cross-river relation understandable where possible;
- retain negative space for the observation prompt.

Recommended `R01-H02`: medium contour/edge/river relation study.

Failure: rock-only close-up, no river, strong HDR.

### `R06-H01` — 多级阶地·不对称河谷 / S2 / REQUIRED

Goal: one real view capable of supporting the later 2D Reveal.

- Qingjiang main channel visible;
- both banks visible;
- terrace/elevation layers readable where possible;
- preferably close to the operator-described observation-platform relation;
- boat is context, not hero.

`R06-H02 / REQUIRED`: medium relation view with one bank emphasized and the opposite bank retained as reference.

OLEANDER draws the later explanatory section. The field executor should not invent a geological diagram.

Failure: river-only aerial, one-bank-only crop, map screenshot replacing a view.

### `R13-H01` — 一线天 / S0 / REQUIRED

Goal: show body-scale slit and natural framing.

- upper-narrow / lower-wide slit readable;
- slit boundaries retained;
- external Qingjiang / boat / north-bank context visible where possible;
- vertical orientation preferred.

Recommended `R13-H02`: human scale reference without portrait-centric posing; obtain release or use non-identifiable framing.

Failure: rock-texture-only image, extreme-wide distortion, person blocking the natural frame.
