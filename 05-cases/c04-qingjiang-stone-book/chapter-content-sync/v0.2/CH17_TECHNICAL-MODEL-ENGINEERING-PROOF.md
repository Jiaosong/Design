真实清江景观拥有体验主权；剖面、节点、模型和轴测承担近读证明。

`MODEL / RENDER PASS ≠ DESIGN PASS ≠ FIELD PASS`。

## CH17-P05｜Plan / Section / Axon / Model必须互相对得上

# 同一个对象不能在不同媒介里拥有不同的空间事实。

跨媒介不变量至少包括：
- anchor identity；
- order；
- adjacency；
- component role；
- source-bound dimensions；
- route / Return relation。

可变化的是：projection、camera、crop、graphic style、annotation density。

检查链：`SOURCE AUTHORITY → SHARED ANCHORS → INVARIANTS → MEDIA TRANSLATION → SIDE-BY-SIDE READ → MEDIUM-SPECIFIC CRIT`。

若轴测 / 模型比线稿更难说明关系，则降级为SUPPORT。

## CH17-P06｜工程 / FIELD验证矩阵

远程研究可完成的：
- 结构体系建议；
- 规范 / 工程参考；
- 推荐规格区间；
- 敏感因素；
- 可逆连接逻辑；
- 维护策略；
- 情景计算。

必须现场 / 专业确认的：
- 基础与既有构件承载；
- 锚固 / 焊接 / 防腐最终规格；
- 坡度、净宽、栏杆、坠落风险；
- 无障碍连续性；
- 湿态防滑；
- 排水与暴雨；
- 实际客流 / 容量；
- 施工许可和运营停用方案。

最终表达：`DESIGN INTENT / RECOMMENDED RANGE / BASIS / SENSITIVE FACTORS / FIELD CHECK / ENGINEERING CHECK / DOES NOT PROVE`。

这页的目的不是把HOLD画成红色警告，而是给后续专业验证建立明确接口。
