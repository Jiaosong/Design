## CH18-P01｜从十三站到多分支阅读网络

早期方案把十三印容易理解成线性节点序列。第一方导览与后续路线审查显示南岸是分支 / 回环网络，因此项目完成关键转向：

`13 FIXED STATIONS → 13 CONTENT OBJECTS / OPTIONAL READING LAYER`。

判断标准：空间真实性、Route authority、可跳过性、回程、身体负担、运营异常。

设计学习：**叙事数量不能反向决定真实路径结构。**

## CH18-P02｜从任务式游戏到探索式陪伴

被否决方向：打卡、进度、收集、下一任务、强制Reveal、13/13。

保留方向：Game Map 的探索感、关系发现、局部Reveal、个人记录。

当前行为语法更接近：
`INTENT → SCOUT → COMMIT → REVEAL → RETREAT / RETURN`，而不是 `HOVER → GLOW → CLICK → CARD`。

设计学习：**游戏感来自行为与空间关系，不来自任务化UI特效。**

## CH18-P03｜实体介入比较：不做，也是一种设计决定

候选包括：
- NO INTERVENTION / VIEW ONLY；
- INFORMATION ONLY；
- P02 lean-rest support；
- Step Light；
- Fluid Rest；
- Qingfengyin。

判断轴：
`LANDSCAPE NEED × BODY NEED × EXISTING FACILITY × REVERSIBILITY × MAINTENANCE × SAFETY × FIELD EVIDENCE × VISUAL INTRUSION`。

当前原则：真实清江 > 新装置；局部实体必须证明必要性。HOLD不是删除，而是等待位置 / 工程 / 运营证据。

## CH18-P04｜R06 与 R13：成熟体验不应共享一个模板

R06：`OPEN / RECOVER / COMPARE`。
- 景观先行；
- 身体恢复；
- 可选Reveal；
- 允许深读。

R13：`COMPRESS / BODY FIRST / RETURN`。
- 通过优先；
- 内容退场；
- 退出后才允许重新解释。

设计学习：**系统一致性不等于每个场景都使用同一个交互组件和同一种信息密度。**

## CH18-P05｜从“VI覆盖项目”到“品牌强度调制”

品牌演化不是让Logo、色彩和图形更密集，而是建立不同媒介的身份强度：
- FULL：封面 / 传播；
- LIGHT：App / 地图 / 内容；
- TRACE：现场服务 / 轻介入；
- OFF：高景观 / 高身体注意场景。

同时把 `恩施大清江 / ENSHI DAQINGJIANG` 的运营 / 景区背书与 `清江石书` 体验身份分开，避免双主标竞争。

设计学习：**品牌成熟度可以表现为知道什么时候不出现。**

## CH18-P06｜KEEP / HOLD / DROP不是审美标签，而是专业角色判断

每个对象必须分开记录：
- Concept State；
- Presentation State；
- Truth / Evidence State。

例如：
- 概念 KEEP 但像素 REVISE；
- 技术图 KEEP SUPPORT 但不是MAIN Hero；
- Physical HOLD 但仍进入Process说明判断；
- AI概念图可作为探索 / 效果参考，但不能替代真实景观、几何和技术证据。

独立审查原则：producer 不自发放 KEEP。工程闭环只证明 EXECUTED / TRACEABLE / REPRODUCIBLE。

章节结论：**真正的方案演化不是展示越来越多版本，而是展示为什么某些关系被保留、某些表达被重做、某些介入被克制地放弃。**
