## CH01-P01｜这不是一个“缺景点”的场地

# 清江的问题不是景观不够，而是已有山水、交通、内容与服务之间缺少一套稳定的阅读关系。

红花峰林已经是成熟运营景区的一部分，不是等待被“策划填满”的空白场地。第一方公开资料能够确认的既有系统至少包括：
- 大清江游船；
- 云坛口旅游码头；
- 跨清江索道；
- 南岸游步道网络；
- 餐饮、停车等配套；
- 水路、索道、步行共同构成的复合游程。

官方资料还把红花峰林描述为清江不对称河谷代表性区段和多级阶地重要观察点。由此形成的设计前提是：

**项目必须先解释“游客如何在现有山水和现有运营系统中更好地看、走、停、读、回”，而不是先制造新的景点数量。**

设计后果：
1. 真实景观与真实移动拥有第一权重；
2. 新内容只能进入已有游程的空隙，而不能重写场地为主题乐园；
3. 新实体介入必须证明它比“不介入”更有价值；
4. Digital / Brand / Memory 都是对真实旅程的支持层，不拥有场地主权。

结论：**C04 是关系重构项目，不是景点增量项目。**

## CH01-P02｜十三个内容对象，不等于十三个必到站点

# 内容库可以有十三印，真实路线不必被改造成十三站。

项目早期最危险的误读是把“十三印”直接投射成线性 `R01 → R02 → … → R13` 的强制路线。

当前第一方导览证据显示南岸游步关系具有多分支 / 回环特征；当前 `ROUTE-03` 也以此为路线权威。因此：
- `R01–R13` 是完整内容 / 互动对象库；
- 路线由真实交通、游步网络、服务与 Return 决定；
- 内容允许跳过、改序、条件关闭；
- “少读几页”仍是完整旅行，不产生失败状态。

问题不是“如何让游客完成十三个点”，而是：

> **怎样让十三个内容对象在不夺取路线主权的情况下，帮助游客真正认出清江的空间、地貌、地方叙事和身体感受？**

设计后果：`13 IMPRINTS = OPTIONAL READING LAYER`；`ROUTE = MOVEMENT / SERVICE / RETURN AUTHORITY`。

## CH01-P03｜最大的体验冲突：解释越多，越可能看不见清江

# 一个自然景区最容易被“好意的信息”再次遮挡。

清江石书需要解决的不是信息贫乏，而是注意力竞争：
- 山水需要长时间、低干扰观看；
- 地貌与文化又确实需要解释；
- 数字界面、导视、品牌、装置和文化内容都可能争夺第一阅读；
- 体力下降、天气变化、回程窗口和异常运营会进一步压缩注意力。

因此不能使用“每到一个节点就解释一次”的均质策略。

项目把阅读强度拆成：
- `S0 LANDSCAPE / BODY`：先看、先走、先通过；
- `S1 PROMPT`：一句观察提示 + 可选短解释；
- `S2 REVEAL`：只在真正需要比较关系的节点进行深读。

其中 R06 是主要 `Landscape First → Relation Reveal` 场景；R13 则相反，优先 `BODY FIRST / CONTENT WITHDRAW`。

设计机会：**把“信息设计”转化为“注意力设计”。**

## CH01-P04｜一条景区旅程，同时是交通、身体、认知和服务系统

# 游客不是只在“看景”，他也一直在判断下一步是否值得、是否走得动、是否回得去。

官方运营资料表明红花峰林与大清江已经通过游船、码头、索道、步行形成复合交通关系；因此设计不能只画体验高峰，还必须面对：
- 到达与换乘；
- 时间与体力变化；
- 分支选择；
- 休息与恢复；
- 无手机 / 无网络；
- 节点关闭或状态未知；
- 人工服务；
- Return。

OLEANDER Service Design / Journey Mapping 要求把成功路径和失败 / 绕行 / 退出路径同时建模。对 C04，意味着：

`SERVICE / RETURN > ROUTE > OBSERVATION > EXPLANATION > MEMORY > SHARE`

这不是功能排序，而是风险和认知负担排序。

设计机会：**把 Return 从旅程最后一页提前为贯穿整个项目的安全底层。**

---

## CH01-P05｜设计机会：把“水陆空联游”转译成三种观看尺度

# 交通不是三段接驳，而是三种认识同一条清江的方法。

第一方资料把红花峰林与大清江描述为水陆结合 / 水陆空复合游程。C04 不把它进一步娱乐化，而是提炼为三种观看尺度：

### BOAT｜水上看
从河谷内部建立连续山水和两岸尺度。

### CABLE｜空中看
在移动视点中建立江、两岸、峰林与站点的整体关系。

### WALK｜山中走
把宏观关系转成身体尺度、局部发现、停留、比较和回望。

三者共同形成：

`WHOLE LANDSCAPE → RELATION → DETAIL / BODY → RETURN / MEMORY`

最终命题因此不是“设计十三个新景点”，而是：

> **在不削弱真实清江的前提下，让已有游程变成一套可轻读、可深读、可退出、可回程、可留下个人记忆的山水阅读系统。**
