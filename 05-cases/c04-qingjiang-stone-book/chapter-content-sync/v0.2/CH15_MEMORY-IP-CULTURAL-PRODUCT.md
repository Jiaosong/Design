# CH15｜记忆、IP与文化产品

Project: `PRJ-C04-QINGJIANG-SHISHU`

## CH15-P01｜记忆系统：PARTIAL IS COMPLETE

# 记忆不是把十三印收集完整，而是把真正看见的几页带走。

Memory 的完成条件不是 `13/13`。游客可能只留下4页、7页或11页，只要这些页来自真实旅程、主动记录和可追溯场景，就构成完整个人石书。

核心链：`RETURN → RECOGNITION → RECORD → TAKE AWAY`。

---

## CH15-P02｜清江旅记｜Physical Memory Hero

物理旅记承担手机之外的旅行记录：
- 路线折页 / 空白页；
- 手写、画线、照片、拓印纹理或短句；
- Core Page预设结构 + Companion / 留白；
- 不要求现场逐页操作。

它必须在无网络、无账号、无App条件下独立成立。

---

## CH15-P03｜我的石书｜Digital Memory Hero

数字层记录“这次我真正看见了什么”，不是成就页。

每页最低信息：
- 场景 / 页名；
- 阅读类型 `S0 / S1 / S2`；
- 用户主动保存的照片 / 一句话；
- 可选来源层；
- 未读页保留为空白，而不是失败灰态。

---

## CH15-P04｜纸本 × 数字：互补，不互相备份

Physical 适合身体痕迹、手写、折叠、留白；Digital 适合场景索引、图片、短记录、重新编排与回访。

共同语法：`SCENE + ACTION + ONE SENTENCE`。

二者不做同步依赖，不要求登录后纸本才完整，也不把纸本降成App二维码载体。

---

## CH15-P05｜文化产品家族：从同一记忆语法出发

已有 `清江一线 / 清江雾气 / 清风吟 / 红花峰崽` 等延展必须按实际状态分层：
- Memory Main：清江旅记 × 我的石书；
- Secondary Extension：与真实旅行、材质、句子或观看动作有关的轻产品；
- Optional Family：适合亲子 / 传播但不承担项目核心叙事；
- HOLD：没有足够产品、材料、运营或权利证据时不伪装成已落地商品。

判断不是“像不像文创”，而是它是否继续项目的记忆关系。

## CH15-P06｜记忆与商业边界

# 能卖，不等于应该成为体验完成条件。

任何文化产品都不得：
- 与路线通行绑定；
- 与13/13完成绑定；
- 代替免费 / 无手机基础体验；
- 把地方叙事写成无来源商品故事；
- 宣称已商业化、量产或版权全部核清。

Brand Strategy 规则要求 `PROMISE → ACTOR → ACTION → DELIVERY OWNER → EVIDENCE → FAILURE / RECOVERY`。因此文化产品必须有生产、供应、售后与更新责任，不能只停在Mockup。

Truth boundary: print specification / manufacturing / pricing / operator approval / sales data / rights remain OPEN unless separately evidenced.
