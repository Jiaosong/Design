# CH14｜品牌与视觉识别系统

- 章节角色：把“清江石书”从项目名称发展为可跨 Web、App、纸图、十三印、实体、展板、视频、文化产品一致识别的品牌系统。
- 结构变更：品牌作为独立章节新增，不压进“记忆/IP与文化产品”。原 CH14–CH18 顺延为 CH15–CH19。
- 原则：品牌识别不能压过真实清江；不同媒介拥有不同品牌存在强度。

## CH14-P01｜品牌核心：为什么叫「清江石书」

# 山水是正文，设计只是翻页的方法。

核心解释：
- **清江**：真实地域与空间主体。
- **石**：不是“石头纹样”，而是峰林、地貌、时间、地方记忆的物质隐喻。
- **书**：不是把景区做成一本书，而是游客通过行走、观看、比较、停留和回望，逐页形成自己的清江理解。

品牌概念：`LANDSCAPE AS TEXT / JOURNEY AS READING`。

禁止：把石头直接做成书页造型，用形式比喻替代体验逻辑。

## CH14-P02｜品牌命题与语言系统

### 品牌层级
- **BRAND NAME**：清江石书。
- **CORE PROPOSITION**：先游清江，再读清江。
- **EXPERIENCE LINE**：水上看，空中看，山中走。
- **SYSTEM PRINCIPLE**：需要时，再打开一页清江。
- **RETURN / MEMORY**：走过以后，再认出同一条江。

不同媒介消费不同语言层级，不在每处重复同一句口号。

### 文案语气
- 不喊口号。
- 不夸张。
- 不网红景区化。
- 不民族符号堆砌。
- 不把自然过度拟人化。
- 句子短，观察性强。
- 少解释，多邀请。

## CH14-P03｜品牌标志 / 字标系统

品牌标志必须作为独立设计成果展开，不只展示一个Logo。

至少包括：
- Primary Mark｜主标识。
- Wordmark｜中文“清江石书”。
- English / Roman system｜如存在英文系统，说明边界。
- Horizontal / Vertical lockup｜横/竖组合。
- Small-size version｜数字小尺寸/图标环境。
- Clear Space｜安全距离。
- Minimum Size｜最小尺寸。
- Incorrect Use｜不拉伸、不加描边、不套俗套民族纹样、不泛滥发光、不在复杂背景失去可读性。

最重要的是解释为什么它属于清江石书，而不是任何山水文旅品牌；生成逻辑应与水、峰、线、印、页、行走痕迹建立可验证的设计关系，而非装饰性拼贴。

## CH14-P04｜色彩系统：来自清江，但不复制风景照片

色彩按角色建立，不只是“清江蓝/山林绿/石头灰”。

- **LANDSCAPE BASE**：大面积低干预基础色，用于页面背景、纸本、技术图底层。
- **QINGJIANG WATER**：清江水色，作为主要识别色但克制使用。
- **INK / STONE**：文字、结构、技术图。
- **SEAL / MEMORY**：小面积“印”或记忆强调。
- **STATE COLORS**：NORMAL / DEGRADED / CLOSED / UNKNOWN，必须与品牌色逻辑区分。

核心边界：`BRAND COLOR ≠ OPERATIONAL STATUS COLOR`。品牌统一不能降低状态识别和安全判断。

## CH14-P05｜字体与版式系统

品牌辨识度应大量来自 `TYPOGRAPHY + LAYOUT`，而非只靠Logo。

层级：
- DISPLAY：大标题、章节、品牌语句。
- BODY：长文阅读。
- DATA / TECHNICAL：数字、图注、技术信息。
- BILINGUAL：中英并置比例与层级。

版式语言：真实大景观、留白、细线、清楚层级、纸/墨/线/印的现代转译；禁止仿古书法式“纸墨风”。

核心方向：`CONTEMPORARY EDITORIAL + LANDSCAPE SPACE`——现代编辑设计 + 清江景观尺度。

---

## CH14-P06｜图形语言：线、印、页、路径成为一套系统

从项目自身提取图形行为，而不是建立抽象民族纹样图库：
- **LINE｜线**：路线、河流、视线、Relation Reveal；用于导航、关系、信息连接。
- **SEAL｜印**：来自十三印；作为发现、保存、记忆的轻识别元素，不变成13个红印章。
- **PAGE｜页**：来自“书”；不是画一本书，而是内容 Reveal / Layer / Fold / Crop 的版式逻辑。
- **TRACE｜痕迹**：来自行走、路线、记忆；用于 My Book / 清江旅记 / 路线记录。

可形成动态图形链：`LINE → REVEAL → TRACE → MEMORY`。

---

## CH14-P07｜图标、地图与信息图形语言

品牌必须延伸到 Route icon、Boat、Cable、Walk、Return、Service、Read、Memory、Offline、状态、十三印、安全/关闭等真实功能信息。

目标：`SIGNAGE / MAP / APP SHARE ONE VISUAL GRAMMAR`。

但地图、导视和状态信息必须优先判读效率，不能为了统一视觉把所有功能“Logo化”。

核心边界：**识别系统可以统一视觉语言，但不能降低功能信息的判读效率。**

---

## CH14-P08｜跨媒介品牌应用

不是Mockup墙，而是证明品牌系统在不同媒介中以不同强度工作：
- Web：章节标题、Hero、图注、技术页。
- App：TODAY、ROUTE、READ、MY BOOK。
- Paper Map：纸图与Return。
- 十三印：内容入口与轻标记。
- Physical：P02等实体上的最小识别。
- 清江旅记：纸本记忆。
- Exhibition / Board：展板。
- Motion：视频标题、转场、字幕。

建立 `BRAND PRESENCE SCALE`：
- FULL IDENTITY：传播/封面。
- LIGHT IDENTITY：App/地图/内容。
- TRACE：现场。
- OFF：高景观/高身体注意场景。

此强度逻辑与项目FULL/LIGHT/OFF思想相呼应，但不得与运行状态系统混为一套。

## CH14-EXPANSION｜后续品牌专业页候选
- Brand Architecture：清江石书/十三印/我的石书/清江旅记等主从关系。
- Naming System：R01–R13、产品、内容、场景命名规则。
- Editorial System：Web、展板、册子的网格与视觉节奏。
- Motion Identity：Reveal / Withdraw / Trace / Return 的品牌动效。
- Photography Direction：真实清江图像选择、尺度、人物、景观占比与禁区。
- Illustration / Diagram Direction：分析图、地图、技术图统一但不模板化。
- Material / Print：纸张、压印、墨、透明层、折页等实体传播语言。

### 与后续章节的边界
- **Brand**：整个项目如何被识别。
- **Memory / IP**：游客离开以后，哪些东西继续被带走和传播。

因此品牌不允许被压缩成记忆/IP章节中的一张Logo页。
