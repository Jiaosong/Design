## CH02-P01｜清江不是一个“点”，而是一套山水关系

### 主标题
# 江、岸、峰、谷，共同构成清江的空间主体。

副标题：设计首先面对的不是十三个内容点，而是一条被河谷、峰林、两岸、交通与移动视点共同组织的山水系统。

### 五类空间对象
- **江**：视觉轴、移动空间、两岸分隔、尺度参照、游船观看界面、回程方位识别。结论：**江面既是景观主体，也是整个游程最稳定的空间参照。**
- **两岸**：高差、观看、跨江、站点与步行网络；体验从“看对岸”变成“跨越—进入—回望”。
- **峰林**：遮挡、框景、背景、方向、空间压缩、视野突然打开。结论：**峰林通过遮挡与显现制造清江最重要的空间节奏。**
- **河谷**：控制人和山体尺度、视线深度、R06展开阅读、R13减弱内容。结论：**河谷是一套控制视野、身体与注意力的空间结构。**
- **天空/雾/风/水面**：提醒设计不能假设所有时刻拥有同等可见度与信息容量；后续可与 NORMAL/DEGRADED/UNKNOWN 关联，但本页不做状态机。

### 核心图
大幅清江山水关系轴测/剖视图，只保留江、南北岸、峰林、河谷、索道、主要步行关系；箭头表达 `看对岸 → 跨江 → 进入山体 → 再看清江`。

三个 Spatial Finding：
1. 江是稳定参照。
2. 两岸制造观看转换。
3. 峰谷控制空间收放。

页面底部：**设计后果：项目必须围绕“观看关系的变化”组织，而不是围绕十三个点组织。**

## CH02-P02｜三种移动方式，产生三种不同的清江

### 主标题
# 同一条清江，在三个高度被重新认识。

副标题：游船、索道和步行不只是交通方式，它们分别建立江域尺度、两岸关系尺度和身体尺度。

### 游船｜水上｜河谷内部
- 视点低、运动连续、两岸同时出现、峰林形成连续长景、身体操作少。
- 设计后果：**BOAT：景观信息强，数字信息应弱。**

### 索道｜空中｜两岸关系
- 高视点、移动、两岸同时可见、江面成为空间关系线、不适合深读。
- 设计后果：**CABLE：关系判断强，解释和操作应克制。**

### 步行｜山中｜身体尺度
- 速度下降、身体参与上升、可停留、可观察细节、分支选择和疲劳增加。
- 设计后果：**WALK：允许更深内容与互动，但必须随场景和身体状态变化。**

### 核心尺度线
`TERRITORY → RELATION → BODY`
中文：`江域尺度 → 空间关系尺度 → 身体尺度`

## CH02-P03｜真实路线不是十三个点，而是分支与回环网络

### 主标题
# 游客走过的是网络，不是十三站。

副标题：官方导览关系显示真实游步系统具有分支、连接与回环；十三印不能反过来成为路线骨架。

### 三层并置
1. **SOURCE / 官方导览关系**：保留官方路线图原始关系，不先美化。
2. **Spatial Finding / 关系转译**：只保留主网络、支路、回环、江、两岸、交通关系。
3. **Design Consequence**：Route Layer 负责方向、选择、交通、服务、Return；Content Layer 负责发现、阅读、比较、互动、记忆。

核心公式：

# ROUTE ≠ CONTENT ORDER

> **十三印可以改变游客“看见什么”，但不能决定游客“必须怎么走”。**

## CH02-P04｜清江空间不断收放

### 主标题
# 开阔、收束、再打开——空间本身已经在控制注意力。

### 空间序列
`远景/江面 OPEN → 索道 MOVING OPEN → 山路 FILTERED → R06 河谷 OPEN + STAY → 山体路径 COMPRESSED → R13 HIGH COMPRESSION → 退出 REOPEN → 回看清江 MEMORY`

### 四条变量曲线
- 视野宽度。
- 身体压力。
- 内容容量。
- Return / Safety 优先级。

### R06
`OPEN SPACE → LOWER BODY PRESSURE → LONGER ATTENTION → OPTIONAL DEEP READING`
河谷展开，可停留，可允许短恢复、关系揭示和可选深读。

### R13
`COMPRESSION → HIGH BODY ATTENTION → LOW CONTENT CAPACITY → PLAY OFF / RETURN FIRST`
空间收束时，身体通过、脚下判断、出口和回程成为第一任务；增加内容会竞争有限注意力。

## CH02-P05｜从场地分析得到的第一组设计规则

### 主标题
# 场地不是设计的背景，它已经给出了第一组设计规则。

### Finding → Consequence
1. **清江本身已经足够强** → 不用大型视觉物件与清江竞争；真实清江优先。
2. **三种移动方式产生三种观看尺度** → 不用同一种内容密度和交互覆盖全程；场景决定内容密度。
3. **路线是网络** → ROUTE 与十三印分离；`ROUTE ≠ CONTENT ORDER`。
4. **空间不断收放** → R06 可 Reveal，R13 必须 Withdraw。
5. **身体状态不断变化** → 实体、数字和内容不能一直保持同一强度。
6. **清江始终是方位参照** → 数字不是唯一导航；Return 同时存在于空间、标识、纸图与人工服务。

### 章节收束
CH02读完后应明确：清江是什么样的空间；三种移动为什么必须差异化；为何十三印不能成为十三站；为何R06可以增加内容而R13必须减少；空间事实如何生成设计规则。
