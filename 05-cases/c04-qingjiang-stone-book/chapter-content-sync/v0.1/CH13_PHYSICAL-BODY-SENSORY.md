# CH13｜实体、身体与感官设计

- 章节角色：判断哪些体验问题必须通过实体、身体接触或感官介入才能解决。
- 禁止：把P02、步步生光、Fluid Rest、清风吟画成四件并列产品。
- 生成链：`身体需求 → 现场行为 → 是否必须介入 → 最小介入程度 → 人体关系 → 感官反馈 → 场地关系 → 构造与维护可能性`。

## CH13-P01｜Physical Strategy｜什么时候才值得增加一个实体

# 不是因为这里“缺一个设计”，而是因为身体真的出现了一个问题。

每个场景先问：`0｜什么都不增加，会发生什么？` 如果真实景观、既有设施和路线已经成立，不介入就是有效方案。

介入四级：
- **LEVEL 0｜EXISTING**：不增加新实体。
- **LEVEL 1｜SUPPORT**：最小身体支持，代表P02。
- **LEVEL 2｜SENSORY FEEDBACK**：轻感官介入，如步步生光概念。
- **LEVEL 3｜SPATIAL INTERVENTION**：强空间介入，如Fluid Rest。

每提升一级重新判断：BODY VALUE / LANDSCAPE COST / SITE NECESSITY / MAINTENANCE COST / SAFETY CONSEQUENCE / FIELD DEPENDENCY。

当前设计角色：P02高优先级深化；步步生光保留概念继续筛选；Fluid Rest只允许单点竞争；清风吟作为感官候选，需避免俗套风动景观装置。

结论：**实体设计不是“项目还缺什么”，而是“身体还缺什么”。**

## CH13-P02｜P02｜短恢复：从“坐下”重新定义为“恢复一下”

# 疲劳不总意味着坐下。有时身体只需要一分钟重新站稳。

行为链：`WALK → FATIGUE → STOP → LEAN → LOOK → CONTINUE / RETURN`。

P02支持：LEAN / REST / LOOK / DECIDE。

必须研究真实接触：手扶、前臂支撑、髋/腰短倚、半坐、站立观看；并验证成年站立、成年倚靠、长者短恢复、儿童+成人同行、两人错身。

设计完成状态不是“人坐在P02上看P02”，而是 `身体被支持 → 人重新抬头 → 清江重新成为主体`。

结论：**P02不是新的停留目的地，而是让游客重新获得继续观看和继续行走能力的一段身体支持。**

## CH13-P03｜P02｜人体、边界与使用冲突

# 一个可以倚靠的构件，首先必须是一段不会制造新冲突的公共边界。

研究：
1. 身体尺度：站立/倚靠/短半坐；无现场精确数据时用推荐值+合理区间+FIELD校核项。
2. 安全边界：严格区分 FALL PROTECTION 与 BODY SUPPORT；不能削弱既有防护逻辑。
3. 儿童行为：攀/踩/钻/坐/游戏误用。
4. 双人/多人：不堵主通道、视线、扶手、通行空间。
5. 转身/回望：走来→停→转身→靠→看→再走。
6. 雨湿/防滑/边缘/热舒适：接触面和足下现实性。

核心剖面应出现：山地路径、栏杆/支撑、人体、视线、安全边界、通行带，并标 BODY SUPPORT / CLEAR WALKING ZONE / VIEW / FALL EDGE / FIELD VERIFY。

结论：**P02只有在身体支持、安全边界和公共通行同时成立时，才有资格继续进入构造深化。**

## CH13-P04｜步步生光｜身体经过之后，反馈短暂发生

# 光不是目的，它只是身体经过以后留下几秒钟的痕迹。

核心：`STEP → RESPONSE → FADE`，而不是STEP→SCORE。

原则：
1. 不要求改变步态；正常行走即可。
2. 反馈时间短：APPEAR→FADE，路径重新安静。
3. 不形成完成逻辑：无正确踩法、分数、奖励。

现实问题必须显式：白天是否可读、防滑、排水、电源/维护、多人同时经过的噪声、是否把注意力拉向足下过久。

当前角色：**身体—短反馈—退场**交互原型，不宣称已实施。

## CH13-P05｜Fluid Rest｜身体真正停下来时，空间怎样改变

# 当“短倚靠”不够时，才有资格讨论一个真正改变停留方式的空间介入。

Fluid Rest目标：较长恢复 + 身体姿态改变 + 持续观看清江，接近 `BODY-LANDSCAPE INTERFACE`。

先证明P02不足：候选场景需同时满足较长停留、明显疲劳、持续视野价值、足够空间、不妨碍通行、不破坏自然边界。

形态从身体生成：SIT / RECLINE-LEAN / TURN，再形成表面、坡度、边缘、材料、支撑。

“Fluid”不做水波造型，表达 `BODY TRANSITION`：走→停→靠→坐→看。

必须做景观竞争测试：无装置 vs 介入后，若第一视觉变未来感Hero物件，则方向失败。

角色：`SINGLE-SITE COMPETITION`，不能成为全线标准家具。

## CH13-P06｜Fluid Rest｜人体、剖面、材料与排水

# 强实体介入的代价，必须在剖面里被看见。

必须表达：
- 典型剖面：山体/地面、Fluid Rest、人体、路径、视线。
- 人体接触：背、臀、腿、脚与表面关系。
- 排水：高点、低点、方向、接缝、雨水退出。
- 防滑：人体使用面与足下区域不同策略。
- 材料热舒适：夏季太阳、冬季低温、潮湿。
- 结构与基础：受力逻辑、支承、与地形连接、基础、可替换构件。

边界：`CONCEPT / NTS / FIELD OPEN / NOT FOR CONSTRUCTION`。FIELD OPEN不等于不画清楚。

结论：**一个实体越像Hero，越应该用剖面、人体、排水和维护证明它不是一张效果图。**

## CH13-P07｜清风吟｜设计“等待风”的行为

# 风看不见。设计也不一定需要把它变成一个大型装置。

潜力不是风动造型，而是 `WAIT + LISTEN + NOTICE`。

从自然现象开始：风向、植物运动、温度、声音、雾、水面变化。比较：
- 0 NONE：什么都不做；如果已足够就停。
- 1 TRACE：用细小运动/声音/材料轻反馈让风可被察觉。
- 2 FRAME：提供停一下/等待/听的身体条件，重点是人愿意多停几十秒。

体验序列：`WALK → NOTICE → STOP → WAIT → WIND/SOUND → CONTINUE`。

禁止：民族符号化、风铃景观化、巨大风动雕塑、强解释。

结论：**感官设计不是替自然制造风、光和声音，而是让游客在正确的时候意识到它们本来就在这里。**

## CH13-EXPANSION｜后续独立深化页
- P02方案演化：从座椅/平台/独立家具收敛到短倚靠。
- P02 1:1人体行为验证：站、倚、半坐、儿童误用、双人使用。
- P02位置选择规则：适合/不适合场景。
- 步步生光昼/夜性能比较。
- 步步生光技术原理与维护替换：感应、模块、排水、防滑、电源。
- Fluid Rest候选场景比较。
- Fluid Rest方案A/B/C剖面对比。
- 清风吟无装置/微介入/强介入三方案对照。

实体介入梯度：`不介入 → 身体支持 → 轻反馈 → 空间介入 → 感官提示`；判断标准始终是：**身体因此获得了什么？真实清江失去了什么？**
