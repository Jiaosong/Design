# CH04｜人群与使用状态分析

- 章节角色：解释同一个清江、同一条路线、同一个 R06/R13 为什么面对不同的人，内容深度、互动强度、身体支持和回程优先级必须变化。
- 状态：`AUTHORING SYNC / NOT PAGE-ID MIGRATION`
- 禁止：把本章压成4张 Persona 卡。
- 核心：`CONDITION → NEED → DESIGN RESPONSE`，而不是“年龄→产品版本”。

## CH04-P01｜人群不是年龄分类，而是一组不断变化的使用状态

# 同一个游客，在一天里也会变成不同的人。

年龄只能解释一部分差异。真正影响清江体验的是某个具体时刻的体力、注意力、行动能力、阅读意愿、数字熟悉度、同行关系和回程压力。

### 7个设计变量
1. **Mobility｜移动能力**：影响路线选择、短恢复、R13通过、Return容忍度。
2. **Stamina｜体力与疲劳**：充足→中等→疲劳→需要恢复；体力下降时内容密度下降、互动减少、Return提权、Physical support增加。
3. **Attention｜注意力容量**：景观、找路、照看儿童、过窄道、拍照、疲劳、同行交流共同占用注意力。**可用注意力是一种设计资源。**
4. **Reading Depth｜阅读深度**：看见→理解→比较→深入阅读→继续研究。
5. **Digital Comfort｜数字熟悉度**：主动手机→只看路线→低数字熟悉→完全无手机；App不能让后两类体验残缺。
6. **Companion Condition｜同行关系**：独行、朋友、情侣、家庭、儿童陪同、长者陪同、小团体；影响速度、停留、等待、导航和Return决策。
7. **Return Urgency｜回程压力**：低→高；一旦升高，Explanation/Play/Collection 全部降级。

结论：**清江石书不为“某类人”设计固定版本，而是让同一套系统随着人的状态改变深度。**

## CH04-P02｜儿童 / 亲子：不是给儿童加更多游戏

# 对儿童来说，最重要的不是“更多任务”，而是更容易共同发现。

- 注意力短：更适合 `看见 → 比较 → 找到 → 指给别人看`，不适合长文/长解释。
- 身体尺度不同：栏杆、路边植物、岩石、水、足下变化都与成人视点不同。
- 设计对象是 `CHILD + ADULT`，优先共同动作，不做儿童独立任务链。

动作重点：LOOK / COMPARE / TRACE / STEP / REMEMBER；弱化长阅读、复杂操作、强地图判断。

R06例：不要给儿童“不对称河谷”的定义；可问“哪边山更近？哪边更高？江水从哪里穿过去？”成人同时可进入更深解释。

十三印可发现部分内容，但不要求13个都找到；“我的石书”可留画、形状、一句话、照片，而不是知识答题。

结论：**儿童层目标是降低理解门槛，同时保护共同观看，不把项目儿童化。**

## CH04-P03｜青年探索者：允许探索，但不把整个清江游戏化

# 探索感来自路线、发现和判断，不来自任务数量。

青年可以接受更多分支、数字地图、自主选择、长步行、摄影、社交、轻游戏和内容发现；但核心不是任务，而是 **Agency：我能决定怎么走。**

- **Route Choice**：不同时间/方向/体力下的真实路径选择。
- **Optional Discovery**：地图显示“附近可能有内容”，不显示“还有4个任务未完成”。
- **Frame / Share**：允许摄影分享，但不为了传播制造巨大打卡装置。
- **Deeper Reading**：可主动进入R06空间关系、R07地名、地方故事和更深十三印。

结论：**青年体验的游戏性应该来自“自己发现了一条路”，而不是系统告诉他还有多少没完成。**

## CH04-P04｜成年深读者：允许更深，但不要逼所有人一起深读

# 深度内容应该存在，但它必须可以被主动打开。

### 深度分层
- `L0｜Landscape`：只看清江。
- `L1｜Recognition`：知道这是什么。
- `L2｜Relation`：理解与周围的关系。
- `L3｜Context`：地方文化/空间知识/来源。
- `L4｜Evidence`：来源、研究、资料。

核心：**深度内容不是应该删除，而是应该建立进入顺序。**

R06：`Landscape → Relation → Explanation → Evidence`。
R07：看到仓禀峰/仓廪峰→发现名称差异→主动打开→进入来源差异。

结论：**专业深度不是界面噪声；问题不是内容太多，而是内容是否在正确层级出现。**

## CH04-P05｜长者 / 低体力 / 低数字熟悉度：减少负担，而不是减少尊严

# 当身体开始疲劳，系统首先应该减少决定，而不是增加提示。

优先序：`RECOVER → ORIENT → CONTINUE / RETURN → OPTIONAL CONTENT`

- 体力下降时优先坐/倚/停、确认方向、判断继续或返回，再考虑内容。
- 疲劳时减少复杂地图、多模式选择、长内容和多状态记忆。
- 无手机时仍必须知道：在哪里、回哪边、服务在哪里、前面是什么、是否应该继续。
- Paper Map / Signage / Human Service / Landscape Recognition 并行存在。

P02逻辑：`身体疲劳 → 不一定需要长坐 → 需要短恢复 → Stand / Lean / Short Sit → 再决定继续或回程`。

结论：**可达性不是给一类人增加特殊版本，而是让系统在身体能力下降时仍保持清楚、可退、可返回。**

## CH04-P06｜同一个 R06，四种不同深度

# 不是四个版本的 R06，而是一个场景允许四种进入深度。

必须使用同一个 R06 真实景观，不做四个不同空间版本。

- **所有人共同拥有**：看完整河谷；清江、两岸、山体、江面和自己的位置；无需数字。
- **儿童/亲子｜SEE / FIND**：LOOK / COMPARE；通过问题共同观察。
- **青年探索｜COMPARE / DISCOVER**：COMPARE / TRACE / FRAME；可进一步打开路线和空间差异。
- **成年深读｜RELATION / EXPLANATION**：关系、空间结构、地方知识、来源。
- **低体力｜RECOVER / RETURN**：可以什么都不读；先 LEAN、RECOVER、RETURN。

深度剖面：`真实清江 → LOOK → COMPARE → RELATION → DEEP READ`，而 `RECOVER / RETURN` 穿过全部层级。

Audience Depth Model：`SHARED LANDSCAPE → VARIABLE DEPTH → VARIABLE SUPPORT → SAME RETURN`。

章节结论：人群分析不是决定“给谁设计什么产品”，而是决定同一套清江体验什么时候更深、更轻、更慢、更少，或直接退场。
