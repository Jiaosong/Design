# CH03｜地域文化与内容分析

- 章节角色：决定清江到底有什么值得被读、为什么适合在某个地方/时刻出现，以及通过什么动作被体验。
- 同步来源：2026-08-17 当前对话逐页展开内容。
- 核心链：`内容来源 → 内容价值 → 空间匹配 → 游客动作 → 设计载体 → 是否进入十三印`。
- 禁止：把本章做成恩施文化百科、纹样拼贴、地方传说资料墙。

## CH03-P01｜不是所有文化，都应该被放进清江

### 主标题
# 先判断什么值得留下，再决定怎么讲。

副标题：清江石书不是把地方文化全部搬进景区，而是筛选那些能够改变游客观看、理解、行动或记忆方式的内容。

### 内容来源组

#### A｜山水与自然认知
峰林形态、河谷关系、两岸关系、植物观察、地形与空间关系、水/雾/风等感官现象。目标不是百科科普，而是**帮助游客重新看见眼前已经存在的清江**。重点对应 R02/R05/R06。

#### B｜地名与地方命名
例如 `R07｜仓禀峰／仓廪峰`。内容价值不是替游客宣布唯一正确答案，而是追踪为什么出现不同写法、一个名字如何改变观看；名称是进入地方知识的方法。

#### C｜地方故事与人物叙事
可继续深化 R09/R12。判断故事发生位置、游客是否有耐心听、适合听/读/比较还是只留线索，以及是否与眼前景观有关。与空间无关系的故事，不因“文化重要”强行进入节点。

#### D｜地方生活智慧与身体经验
等待、纳凉、观风、看水、休息、行走、识路、记录旅程。可连接文化→身体→实体→感官，但本章只建立“地方经验可以转化为身体行为”的研究方向，不提前宣称具体民俗与设计的事实绑定。

### 内容筛选漏斗
`所有可能地方内容 → 与清江有关吗？ → 眼前能看见/感受到吗？ → 会改变游客观看或行动吗？ → 有合适场景吗？ → 不讲它体验是否仍完整？ → 进入清江石书内容系统`

设计后果：**只有能够与真实场景、游客行为和空间体验建立关系的内容，才进入十三印。**

## CH03-P02｜从“文化内容”变成“游客动作”

### 主标题
# 文化不是被“展示”的，而是通过动作被理解的。

核心：`CONTENT → ACTION`。

### 动作语法
- **LOOK｜看**：景观、峰形、河谷、植物、水面、空间关系；眼前可见，不先用文字替代。
- **COMPARE｜比较**：两岸、峰形差异、地貌关系、不同视角、名称与形态；R06先自己比较，再解释。
- **TRACE｜追踪**：地名来源、路线痕迹、水系、历史线索；R07适用。
- **LISTEN｜听**：地方故事、口述、声音、短叙事；只在允许停留的场景发生。
- **WAIT｜等待**：风、雾、水光、视线变化；有时设计只是让游客多停一会儿。
- **FRAME｜取景**：峰林、对岸、局部关系、回望；不是网红拍照框，而是视觉判断行为。
- **STEP｜行走/踏步**：身体路径、距离、高差、空间变化；可支持低强度互动。
- **REMEMBER｜记忆**：清江旅记、我的石书、路线、名字、回望；记忆不是奖励。

### 视觉组织
避免八张卡片墙。更适合建立眼睛→身体→感官→经历的动作轨迹，并把 R05/R06/R07/R09-R12/R13 绑定到真实动作。

核心判断：**同一种文化内容，因为场景不同，动作也可以完全不同。**

## CH03-P03｜内容应该出现在哪里

### 主标题
# 内容不是贴在节点上的标签，场景决定它能不能发生。

核心公式：

# CONTENT × SCENE × ATTENTION

### 场景 A｜移动观看（游船/索道/R01）
特征：移动、操作机会低、视野变化大。适合看、辨认、非强制线索、极短内容；不适合长文、长视频、强交互、必做任务。

> **移动场景中的文化应该成为“看见的线索”，而不是“停下来的课程”。**

### 场景 B｜开阔停留（R05/R06）
视野展开、可停、身体压力低。适合 LOOK / COMPARE / TRACE / 可选阅读 / 短解释 / 深读入口。R06顺序：`完整河谷 → 自己比较 → 关系 Reveal → 可选深读`。

### 场景 C｜收束通过（R13）
路径窄、身体注意高、安全与出口优先。适合极弱内容、方向、出口、Return；不适合游戏、故事、深读、多媒体。

> **文化体验成熟的标志，不是哪里都有内容，而是知道哪里应该沉默。**

### 场景 D｜离场/回程/旅后
适合 REMEMBER、故事补读、我的石书、清江旅记、路线回看、记忆物。内容从“告诉你应该怎么看”转成“你刚才看见了什么？”

### 矩阵
横轴：移动→停留→通过→回程；纵轴：看/比较/追踪/听/等待/取景/踏步/记忆；以相对适配强度表达，不伪造精确认知测试值。

## CH03-P04｜用清江真实案例证明内容逻辑

### 主标题
# 文化内容只有放回真实场景，才成为设计。

### Case 01｜R06
河谷不是知识点，而是一次比较行为。`LOOK → COMPARE → REVEAL`。景观为主内容，数字/解释为次内容。

### Case 02｜R07
`仓禀峰／仓廪峰`：地名不是标准答案，而是一条地方知识线索。`看见名称差异 → 追踪来源 → 理解命名 → 保留 FIELD OPEN`。动作：TRACE。

### Case 03｜R09 / R12
地方故事应帮助重新看景观，而不是脱离景观讲故事。`地方故事 → 眼前形态/场景 → LISTEN / LOOK / COMPARE → 继续走`。

### Case 04｜R13
最重要的内容可能是暂时没有内容。空间压缩后：`READ OFF / PLAY OFF / BODY ON / RETURN ON`。

> **如果文化内容让游客在最需要看路的时候低头看屏幕，这个内容就是放错了地方。**

### 章节总公式
`来源 → 与清江的关系 → 场景适配 → 游客动作 → 内容深度 → 载体 → 记忆`

收束句：**清江石书不是把文化“装进景区”，而是让文化在游客真正看、走、停、听和回望清江时出现。**
