# CH05｜游程与行为分析

- 章节角色：解释一个人在一次真实清江游程中，身体、注意力、信息需求和回程需求如何持续变化。
- 核心链：`时间推进 → 空间变化 → 身体变化 → 注意力变化 → 行为变化 → 设计需求变化`。
- 与 CH04 区分：CH04 是“不同状态的人需要什么”；CH05 是“同一个人在一次游程中状态怎样变化”。

## CH05-P01｜一次清江游程，不是连续保持同一种体验状态

# 人在移动，设计的优先级也必须跟着移动。

完整行为分析模型：
1. **ARRIVE｜到达**：先问“我到了哪里”；方向确定性高于文化内容；重点 ORIENT / SERVICE / RETURN。
2. **ORIENT｜定向**：判断游船/索道/步行、时间、体力、回程；决策密度高，减少深文化和游戏。
3. **MOVE｜移动**：游船/索道；空间变化占注意力；减少操作文本，景观第一读，不制造必做内容。
4. **EXPLORE｜进入步行**：速度下降、自主选择和身体参与上升；路线仍重要，内容开始允许变化。
5. **DISCOVER｜发现**：遇到R节点、地名、植物、故事线索；是 OPTIONAL ENTRY，不是任务状态。
6. **STOP / OBSERVE｜停留**：如R06；行走下降、观看上升、身体压力下降，允许更长注意和更深阅读。
7. **PASS｜通过**：如R13；身体/路线判断上升，信息容忍度下降，BODY / EXIT / RETURN 提权，PLAY / READ退场。
8. **RETURN｜回程**：关心怎么回来、还有多远、服务、休息；不再增加内容负担。
9. **REMEMBER｜记忆**：经历完成后，路线回看、照片、手写、我的石书、清江旅记才真正成立。

视觉：连续游程剖面/时间轴，并同步身体状态、注意力、信息需求、数字介入、Return优先级。

结论：**设计不是沿路线不断加东西，而是在不同阶段不断重新排序优先级。**

## CH05-P02｜身体状态不是背景变量，它直接决定设计

# 游客不是一双移动的眼睛，他还有一副不断疲劳、停下和恢复的身体。

身体动作语言：
- `STAND｜站`：到达/定向/短观察；信息需快速读懂。
- `MOVE｜移动`：游船/索道/步行；减少精细操作。
- `WALK｜持续行走`：产生体力消耗、路线判断、足下注意、同行节奏差异；不能持续要求停下操作。
- `STOP｜停`：注意力从方向转向观察/理解。
- `LEAN｜倚`：P02行为基础；停一下→倚一下→看一下→决定继续。
- `SIT｜坐`：更长恢复；需要回答为什么在这里坐。
- `PASS｜通过`：R13；身体优先，解释降级。
- `TURN / LOOK BACK｜转身/回望`：重新理解自己刚才经过的空间，R13尤其重要。

身体语法：`MOVE → STOP → OBSERVE → LEAN / RECOVER → CONTINUE / RETURN`。

设计后果：实体设计从身体状态推导，不作为景观家具被添加。

## CH05-P03｜注意力是一种有限资源

# 游客每一刻能处理的信息，都有上限。

注意力对象：
- LANDSCAPE｜景观
- BODY｜身体
- ROUTE｜方向
- PEOPLE｜同行关系
- CONTENT｜内容

每个场景必须有第一优先级：
- 游船：LANDSCAPE。
- 到达：ROUTE / SERVICE。
- R06：LANDSCAPE → BODY/RECOVERY → CONTENT。
- R13：BODY / ROUTE；CONTENT 可以 OFF。

### Attention Budget
用相对设计优先级图表达，不伪造精确百分比或认知测试数据。

### 从注意力导出介入状态
- **FULL**：可停留、身体压力低、路线清楚、用户主动进入。
- **LIGHT**：移动或短停，注意力部分被景观/路线占用。
- **OFF**：通过、高身体压力、路线/Return优先、UNKNOWN/CLOSED等；内容与游戏主动退出。

结论：FULL/LIGHT/OFF 不是软件工程先验，而来自 `ATTENTION BUDGET`。

## CH05-P04｜把“行为”变成设计动作语言

# 游程不是一串节点，而是一串行为。

正式行为语法：
- LOOK｜看
- COMPARE｜比较
- TRACE｜追踪
- LISTEN｜听
- WAIT｜等待
- FRAME｜取景
- STEP｜踏步/行走
- RECOVER｜恢复
- PASS｜通过
- LOOK BACK｜回望
- RETURN｜返回
- REMEMBER｜记忆

组织方式：
- 移动类：MOVE / STEP / PASS / RETURN
- 观察类：LOOK / COMPARE / FRAME / LOOK BACK
- 理解类：TRACE / LISTEN
- 停留类：WAIT / RECOVER
- 记忆类：REMEMBER

动作与系统绑定：
- LOOK 主要由景观承担。
- COMPARE = 景观 + optional digital。
- RECOVER = Physical + route/service。
- RETURN = 空间 + 标识 + 纸图 + App + 人工服务。
- REMEMBER = Memory + App。

### 四个设计判断
1. 同一个人也需要不同模式。
2. 行走越复杂，内容越后退。
3. 停留不等于内容触发；人可能只是累、看景观或等同伴。
4. Return不是游程最后一个功能，而是从一开始就与旅程平行存在。

章节公式：`游程阶段 × 身体状态 × 注意力容量 × 行为 = 设计需求`。
