# 清江石书

## 先游清江，再读清江。

正文：

清江石书不是在山水之间增加十三个新的景点，而是重新组织一次真实的清江游程。游客先从江面、索道与山路认识清江，再在适合发生的场景中选择观看、辨认、聆听、停留、休息、阅读或继续前行。

体验入口可极轻呈现：

- **游船｜水上看清江**：从江面建立两岸、峰林与河谷的整体尺度。
- **索道｜空中看清江**：在移动视点中重新理解江、两岸与山体之间的关系。
- **步行｜山中读清江**：进入分支与回环的山路，在真实场景中发现可选内容。
- **回程｜重新认出清江**：当内容退出、手机关闭或身体疲劳时，路线、服务与景观仍然成立。

收束句：

> **水上看，空中看，山中走；需要时，再打开一页清江。**

## CH00-P02｜清江石书是什么

### 核心职责
正式建立项目定义，回答：**项目到底在设计什么。**

### 页面主命题

# 不是十三个新景点，
# 而是一套围绕真实游程展开的清江体验系统。

副标题：

清江石书把路线、内容、数字体验、身体支持与旅行记忆放回同一次真实游程中。不同系统不争夺游客注意力，而是在真正需要的时候出现，并在景观、身体或回程更重要时主动退场。

### 核心关系图
中心不是 App，也不是十三印，而是：

# 一次真实的清江游程

游程链：

`到达 → 游船 → 索道 → 步行 → 发现 → 停留 → 通过 → 回程 → 记忆`

围绕游程建立以下设计层：

### 01｜真实清江
项目空间主体：江面、两岸、峰林、索道、山路与真实身体移动。

> **景观不是设计的背景，而是设计首先要保护的主体。**

### 02｜路线 · 交通 · 服务
负责怎么进入、怎么走、怎么回来。包含游船、索道、步行网络、分支/回环、服务、纸图、标识、Return、无手机路径。

> **路线负责“怎么游”，内容不拥有路线主权。**

### 03｜十三印
沿途出现的可选阅读层。游客可以发现、阅读、比较、聆听、跳过或重新进入；不组成必须完成的十三站路线。

动作语法可轻呈现：`看 / 辨 / 比较 / 听 / 等待 / 取景 / 行走 / 记忆`。

### 04｜数字陪伴
需要时出现，不需要时消失。App 帮助获得方向、发现附近内容、理解场景、记录旅程、寻找回程，但不是清江入口或路线控制器。

主链：`TODAY → ROUTE → READ → MY BOOK → SERVICE / RETURN`

> **手机关闭以后，游程仍然完整。**

### 05｜身体 · 实体 · 感官
只在真实身体需求出现时介入。实体设计不以增加装置数量为目标；只有停留、恢复、观察、身体支撑或感官体验真正需要时才进入场景。

可示意：短恢复/倚靠、步步生光、Fluid Rest、清风吟。此页不写 KEEP/HOLD。

### 06｜人群 · 记忆 · 回程
人群不是一个独立载体，而是改变所有系统深度的变量：儿童/家庭、青年探索、成年深读、长者/低体力、无手机。

> **同一片清江，不同的人拥有不同的停留深度、信息密度与身体支持，但看到的仍然是同一片真实景观。**

游程最终进入 `回程 → 记忆`：
- **清江旅记**：实体旅行记录。
- **我的石书**：数字旅行记忆。
- 其他文化产品/IP：作为不同深度的记忆延展。

### 正式项目介绍母文本

> **《清江石书》是一套围绕真实清江游程展开的空间、内容、数字、实体与记忆体验系统。**
>
> 项目不把“十三印”设计成十三个必须完成的新景点，而是从真实的游船、索道与山地步行关系出发，重新组织游客如何进入清江、理解方向、观看山水、选择内容、停留恢复、安全通过并完成回程。
>
> 十三印成为沿途可以发现、阅读和跳过的内容层；数字体验在需要方向、解释与记录时出现，在景观、身体和安全更重要时主动退场；实体设计只在真实身体需求发生的位置介入；不同人群通过不同的信息深度、互动强度与恢复支持，共享同一片清江。
>
> 游程最终不以“13/13完成”结束，而是以一次安全回程，以及《清江旅记》和“我的石书”留下的个人记忆完成闭合。
