# CH10｜十三印内容与互动系统

- 章节角色：把 R01–R13 定义为完整内容系统，而不是十三站、十三关或十三个实体装置。
- 基础规则：路线负责怎么游；十三印负责沿途可能看见什么。
- 核心：可发现、可选择、可跳过、可深入，并根据场景改变互动强度。

## CH10-P01｜十三印不是十三站，而是十三种“读清江”的入口

# 十三印不是十三个目的地，而是十三次可能发生的阅读。

游客不需要按顺序找到十三印，也不需要完成13/13。每一印只在与真实场景发生关系时出现，并提供一种重新看、辨、听、比较、停留或记忆清江的可能。

不是 `13 PLACES / 13 TASKS / 13 INSTALLATIONS`，而是：`13 OPTIONAL READINGS`。

每一印至少回答：
1. **SCENE**：与什么真实场景发生关系？
2. **CONTENT**：这里真正值得读什么？
3. **ACTION**：游客实际做什么？
4. **DEPTH**：可以读多深？
5. **EXIT**：不想读时怎么继续？永远保留 SKIP。

视觉不做13张同尺寸卡片；更适合非线性内容星图/内容场，并明确 `排列关系 ≠ 游览顺序`。

核心句：**看到一个印，是一次邀请；跳过一个印，不是一次失败。**

## CH10-P02｜十三印完整索引：每一印究竟在设计什么

每个R项至少记录：`R-ID / 场景 / 内容角色 / 游客动作 / 可能载体 / 互动强度 / 退出方式`。

### 已成熟/明确示例
- **R01**：索道/移动视点；价值是重新认识两岸与跨江关系；LOOK / RECOGNIZE；LIGHT/OFF优先；不强制UI、不长解释、不做任务。
- **R02**：植物/近距离自然观察；LOOK / COMPARE / NOTICE；从宏观山水进入身体尺度；不做植物百科。
- **R05**：景观识别/峰林观察；LOOK / FRAME / COMPARE；“如何重新看山”。
- **R06**：河谷关系观察 + 身体恢复；LOOK / COMPARE / RECOVER / OPTIONAL READ；`Landscape First → Relation Reveal → Optional Explanation`。
- **R07**：仓禀峰／仓廪峰；地名与地方知识；TRACE / COMPARE；展示来源边界，不伪造唯一现场定论。
- **R09 / R12**：地方故事如何重新连接眼前景观；LISTEN / LOOK / COMPARE。
- **R13**：空间压缩/身体通过/退出/回望；PASS / LOOK BACK / RETURN；`PLAY OFF / READ OFF`。

其余R项如内容成熟度不足，保留 `CURRENT CONTENT DEFINITION / FIELD OPEN / TO BE DEEPENED`，不为填满十三格编造。

视觉：R01–R13按 SCENE / CONTENT / ACTION / DEPTH / CARRIER 属性横向读取，形成内容谱系而非路线顺序。

## CH10-P03｜一印可以有多深：从“看到”到“深入阅读”

# 同一个印，不需要一次讲完。

内容采用渐进式阅读：
- **L0｜SCENE**：真实场景；不打开任何东西也成立。
- **L1｜CUE**：一个名字/问题/轻标记/声音入口。
- **L2｜RELATION**：关系揭示。
- **L3｜DEEP READ**：来源、故事、文化、科学解释、历史背景。
- **L4｜MEMORY / EVIDENCE**：旅后继续阅读、加入“我的石书”、查看来源。

R06：完整河谷→轻问题→Relation→可选解释→退出。
R07：看到山→看到仓禀峰/仓廪峰→发现差异→主动追踪来源。
R13：可能只停在L0后直接 PASS / RETURN；Depth是可能性，不是进度条。

结论：**深度可以增加，但注意力主权始终属于游客。**

## CH10-P04｜互动不是“点一下”，而是让游客做出真实动作

# 好的互动首先改变游客怎么看、怎么走、怎么停。

体验互动优先于屏幕操作。动作谱系：
- LOOK｜看
- COMPARE｜比较
- TRACE｜追踪
- LISTEN｜听
- WAIT｜等待
- FRAME｜取景
- STEP｜行走/踏步
- RECOVER｜恢复
- PASS｜通过
- LOOK BACK｜回望
- REMEMBER｜记忆

区分：`SCREEN INTERACTION = 点击/滑动/打开`，只是载体操作；`EXPERIENCE INTERACTION = 看/走/停/比较/等待/回望`，才是清江真正互动。

互动价值门：至少满足一项——让我看到原本没注意的东西、理解空间关系、改善身体体验、支持路线判断、加深地方内容关系、留下真实记忆；仅“让页面更有趣”不足。

## CH10-P05｜R13：成熟的十三印系统可以什么都不要求你做

# 有些地方最好的互动，是让游客把注意力完全交还给身体和空间。

阶段：
1. **APPROACH**：空间开始收束，内容 LIGHT。
2. **ENTER**：BODY ON / ROUTE ON / EXIT ON。
3. **PASS**：READ OFF / PLAY OFF / DEEP CONTENT OFF。
4. **REOPEN**：离开窄段，景观重新拥有主权。
5. **LOOK BACK / RETURN**：轻回望或直接继续。

核心：**十三印不是功能集合，而是一套注意力编排系统。**

### 十三印十条规则
1. 不拥有路线主权。
2. 不要求13/13完成。
3. 每一印必须绑定真实场景。
4. 每一印对应一种游客动作，而不仅是一段内容。
5. 内容采用渐进深度。
6. 所有内容可跳过。
7. 场景和身体状态可让互动降级或关闭。
8. 实体、数字、纸本、声音都只是载体，不是十三印本身。
9. 内容最终重新指向真实清江。
10. 记忆比完成率重要。

章节结论：十三印是一套“什么时候值得让游客多看一眼、再理解一层，以及什么时候应该什么都不说”的内容与互动系统。
