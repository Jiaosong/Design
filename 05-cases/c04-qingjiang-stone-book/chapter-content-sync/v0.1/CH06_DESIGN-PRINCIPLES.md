# CH06｜设计原理

- 章节角色：项目从分析正式进入设计判断。
- 原理要求：每条必须包含 `问题/矛盾 → 原理 → 具体设计决定 → 清江案例 → 边界`，不得只做口号。

## CH06-P01｜原理一：真实清江优先

# 设计不是再造一个清江，而是帮助人重新看见已经存在的清江。

当真实景观、数字内容、实体装置和解释信息发生注意力竞争时，真实清江拥有第一优先级。

核心顺序：`LANDSCAPE → RELATION → OPTIONAL EXPLANATION → MEMORY`
中文：`景观 → 关系 → 可选解释 → 记忆`。

### R06证明
错误方式：一到R06就弹“不对称河谷”、大段说明、标注覆盖景观。
当前方向：完整河谷→游客自己看→需要时Relation Reveal→继续深读或离开。

结论：**解释不是景观替代品，而是第二次观看的工具。**

### 模型边界
`真实清江 > Model Hero`。模型负责证明空间关系，真实景观承担第一阅读。

否决规则：**如果一种设计必须遮住清江才能被看见，首先应重新判断它是否有必要存在。**

## CH06-P02｜原理二：先保证能走、能停、能回来，再增加内容

# 游客首先需要确定性，然后才需要丰富性。

当方向、身体、天气、路线或运营存在不确定性时，服务与回程优先于解释、互动和游戏。

体验优先序：`SERVICE / RETURN > ROUTE > OBSERVATION > EXPLANATION > MEMORY > SHARE`。

### 三层
- **BASE｜基本成立层**：方向、服务、继续/返回判断、无手机路径。
- **EXPERIENCE｜体验层**：看景观、观察、停留、比较、身体恢复。
- **ENRICHMENT｜丰富层**：十三印、深读、游戏、分享、收藏。

R13：BODY / ROUTE / RETURN ↑；READ / PLAY ↓或OFF。
App：Return必须可在 TODAY/ROUTE/R06/R13 重入，不是最后一屏。
No-phone：纸图、标识、人工服务、景观方向识别并行；**数字增强可以失败，但基本游程不能一起失败。**

收束：**丰富体验之前，先保证游客始终拥有退出体验的权利。**

## CH06-P03｜原理三：游船、索道、步行是三种观看尺度

# 同一片清江，应该从三个尺度被重新认识。

核心：`TERRITORY → RELATION → BODY`

- **游船｜江域尺度**：SEE / FLOW / SCALE；内容弱、景观强。
- **索道｜关系尺度**：RELATE；允许轻关系提示，不进行复杂操作。
- **步行｜身体尺度**：WALK / STOP / NOTICE / RECOVER；允许内容深度变化和局部实体介入。

三者不是平行交通产品，而是 `整体 → 关系 → 身体` 的理解递进。

R01克制：移动视点本身改变观看，因此不设置强制App、长解释、Relation Mark持续覆盖或任务链。

结论：**不同尺度不是重复讲同一个内容，而是逐渐把游客从“看见清江”带到“理解自己在清江中的位置”。**

---

## CH06-P04｜原理四：场景决定注意力密度

# 每个场景都有自己的信息容量。

核心公式：`SCENE × BODY × ATTENTION = CONTENT DENSITY`

- **FULL**：开阔、可停、身体压力低、路线清楚、用户主动进入；可关系揭示/深读/比较/记录。
- **LIGHT**：移动、短停、景观强、注意力有限；只保留短线索/轻反馈/可发现性。
- **OFF**：收束、高身体压力、安全优先、路线异常、CLOSED/UNKNOWN；内容退场。

十三印必须可跳过；13/13逻辑会把内容系统永久提到空间和身体之上，因此与本原则冲突。

R06 vs R13：`OPEN → CONTENT CAPACITY ↑`；`COMPRESSED → BODY PRESSURE ↑ → CONTENT CAPACITY ↓`。

结论：**成熟的体验系统不是一直提供内容，而是能够判断什么时候应该减少，甚至保持沉默。**

## CH06-P05｜原理五：设计必须能退出，但经历应该留下

# 介入可以消失，经历应该留下。

### 数字可退场
需要时出现，帮助方向/关系/阅读/记录；完成作用后退出。R06 Reveal后撤退；R13 PLAY OFF。

### 最小必要实体介入
先问“如果什么都不加，这个场景是否已经成立？”再比较：
- 0 不介入
- 1 最小支持（倚靠/短恢复）
- 2 增强介入（感官/互动）

Physical不是Minimalism，而是 `MINIMUM NECESSARY INTERVENTION`。

### 记忆不是积分结果
传统：任务→完成→得分→奖励。
清江：经历→选择→停留→判断→记忆。
“我的石书”不是完成清单；“清江旅记”不是打卡册。

核心表达：`SYSTEM RETREATS / EXPERIENCE REMAINS`——**系统退场，经历留下。**

可逆性方向：Attention Reversibility / Behavioral Reversibility / Digital Reversibility / Physical Reversibility（概念原则，不作工程承诺）。

### CH06总原则序列
1. 真实清江优先。
2. 确定性先于丰富性。
3. 三种观看尺度。
4. 场景决定信息密度。
5. 最小必要介入。
6. 可选而非完成。
7. 同场景不同深度。
8. 数字可退场。
9. 回程始终存在。
10. 经历留下，而非完成率。
