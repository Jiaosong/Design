# CH07｜设计方法

- 章节角色：说明实际设计时，如何从证据和问题一步一步生成方案。
- 禁止：Double Diamond、Design Thinking、调研→定义→发散→收敛等通用方法替代清江项目方法。
- 目标：回答清江石书怎样把场地证据、游客状态、文化内容和空间条件转化为路线、十三印、App、实体和场景设计。

## CH07-P01｜方法一：证据 → 空间发现 → 设计后果

# 不从“想做什么”开始，从“现场关系告诉我们什么”开始。

核心：`EVIDENCE → SPATIAL / BEHAVIORAL FINDING → DESIGN CONSEQUENCE`

### Case 01｜官方路线证据
Evidence：官方导览关系表现为分支+回环网络。
Finding：游客实际拥有路线选择，十三印不应决定路线次序。
Consequence：ROUTE 与 CONTENT 分离；ROUTE-03、非任务Game Map、十三印可跳过、删除13/13、Return始终存在。

### Case 02｜R06
Evidence/Observation：开阔河谷观看场景。
Finding：身体压力低、视线展开、可比较。
Consequence：`Landscape First → Compare → Relation Reveal → Optional Read`。

### Case 03｜R13
Observation：空间收束。
Finding：身体、足下、出口、路线判断占更多注意力。
Consequence：`PLAY OFF / READ OFF / BODY ON / RETURN ON`。

### Case 04｜P02
Observation/User Condition：长距离步行存在短时恢复需求。
Finding：很多时候“停→倚→看→决定继续”已经足够。
Consequence：栏杆式短恢复/倚靠支持，而不是先造型再找位置。

结论：每项研究必须回答“它让我改变了什么设计决定？”

## CH07-P02｜方法二：场景 × 注意力 × 人群

# 不先设计功能，先判断这个场景允许发生多少设计。

核心：`SCENE × ATTENTION × AUDIENCE = DESIGN DEPTH`

### Step 1｜SCENE
判断场景：MOVING / OPEN+STOP / WALKING / COMPRESSED+PASS / RETURN+SERVICE。

### Step 2｜ATTENTION
判断第一注意对象：Landscape / Body / Route / Companion / Content；内容强度由 FULL / LIGHT / OFF 调整。

### Step 3｜AUDIENCE
判断当前深度：SEE / DISCOVER / UNDERSTAND / DEEP READ / RECOVER / RETURN。

输出：`SAME PLACE / VARIABLE DEPTH`，不是不同App版本。

### R06完整验证
儿童：SEE/COMPARE；青年：COMPARE/TRACE/FRAME；深读者：RELATION/EXPLANATION/EVIDENCE；疲劳状态：RECOVER/P02/Return。

### R13反例
即使深读者进入高压缩段，也由场景条件覆盖Persona偏好；BODY/ROUTE优先。

结论：**SCENE 可以覆盖 PERSONA。**

## CH07-P03｜方法三：完整景观 → 关系揭示 → 可选解释

# 先不解释，让游客获得第一次自己的判断。

方法：`LANDSCAPE FIRST → SELF OBSERVATION → RELATION REVEAL → OPTIONAL EXPLANATION → WITHDRAW`

1. **完整景观**：第一状态不给结论。
2. **自主观察**：用极小问题引导，如“哪边更近/更高？”
3. **Relation Reveal**：线、区域、对照、短提示，让刚刚看见但未说出的关系显形。
4. **Optional Explanation**：主动继续者进入地貌/地名/故事/文化/来源。
5. **Withdraw**：完成作用后把视觉主权交回清江。

### 扩展应用
- R05：先看峰形→找差异→可选识别。
- R07：先看山→看名字→发现写法差异→追踪来源。
- R13：可能只到 Landscape/Body，不发生后续Reveal。
- App：打开R06不是先弹知识卡，而是景观/关系→轻Reveal→主动继续→详细阅读。

核心视觉：同一R06的连续五帧，而不是五张不同场景。

## CH07-P04｜方法四：介入强度比较——不是所有问题都需要一个设计物

# 每次增加设计之前，先证明“不设计”为什么不够。

介入级别：
- `0｜EXISTING CONDITION`：不介入。
- `1｜MINIMUM SUPPORT`：最小支持，如P02。
- `2｜ENHANCED INTERVENTION`：感官/互动/数字反馈。
- `3｜HERO INTERVENTION`：单一强空间装置，如Fluid Rest概念。

每级比较维度：
1. Visitor Value
2. Landscape Competition
3. Body Value
4. Site Fit
5. Operation / Maintenance
6. Evidence Risk

### Physical真实比较
- Existing：景观最纯，但可能缺身体恢复。
- P02/Lean：小介入解决短恢复；高优先级支持。
- 步步生光：走过→低强度反馈；但电源/防滑/排水/夜间/运维/场景适配仍需判断。
- Fluid Rest：身体—景观关系强，但工程和景观代价高；仅单点竞争。
- 清风吟：风与等待有价值，但要避免俗套景区装置。

### 数字与十三印同样适用
R06：0无UI→1轻关系线→2可选阅读→3强AR/强游戏；1–2更合理。十三印也应比较无内容/名字/短解释/完整任务。

结论：**设计强度不是能力展示，而是不断被证明的必要性判断。**

### 总生成流程
`证据进入 → 形成发现 → 判断场景 → 判断人和注意力 → 确定行为 → 选择介入强度 → 选择载体 → 验证可跳过/关闭/退场/替代 → 进入空间/界面/人体/材料/构造/维护深化`。
