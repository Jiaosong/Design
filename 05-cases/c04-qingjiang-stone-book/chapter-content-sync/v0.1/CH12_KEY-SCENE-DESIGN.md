# CH12｜关键场景设计

- 章节角色：把路线、十三印、数字、人群、身体等系统真正落到具体场景中。
- 要求：开始出现真实场景效果、空间序列、人体动作、平剖关系、数字状态、实体介入和时间变化。
- 当前基础页：7页；后续可继续增加R02/R07/R09/R12等独立页，不压回这7页。

## CH12-P01｜R01｜索道：设计移动中的第一次关系转换

# 跨过清江的过程，本身就是一次阅读。

R01核心不是“索道互动节点”，而是保护移动视点转换。

连续阶段：
1. **接近索道**：地面视点，看到江/站点/对岸；数字只ORIENT。
2. **离岸**：`GROUND → AIR`，江缩小，两岸进入同一画面；`PHONE DOWN`。
3. **跨江中段**：移动+高景观价值+操作能力低；`LANDSCAPE ON / UI OFF or LIGHT`；不扫码任务、不长故事、不持续Relation Mark。
4. **抵达/回望**：可轻提示“刚刚你从这里跨过了清江”，帮助两岸关系第二次理解。

序列：`BEFORE ORIENT → DURING OBSERVE → AFTER RECOGNIZE`，不是 `TRIGGER → INTERACT → COMPLETE`。

视觉：长横向空间剖面，UI只在头尾出现，中间几乎消失。

结论：**R01的设计成果不是增加了什么，而是成功保护了一段原本就足够强的跨江体验。**

## CH12-P02｜R05｜发现：从“看山”到“自己找到一个关系”

# 不是告诉游客“这里有什么”，而是让他先自己找到一点不同。

序列：远看真实峰林→出现轻线索→LOOK/FRAME/COMPARE→主动时轻Reveal→继续走。

不要求 `✓ R05 COMPLETE`；可以什么都不留下。

R05证明 `LIGHT INTERACTION` 也可以是完整设计。最好用两个真实观察视点表现“移动后关系变化”，让发现发生在真实观看中。

结论：**R05的互动价值来自游客改变自己的观看位置，而不是系统增加一个任务。**

---

## CH12-P03｜R06｜Landscape First：先让河谷完整成立

# 在解释河谷以前，先让游客真正看到它。

第一视觉必须是真实R06景观，大画幅；不让分析箭头、UI、模型、技术说明、文化内容成为第一读。

场景先满足：SEE → STOP → RECOVER → READ。

P02在这里仅承担“让身体稳定下来”，视觉存在感低；路径应是 `PHYSICAL SUPPORT → LANDSCAPE`。

数字可 `NO PHONE` 或 `APP LIGHT`。

身体/视线/内容序列：`WALK → STOP → LEAN`；`NEAR → FAR`；`OFF → OPTIONAL`。

结论：**R06第一层设计不是告诉游客这是怎样的河谷，而是创造足够好的条件，让他有时间自己看。**

---

## CH12-P04｜R06｜Relation Reveal：第二次看见同一个河谷

# 解释不是第一次观看的替代，而是第二次观看的工具。

状态：景观 → 自主判断 → Relation Reveal → Compare Again → Optional Deep Read → Withdraw。

Reveal只短暂出现两岸、高低、远近、空间关系；Reveal后要重新看真实河谷，而不是立刻进入文章。

视觉必须用同源同视点的 `LANDSCAPE FIRST` 与 `RELATION REVEAL`，空间不能不一致。

结论：**内容的作用不是让景观变得更丰富，而是让同一个景观能够被第二次看见。**

---

## CH12-P05｜R06｜身体恢复：同一场景怎样容纳不同的人

# 同一个河谷，不同的人可以停在不同的深度。

保持 `SAME R06`：
- CHILD/FAMILY：LOOK/COMPARE，共同发现。
- EXPLORER：换角度、Reveal、拍照、继续探索。
- DEEP READER：Relation/Explanation/Evidence。
- FATIGUED USER：可完全不读；LEAN/RECOVER/RETURN。

必须出现真实人体尺度与动作：站、倚、成人儿童、转身、观看、恢复；如使用P02，应表达身体具体接触，但详细人体工学留到CH13/CH15。

结论：**R06不是为四类游客做四套体验，而是允许只看、比较、深读、恢复四种合法状态。**

---

## CH12-P06｜R13｜进入：空间开始收束，设计开始退出

# 当空间变窄，设计必须比游客更早意识到注意力正在改变。

渐变：APPROACH（内容从FULL/LIGHT降低）→ PREPARE（数字只剩必要方向）→ ENTER（BODY/ROUTE↑，CONTENT↓）→ PASS（PLAY/READ/SHARE/COLLECTION OFF）。

视觉：开阔→收窄→压缩→通过；越往中间UI越少。

人体必须可信；精确净宽未知时不伪造施工尺寸，标 `FIELD OPEN / NTS`。

结论：**R13设计不是如何把互动放进狭窄空间，而是如何在进入之前完成互动退场。**

---

## CH12-P07｜R13｜退出：重新展开之后才完成一次阅读

# 通过不是结束。重新打开视野以后，游客才第一次理解刚才的空间。

序列：EXIT → REOPEN（先LANDSCAPE）→ TURN / LOOK BACK → RECOGNIZE → CONTINUE / RETURN。

记忆机制：`身体压缩 → 通过 → 重新展开 → 回望 → 空间被记住`，属于 SPATIAL MEMORY，不是积分记忆。

结论：**R13通过正确安排收束、通过、释放和回望，让原本的空间成为内容本身。**
