# CH04｜人群与使用状态分析｜v0.3 深化

Role: 同一清江、同一路线、同一场景如何允许不同深度与支持。

## 1｜保留模式
`QUICK / STANDARD / FAMILY / DEEP / LOW-DIGITAL / LOW-STAMINA-ACCESS / RETURN`。

它们不是七条路线，也不是七套 App。

## 2｜本轮深化：从 Persona 进一步转成七个设计变量

1. **TIME AVAILABLE**｜还愿意/能够投入多少时间；
2. **STAMINA**｜体力与恢复需求；
3. **ATTENTION LOAD**｜景观、找路、同行、足下共同占用的注意力；
4. **READING INTENT**｜只看 / 关系 / 深读；
5. **DIGITAL RELIANCE**｜主动手机 / 轻使用 / 低熟悉 / 无手机；
6. **COMPANION CONDITION**｜独行、朋友、家庭、儿童/长者同行；
7. **RETURN URGENCY**｜继续探索与尽快返回的权重。

这些变量改变内容和载体强度，但不改变 route truth。

## 3｜Family / 红花峰崽

红花峰崽只允许作为 `OPTIONAL FAMILY OBSERVATION LAYER`：帮助儿童找、看、比较、说、记；不得成为成人路线 mascot、十三印任务主持人或收集型 IP。

## 4｜低体力与无手机必须成为主设计条件

低体力时：`RECOVER → ORIENT → CONTINUE / RETURN → OPTIONAL CONTENT`。

无手机时：Paper / Signage / Human / Landscape Recognition 必须能独立完成基础判断。

## 5｜跨章输出
CH04 不发明产品，只向后提供 modifiers：
- CH09：服务/Return优先级；
- CH10：阅读深度；
- CH11：Digital intensity；
- CH13：身体支持；
- CH15：记录方式；
- CH19：退出与回程。

结论：**不同人不是得到不同清江，而是对同一清江拥有不同深度、速度和支持。**
