# CH08｜总体策略与体验系统｜v0.3 Full-source 深化

Role: `MASTER INTEGRATION STRATEGY`。不是第二套子系统，也不重新定义 CH09–CH15。

## 1｜Experience Spine｜已有体验母线

CH08 首先保护真实体验，而不是先展示控制术语：
`ARRIVAL → ORIENT → CROSS / MOVE → WALK / DISCOVER → OBSERVE / RECOVER / CHOOSE → PASS → RETURN → REMEMBER`。

原有 `开卷 → 换眼 → 寻页 → 写入 → 看懂 → 收束 → 成书` 保留为叙事层。

重要 authority 修正：Boat 是条件性 access / water-scale experience，不强制所有游客以 Boat 开始；Route 事实由 CH09 / ROUTE-03 控制。

## 2｜Touchpoint Assignment｜谁什么时候出现

- Landscape / Body：第一体验主体；
- Route / Service / Return：现实决策；
- Thirteen Imprints：可选阅读；
- Digital：定向、Reveal、记录、服务辅助；
- Physical：回应身体问题；
- Sensory：放大真实已有环境资源；
- Brand：识别，不拥有功能语义；
- Memory：Return 后逐渐取得主权。

系统完整性来自 `CORRECT ABSENCE`，不是同时出现。

## 3｜Variation｜同一路线的不同深度

Audience、time、fatigue、weather、low-network、no-phone、operational state 只改变：
- 停留；
- 阅读深度；
- Digital intensity；
- Physical support；
- Return priority；
- Memory mode。

它们不改变 route truth。

## 4｜Selection｜总体策略必须能删设计

每个问题都允许：`NO DESIGN / SERVICE / PAPER / DIGITAL / PHYSICAL / MEMORY` 参与竞争；但候选依据问题类型选择，不使用机械升级梯。

## 5｜State / Handoff 作为运行语法
保留三个互不借权的状态轴：
- Operational: `NORMAL / DEGRADED / CLOSED / UNKNOWN`；
- Digital/Content: `FULL / LIGHT / OFF`；
- Brand: `FULL / LIGHT / TRACE / OFF`。

`Digital OFF ≠ CLOSED`；`Brand OFF ≠ abnormal`。

## 6｜总体判断
> 清江石书的总体策略不是让所有系统互相连接，而是让每个已有设计只在真实旅程需要它时出现；当真实清江、身体、路线或回程更重要时，设计主动退出。
