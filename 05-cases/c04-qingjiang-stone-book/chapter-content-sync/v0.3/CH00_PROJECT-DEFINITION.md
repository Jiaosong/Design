## 2｜本轮深化：把“项目是什么”写成设计职责

### REAL QINGJIANG
江、两岸、峰林、索道、山路、风、水、雾、光与真实身体移动是项目主体。

### JOURNEY / ROUTE / SERVICE
负责怎么进入、怎么走、怎么判断、怎么恢复、怎么回来。Boat 只作为条件性 access / viewing mode，不写成所有人的固定首段；`ROUTE-03 = LOCKED CURRENT`。

### THIRTEEN IMPRINTS
R01–R13 是完整可选内容对象库，不拥有路线主权，不形成 13/13。

### DIGITAL COMPANION
需要时用于定向、Reveal、记录与服务；不需要时退场。原《清江石书：山水服务探索界面》是上游数字/服务设计源，当前 App 是后续实现。

### PHYSICAL / BODY / SENSORY
只在身体或感官问题真实存在时介入；`NO DESIGN` 永远是正式竞争者。

### BRAND
跨媒介识别语法，不拥有路线、安全、当前位置或运营状态语义。

### MEMORY
以清江旅记 × 我的石书形成“开卷—途中—成书”；Secondary IP 只做选择性延展。
