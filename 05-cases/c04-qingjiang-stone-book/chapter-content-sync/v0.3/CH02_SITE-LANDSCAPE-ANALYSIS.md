# CH02｜场地与山水分析｜v0.3 深化

Role: `EVIDENCE → SPATIAL / ENVIRONMENTAL FINDING → DESIGN CONSEQUENCE`。

## 1｜保留的空间分析骨架
- 江是稳定参照；
- 两岸制造观看转换；
- 峰谷控制空间收放；
- `TERRITORY → RELATION → BODY` 三种观看尺度；
- 真实路线为分支 / 回环网络；
- R06 允许展开，R13 要求收束与退场。

## 2｜本轮深化 A｜移动尺度分析

不再只列 BOAT / CABLE / WALK，而分别回答：
- **BOAT / water access**：哪些整体关系只能在水面或河谷内部被感知？保持条件性，不写成 universal core。
- **CABLE**：哪些两岸、江体、峰林关系来自移动视点？这些关系决定 CH09 Cable Choreography。
- **WALK**：哪些内容必须进入身体尺度才成立，如坡度感、近植物、岩体、停留、疲劳、分支判断。

输出必须是空间发现，不是新路线。

## 3｜本轮深化 B｜停留与身体条件

建立 `PASS / SHORT STOP / OBSERVE / SHORT RECOVERY / LONGER STAY / NO-STAY` 场地条件分类。

它只说明适配条件，不直接给 P02 / Fluid Rest 定位。后续由 CH13 / CH18 做 site-fit competition。

## 4｜本轮深化 C｜感官资源分析

把风、水声、雾、湿度、光影、植被运动、岩壁反射、足下触感作为**现有场地资源**记录。

规则：`EXISTING SENSORY RESOURCE > GENERATED EFFECT`。

这层为 Qingfengyin / Step Light / Memory 提供输入，但不自动生成“风装置、水装置、雾装置”。

## 5｜本轮深化 D｜服务与 Return 条件

识别：
- 岔路 / 决策点；
- 方向不确定位置；
- 疲劳后重新判断的位置；
- CLOSED / UNKNOWN 需要 hard stop 的条件；
- 人工服务与纸本可能介入的关系；
- Return 需要从探索复杂度中脱离出来的条件。

## 6｜边界

现有 GIS / ENV 图继续按各自证据状态使用；不得把区域地形、遥感、插值或演示图升级成现场测量。任何新的位置、坡度、净宽、视距、风场、声音或风险判断仍为 `FIELD OPEN`。
