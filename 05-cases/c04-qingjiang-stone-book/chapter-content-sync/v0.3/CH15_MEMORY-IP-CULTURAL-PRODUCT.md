# CH15｜记忆、IP与文化产品｜v0.3 Full-source 深化

Role: 旅程结束以后什么继续存在，以及现场如何从一开始为记忆留出空间。

## 1｜Memory Principle
保持 `PARTIAL IS COMPLETE`。Memory 不来自 13/13，而来自真实路线、选择、观察和主动记录。

## 2｜ODI-02｜清江旅记｜Physical Memory Hero
Current: `KEEP / MEMORY MAIN / REQUIRED`。

本轮正式深化为三段：

### OPEN / 开卷
在出发/定向阶段提供最低必要内容：Route context、Return、必要状态、空白记录区。它不是“任务册”。

### DURING / 途中
允许折、写、画、trace、照片/票据、少量印记、一个观察、一句话；不要求每个节点现场操作。

### BECOME A BOOK / 成书
返回后形成实际走过的路径、主动读过的内容、个人观察、纸张/折痕/手写等身体痕迹。没读完仍完整。

清江旅记同时承担 no-phone support，但不能因为服务信息过多而退化成普通纸地图。

## 3｜ODI-03｜我的石书｜One Identity
CH15 拥有 **Memory Object Model**，CH11 拥有 UI implementation。
