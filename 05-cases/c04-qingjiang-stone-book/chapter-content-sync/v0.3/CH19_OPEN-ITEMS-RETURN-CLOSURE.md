# CH19｜开放项、回程与结尾｜v0.3 深化

Role: 把项目从“设计系统”重新带回真实旅行结束，并明确所有仍需现场/专业替换的不确定量。

## 1｜Open Items 保留
继续明确：Route trace/GPS、距离、坡度、台阶、净宽、视点遮挡、R13安全、植物/地质、命名现场证据、客流/容量、无障碍、网络、实时状态、结构/基础、施工/维护许可等均 OPEN。

## 2｜Return 从后台成为前台
全程已有 Return；结尾只是其权重最高：
`END EXPLORATION → ORIENT → RECOVER IF NEEDED → RELIABLE RETURN → EXIT`。

必须由多载体共同承担：
- Landscape recognition；
- CH09 Route/Return touchpoint；
- Paper / Qingjiang Journal；
- Human Service；
- Digital Return helper。

任何单一技术失败不能让游客失去基础回程。

## 3｜状态闭合
- NORMAL：正常返回；
- DEGRADED：减少体验负荷，保留基础 Return；
- CLOSED：hard stop，不以探索视觉诱导继续；
- UNKNOWN：不宣称安全/开放，转向可靠路径/人工确认/Return。

## 4｜Recognition
离场时重新认出：江、两岸、索道、刚才走过的空间。这里完成从“第一次看”到“第二次认出”的变化。

## 5｜Record
进入 Qingjiang Journal / My Book：只记录真正发生和主动保存的经历。未读页保持空白。

## 6｜Take Away
Qingfengyin keepsake、Qingjiang Line、Mist、Honghua Peak Cub 等只作为 secondary/optional extensions；不成为完成体验的收费门槛。
