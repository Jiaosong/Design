# C04｜Design System → Chapter Ownership Matrix｜v0.3｜2026-08-19

State: `AUTHORING SUCCESSOR / OWNERSHIP BINDING / NO PAGE-ID MIGRATION / NO_PROMOTION`

Purpose: 把 C04 已有设计、真实清江体验、Route / Return、可选阅读、Physical、Digital、Brand、Memory 重新绑定到 `CH00–CH19` 的正确专业章节。一个对象只能有一个 **PRIMARY OWNER**；其他章节只能作为 `INPUT / CROSS-LINK / SCENE VALIDATION / DETAIL / PROOF / EVOLUTION / CLOSURE` 使用，不能重复夺取设计身份。

## 0｜Ownership rules

1. `USER ORIGINAL DESIGN SOURCE → CURRENT DESIGN IDENTITY → DEVELOPMENT → TECHNICAL / MODEL PROOF → REVIEW → PRESENTATION`，方向不可倒置。
2. `PRIMARY OWNER != ONLY APPEARANCE`：一个设计可以跨章出现，但必须只有一个主责章节。
3. `REAL QINGJIANG != A DESIGN OBJECT`：CH02 负责证据与场地条件，CH08 负责体验母线，CH09 负责移动/路线/Return 决策，CH12 负责关键场景证明。
4. `RETURN` 分层：CH09 = functional / operational owner；CH19 = closure / final narrative owner；CH11 = Digital helper；CH15 = Record/Memory consumer。
5. `MY BOOK` 一种身份：CH15 = Memory Object Model owner；CH11 = UI implementation owner。
6. `QINGFENGYIN` 一种 family、多个专业角色：onsite sensory → CH13；keepsake/product + memory narrative → CH15；visual grammar/application → CH14 only as application layer。
7. CH16 / CH17 不创造设计来源；它们只深化和证明已存在/已选择的对象。
8. CH18 不重新设计；它负责 selection / evolution / KEEP-DEEPEN-COMPETE-HOLD-NO DESIGN judgment。
9. `ROUTE-03 = LOCKED CURRENT`；CH14 / CH11 / CH15 只能消费，不得重画第二套路形。
10. `R06 = FINISHED / FROZEN / NO REOPEN`；后续章节只能证明/表达，不重新设计体验。
