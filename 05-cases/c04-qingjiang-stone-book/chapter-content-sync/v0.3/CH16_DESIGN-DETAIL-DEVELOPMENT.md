# CH16｜设计深化与细节｜v0.3 深化

Role: 把已经选定/仍在竞争的设计对象发展到可被人体、材料、接口、维护继续审查的程度；不发明新概念。

## 1｜通用深化链
`USE → GEOMETRY / STATE → BODY → MATERIAL / CMF → INTERFACE → CONNECTION → DRAINAGE / SAFETY → MAINTENANCE → OPEN ITEM`。

所有非现场值继续 `DESIGNER ESTIMATE / RANGE / NTS / FIELD OPEN`。

## 2｜本轮明确的五条深化主线

### D-01｜Route / Return Touchpoint Family
深化信息层级、视距/阅读条件、物理载体、安装概念、夜间/低能见、CLOSED/UNKNOWN表达、Paper对应和维护更换。位置仍由 CH09/现场证据决定。

### D-02｜P02 Lean Rest
延续原始板设计：人体、栏杆兼容、body support/fall protection分离、连接、防滑、排水、腐蚀、替换、维护。

### D-03｜Fluid Rest
只有 CH18 Site-fit Competition 通过后进入进一步构造深化；LOCATION HOLD 时不得画成已落位设计。

### D-04｜Qingjiang Journal
纸张/厚度/折叠/装订/书写/湿环境携带/纸图信息层/压印/可替换补充页/长期保存等从“Memory Hero”转成真实产品设计问题。

### D-05｜Digital critical states
只深化关键状态与 handoff：Route decision、Reveal/Withdraw、Return、Offline、CLOSED/UNKNOWN、handoff to paper/human。

## 3｜图纸要求
每条主线都必须出现实际对象、人体/行为、材料和连接关系；文字列举不能替代图形。技术图和当前视觉候选仍需独立 Professional Design Review。

## 4｜Open Register
继续保留 Source / intent / range / sensitive factors / engineering / field / maintenance / does-not-prove，作为专业交接，不做治理式主视觉。
