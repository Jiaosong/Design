## 0｜核心规则

1. `PRIMARY OWNER` 只有一个章节；它负责对象/系统的设计定义与核心判断。
2. 其他章节只能以 `EVIDENCE / ORCHESTRATION / APPLICATION / DETAIL / PROOF / EVOLUTION / CLOSURE` 身份消费。
3. `SAME OBJECT IN MULTIPLE CHAPTERS != MULTIPLE OWNERS`。
4. `REAL QINGJIANG` 是项目基底，不属于 Brand / Digital / Imprint / Physical 的任何一个系统。
5. `ROUTE / RETURN` 的功能权威不被 Brand、App、十三印、Memory 借用。
6. `OPTIONAL READING` 不拥有路线，不形成 13/13，不成为 compulsory journey。
7. `PHYSICAL / DIGITAL / BRAND / MEMORY` 都必须服从真实场景、身体、路线和回程的出现/退场条件。
8. CH16–CH18 是 downstream development / proof / judgment；不得反写 CH09–CH15 的设计源。

## 2｜真实清江体验重新分配

`REAL QINGJIANG` 不是一个品牌资产，也不是 App 背景图，而是项目第一 authority / experience substrate。

### CH02｜EVIDENCE OWNER
负责：江谷、两岸、峰林、公开路线关系、移动尺度、风/水/光/雾/植被等可验证场地条件与证据边界。

### CH05｜BEHAVIOUR INTERPRETATION
负责：人在真实清江中的 MOVE / LOOK / OBSERVE / RECOVER / CHOOSE / PASS；身体与注意力如何变化。

### CH08｜MASTER ORCHESTRATION
负责：`WHOLE → RELATION → BODY` 尺度转换、系统出现/退场和跨系统 handoff。

### CH12｜SCENE APPLICATION
负责：R06、R13、Cable、Route Decision 等关键场景如何保持 `LANDSCAPE FIRST`，并验证同源 Reveal / Retreat。

### CH19｜RECOGNITION / CLOSURE
负责：离场时再次认出清江，把“第一次看见”转成“经历后的再认”。

**禁止：** CH14 用 Brand 重新定义景观；CH11 用 UI 覆盖景观；CH10 用十三印数量替代旅行。
