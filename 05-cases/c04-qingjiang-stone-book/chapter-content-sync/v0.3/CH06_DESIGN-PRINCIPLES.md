# CH06｜设计原理｜v0.3 深化

Role: 从分析进入明确设计判断。

## 1｜保留的十条原则
1. 真实清江优先；
2. 确定性先于丰富性；
3. 不同移动尺度承担不同观看任务；
4. 场景决定信息密度；
5. 最小必要介入；
6. 可选而非完成；
7. 同场景不同深度；
8. 数字可退场；
9. 回程始终存在；
10. 经历留下，而非完成率。

## 2｜本轮新增 Principle 11｜NO DESIGN IS A VALID DESIGN DECISION

> 每个新实体、新数字功能、新内容层都必须先和“不设计”竞争。

不介入不是“没做完”，而是当以下条件成立时的正式结果：
- 真实景观已经提供足够体验；
- 现有服务/设施可以解决问题；
- 新介入只增加视觉存在而不增加 Visitor Value；
- 新介入增加维护、安全或证据风险；
- 介入会削弱 Landscape / Route / Body 的第一阅读。

## 3｜两种优先模式

### NORMAL EXPERIENCE MODE
`LANDSCAPE / ROUTE / BODY FIRST → OPTIONAL READING / SUPPORT`。

### OVERRIDE DECISION MODE
当 `CLOSED / UNKNOWN / Return urgency / high fatigue / route uncertainty` 出现时：
`SERVICE / RETURN / ROUTE` 可以越级成为第一层。

这样避免把“Landscape First”错误理解为安全/回程永远排在景观之后。

## 4｜原则的使用方式
原则不是墙上的口号。每个方案必须说明它具体执行了哪条原则、牺牲了什么、为什么仍值得存在。
