# CH10｜十三印内容与互动系统｜v0.3 深化

Role: R01–R13 完整内容/互动对象库；不拥有路线。

## 1｜保留
`13 OPTIONAL READINGS / PARTIAL IS COMPLETE / ROUTE ≠ CONTENT ORDER`。

## 2｜本轮深化：IMPRINT DESIGN GRAMMAR

每一印统一回答七项：
1. `REAL SCENE`｜真实场景是什么；
2. `WHAT TO NOTICE`｜游客应该注意什么；
3. `OBSERVABILITY`｜CH03 O0–O4 可观察性；
4. `ACTION`｜LOOK / COMPARE / TRACE / LISTEN / WAIT / FRAME / STEP / PASS / REMEMBER；
5. `PROMPT / QUESTION`｜是否需要一句问题；
6. `OPTIONAL REVEAL / EVIDENCE`｜何时进入 S1/S2/来源层；
7. `EXIT`｜不读时如何继续/Return。

## 3｜深度
统一使用：
- `S0 LANDSCAPE / BODY`；
- `S1 PROMPT / RECOGNITION`；
- `S2 RELATION / REVEAL`；
- `DEEP EVIDENCE / TRAVEL-AFTER` 仅在需要时出现。

它不是进度条，也不是每一印都必须走完全部层。

## 4｜对象级深化优先级
- R01：保护移动视点；
- R02：植物从宏观景观进入近身体尺度，避免植物百科；
- R05：观察位置与峰形差异；
- R06：冻结体验，保留 Landscape First → Relation Reveal；
- R07：仓禀峰／仓廪峰来源边界；
- R09/R12：故事与眼前景观的可观察关系；
- R13：PASS / LOOK BACK / RETURN，内容可 OFF。

其余 R 项不足时继续标 `TO BE DEEPENED / FIELD OPEN`，不为填满十三格编造。
