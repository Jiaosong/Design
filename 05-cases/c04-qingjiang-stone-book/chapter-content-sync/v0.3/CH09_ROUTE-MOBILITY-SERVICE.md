# CH09｜路线、交通与服务设计｜v0.3 深化

Role: 唯一主责“游客到底怎么走、怎么判断、怎么回”。  
Authority: `ROUTE-03 = LOCKED CURRENT`；不创建第二套路形。

## 1｜ROUTE-03｜保留
继续把路线作为 Decision Map：`WHERE AM I / WHAT NEXT / CONTINUE OR RETURN`。十三印只能作为附近内容层。

## 2｜Arrival / Boat｜条件性进入
Boat 保留为水上观看和 access variant。设计价值是整体尺度 / 连续山水，不写成所有游客的固定第一站。

## 3｜Cable｜本轮正式深化：CABLE EXPERIENCE CHOREOGRAPHY

### BEFORE / 进入前
完成 ORIENT、必要状态和 Return；提示接下来是“看清江关系”的低操作段。

### LEAVE BANK / 离岸
Digital 降为 LIGHT；不制造新任务。

### MID-CROSSING / 江上
`LANDSCAPE FULL / DIGITAL OFF or minimal / BRAND TRACE-OFF`。移动视点本身是内容；不预设 AR / Relation Mark / 新实体。

### APPROACH SOUTH BANK / 接近南岸
允许轻关系识别，但不在移动中深读。

### AFTER / 抵达
ROUTE / Service 恢复，帮助理解“刚才跨过的关系”，再进入 Walk。

设计结果可以是“中段无新增物体”。

## 4｜Walk｜保留并接 CH05 六种条件
MOVE / LOOK / OBSERVE / RECOVER / CHOOSE / PASS 决定信息和支持强度，不改变真实路线。

## 5｜本轮新增设计对象：ROUTE / RETURN PHYSICAL TOUCHPOINT FAMILY

### RT-01 ORIENTATION CONFIRMATION
在真正决策点确认当前位置关系与下一步，不做 POI 墙。

### RT-02 RETURN MARKER
高于十三印和品牌的回程识别；只回答“怎么回来”。

### RT-03 BRANCH DECISION
区分继续 / 回程 / 其他选择，并为 CLOSED / UNKNOWN 留出明确状态槽位。

### RT-04 PAPER ↔ SITE BINDING
纸图 / 清江旅记与现场 Route / Return 使用同一功能语法，但不要求图形一模一样。

### RT-05 HUMAN SERVICE KIT
给现场服务人员的最低必要信息：方向、Return、状态、关闭、替代方式、no-phone support。

### RT-06 OPERATIONAL STATE CARRIER
NORMAL / DEGRADED / CLOSED / UNKNOWN 使用功能语义和非色彩冗余；品牌色不得代替状态色。

## 6｜设计约束
- Touchpoint family 必须从 ROUTE-03 / Current state semantics 派生；
- Brand 只提供视觉语法，不拥有方向 / Return / Safety；
- 未知位置和实时状态仍 FIELD / OPERATION OPEN；
- 不因新增 physical carrier 而制造“景区到处立牌”。
