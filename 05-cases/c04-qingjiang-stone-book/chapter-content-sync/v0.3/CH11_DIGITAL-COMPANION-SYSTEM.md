# CH11｜数字陪伴系统 / App｜v0.3 深化

Role: 当前 Digital Companion 的行为、信息与界面实现。  
Source precedence: `ODB-01 原始山水服务探索界面 → 当前数字设计 → App v1.28 successor candidate`。

## 1｜原始设计源必须保留
《清江石书：山水服务探索界面》继续作为数字/服务母本，证明 Landscape、Route、Reveal、My Book、Service、Return 在原设计中已有关系。原板主要进入 Source / Evolution，不强迫成为当前最终像素。

## 2｜当前主能力不扩张
保留：
- TODAY；
- ROUTE；
- READ；
- MY BOOK；
- SERVICE / RETURN；
- APP_INIT / OFFLINE PREP；
- FULL / LIGHT / OFF；
- NORMAL / DEGRADED / CLOSED / UNKNOWN；
- no-phone continuity。

不新增 AR、积分、排行、任务树、社交 grind、13/13。

## 3｜本轮深化 A｜Discovery Behaviour
游戏感来自：
- route viewport / partial reveal；
- nearby relation gradually appears；
- same-scene reveal；
- personal trace / memory accumulates；
- retreat / return。

禁止把发现翻译成“下一任务”。

## 4｜本轮深化 B｜Digital Retreat
为每类场景定义数字存在强度：
- Cable mid-crossing = OFF / minimal；
- R06 = Landscape first → optional short FULL → Withdraw；
- R13 PASS = OFF；
- CHOOSE / Return urgency = Route/Service foreground；
- after journey = Memory 可增强。

## 5｜本轮深化 C｜No-phone Handoff
明确 App 在什么时刻把责任交回：
`PAPER / SIGNAGE / HUMAN / LANDSCAPE RECOGNITION`。

Digital 不能成为唯一 Route/Return。

## 6｜My Book ownership
`MY BOOK = ONE IDENTITY`：CH11 只拥有交互与界面实现；“记住什么”由 CH15 Memory Object Model 决定。

Current App candidate 的像素/运行状态与本章内容 Authority 分开，仍需独立 Design Crit。
