# CH03｜地域文化与内容分析｜v0.3 深化

Role: 决定“什么值得读、现场能否读、通过什么动作读”。

## 1｜保留
继续使用：山水自然认知、地名与命名、地方故事、地方生活/身体经验；动作语法保留 `LOOK / COMPARE / TRACE / LISTEN / WAIT / FRAME / STEP / REMEMBER`。

## 2｜本轮深化：增加“现场可观察性”门

每条内容进入十三印前必须标记一种可观察性：

### O0｜NOT OBSERVABLE ON SITE
现场无法直接证明；只能作为旅后/来源层，不能用现场界面伪装成眼前事实。

### O1｜DIRECTLY NOTICEABLE
游客不需要解释即可看见/听见/感到，如峰形、两岸关系、风、水、植物形态。

### O2｜RELATION NEEDS PROMPT
对象可见，但关系需要一句问题或对照才能被注意。

### O3｜RELATION NEEDS REVEAL
需要同源图形、比较或空间关系揭示，如 R06。

### O4｜DEEP EVIDENCE
地名来源、历史材料、科学说明等，需要来源层，不应抢现场第一阅读。

## 3｜内容选择新增判断

每条候选内容依次回答：
`与清江有关？ → 现场可观察？ → 会改变观看/行动？ → 有合适场景？ → 有合适动作？ → 不讲是否仍完整？ → 进入哪一级深度？`
