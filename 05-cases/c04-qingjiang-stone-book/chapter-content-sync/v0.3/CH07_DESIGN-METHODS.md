# CH07｜设计方法｜v0.3 深化

Role: 用已有 OLEANDER / C04 方法把证据转成具体设计，不再发明平行方法论。

## 1｜保留方法
- `EVIDENCE → FINDING → DESIGN CONSEQUENCE`；
- `SCENE × ATTENTION × AUDIENCE = DESIGN DEPTH`；
- `LANDSCAPE FIRST → SELF OBSERVATION → RELATION REVEAL → OPTIONAL EXPLANATION → WITHDRAW`；
- 介入强度比较；
- Same-source Reveal；
- Semantic Firewall；
- No-phone continuity。

## 2｜本轮深化：统一设计选择链

对 Digital / Physical / Service / Memory 的新动作统一经过：

`PROBLEM → EXISTING CONDITION → NO DESIGN → REUSE EXISTING DESIGN → MINIMUM SUFFICIENT CARRIER → NEW OBJECT IF STILL NEEDED → ATTACK TEST → KEEP / COMPETE / HOLD / DROP`

注意：这不是固定载体梯子。问题类型不同，候选集不同。

### Route / decision problem
优先比较现有空间识别、Signage、Paper、Human、Digital。

### Body / recovery problem
优先比较 No Intervention、Existing Facility、P02、Fluid Rest，而不是先试 App。

### Interpretation problem
优先 Landscape / Prompt / Same-source Reveal，再决定 Digital / Paper。

### Memory problem
比较真实经历本身、Qingjiang Journal、My Book、Secondary Product。

## 3｜Attack Test
每个候选至少检查：
- 去掉品牌后是否仍能工作；
- 去掉数字后基础旅程是否仍成立；
- 不做该对象是否更清楚；
- 是否改变 route truth；
- 是否让第一视觉从清江变成设计物；
- 是否把 HOLD / UNKNOWN 画成已经成立。
