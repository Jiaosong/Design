# CH05｜游程与行为分析｜v0.3 深化

Role: 同一个人在旅程中状态如何连续变化。

## 1｜保留 Journey
`ARRIVE → ORIENT → MOVE / CROSS → EXPLORE → DISCOVER → STOP / OBSERVE → PASS → RETURN → REMEMBER`。

体验叙事 `开卷 → 换眼 → 寻页 → 写入 → 看懂 → 收束 → 成书` 保留为 narrative layer，不反写真实路线。

## 2｜本轮深化：六种 Walking / Experience Condition

### MOVE
正常移动。Route 清楚，内容弱。

### LOOK
景观主动占据注意力。设计优先退场，只允许轻提示。

### OBSERVE
稳定停留和比较发生；十三印 / Digital Reveal 可以获得有限出现资格。

### RECOVER
身体疲劳或同行等待；Physical / Return 高于文化解释。

### CHOOSE
出现分支或下一步不确定；Route / Service 获得最高决策权。

### PASS
身体和足下成为第一任务；R13 是典型，`READ OFF / PLAY OFF`。

这不是新增路线分类，而是后续系统的设计输入。

## 3｜行为与载体的明确绑定
- `LOOK` → Landscape first；
- `COMPARE / TRACE` → optional content / Digital；
- `RECOVER` → Physical + Service；
- `CHOOSE / RETURN` → Route + Signage + Paper + Human + Digital；
- `REMEMBER` → Qingjiang Journal + My Book。

## 4｜重要修正
停留不等于触发内容；游客可能只是累、等人、拍照、看景。任何系统不得把 STOP 自动转译成 READ / TASK。

结论：**旅程设计的成熟度体现在优先级随状态变化，而不是沿路不断新增触点。**
