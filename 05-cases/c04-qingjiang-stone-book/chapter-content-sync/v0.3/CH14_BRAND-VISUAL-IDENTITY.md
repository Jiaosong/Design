# CH14｜品牌与视觉识别系统｜v0.3 深化

Role: 跨 Web / App / Route / Paper / Physical / Memory 的识别语法；不拥有功能/安全语义。

## 1｜保留当前品牌系统
- `清江石书` naming；
- `先游清江，再读清江`；
- Stone Seal / Wordmark；
- Current role-bound palette；
- typography / editorial hierarchy；
- ROUTE-03-derived `LINE / TRACE / PAGE`；
- icon / information family；
- `FULL / LIGHT / TRACE / OFF` brand presence。

Current source locks / candidates 的 Design PASS 状态仍与内容层分开。

## 2｜Semantic Firewall 保持硬约束
- Brand does not own Route；
- Brand color does not encode operational state；
- Seal is not a map node；
- Return / Safety / Landscape may suppress Brand；
- ROUTE-03 geometry 只能被消费，不被 Brand 重画。

## 3｜本轮深化：MATERIAL BRANDING
不是增加新 VI，而是把现有 grammar 放进真实媒介：

### PAPER
清江旅记、纸图、阅读页：纸张、折叠、压印、墨、留白与耐用性。

### METAL
Route/Return touchpoint、P02等：低密度识别、蚀刻/印刷/嵌件或可替换信息层；功能可读性优先。

### WOOD / EXISTING NATURAL MATERIAL
只在真实场地/维护条件支持时作为载体，不用“原木色”制造泛文旅气质。

### TRANSLUCENT / LAYER
用于 PAGE / REVEAL / Light 的材料表达时必须服务功能，不制造虚构科技感。

### EMBOSS / SEAL / TRACE
适合 Memory / Packaging；不能把十三印变成十三个红章任务。

## 4｜品牌统一对象是 Grammar，不是 Template
同一语法可以在 Web、App、Paper、Signage、Physical、Memory 中采用不同强度和不同材料；不能为了“一致”让所有载体长成同一张卡片。

## 5｜后续
优先深化 Material / Print / Cross-media application；暂不增加第二套 Logo、色彩或独立 Brand layer。
