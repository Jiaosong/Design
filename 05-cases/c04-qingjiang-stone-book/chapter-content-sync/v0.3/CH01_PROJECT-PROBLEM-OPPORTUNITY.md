# CH01｜项目问题与机会｜v0.3 深化

Role: 证明为什么需要设计、设计真正解决什么，而不是提前展示方案。

## 1｜核心问题保持

### P1｜不是“缺景点”
清江已有成熟景观与复合游程。设计任务是重构关系：看、走、停、读、回，而不是增加景点数量。

### P2｜十三个内容对象不等于十三站
官方导览与当前 ROUTE-03 支持多分支/回环关系，因此 `ROUTE ≠ CONTENT ORDER`。

### P3｜信息会遮挡景观
文化、App、Brand、Physical 都可能与真实清江竞争注意力；设计必须管理“何时出现、何时沉默”。

### P4｜游程也是身体与服务系统
游客同时处理方向、体力、同行、天气、异常、Return；内容不是唯一问题。

## 2｜本轮增加的两个问题层

### P5｜实体服务缺口
项目已有 Return / no-phone / Service 原则，但现场“怎样确认方向、怎样识别 Return、CLOSED/UNKNOWN 如何表达、纸图如何和现场对应”仍缺少完整设计对象。

**Design Opportunity:** `Route / Return 实体触点 family`，归 CH09，不创建第二套路形。

### P6｜项目已有很多方案，但缺少明确选择机制
P02、Fluid Rest、Step Light、Qingfengyin、Digital、Memory 都已存在。当前问题不再是“方案不足”，而是：
- 哪些必须 KEEP / DEEPEN；
- 哪些只允许单点竞争；
- 哪些应 HOLD；
- 哪些地方应该 NO DESIGN。

**Design Opportunity:** 将 Selection 作为 CH08 / CH18 的正式设计能力，而不是事后审美标签。

## 3｜本章必须导出的项目问题

> 如何在不削弱真实清江的前提下，使游客能够看懂空间、走清路线、根据身体和兴趣选择阅读深度、在异常或疲劳时可靠退出，并把真正经历过的部分带走？

本章不解决这个问题，只把它定义清楚。
