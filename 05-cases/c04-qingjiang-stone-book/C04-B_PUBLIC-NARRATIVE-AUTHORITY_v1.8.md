## 1｜Public project definition

### Main statement

**《清江石书》不是在清江增加十三个景点，而是重新组织一次真实的清江游玩体验：先让游客知道怎么到达、怎么过江、怎么走、在哪里停、怎么玩、怎么回来；再把地域文化、自然观察、地方智慧、轻娱乐和身体休息内容放进真正适合发生的场景。**

“十三印”是一组可选择打开的内容入口，不是十三个强制任务站；游客可以读、可以玩、可以跳过，路线、安全与回程不依赖完成率。

### Hero copy

**先游清江，再读清江。**

从游船、索道到峰林步道，在真实游程中加入必要的地图、导向、休息、文化阅读、互动与回程支持。

## 2｜Five-part public narrative

### 01 地域文化｜Qingjiang Culture Library

先回答“清江有什么值得体验”，再谈设计。

内容库按六类整理：
1. `HISTORY / REGIONAL`：清江流域、沿江聚落、交通与地方历史；
2. `LOCAL STORY`：廪君、盐水女神、地名与地方传说；
3. `CRAFT / INTANGIBLE CULTURE`：西兰卡普、摆手舞、傩戏、龙船调、地方工艺与饮食；
4. `LANDSCAPE KNOWLEDGE`：峰林、峡谷、河流、植物和季节观察；
5. `TRADITIONAL LANDSCAPE VIEW`：风水、山水观、方位、水口、山势等作为**传统环境观/文化解释**研究，不作为科学地貌、选址或安全证明；
6. `DAILY WISDOM / WELLBEING`：行走、休息、天气感知、听水、观察、身体节奏、自我关照；不得转化为医疗/治疗功效宣称。

文化使用规则：`来源 → 内容类型 → 场景适配 → 互动方式 → 年龄深度 → 审核/待替换字段`。

## 3｜Journey first｜游客到底怎么游

Public journey:

`到达 → 看地图/确认回程 → 选择交通 → 过江 → 进入南岸步道网络 → 选择场景 → 观看/休息/互动/阅读 → 回程 → 离场记忆`

### Three ways to experience Qingjiang

- `BOAT / 水上看清江`：以江面尺度、峡谷整体、倒影、声音和长距离观看为主；
- `CABLE / 空中看清江`：首先是跨江交通与回程工具，其次提供两岸、河谷、峰林的整体观看；
- `WALK / 山中看清江`：以身体尺度、坡度感、岩壁、植物、转折、停留和近距离观察为主。

地图可采用高完成度的**开放世界/探索游戏地图语言**：地标、区域、路径、交通、休息、故事、观察、关闭状态清楚分层；但真实路线仍由现有多分支/回环网络拥有主权，禁止用任务解锁、13/13进度或故事章节强制路线。

## 4｜Game/content model｜到一个场景具体做什么

游戏化作用在**内容和探索**，不作用在安全、回程和基本导航。

### CULTURE｜文化
- 地名故事、地方人物、传说、非遗、历史交通；
- 适合音频、插画、故事卡、人物关系、旧地图、现场简短提示；
- 传说不得写成考古/历史地点事实。

### WISDOM｜智慧/观察
- `观察 → 猜测 → 对照解释`；
- 比较两岸、河谷尺度、峰形、路径方向、天气能见度、植物与岩壁表面等；
- 科学解释必须使用已核验来源，未知就保持问题，不用名称或外观反推物种/地质结论。

### PLAY｜娱乐/探索
- 找峰形、轮廓匹配、声音寻找、地图探索、家庭合作寻找、轻解谜、个人“石书”收集与记录；
- 可以收集，但没有“集齐才能完成”；
- 狭窄/高风险/回程紧迫场景自动关闭高注意力游戏。

### WELLBEING｜身体与自我关照
- 休息、遮阴/饮水提示、步行节奏、听水、安静观看、疲劳时减少内容、回程时间提醒；
- 面向不同体力状态提供更短、更清楚的选择；
- 只表达体验与服务，不做保健治疗、硒疗效或医疗功效宣传。

## 5｜Audience depth｜同一场景，不同人获得什么

不为儿童/成人/老人复制三套产品。使用同一个场景与系统，通过信息密度、交互难度、字体/触控尺度、声音/图像和回程优先级调整内容深度。

| 人群 | 优先获得 | 内容/交互 | 禁止简化成 |
|---|---|---|---|
| 儿童/亲子 | 发现、共同探索、自然注意力 | 找形状、找声音、故事插画、亲子合作 | 连续答题/强制打卡 |
| 青少年/青年 | 探索、空间判断、轻挑战、社交记忆 | 地图探索、观察推理、轮廓/路线挑战、内容收藏 | 纯科普课件 |
| 成年游客 | 文化、景观理解、自由深读、时间管理 | 地域故事、自然解释、路线选择、深度内容 | 长篇说明墙 |
| 长者/低体力状态 | 方向确定、休息、回程、低认知负担 | 大字地图、明确剩余路线、休息/返回、可跳过内容 | 被动“老年模式”标签 |

### R06 example
- 儿童/亲子：找出江、两岸和不同峰形 → `发现 + 共同观察`；
- 青少年/青年：用简化剖面判断步道/河谷相对位置 → `空间推理`；
- 成人：河谷整体 + 地域/自然解释 → `景观理解`；
- 长者/低体力：先看到可休息点、回程方向和继续/返回选择 → `恢复 + 确定感`。

### R13 example
- 所有人首先获得通过/返回/风险边界；
- 儿童不设置追逐、计时、搜寻类任务；
- 青年/成人可选择身体尺度、岩壁/光线观察；
- 长者/低体力状态优先提供绕行/返回信息（若未来现场证明存在）。

## 7｜Physical / Product / Memory

实体层不再只作为“支撑装置”，而要明确产品功能：
- `F01`：短时倚靠/恢复；
- `F02`：可选阅读板/场景提示；
- `F03`：关键位置回程识别；
- `F04`：纸质地图、旅行记录、离场后的“我的清江/我的石书”。

Memory 采用：`回程重认路线 → 个人记录/可选收集 → 离场后纸图/数字内容延续`。不以“13/13完成率”作为项目闭合。

可从原始 @恩施 文创研究中继续筛选“可带走、可日用、可记录”的内容，但任何材料健康功效、硒疗效、真实量产性/价格/销量等不得未经专项验证进入当前项目事实。

## 8｜New eight public design decisions

These replace the old abstract eight anchors for public-facing storytelling:

1. **先把清江的地域文化和故事梳理清楚，再决定讲什么。**
2. **先把一次真实游程讲清：怎么来、怎么过江、怎么走、怎么回。**
3. **游船、索道、步行提供三种不同尺度的清江体验。**
4. **地图可以像探索游戏，但路线、安全和回程不能靠任务解锁。**
5. **每个场景只放真正适合发生的文化、智慧、娱乐或身体内容。**
6. **同一场景为不同年龄与体力状态提供不同深度，而不是复制多套产品。**
7. **实体设施、纸图和数字界面互相补充；没有手机仍能完成游程。**
8. **最后用回程、个人记录和可带走的记忆收束，不用十三印完成率收束。**
