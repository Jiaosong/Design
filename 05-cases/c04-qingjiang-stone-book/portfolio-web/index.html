04 / EXPERIENCE STATES
ATTENTION AS A LIMITED RESOURCE

什么时候
设计应该消失

作品的核心不是“加多少内容”，而是给每种身体状态设上限。MOVE / RECOVER / OBSERVE / READ / WITHDRAW / RETURN 决定信息是否出现；NORMAL / DEGRADED / CLOSED / UNKNOWN 是现实状态，两套轴不能混写。

05 / EVIDENCE BOUNDARY
PROOF WITHOUT PROMOTION

做得完整
不等于被现场证明

远程研究已经足以形成专业的关系模型、路线合同、视觉构件和数字降级逻辑；但现场、专家、实体样板、实施仍是不同证据层。网页把这些边界放在作品里，而不是藏在后台。

DESIGN DECISION

以 Atlas 作为作品网页主结构：官方总图负责真实空间第一阅读，关系剖面负责解释视点转换，节点库负责可选阅读，证据层负责告诉读者哪里必须停止。

DOES NOT PROVE

不证明现场微路线、尺寸、坡度、安全、无障碍、地质成因、植物鉴定、施工可行性或实时运营。
