## 2｜三种作品画布比较

### A｜Landscape Atlas — KEEP / PRIMARY

官方关系证据 + C22 总图 + 平剖联动 + 节点阅读。

- 最符合 `Landscape First`；
- 路线网络保持主权；
- 1920×1080 一屏一个视觉中心；
- 图纸、叙事、证据可以在同一作品系统中互相校验；
- A3 print 仍能保持图纸式阅读。

风险：关系叠层容易被误读为 GIS / survey，因此统一标注 `NTS / NOT SURVEY / NOT GEOREFERENCED`。

### B｜Cableway Cinematic Scroll — KEEP / BOUNDED

用于解释跨江导致的视点变化，但不作为主作品结构。

反证：真实 continuous cabin POV 仍缺；纯电影叙事会隐藏 Route / Safety / Return，并且当前 QJ-E 72 秒 MP4 仍以数字演示/静态状态切换为主，不能升级成主作品影片。

结论：网页保留 `Moving View Study`，明确 `NOT FIELD VIDEO`；未来用真实连续素材替换，不用 AI 视频冒充现场。

### C｜Evidence Archive / Paper-Ink Relation Layer — KEEP / SUPPORTING

用于来源、证据状态、开放项、责任与图纸注释。

在 Dual Quality Gate 下，视觉语言修正为：

`Paper / Ink / Relation Line / Evidence Trace`

不再把 generic `Seal` 或仿古图卷语言作为默认视觉元素。

### Final composition

`Landscape Atlas + bounded cinematic transition + evidence archive layer`。

## 5｜Key design decisions

### D01｜Landscape / Route first

官方导览与 C22 支持清江分隔、跨江索道、南岸多分支网络。它们不证明距离、坡度、步行时间、精确坐标、容量或强制节点顺序。

### D02｜13 Impressions = Reading Library

C17 明确 `no 13 linear stations`。旧线性序列不再拥有 Current Route Authority。

### D03｜Plan × Section = relational, not measured

平剖联动只表达：

`north-bank service → cable moving view → south-bank walking network → observe/read/recover → natural closure → return`

除来源明确的公开设施参数外，不从非测绘图读取高度、坡度、长度或净宽。

### D04｜C22 drawings are public design evidence

网页不重复画一套弱化图纸，而是直接消费 C22 current editable SVG；交互关系图负责理解，C22 图纸负责专业图纸证据。

### D05｜Motion makes the evidence gap visible

真实索道连续 POV 仍是 blocker。当前 motion 只作为镜头运动研究，明确 `NOT FIELD VIDEO`。

### D06｜State system uses existing contracts only

公开展示：`MOVE / RECOVER / OBSERVE / READ / WITHDRAW / RETURN`。

现实状态仍是：`NORMAL / DEGRADED / CLOSED / UNKNOWN`；`OFFLINE / RETURN-PRIORITY` 是 modifier，不改写现实状态。

## 6｜Cross-discipline conflict check

- **Route × Narrative:** PASS — M0–M7 > Reading Page；无 13/13。
- **Route × Digital:** PASS — No-phone 保留 Route / Safety / Return。
- **Visual × Evidence:** PASS — C22 / overlay 明标 NTS、非配准、非测绘。
- **Science × Narrative:** PASS WITH FIELD/EXPERT OPEN — R02、R03/R08/R10、R06、R13 不越过专家/现场边界。
- **Operations × Experience:** PASS — 2026 居民跨江语境阻止 tourist-only persona；M2 交通/安全/回程优先。
- **Video × Evidence:** PASS-WITH-OPEN — 不把 slide-heavy digital demo 或 motion study 写成现场影片。
- **Print × Screen:** target is 1920×1080 section capture + A3 landscape PDF; both require actual browser render review.
