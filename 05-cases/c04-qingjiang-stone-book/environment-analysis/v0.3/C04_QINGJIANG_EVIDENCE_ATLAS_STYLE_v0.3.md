## Core character
A field-atlas / landscape-research language rather than a scientific dashboard:
- warm paper field;
- Qingjiang blue-green for water / evidence;
- ink-grey terrain and source context;
- muted moss / ochre for environmental variables;
- seal red only for HOLD / risk / critical boundaries;
- serif display titles + sans-serif technical annotations.

## Visual hierarchy
1. Current analytical claim / task layer
2. Qingjiang / route / site authority
3. source geometry / contours / sample grid
4. legends / units
5. evidence boundary / governance

`SOURCE DETAIL RETAINED → BASE EVIDENCE RECEDES → CURRENT TASK OVERLAY EARNS VISUAL PRIORITY.`

## Hard rules

## Layout
- analytical figure / map ≈ 72%
- evidence / method / design consequence column ≈ 28%
- one figure = one primary claim
- figures may vary internally, but the title / state / legend / boundary grammar is fixed.

## Pinterest-derived patterns absorbed
Visual-reference boards studied include site-analysis, landscape-presentation, mapping and toolkit collections. The transferable patterns are:
- pale/neutral base;
- precise linework over soft source layers;
- limited accents rather than full-spectrum color;
- lightweight legends;
- integrated plan/section/data hierarchy;
- task information stronger than the base map.

These are synthesized patterns; no single pin, studio style, trade dress, or copyrighted layout is copied.
