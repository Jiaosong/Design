TODAY / CURRENT DECISION

现在，什么最重要？

TODAY 不再是信息首页，而是当前旅行决策页：先看状态，再决定移动、场景、休息或返回。

T1 / SITUATION

UNKNOWN · 先确认返回

运营与微路线未确认时，不把未知状态画成正常开放。基础动作始终保留：确认方向、人工服务、纸图、返回。

T2 / NEXT MOVE

选择这一段怎么移动

BOAT水面连续观看适合完整景观，不要求持续看屏幕。
CABLE跨江移动视点R01 以观察为主，Digital LIGHT/OFF。
WALK山中多分支需要判断分支、休息、场景与返回。
RETURN随时退出探索不依赖内容完成率。
T4 / NEARBY MEANINGFUL SCENE

只推荐此刻真正值得打开的场景

T5–T6 / REST + NO-PHONE

不拿手机也能继续

纸图、现场方向、人工服务、休息与返回形成最低完整路径。App 只提供可选深度。

ROUTE / SPATIAL BACKBONE

路线不是游戏棋盘。

ROUTE 被拆成总游程、移动方式、分支判断、场景密度、休息、现实状态、返回和无手机交接八个模块。

ARRIVAL → BOAT → CABLE → WALK → RETURN

内容可以错序或跳过；路线从不由十三印解锁。

R3 / BRANCH DECISION

步行时，真正需要判断的是“继续、分支、休息还是回来”

R6 / REALITY OVERLAY

NORMAL / DEGRADED / CLOSED / UNKNOWN

状态改变推荐密度和可见动作；CLOSED / UNKNOWN 时 Return 权重自动上升。

READ / OPTIONAL CONTENT WORLD

不是打开“十三张卡”，而是进入一个场景对象。

READ 有 Nearby / By Question / By Mode / Full 13 Index 四种入口，真正的核心单位是 Scene Object。

S1 / FIRST READ先看景观

先建立现实场景和身体关系，不急着解释。

S2 / ORIENT我在游程哪里？

显示与 BOAT / CABLE / WALK / Return 的关系，不宣称 GPS 精确位置。

S3 / OPTIONAL ACTIONLOOK / COMPARE

动作可跳过，不产生通行权或完成率。

S4 / FEEDBACK短暂反馈，或完全不反馈

景观足够强时，最正确的数字反馈可能是“没有反馈”。

S5 / DEPTH同一场景，不同深度

亲子 / 青年 / 成人 / 长者低体力共享场景，只改变解释和动作负担。

S6 / BODY + REST站 / 走 / 停 / 靠 / 听

只有场景真正需要身体参与时才出现。

S7 / DIGITAL RETREATLIGHT → OFF

数字层必须明确何时结束。

S8 / NO-PHONE关掉以后，什么还成立？

景观、方向、纸图、人工服务、休息与返回继续成立。

S9 / EXITCONTINUE / RETURN / REST / SAVE / PHONE OFF

没有明确 EXIT 的场景，不进入 MAIN。

MY BOOK / PERSONAL JOURNEY

不是完成记录，是个人清江。

MY BOOK 被拆成 Journey Trace / Saved Scenes / Recognition / Journal Page / Take Away 五层。

M1 / JOURNEY TRACE

BOAT → CABLE → WALK → selected stops

只记录关系，不宣称 GPS 精确轨迹。

M2 / SAVED SCENES

只留下主动保存的场景

不会自动把 R01–R13 全部变成收藏清单。

M3 / RECOGNITION

回来时，我重新认出了什么？

M4–M5 / JOURNAL + TAKE AWAY

一句话、一页纸、一个自己的清江版本

数字端负责整理和再读；纸本保留手写、折痕与材料痕迹。

SERVICE / RETURN PARALLEL LAYER

它不是第五个内容页，而是优先层。

任何页面都能进入 Return。CLOSED / UNKNOWN / 低体力 / R13 等状态下，它自动高于内容。

SR1 / RETURN NOW

现在就回来

不需要完成任何十三印，不需要登录，不需要 GPS，不需要保持 App 开启。

SR2–SR4

人工服务 / 纸图 / 现场方向 / Digital OFF

这些共同构成无手机最低完整路径。

DIGITAL SILENCE / 手机退场

屏幕到这里就够了。

现在把注意力还给清江、身体和方向。

LOOK / 看MOVE / 走REST / 停RETURN / 回来
