# C04-WS-01｜项目治理与场地证据｜G0–G1 Alignment

**Parent:** `C04｜清江石书｜红花峰林十三印`  
**Formal stage:** `G0 CONDITIONAL / G1 PREWORK ACTIVE`

本工作流只负责关闭项目治理、来源证据和现场证据。Gate 0 与 Gate 1 未通过前，不把体验、数字、空间或装置探索升级为正式方案阶段。

## G0｜Project Charter closure

- [ ] 明确项目发起／委托／决策关系以及 OLEANDER 在项目中的实际角色。
- [ ] 建立 Stakeholder Map。
- [ ] 建立 RACI：信息提供、科学／文化审核、设计、决策、实施、运营、维护、修订、退出。
- [ ] 核对视觉、图片、地图、导游词、品牌资产、赛事成果、小程序原型等内容的权利与发布边界。
- [ ] 明确范围、不做事项、预算、周期、采购、实施权限和维护责任。
- [ ] 定义成功指标及失败／降级／退出条件。

## G1｜Source & Site Evidence closure

### Existing source layer

已存在的研究输入包括用户上传的导游解说词、景区导览图、索道资料、视觉规范、小程序低保真、设计展板，以及后续取得的官网／运营方／政府／专业来源网络证据。

这些材料均属于来源证据，不等价于现场 Observed / Measured。

### Field evidence still required

- [ ] 13候选节点的现行名称、现场标牌和实际位置。
- [ ] 12段真实路线的轨迹、分叉、时间、坡度、台阶、地面与停留点。
- [ ] 关键视点、遮挡、尺度、安全、排水、维护及可达条件。
- [ ] GPS、网络、手机屏幕可读性和 AR 识别条件。
- [ ] 步步生光候选场地的结构、踏步、电源、排水、防滑、检修、夜间运营和照明条件。
- [ ] 阶地／不对称河谷科学解释及 P/T 具体露头的专业核验状态。

## Evidence vocabulary

正式项目字段统一为：

- `Material / Source`
- `Observed`
- `Reported`
- `Measured`
- `Compared`
- `Inferred`
- `Unknown`
- `Design Proposal`

此前 QJ13 工作稿中的 `SOURCE / OBSERVED / MEASURED / DESIGN / INFERENCE / PROPOSAL` 仅作为 Legacy working labels 映射，不建立第二套治理系统。

## Blocking register

- `BLK-G0-01` 角色／权责／决策路径未确认。
- `BLK-G0-02` 权利与发布边界未闭合。
- `BLK-G0-03` 预算、实施、采购与长期运营责任未确认。
- `BLK-G1-01` Field Observed = 0；Field Measured = 0。
- `BLK-G1-02` 13候选节点最终排序和12路线段未实测。
- `BLK-G1-03` 绝壁天书、P/T分界等 Pin / Science 状态未关闭。
- `BLK-G1-04` 母子相望／母子峰、仓廪／仓禀等命名冲突未关闭。
- `BLK-G1-05` 步步生光现场适配未验证。

## Gate rule

只有当 G0 形成可审查的 Project Charter / Stakeholder / RACI / Rights / Scope / Metrics，且 G1 形成可复核的 Site Evidence Atlas / Route Evidence / Field Status 后，才复核 G2 Relation Statement 与 Design Brief。

`QJ13 Experience Architecture v0.8` 当前只作为探索输入；`Digital Product Architecture v0.9` 暂停进入正式设计序列。
