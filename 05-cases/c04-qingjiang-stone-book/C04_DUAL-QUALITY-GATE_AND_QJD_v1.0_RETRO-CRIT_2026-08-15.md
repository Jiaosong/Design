# C04｜Dual Quality Gate + QJ-D v1.0 Retroactive Design Crit

**Date:** 2026-08-15  
**Applies to:** C04 drawings / models / diagrams / web / boards / video and all A–F delivery-lane artifacts  
**Project truth:** `FIELD OBSERVED=0 / FIELD MEASURED=0 / G1F HOLD / NO_PROMOTION`

## 1｜Dual Quality Gate

Every milestone artifact must pass **both** gates before it can enter the primary website / board / video narrative.

### Gate A｜OLEANDER Compliance
Check at minimum:
- Current Authority / Project State / Source Authority / Current Task consumed;
- one source of truth and editable/rebuildable design authority;
- Evidence / Inference / Assumption / Decision / Open-Hold boundaries explicit;
- no Remote/Runtime/Render/Prototype PASS promoted into Field/Implementation PASS;
- stable IDs and cross-line compatibility;
- post-generation preview actually reopened;
- reversible delta/version record;
- `FIELD OBSERVED=0 / FIELD MEASURED=0 / G1F HOLD / NO_PROMOTION` retained where applicable.

### Gate B｜Professional Design
A file existing, opening, building, rendering or passing CI = `EXECUTED` only.

Actual preview must be reviewed for:
1. concept distinctiveness;
2. spatial logic / plan-section-axon-model correspondence where relevant;
3. composition hierarchy and first-read clarity;
4. proportion / human scale / construction plausibility where relevant;
5. lineweight / legend / diagram grammar;
6. material / light / rendering credibility where relevant;
7. interaction meaning rather than decorative UI;
8. narrative rhythm / motion causality rather than static slideshow;
9. cross-media consistency;
10. portfolio value at intended display size.

Hard rejects for primary display:
- generic tourism templates;
- admin-dashboard/card-wall composition;
- generic pseudo-traditional / antique-Chinese styling;
- text walls;
- asset collage without relation logic;
- obvious AI spatial contradiction;
- data/map/chart that does not lead to a design implication;
- plan/section/axon/model that contradict one another;
- effect imagery without credible scale/construction when claiming a spatial intervention;
- website first screen that does not read as Qingjiang Stone Book at 1920×1080;
- video as a static page/slide carousel.

## 2｜Mandatory Design Crit at Every Milestone

Record one decision per artifact: `KEEP / REVISE / REJECT / HOLD`.

Crit must explicitly cover:
- Claim: what does this artifact prove or communicate?
- Professional completeness: is it actually finished enough for its role?
- Template / AI feel: could it belong to another tourism project or expose synthetic contradictions?
- Data–Space–Narrative corroboration: do evidence, spatial logic and story support each other?
- Deletion test: what can be removed without damaging the core claim? Remove it.
- Page/sequence rhythm: does first-read → relation → explanation → evidence work?
- Portfolio value: is it strong enough for the primary public sequence, or only useful as process/evidence?
