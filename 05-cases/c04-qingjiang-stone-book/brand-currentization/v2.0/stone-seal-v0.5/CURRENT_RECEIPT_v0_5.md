## Why superseded
The geometry direction remained useful, but the surface system over-compressed material identity into flat color plus sparse texture. It did not sufficiently preserve:
- chromatic depth;
- controlled gradients;
- micro / meso / macro texture differentiation;
- regional density variation;
- finish / edge behaviour;
- explicit Gradient-Off and Texture-Off states.

These gaps triggered the reusable-skill optimization now tracked in GitHub Draft PR #242 and the v0.6 project rerun.
