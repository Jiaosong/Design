# Pixel Readback Correction v0.5

v0.4 producer readback exposed:
- equal-length/equal-spacing strata read too much like a generic glyph/interface symbol;
- river cut was visually heavy;
- texture was valid in principle but too dot-like.

v0.5 corrections:
- removed left auxiliary stratum;
- varied right strata lengths and positions;
- narrowed and softened river cut;
- reduced grain density;
- shifted texture toward micro-grain + sparse abrasion + subtle mineral veins;
- refined symbol-to-wordmark relation and reduced Chinese wordmark weight.

This is a producer correction, not an independent Design PASS.
