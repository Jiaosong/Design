## Professional Design Gate
1. First-read: does real Qingjiang remain the primary visual subject?
2. Existing identity fidelity: does the system preserve the mature `清江石书 / QINGJIANG STONE BOOK` typographic identity instead of substituting a new scenic icon?
3. Qingjiang specificity: if project names are hidden, do landscape-first, editorial hierarchy, reveal/trace and return logic still create a coherent family?
4. Template test: do Cover / Core / Logo / Journey / Scene / Digital / Editorial / Field / Motion / Audit pages have genuinely different visual tempos?
5. Remove-decoration test: does title/identity survive without decorative effects?
6. Task hierarchy: in App / map / field / Return, do route, state and safety dominate branding when required?
7. Small-size: is fallback conservative rather than inventing a new logo?
8. Typography: role hierarchy strong at distance and near read; no glyph fallback defects.
9. Color: brand color, evidence accent and operational state remain distinct.
10. Evidence boundary: no operator approval, field geometry, live operation, trademark or production approval is implied.
11. Professional finish: alignment, crop, type measure, spacing, edge handling, image quality and source labeling.
12. Regression test: v2.0 must be visually and conceptually stronger than v1.2 without deleting valid C04 design content.

Decision vocabulary:
`KEEP / REVISE / REJECT / HOLD`

`Artifact / XML / render / checksum PASS` cannot be mapped to `Design PASS`.
