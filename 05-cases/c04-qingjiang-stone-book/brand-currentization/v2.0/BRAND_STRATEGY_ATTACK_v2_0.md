## Brand task
The project is not asked to invent a new scenic-area corporate identity. The design task is to make the existing `清江石书 / QINGJIANG STONE BOOK` experience recognizable across the already-designed journey, digital, paper, field, board, film and memory system without visually replacing Qingjiang itself.

## Evidence-grounded offer
- real Qingjiang journey remains primary;
- BOAT / CABLE / WALK / RETURN form the journey spine;
- reading is optional and progressive;
- digital can retreat;
- no-phone path remains valid;
- memory records what was actually noticed or retained, not 13/13 completion.

## Position / trade-off
Position: `LANDSCAPE AS TEXT / JOURNEY AS READING`.
Trade-off: the brand refuses to compete by adding a louder scenic icon, a stronger ethnic motif package, forced gamification, a 13-stamp completion system, or a universal visual skin over every medium.

## Architecture decision
- `清江石书` = current experience identity.
- `恩施大清江` = source/operator/scenic context.
- Co-brand / endorsement lockup = `HOLD FOR GOVERNANCE`; no operator/legal/trademark approval was recovered in the current authority.
- `十三印`, `我的石书`, `清江旅记`, Return etc. are experience/content/memory subsystems, not equal master brands.

## Failure triggers
- logo becomes more visually dominant than landscape/route/safety;
- different media collapse into one card/template;
- identity relies mainly on green color or decorative mountain/water symbols;
- route/state information is Logo-ized;
- thirteen optional readings become a badge/achievement system;
- the system implies operator approval, field validation, measured geometry or final production approval.
