# C04 Digital UI Detail System v0.6

**Project:** C04｜清江石书｜红花峰林十三印  
**Basis:** Remote Experience Architecture v0.4 + Digital Product Migration v0.5  
**Status:** `PROVISIONAL G3 / REMOTE-GROUNDED / IMPLEMENTATION NOT VERIFIED`

## 1｜视觉系统修正

本版不采用“现代简洁系统”，也不采用传统仙侠手游皮肤。正式方向为：

**山水游历志 × 石拓印记 × 图卷式探索 UI**

类游戏感来自：章节推进、节点揭示、地图探索、印记留存、已读/未读页、轻量反馈和终章生成；不使用角色战力、经验值、金币、宝箱、稀有度、任务清单、强制通关。

### 视觉语法
- 框架：石牒边框、书页角记、图卷分章、印记节点、路线珠链。
- 色彩：岩层黑、清江青、旧铜金、少量朱印；不做满屏金色。
- 字体关系：标题使用宋体/书卷感衬线；功能文字使用清晰无衬线。
- 动效逻辑：缓慢揭页、路线显现、印痕留下；不做抽卡、升级、爆光。
- 视觉中心：真实景观与阅读对象始终高于 UI 装饰。

## 2｜信息层级

- `L0 场地/景观`：第一阅读层。
- `L1 观察令`：一句话告诉用户“先看什么”。
- `L2 看懂它`：一屏核心解释。
- `L3 再深一点`：事实 / 地方叙事 / 资料层，用户主动展开。

每屏只保留一个强主动作。

## 3｜一级界面

- 今日：章节、下一页、当前路线、状态提示、继续行走。
- 路线：真实游线逻辑、13印层、服务层、当前节点。
- 十三印总览：四章分组的节点目录，不作为任务清单。
- 我的石书：已读/未读页、四章轨迹、印记、分享卡。
- 服务：索道、游船、厕所、休息、餐饮、急救、返回、离线包。

## 5｜按钮与反馈

- 一级动作：旧铜“卷轴门槛”式按钮，如 `继续行走 / 记录此页`。
- 二级动作：深青石牒按钮，如 `打开路线 / 揭示这一层`。
- 三级动作：细边或文字动作，如 `返回路线 / 查看解释`。
- 记录反馈：非阻塞提示 `此页已写入你的清江石书`。

## 6｜节点页统一模板

1. 章节 + 节点编号 + 节点名。
2. 景观视觉区。
3. `先看什么`。
4. `看懂它`。
5. S2节点可进入 Reveal。
6. `再深一点`：事实 / 地方叙事 / 资料层。
7. `记录此页` + `下一页`。

S0节点不使用上述完整模板，而进入静观模式。

## 7｜类游戏边界

允许：四章推进、13页目录、节点珠链、已读/未读、自动/观察/揭示/身体印、路线逐步显现、终章生成个人石书。

删除：三角色系统、经验值、等级、金币、奖励、宝箱与稀有度、每点强制任务、13/13通关表达、全屏成功页、每点强制AR。
