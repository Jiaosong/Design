CH08 / P01 / MASTER OWNERSHIP / SYSTEM

不是叠加更多层，
而是决定谁现在拥有主权。

清江石书的总体策略，是让正确的系统在正确时刻出现，并允许其余系统完整地退后。

CH08 不再把 Route、十三印、App、实体、品牌和记忆重新讲一遍。它只控制注意力、当前决策、介入阈值、状态与交接：先让真实清江和身体成立，再判断是否需要解释、数字、物体或品牌。

MASTER CONTRACT LANDSCAPE / BODY ENCOUNTER > CURRENT DECISION / RETURN > OPTIONAL RELATION > SUPPORT CARRIERS. 这是一套动态 ownership，而不是固定 z-index。
