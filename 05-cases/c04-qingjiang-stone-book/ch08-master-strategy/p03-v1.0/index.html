CH08 / P03 / BEHAVIOR CONDITIONS

不是每次停下，
都要变成内容。

内容资格来自当下的身体与决策条件，不来自“停了多久”或“系统猜他想看什么”。

CH08 把 MOVE、LOOK、OBSERVE、RECOVER、CHOOSE、PASS 作为触点分配条件。它们不是追踪用户的行为标签，而是设计师判断什么时候应加强路线、解释、身体支持，什么时候必须让内容退出。

NO FALSE PRECISION不设固定停留秒数、疲劳分数、注意力置信度或自动触发阈值。FIELD=0 时只建立条件关系，不伪装成已验证的人因模型。

01 / STOP ≠ READ
STABLE BODY ≠ CONTENT CONSENT

停下来，只证明发生了停留。

它可能是看风景、等人、恢复、犹豫、拍照、整理物品，也可能只是让路。系统不能把一个身体状态直接翻译成文化内容需求。

THE EQUATION WE REFUSE
STOP
≠ READ

真正有资格进入 Reveal 的，不是“停了”，而是稳定观察已经成立，并且游客出现主动问题、比较或解释需求。

LOOK / RECOVER / CHOOSE MAY ALL INCLUDE STOP WITHOUT BECOMING READ.

02 / CONDITION RULES
DESIGN RESPONSE / FORBIDDEN COLLISION

六种条件改变的是设计响应，不是游客身份。

同一人可以在一分钟内从 LOOK 转为 CHOOSE，再转为 RECOVER；因此系统必须能重新分配主权，而不是给游客贴一个永久标签。

MOVE
Route 清楚，Content 弱。
方向保持可读；阅读、互动和品牌全部减弱。
FORBID：沿路平均触发内容
LOOK
Landscape first；最多轻 cue。
让景观自己完成第一阅读，只在需要时给最轻提示。
FORBID：Overlay / 长解释抢景
OBSERVE
十三印 / Reveal 可有限出现。
稳定比较与主动问题成立后，允许更深一层解释。
FORBID：STOP 自动等于 READ
RECOVER
Physical / Service / Return 提升。
身体恢复和回程判断优先，文化内容不抢恢复窗口。
FORBID：强制文化内容
CHOOSE
Route / Service 获得当前决策权。
先让“继续还是返回、往哪走”变清楚，再恢复可选内容。
FORBID：Brand / Imprint 充当导航
PASS
内容退场；必要方向保留。
足下、边界、通过与回程成为主层，解释不进入。
FORBID：PLAY / READ / COLLECTION
