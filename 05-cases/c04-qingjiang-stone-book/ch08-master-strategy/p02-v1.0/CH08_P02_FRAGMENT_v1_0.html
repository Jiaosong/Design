CH08 / P02 / ENCOUNTER + FREEDOM

先遇见，
再解释。

看见不等于必须停留；停留不等于必须阅读。解释只有在真实问题已经出现时才有资格进入。

清江石书不把一次游程改造成“逐页完成”的任务链。最小体验可以只是看见、经过、继续；更深的 Reveal 必须来自同一个对象、同一个场景，并在完成关系揭示后主动退场。

ENCOUNTER CONTRACTREAL SCENE → NOTICE → QUESTION / NEED? → SAME-SOURCE REVEAL → OPTIONAL EVIDENCE → WITHDRAW / CONTINUE。没有 Question，就不强行制造 Read。
ATTENTION CHOREOGRAPHY

内容不是越多越完整；退场也是系统动作。

SEQUENCE = ATTENTION LOGIC · NOT ROUTE ORDER · NOT REQUIRED COMPLETION

STOP ≠ READ这套顺序控制的是注意力，不是把游客锁进一次内容完成流程。
01 / FREEDOM GRAMMAR
SPATIAL ORDER ≠ FORCED SEQUENCE

系统允许“少做一点”，并且仍然算完整旅行。

十三印是可选阅读语法，不是 13/13；App、实体触点、品牌与记忆也不能把自由游程偷偷变成任务链。

02 / SCENE PRESSURE TEST
CONTENT EARNS PRESENCE

不是每个“好场景”都值得更多内容。

同一套规则要经得住移动视点、稳定观察和身体通过三种不同注意力条件。

CABLE / MOVING VIEWPOINT
关系正在变化，先看。
CONTENT = DOWN / OFF

移动本身已经提供空间关系变化；中段手机与长解释退出。

R06 / STABLE OBSERVATION
稳定观察后，Reveal 才可能成立。
CONTENT = OPTIONAL / LIGHT

同一 scene base；短时揭示两岸 / 相对平缓面等关系，然后退回 Landscape。

R13 / PASSAGE
身体通过，不设阅读站。
READ / PLAY / BRAND = OFF

Passage 的正确设计是减少内容，让 Route / Body / Return 保持主权。
