CH08 / P06 / HANDOFF + PROOF BOUNDARY

交接不是叠加，
而是把主权交给下一层。

每个系统只交出它有权交出的东西；完成任务后，应主动把注意力还给真实清江、身体或下一次现实决策。

Route、Imprint、Digital、Physical、Memory 与 Brand 不组成一条“功能越来越多”的链。它们通过条件式 handoff 协作：路线先清楚，解释才有资格出现；身体被支持后，实体必须退回背景；Memory 只在 Return / Leave 后取得主导。

Paper、Human、Digital 不是竞争谁更先进，而是在 no-phone、low-network 和 uncertainty 中共同守住基础判断。

02 / PROJECT PROOF BOUNDARY
TECHNICAL PROOF ≠ VISITOR MATRIX

技术证明要公开可读，但不进入游客实时载体矩阵。

Evidence 必须证明自己的范围，也必须写清不能证明什么；工程闭环不能替代空间、体验和视觉质量。
