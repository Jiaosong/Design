This is a production verdict. It does **not** authorize historical-source substitution. Where a new Current asset is intentionally redesigned, it must receive a new identity/provenance record rather than masquerading as recovery of a missing legacy runtime file.

Verdict vocabulary:
- `KEEP` = object and current representation may remain, subject to final browser/design readback.
- `KEEP SOURCE / REWORK` = source/authority remains useful, but crop, treatment, composition, presentation or derivative must be redesigned.
- `REMAKE` = rebuild the representation from authoritative project facts/design logic in a native editable form.
- `REMODEL` = rebuild native geometry/model representation because a trustworthy native master is not currently proven or the existing representation has not earned Design KEEP.
- `MODEL-DERIVE` = produce a new view/drawing/render from the same verified Current native geometry after that geometry exists and passes its owner review.
- `REMOVE MAIN` = do not use as a main public artifact in the current state.
- `HOLD` = no production binding until a required authority/identity boundary is resolved.

## Hard boundaries for the remake phase

- `AUTHORITY KEEP ≠ PIXEL KEEP`.
- `CONCEPT KEEP ≠ MODEL KEEP ≠ DRAWING KEEP`.
- New Current redesign is allowed; silent historical recovery claims are not.
- A weak current asset may be replaced even if it previously had `KEEP` language; that older verdict remains provenance, not immunity from present design review.
- Technical proof must remain honest about `FIELD OBSERVED=0`, `FIELD MEASURED=0`, `G1F HOLD`, NTS / NOT FOR CONSTRUCTION where applicable.
- Public assets must remove internal workflow/status/AI-process theatre unless the information is genuinely part of the visitor-facing design argument.
- Every rebuilt asset returns through its existing OLEANDER owner Skill and Artifact Review. Skill-caused failure must be recorded and repaired in that Skill before project re-application.
- `SOURCE/STATIC READBACK ≠ BROWSER PASS`; this file cannot grant finished-pixel or interaction PASS.
