## 4. No-loss public restructuring target

The public work should be reorganized around what the visitor encounters and what the design changes, while the project remains fully retrievable through chapters/support material.

Provisional public reading spine:

1. **清江 / 到达** — real landscape and the actual journey.
2. **水上、空中、山中** — three scales of seeing and moving.
3. **怎么走、怎么回** — route, transport, service and Return.
4. **十三印** — optional reading/content system.
5. **场景** — R06 open-stop-recover and R13 body-return contrast; expand to other valid nodes when visual evidence is strong enough.
6. **数字陪伴** — orientation, optional reading, memory and retreat.
7. **实体与身体** — rest, reading, return recognition and physical/sensory objects; rebuild weak artifacts.
8. **品牌识别** — independent visual/graphic/motion/editorial identity.
9. **记忆与带走** — paper, personal traces, cultural products and post-visit memory as a separate layer.
10. **空间与技术证明** — model/drawing/detail proof distributed by object, with a support technical overview if needed.
11. **回程** — return, re-recognition and closing landscape.
12. **补充资料** — provenance, process, evolution, unresolved technical boundaries and deeper evidence; not the main experience.

This is a reading spine, **not a fixed page count**. Any one layer may require several surfaces/pages if its independent design content warrants them.

## 5. Asset / model / drawing rebuild rule

### Images / media

Run: source identity → crop/tonal/hierarchy review → target reading distance → image/text relation → keep/reframe/replace.

A weak crop or weak image treatment is not protected by source authenticity.

### 3D / model

Run current `oleander-3d-pipeline` + AR-S02. Rebuild when geometry, hierarchy, camera, material, spatial credibility or explanatory value fail. Existing model provenance remains preserved even if the public model is replaced.

### Drawings

Run technical-drawing route + AR-S01. A technically traceable SVG may still be `VISUAL REVISE`. Redraw lineweight, annotation, scale figures, composition, section hierarchy, material/connection depiction and sheet structure when needed. Do not invent field dimensions to make the sheet look complete.

### Visual / page

Run visual-design / web-ui candidate route under current owner rules plus final Artifact Review. HTML/CSS existence and static dependency integrity do not grant presentation KEEP.
