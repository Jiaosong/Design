L1 · PROJECT + EXPERIENCE

同一条清江，
从三个尺度重新认识。

BOAT / OPEN

先完整地看见清江。

水面把峡谷、峰林、岸线和行进距离同时拉开。设计在这里降低解释密度，让真实景观成为第一信息层。

04

L2 · WHY / PROJECT BRIEF

先把人放回清江，
再谈设计。

01真实清江 · 路线 · 身体

先确认人在什么景观、什么移动方式、什么身体状态里。

02服务 · 回程

能否走、如何退、何时休息，比内容完成度更优先。

03十三印 · 可选阅读

内容是一页页被打开，不强迫游客完成。

04数字 · 识别

数字工具提供方向与深度，也必须能够主动退场。

05记忆

旅程不以积分结束，而以重新认识清江结束。

QINGJIANG / CONDITIONS → EXPERIENCE

河谷、速度、人和退路，
决定内容什么时候出现。

LANDSCAPE

山水关系

河谷、峰林、两岸与开合变化决定观看距离与解释密度。

→ 景观强时，说明退后
CULTURE

地域内容

地名、故事、植物、山水知识与地方文化按场景适配，而非平均铺设。

→ 只在相关场景打开这一页
MOBILITY

移动与服务

游船、索道、步行拥有不同速度、视域、停留与返回压力。

→ 水上、空中、山中使用不同密度
PEOPLE

不同的人

儿童、青年、深读者、低体力人群在同一场景需要不同深度与支持。

→ 同一场景提供不同深度与支持
BEHAVIOR

注意与行为

看、比、寻、听、等、框、望、辨、随、过、记、回、留。

→ 阅读从看、寻、听、过这些动作发生
STATE

状态与退路

NORMAL / DEGRADED / CLOSED / UNKNOWN 与 FULL / LIGHT / OFF。

→ 状态变化时，先保住路线与回程

AUDIENCE / SAME SCENE, DIFFERENT DEPTH

不为不同人复制产品。

07

WHAT APPEARS / WHAT STEPS BACK

什么时候出现，什么时候退后，
设计有清楚的次序。

  1. 景观先出现先看山水与身体关系，再补解释。
  2. 先确认能走、能回路线、恢复与回程优先于内容完成。
  3. 同一条清江，三种尺度水上看整体，空中看关系，山中进入细部。
  4. 十三印可以不读完内容可按兴趣打开，但不成为路线权威。
  5. 信息密度跟着场景变化不同场景分配不同界面、文字与互动密度。
  6. 数字可以退场需要时出现；景观更强时主动让开。
  7. 实体只在真正需要时介入身体、恢复、阅读或回程有需求时才出现。
  8. 同一场景，不同深度通过阅读深度与支持强度回应不同人群。
  9. 先看，再揭示关系尤其 R06：先完整景观，再进入关系与深读。
  10. 最后留下的是记忆以重新认识清江结束，而不是追求 13/13 完成率。

L3 · DESIGN METHODS

不是套模板。
每个决定都有生成路径。

EVIDENCE证据
→
SPATIAL FINDING空间发现
→
DESIGN CONSEQUENCE设计后果
Landscape First → Relation Reveal

完整景观 → 自主观察 → 关系揭示 → 可选深读 → 主动退场。

Scene × Attention × Audience

用场景注意力密度和人群深度共同决定信息量。

Physical + Digital + Paper + Service

多载体冗余，不把安全、路线与记忆押在单一媒介上。

State × Fallback

状态变化时保持最小可用路径，并把 UNKNOWN 视为需要谨慎处理的状态。

L4 · ROUTE / SERVICE / RETURN

游程不是一条强制线。
路线首先服务人。

BOAT / CABLE / WALK 连接的是不同尺度的观察，不是三个必须完成的关卡。

DESIGN STATE SIMULATOR · 非实时运营数据

正常阅读完整游程可见；数字保持低干扰；回程入口持续可见。
