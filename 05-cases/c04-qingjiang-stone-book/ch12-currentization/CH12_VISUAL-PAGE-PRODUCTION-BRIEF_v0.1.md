## 0｜CH12 visual contract

CH12 is not a node catalogue. It must prove how the project behaves in selected key scenes.

Master sequence:

`REAL SCENE FIRST → BODY / ROUTE DUTY → OPTIONAL OBSERVATION / READING → MINIMUM SUFFICIENT DIGITAL / PHYSICAL → WITHDRAW / RETURN`

Visual sequence:

`ATLAS → MOVING VIEW → DISCOVERY → LANDSCAPE → REVEAL → BODY → DECISION → COMPRESSION → RELEASE`

This sequence intentionally changes visual mass, crop, density and medium page by page. Consecutive pages must not collapse into one repeated template.

Global locks:
- `ROUTE-03 = LOCKED CURRENT`; CH12 may consume but never redraw route authority.
- `R06 = FINISHED / FROZEN / NO REOPEN`; CH12 only represents the finished experience more clearly.
- Whole-project Web image uniqueness: one underlying content image source = one semantic Web slot.
- Same-source Reveal = one semantic component with state/layer changes; authoring frames may be separate, final Web source binding must not duplicate.
- `REAL QINGJIANG FIRST`; AI may not substitute factual site/route/field evidence.
- Image Ops derivatives remain presentation derivatives: `WASH-TONAL → WASH-MASK → INK-EDGE` does not create a new source identity.
- Production/process notes, source IDs, Image Ops recipes and truth metadata belong in caption/manifest/near-read, not the first visual field.

## A01｜Selected Scene Atlas

### Page role
CH12 chapter opener / scene-selection argument.

### 3-second claim
**不是五个地点，而是五种关键场景责任。**

### Dominant visual
A single **Selected Scene Responsibility Atlas** consuming locked journey/route evidence without re-authoring it.

Preferred construction:
- source-bound `ROUTE-03` / macro journey relation as a quiet factual base where usable;
- R01 / R05 / R06 / R13 highlighted only at source-supported relation level;
- `DECISION MOMENT` shown outside geometry as a semantic/temporal event: `LOCATION OPEN / NOT ROUTE GEOMETRY`;
- R06 receives strongest visual mass because it is the main observation/recovery scene;
- R13 closes the field with Withdraw / Return.

### Exact content
- headline: `关键场景不是平均分配，而是在不同阶段承担不同责任。`
- scene verbs: `MOVE / DISCOVER / OBSERVE–RECOVER / DECIDE / WITHDRAW–RETURN`;
- one short line explaining scene-selection criteria: route duty + body change + attention change + return significance;
- optional minimal legend: `SCENE / DECISION MOMENT / RETURN`.

### Asset strategy
- no reuse of W00/QJ-D Hero source;
- preferably no content photo at all;
- if a new unique overview image is later allocated, it must remain secondary to the atlas and must not imply precise node coordinates.

### Text budget
Hero claim ≤ 22 Chinese characters; support ≤ 60 Chinese characters; metadata/caption only near-read.

### Prohibited
- fake route curve;
- `five locations` wording;
- AI five-scene moodboard;
- asset-rules box in main composition;
- equal five-card grid.

### Review target
First read = scene responsibility field, not title, rules, or decorative image.

## A02｜R01 Cable Moving View

### Page role
Prove R01 as a moving-view scene where the landscape remains primary and interface intervention retreats.

### 3-second claim
**移动中的第一任务是看，不是操作。**

### Dominant visual
One authentic/approved cable-view source or a source-bound moving-view frame system. The cable/world view must occupy most of the page.

### Exact content
- `BEFORE ORIENT → DURING OBSERVE → AFTER RECOGNIZE`;
- DURING state visually dominant;
- `VIEW ONLY / UI OFF or TRACE / NO MARK / NO TASK`;
- show viewing direction / frame shift only as presentation overlay, not measured field-of-view claim;
- after-view optional reading appears as a small retreating layer, never inside moving-view first read.

### Asset strategy
Required final asset: **new unique R01 source** not already allocated elsewhere in C04 Web.  
Current authentic continuous moving stimulus: `HOLD`.

If only one valid static photo exists, use it once as one semantic image slot with bounded SVG overlay; do not fabricate a photographic sequence by cropping the same source into multiple Web slots.

### Image Ops
Allow bounded wash treatment, but effect-off comparison must retain cable, river/valley relation and viewing direction.

### Text budget
One headline + 3 state verbs + one evidence-boundary caption.

### Prohibited
- cable equipment catalogue page;
- fake moving sequence from unrelated generated frames;
- strong UI/HUD;
- route-node/task markers during cable passage.

## A03｜R05 Discovery

### Page role
Prove the discovery interaction: the visitor notices first, design only gives a light cue when useful.

### 3-second claim
**发现先由景观发生，设计只轻推一次。**

### Dominant visual
A real, unique R05 path/vegetation/rock/occlusion image with a strong foreground–opening relationship.

### Exact content
- sequence: `LOOK → FRAME → COMPARE → OPTIONAL REVEAL → CONTINUE`;
- one visual cue showing conceal/reveal or framed attention;
- one small optional reading/reveal layer;
- clearly state that Light Interaction is complete even without deep reading.

### Asset strategy
Final content image must be a **genuinely different R05 source** from the source already consumed in CH01.  
Current status: `CONTENT-IMAGE SLOT HOLD` until such a source is materialized.

### Image Ops
`WASH-TONAL → local WASH-MASK → INK-EDGE` only if it preserves the discovery edge and does not flatten foreground/background separation.

### Text budget
≤ 45 Chinese characters excluding tiny evidence caption.

### Prohibited
- generic Qingjiang substitute;
- AI factual site image;
- decorative clue icons distributed across image;
- compulsory Reveal/completion semantics.

## A04｜R06 Landscape First

### Page role
CH12 main visual climax. Prove the finished R06 experience before explanation.

### 3-second claim
**先看清江，再决定是否读。**

### Dominant visual
The strongest current R06 Landscape First source, full-field or near full-field. Landscape and body relation must remain readable with labels removed.

### Exact content
- `SEE → STOP → RECOVER → READ`;
- first visual = landscape;
- second read = stopping/recovery/body relation;
- optional reading and digital are visually suppressed until intent;
- no redesign of R06 geometry or experience.

### Asset strategy
Reserve one unique authoritative/current R06 base source for the **R06 semantic component**.  
This source is bound once in final Web and is shared internally with A05 as a state transition, not duplicated as a second image slot.

### Image Ops
Very restrained. Real spatial relation must remain stronger than paper/ink styling. Always retain effect-off baseline.

### Text budget
Hero claim ≤ 16 Chinese characters; sequence ≤ 4 short tokens; no explanation paragraph over landscape.

### Prohibited
- platform/product/object becoming first visual;
- technical drawing takeover;
- generic scenic photo replacing current R06 source;
- re-opening R06 design.

## A05｜R06 Same-source Relation Reveal

### Page role
Not a second scenic page. It is the **state specification** of the same R06 semantic component after visitor intent.

### 3-second claim
**解释只在意图之后出现，并让人重新看同一片景观。**

### Dominant visual
Exactly the same R06 base source and crop as A04, with bounded reveal layers only.

### Exact content
- State 0: Landscape First;
- State 1: visitor intent / optional trigger;
- State 2: Relation Reveal;
- State 3: Compare Again / Optional Deep Read;
- State 4: Withdraw;
- reveal layer must show only relationships that materially change understanding.

### Final Web rule
A04 + A05 must be implemented as **one semantic component / one base image binding**. A05 may remain a separate authoring/spec frame, but must not become a duplicate static Web image slot.

### Visual language
Use masks, thin relation traces, limited annotation and one dominant reveal relation. Avoid dashboard panels.

### Text budget
State labels + max 2 concise reveal statements.

### Prohibited
- different abstract proxy replacing base landscape;
- second R06 photo source only to simulate a reveal;
- dense science annotation wall;
- permanent overlay that destroys Landscape First.

## A06｜R06 Body × Audience

### Page role
Shift from landscape to body depth. Explain how different users inhabit the same finished R06 without turning them into personas/cards.

### 3-second claim
**同一处停留，不同身体需要不同深度。**

### Dominant visual
Large body/gesture field or one source-bound section/edge relation with human figures. Human scale and posture are the main visual, not UI or product.

### Exact content
Show 4 bounded conditions:
- `CHILD / FAMILY` — shorter attention, clear recovery/continue relation;
- `EXPLORER` — observation + optional reveal;
- `DEEP READER` — deeper reading after landscape recognition;
- `FATIGUED USER` — recovery / return may become primary.

`ODB-02 / P02` may appear only as **body-recovery support relation** and must be labelled `NOT LOCATED / FIELD OPEN` if shown.

### Asset strategy
Prefer vector human silhouettes + source-bound R06 support section/edge geometry rather than another R06 photograph. This protects image uniqueness and makes the body claim explicit.

### Text budget
4 short behavior lines; no persona biography.

### Prohibited
- four equal persona cards;
- product hero replacing body;
- claiming P02 is installed at R06;
- technical dimensions not supported by current evidence.

## A07｜Route Decision / Continue vs Return

### Page role
Prove a decision moment, not a new location and not a second route map.

### 3-second claim
**当继续与返回都合理时，系统先帮人做决定。**

### Dominant visual
One directional decision composition: `CONTINUE ↔ RETURN`, with Return carrying equal legitimacy rather than looking like failure/back button.

### Exact content
- decision inputs: body condition / time-service condition / route openness / no-phone continuity;
- output: `CONTINUE` or `RETURN`;
- hierarchy of carriers: human/paper first where sufficient; digital only if needed;
- `CLOSED / UNKNOWN` must fail closed;
- clear label: `DECISION MOMENT / LOCATION OPEN / NOT ROUTE-03 GEOMETRY`.

### Asset strategy
No content photograph required. Use typography + SVG directional field + tiny source-bound status tokens.

### Text budget
One headline + four input words + two decisions + one truth-boundary caption.

### Prohibited
- drawing another map;
- app screen as main visual;
- countdown/queue/live status without evidence;
- gamified success/failure semantics.

## A08｜R13 Enter + Pass

### Page role
Create the strongest spatial compression page. Prove that during passage the design withdraws.

### 3-second claim
**越收束，设计越应该退场。**

### Dominant visual
A narrow vertical/central aperture or authentic/approved R13 passage source. Body scale and compression must be immediately readable.

### Exact content
- `APPROACH → PREPARE → ENTER → PASS`;
- during PASS: `BODY / ROUTE ON`;
- `READ / PLAY OFF`;
- no stopping, scanning, collecting or explanation inside the compressed passage;
- `FIELD OPEN / NTS` where exact width/safety geometry is unknown.

### Asset strategy
Preferred: one unique R13 inside/passage source reserved for A08.  
If only the existing multi-frame remote concept is available, treat A08/A09 as states of one R13 semantic component or obtain a genuinely different second source before final Web split.

### Image Ops
Darkening may reinforce compression only if aperture/body edge remains legible. No artificial glow path.

### Text budget
Very low: headline + 4 sequence verbs + `READ/PLAY OFF` + truth-boundary caption.

### Prohibited
- UI overlay inside fissure;
- dramatic fictional lighting or invented railing/path;
- long explanation;
- exact clearance/safety claim without field evidence.

## A09｜R13 Exit + Re-recognition

### Page role
Release the visual pressure and close CH12 with Return / memory handoff.

### 3-second claim
**离开裂隙之后，清江重新变成完整的景观。**

### Dominant visual
A radically more open composition than A08: broad horizon/water/valley or look-back relation. The page must visibly breathe.

### Exact content
- `EXIT → REOPEN → TURN / LOOK BACK → RECOGNIZE → CONTINUE / RETURN`;
- memory begins only after exit;
- Return is visible but quiet;
- closure line can hand off to CH15 Memory without turning this page into a product page.

### Asset strategy
Preferred: a genuinely different R13 exit/reopening source from A08.  
If unavailable, use one-component state transition with the same R13 semantic source rather than duplicate source slots.

### Image Ops
Lighter tonal wash than A08; maintain source truth; ink edge should retreat rather than increase.

### Text budget
One short closure sentence + 5 sequence verbs + tiny boundary caption.

### Prohibited
- points/badges/collection completion;
- memory product hero;
- same visual mass/darkness as A08;
- duplicated R13 source in a second Web image slot unless implemented as the same component state.

## 10｜Cross-page visual rhythm

The page sequence must visibly change:

| Page | First visual form | Density | Tonal role |
|---|---|---:|---|
| A01 | atlas / relation field | medium | neutral-paper + Qingjiang trace |
| A02 | wide moving landscape | low | airy / moving |
| A03 | close discovery frame | low-medium | textured / local contrast |
| A04 | dominant landscape hero | very low | calm / widest visual authority |
| A05 | same-source reveal state | medium | same base + bounded ink relation |
| A06 | body / gesture field | medium | warm-neutral / human scale |
| A07 | decision split | very low | graphic / high directional clarity |
| A08 | narrow compression | very low | darkest page |
| A09 | release / reopening | very low | lightest closure page |

Hard anti-template rule: no consecutive pair may share the same `hero-left + text-right`, card grid, or equal-module composition merely for consistency.

## 11｜Production order

Do not produce A01–A09 in arbitrary order.

1. **A01** — lock chapter first-read and scene responsibility architecture.
2. **A04 + A05** — lock the R06 semantic component and same-source reveal behavior together.
3. **A08 + A09** — lock R13 compression/release pair together.
4. **A02** — solve authentic moving-view asset / HOLD boundary.
5. **A03** — solve unique R05 source allocation.
6. **A06** — body/audience representation after R06 visual is locked.
7. **A07** — decision grammar after Route/Return hierarchy is visually confirmed.

Every page run:
`CURRENT AUTHORITY → PAGE CLAIM → ASSET ALLOCATION → DOMINANT FIELD → LOW-FI COMPOSITION → IMAGE OPS IF NEEDED → TARGET-SIZE READBACK → OLEANDER COMPLIANCE → PROFESSIONAL DESIGN CRIT → KEEP / REVISE / REJECT / HOLD`.

Do not proceed to polishing if the 3-second first read fails.
