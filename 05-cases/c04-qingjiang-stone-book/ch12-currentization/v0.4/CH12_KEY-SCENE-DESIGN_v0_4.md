## 0｜Chapter role

CH12 不是十三印节点目录、不是产品展板集合，也不是把 CH09–CH13 再讲一遍。

CH12 的任务是用少量**关键场景**证明这套设计在真实游程中如何发生：

`REAL SCENE FIRST → BODY / ROUTE DUTY → OPTIONAL OBSERVATION / READING → MINIMUM SUFFICIENT DIGITAL / PHYSICAL → WITHDRAW / RETURN`

每个场景必须回答：
1. 游客此刻首先看见 / 感到什么；
2. 身体与 Route / Service 此刻承担什么责任；
3. 十三印内容是否值得出现；
4. Digital 是否需要出现，出现到 FULL / LIGHT / OFF 哪一级；
5. Physical / Sensory 是否真正解决身体或感官缺口；
6. Brand 是 FULL / LIGHT / TRACE / OFF；
7. 什么时候退出解释并重新交还给景观 / Route / Return；
8. 当前证据能证明什么、什么仍 FIELD OPEN。

**场景完整性来自关系成立，不来自系统同时出现。**

## 1｜Scene selection rule

CH12 不平均展开 R01–R13。只有满足以下至少一项的场景才进入主章节：
- 改变观看尺度或身体状态；
- 能检验 `Landscape First / Route Authority / Optional Reading / Correct Absence / Return`；
- 能证明两个以上系统之间的真实 handoff；
- 已有足够 source / design material 可进行诚实表达；
- 能形成明确的 KEEP / DEEPEN / HOLD / NO DESIGN 判断。

因此当前主场景只保留：
- `SC-R01 / Cable Moving View`；
- `SC-R05 / Discovery`；
- `SC-R06 / Landscape + Reveal + Body Recovery`；
- `SC-ROUTE-DECISION / Continue vs Return`；
- `SC-R13 / Compression + Re-recognition`。

R02 / R07 / R09 / R12 继续属于内容/文化深化候选；除非场景证据足够，不为补页数升级成 Key Scene。

## 2｜Authoring units｜9 个场景页面单元

> `A01–A09` 是 CH12 authoring unit，不是最终 `C04-WEB-Pxxx / Nxxx` PAGE-ID。

### A01｜Selected Scene Atlas｜关键场景不是五个孤立节点

**第一读：** 同一条真实游程在不同位置发生五种不同责任：
`MOVE → DISCOVER → OBSERVE / RECOVER → DECIDE → WITHDRAW / RETURN`。

**设计目的：** 先让读者看到“场景为什么被选中”，再进入节点细节。

**必须表达：**
- R01 = moving-view / relationship change；
- R05 = self-discovery / low intervention；
- R06 = landscape + recovery + optional reveal；
- Route Decision = function / return / fail-closed；
- R13 = compression / content withdrawal / re-recognition。

**禁止：** 把它画成五个等权卡片、五个新景点或一条新的路线。

### A02｜R01 / Cable｜移动中第一次关系转换

Scene contract:
`BEFORE ORIENT → DURING OBSERVE → AFTER RECOGNIZE`

- **Landscape / Body first:** 索道移动、江面、两岸与山体关系先成立；
- **Route / Safety:** 通行与索道运营信息优先；
- **Reading:** R01 只允许轻量观察提示，默认 `S0 → optional S1`；
- **Digital:** 不强制 trigger / scan / complete；
- **Physical:** 不新增 mid-crossing object；索道本身就是观看条件；
- **Brand:** `TRACE / OFF`，不得成为窗面 HUD；
- **Exit:** 下索道后才允许识别/回看轻提示。

**Evidence boundary:** 当前证据足以支持“索道移动视域”设计问题，但连续真实 cabin POV / moving A-B stimulus 尚未 materialize；静态平移、AI video、他处索道视频不得替代。  
State: `SCENE KEEP / MOVING-STIMULUS HOLD / FIELD VIEWPOINT OPEN`。

### A03｜R05 / Discovery｜从“看山”到自己找到一个关系

Scene contract:
`LANDSCAPE → LIGHT PROMPT → LOOK / FRAME / COMPARE → OPTIONAL REVEAL → CONTINUE`

- **第一读：** 红花峰林/山体本身；
- **Interaction:** 观察动作而非答题；
- **Digital:** `LIGHT` 即可完整，Reveal 只在主动选择后出现；
- **Physical:** 默认 `NO DESIGN`；
- **Brand:** `TRACE`；
- **Memory:** 只记录“我注意到了什么”，不记完成度。

**Current hold:** R05 interaction concept 可保留，但 authoritative Honghua landscape raw pixel 仍未在 current runtime 关闭；因此 `LANDSCAPE PIXEL HOLD` 时不得用 generic Qingjiang 或 AI 图替代 MAIN。  
State: `INTERACTION KEEP / MAIN PIXEL HOLD`。

### A04｜R06 / Landscape First｜先让河谷完整成立

`R06 Experience = FINISHED / FROZEN / NO REOPEN`

Scene contract:
`SEE → STOP → RECOVER → CHOOSE`

- **第一读：** 江、坡、峰林、开阔面与身体尺度；
- **Body:** 允许短时停靠/恢复，先稳定身体再决定是否阅读；
- **P02:** 仅作为 CH13 的 body-recovery support relation 进入，不证明已经落位 R06；
- **Digital:** `OFF / LIGHT` 均可完整；
- **Reading:** 此页不解释河谷科学关系；
- **Brand:** `TRACE / OFF`；
- **Return:** 始终可直接离开或回撤。

Representation priority:
`REAL / CURRENT R06 LANDSCAPE VISUAL > HUMAN SCALE / BODY RELATION > TECHNICAL SUPPORT`。

### A05｜R06 / Same-source Relation Reveal｜第二次看同一个河谷

Scene contract:
`OBSERVE → EXPLICIT CHOICE → REVEAL → COMPARE AGAIN → OPTIONAL DEEP READ → WITHDRAW`

- Reveal 必须建立在**同一 authoritative base / same view** 上；
- 第二层只增加 bounded relation，不重画一个更“好懂”的假几何；
- 普通游客看懂一个关系即可退出；Deep Reader 可继续来源/证据层；
- Digital 只负责 Reveal / evidence edge，不拥有场景；
- 解释完成后回到 Landscape，不让关系线永久覆盖画面。

Technical relation:
`SEC-B / C23-R06` 只回答高低、左右、远近、观看方向与构件关系；`NTS / NOT MEASURED / NO GEOLOGICAL CAUSATION CLAIM`。

### A06｜R06 / Body × Audience｜同一场景容纳不同深度

不新增 persona 页面；直接在同一 R06 场景中比较：
- QUICK / ordinary visitor：看 + 短停；
- FAMILY / CHILD：观察动作 + 共同指出一个关系；
- DEEP READER：Reveal + evidence；
- FATIGUED / LOW-STAMINA：恢复 / Return 优先；
- LOW-DIGITAL / NO-PHONE：景观 + 实体/纸本 + 人工服务仍完整。

**关键判断：** Audience modifier 改变停留、解释深度、Digital intensity 与 recovery priority，**不改变 Route truth，也不强迫同一 Physical object 服务所有人。**

Fluid Rest / Qingfengyin 不因已有效果图或模型自动进入 R06；LOCATION / sensory necessity 未关闭前继续在 CH13/CH18 竞争。

### A07｜Route Decision Scene｜探索必须能可靠地转向 Continue / Return

这是 CH12 唯一新增的**场景类型**，不是新景点，也不创造新路线。

Scene contract:
`APPROACH DECISION → ORIENT → CONTINUE / RETURN → CONFIRM → MOVE`

必须同时检验：
- `ROUTE-03 = LOCKED CURRENT`；
- 当前分支/回撤关系；
- `Continue vs Return` 的第一信息层；
- Paper map 是否与同一 Route Authority 对应；
- Human help 是否可独立工作；
- Digital `FULL / LIGHT / OFF` 都不破坏核心判断；
- `CLOSED / UNKNOWN` 时 optional reading 关闭并 fail-closed；
- Brand 不借路线、方向、状态色的功能权威。

**位置纪律：** exact branch / node 未经 field / operator 验证时保持 `LOCATION OPEN`；页面只做 `SCENE CONTRACT / REPRESENTATION TEST`，不得伪造节点坐标。

### A08｜R13 / Enter + Pass｜空间收束时，设计开始退出

Scene contract:
`APPROACH → PREPARE → ENTER → PASS`

PASS 中：
- `BODY / ROUTE = ON`；
- `READ / PLAY = OFF`；
- Digital = `OFF` 或仅保留必要 Return；
- Brand = `OFF / TRACE`；
- 不设停留任务、不设 Relation Mark、不提前解释出口景观。

R13 的设计价值不是“再做一个 Hero”，而是证明 **Correct Absence**：越收束，设计越少。

Representation truth:
当前四帧为 `REMOTE CURRENTIZED DESIGN / NOT SITE PHOTO`；宽度、安全、无障碍、真实视线仍 OPEN。

### A09｜R13 / Exit + Re-recognition｜重新展开之后才完成一次阅读

Scene contract:
`EXIT → REOPEN → TURN / LOOK BACK → RECOGNIZE → CONTINUE / RETURN`

- 退出后才重新让江、北岸/来路关系进入认知；
- Route / Return 重新取得主权；
- Digital 可恢复为 `LIGHT`，但不继续深读；
- Memory 只在此处开始累积，完整 `RECORD / TAKE AWAY` 仍归 CH15 / CH19；
- 模型/section 只支持 aperture / relation，不替代真实景观或 field view。

**结尾判断：** R06 的 `REVEAL` 与 R13 的 `WITHDRAW` 形成 CH12 最核心的一对空间动词：
`打开关系 → 再把关系交还给景观。`

## 4｜State behavior across CH12

Operational state 与 Digital / Brand state 必须分开：
- `NORMAL`: scene behavior 按本章合同；
- `DEGRADED`: 降低可选深度、提高 Route / Service / Return 可见性；
- `CLOSED`: optional scene content 不继续，进入 bypass / Return；
- `UNKNOWN`: 不画成正常开放，保持 fail-closed；
- Digital `FULL / LIGHT / OFF` 只决定数字表达；
- Brand `FULL / LIGHT / TRACE / OFF` 只决定身份存在感。

`Digital OFF != CLOSED`；`Brand OFF != abnormal`。

## 5｜Representation discipline

每个 CH12 场景的公开/作品表达按以下优先级：
1. **REAL QINGJIANG / source-bound landscape first-read**；
2. body / route / scene relation；
3. optional content / digital / physical carrier；
4. near-read section / diagram / model proof；
5. evidence / FIELD boundary。

禁止：
- grey model 取代真实清江 Hero；
- UI overlay 先于空间第一读；
- generic landscape 或 AI imagery 填 R05/R13 source gap；
- technical drawing 反向变成体验设计来源；
- 为了让 9 个 authoring unit“视觉统一”把场景做成九张同模板 dashboard。
