## Project Frame

本项目不是为红花峰林叠加一套独立游戏、角色宇宙或大型主题装置，而是在成熟运营景区的真实地貌、地方文化、既有游线和运营条件上，建立低干预的山水阅读体验。

> 山水为纸，岩层为字，行走成书。

`清江石书` 为母叙事；`清江十三印` 是编辑／个人记忆结构，不是 13 个必须完成的固定物理站点。当前体验骨架为 `8 Core Reading Pages + replaceable Companion Pool`。
