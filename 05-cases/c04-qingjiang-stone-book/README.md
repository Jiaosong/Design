## Project Frame

本项目不是为红花峰林叠加一套独立的游戏、角色宇宙或大型主题装置，而是在成熟运营景区的真实地貌、地方文化、既有游线和运营条件上，建立低干预的山水阅读体验。

> 山水为纸，岩层为字，行走成书。

核心设计对象是游客、真实地景、地方解释、路径、数字信息、身体行为、运营与记忆之间的关系。
