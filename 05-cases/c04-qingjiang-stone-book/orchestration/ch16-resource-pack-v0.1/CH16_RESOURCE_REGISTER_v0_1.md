## 0｜Status vocabulary

- `READY_CURRENT` — materialized current project source/carrier that can enter production at its registered role.
- `READY_CONTEXT_ONLY` — materialized project resource usable only as scene/context; no geometry/site claim.
- `READY_SECONDARY` — materialized technical/support resource; cannot become first visual automatically.
- `READY_HISTORICAL_TRACEABLE` — exact bytes available at immutable historical ref; must be currentized before public pixels.
- `READY_FILE_LIBRARY_SUPPORT` — available in File Library, support/contrast role only.
- `REFERENCED_NEEDS_MATERIALIZATION` — project lineage names a file, but exact current bytes have not yet been materialized on this production surface.
- `REFERENCE_EXTERNAL` — official standard/test/reference input; supports selection/check questions, not C04 field/engineering truth.
- `PROHIBITED` — known object must not enter CH16 visible production.
- `OPEN_EVIDENCE` — requires field/engineer/operator/sample evidence before any implementation claim.

## 4｜External professional reference boundary

The standards above are used only to define professional questions, candidate ranges/tests and evidence needs. They do **not** prove:
- the real Qingjiang site condition;
- actual accessible-route compliance;
- structural adequacy of an existing railing/base;
- anchor/clamp capacity;
- approved material grade/coating;
- wet slip performance;
- drainage capacity;
- maintenance interval;
- construction permission or approval.

Any quantitative value imported from a reference must be classified as `STANDARD REQUIREMENT`, `REFERENCE RANGE`, `DESIGNER ESTIMATE`, or `FIELD/ENGINEERING OPEN`; it cannot silently become a site measurement.
