## 1｜Authority model

The project is organized as five different authority classes. These classes must not be collapsed:

1. **DESIGN SOURCE** — original C04 presentation boards and mature original design outcomes.
2. **CURRENT MAIN AUTHORITY** — merged `main` authority chain: Governance → `C04_CURRENT.md` → Asset Atlas → 3-Axis Reframe → Public Narrative v1.8 → Active Execution Current.
3. **CANDIDATE DELTA** — open PR / Drive candidate. A newer candidate is not CURRENT merely because it is newer.
4. **TECHNICAL / VALIDATION PROOF** — C22 / C23 / model / runtime / evidence artifacts that prove selected relationships but do not redefine C04.
5. **DOWNSTREAM PRESENTATION CARRIER** — Web / F / boards / film. These consume project objects; they do not define or erase upstream design objects.

Each canonical object keeps:
- one stable object ID;

- zero or more candidate deltas;
