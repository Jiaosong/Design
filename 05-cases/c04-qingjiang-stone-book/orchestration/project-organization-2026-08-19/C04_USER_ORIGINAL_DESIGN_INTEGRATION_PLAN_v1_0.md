## 0｜Integration rule

These designs are not to be filed as an appendix and are not to be represented only by later technical proof.

For every user-original design object, C04 must keep four separate layers:

1. **DESIGN SOURCE** — the user's original board/design identity;
2. **PROJECT ROLE** — where the design belongs in C04's current professional architecture;
3. **CURRENT REPRESENTATION** — the strongest current pixel/model/drawing that can explain it;
4. **PROOF / OPEN GATES** — technical, field, engineering, source or implementation conditions that remain unresolved.

Hard rule:

`ORIGINAL BOARD ≠ FINAL PUBLIC PIXEL`

and simultaneously:

`LATER PUBLIC PIXEL / MODEL / C23 ≠ ORIGINAL DESIGN SOURCE`.

The original board can remain a source/evolution artifact while the design itself is represented by a cleaner current drawing/render/screen. This avoids both loss of authorship and forced use of an old board as the finished public page.

## 1｜Chapter allocation model

Each object gets exactly one **primary professional owner**. Cross-chapter appearances are allowed only when they perform a different role.

- CH11 owns **digital behavior / interface implementation**.
- CH12 owns **scene-specific experience relationships**.
- CH13 owns **physical / body / sensory objects and their experiential role**.
- CH15 owns **memory / IP / cultural-product continuation after the journey**.
- CH17 owns **technical/model/engineering proof descendants**.
- CH18 owns **design evolution, alternative comparison and professional judgment**.
- CH19 may consume Return/Memory closure, but does not own the design source.

No object is duplicated as if it were several independent designs merely because it appears in several chapters.
