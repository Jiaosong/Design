## Carrier and review semantics

`HOLD / REVISE / SUPPORT / PROCESS / REDRAW / MODEL FAIL` may apply to a later pixel, model, implementation or presentation candidate.

Those verdicts must not be translated into:
- `ORIGINAL DESIGN DELETED`;
- `DESIGN SOURCE REPLACED BY C23/MODEL/WEB`;
- `NEWER PR BECOMES ORIGINAL AUTHORING SOURCE`.

Likewise, `KEEP / MAIN` on a downstream presentation does not transfer upstream design authorship/source identity to that carrier.
