08 / PHYSICAL + BODY + SENSORY

实体不是一组产品，
而是一组身体支持。

它们服务不同停留时长与身体状态。景观、身体使用与技术证明各自承担不同层级；模型和效果图不拥有景观主权。

低强度局部短暂不形成任务
P01 / 步步生光

脚步留下短暂反馈，
然后让景观重新占满注意。

步过时产生低强度、局部、短暂的反馈，再自然消退。它仍是重要的身体互动方向，但不被表现成常亮地灯、积分反馈或强制任务。

场地、供电、防滑、排水、昼夜可读性仍需后续校核；这里仅表达交互时间关系与视觉克制度。
P02 / SHORT RECOVERY

站 → 倚 → 短坐，
不制造新的停留负担。

栏杆式可拆卸倚靠 / 休息界面只解决短恢复、短读与身体支撑。它不是唯一防坠栏杆，也不替代完整结构安全体系。

P05 / 清风吟

风已经在清江里，
设计只让人多等一会儿。

清风吟保持低密度、低噪声、低占地。自然风是基线，装置只在微风中提供轻微可感变化；强风、暴雨与维护状态下默认退场，不形成愿望墙或打卡任务。
