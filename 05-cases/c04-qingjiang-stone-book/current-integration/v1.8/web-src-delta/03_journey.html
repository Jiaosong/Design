02 / JOURNEY · 游程与交通

先决定怎么游，
再决定读多深。

01

ARRIVE

服务、天气、回程和基本路线先确定。

02

BOAT

从水面理解两岸、峰林与江面关系，手机不是第一任务。

03

CABLE

跨江先是移动视点，不设置强制 UI 和必做触发。

04

WALK

进入分支 / 回环网络，十三印可发现、跳过、重排。

05

RECOVER

体力、天气或运营条件变化时，身体恢复和 Return 提权。

06

RETURN

手机退出后，纸图、标识、服务和景观识别仍然成立。
