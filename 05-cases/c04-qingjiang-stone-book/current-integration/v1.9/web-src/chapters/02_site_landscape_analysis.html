CH02 / 场地与山水分析

先读山水关系，
再决定设计出现在哪里。

场地分析不重画一张更“漂亮”的假地图，而是从现有官方导览与当前空间关系中提取能够改变设计的事实：江、两岸、峰林、跨江移动、分支步行与空间收放。

观察 / 证据

江面是最大连续空间载体

水体把两岸、峰林和移动视点组织成同一景观场。

→
空间发现

先建立整体尺度

游客必须先知道自己处在怎样的山水关系中。

→
设计后果

BOAT / CABLE 先于解释

宏观观看阶段减少高密度内容，不把屏幕变成第一景观。

观察 / 证据

南岸步行是分支 / 回环网络

公开导览并不支持十三个点串成唯一顺序。

→
空间发现

选择比完成更重要

真实路线允许不同长度、方向与停留。

→
设计后果

ROUTE-03 管路线，十三印管内容

地图服务方向；内容可以发现、跳过和重排。

观察 / 证据

空间经历开敞—收束—再开敞

R06 与 R13 对注意力和身体提出完全不同的要求。

→
空间发现

场景不能使用同一信息密度

开阔观察允许停留，狭窄通过要求减负。

→
设计后果

R06 可读深，R13 必须退场

注意力密度由空间和身体条件决定，而非统一内容模板。

本页是远程、来源约束下的空间关系分析；不证明精确坡度、GPS、台阶、净宽、视距或现场安全条件。
