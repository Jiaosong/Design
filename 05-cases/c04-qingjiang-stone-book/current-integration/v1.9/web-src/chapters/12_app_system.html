04 / QINGJIANG APP · 数字伴随

需要时出现，
完成后退出。

App 不是景区控制面板。它保持山水游历志 × 石拓印记 × 图卷式探索的游戏感，但不再用完成率、13/13 或强制任务夺取游程。

SCREEN 01 / TODAY

今日清江

第一眼是清江，不是系统状态。今天怎么游、服务是否可达、Return 在哪里，比“有哪些内容”更先出现。

LANDSCAPE FIRST
SERVICE NEAR
RETURN ALWAYS
SCREEN 02 / ROUTE

探索地图

BOAT / CABLE / WALK / RETURN 构成游程骨架。标记表示“可以发现”，不代表“必须到达”。

BRANCH / LOOP
OPTIONAL MARKERS
NO TASK GATE

先看河谷

R06 的数字层只允许短暂关系揭示。身体恢复、真实景观与视野比较保持主导，阅读结束后界面撤退。
