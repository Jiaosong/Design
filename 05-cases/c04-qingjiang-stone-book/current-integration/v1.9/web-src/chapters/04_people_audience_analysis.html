CH04 / 人群与使用状态分析

不先画四张人物卡，
先判断身体、注意力和回程压力。

人群分析不是给不同年龄复制四套产品。真正影响设计的是移动能力、体力、认知负担、阅读深度、数字熟悉度、同行关系和回程紧迫度。

移动 / 体力走多久、能否停、是否需要恢复
注意 / 认知能承受多少信息与判断
阅读深度只看景观、比较关系或主动深读
数字熟悉度App可用，但不能成为路线前提
同行关系儿童、家庭、独行与陪伴状态
回程压力时间、疲劳、天气和未知状态下的优先级
R06 / 同一场景，不同深度

同一片河谷，
设计回应不同，但景观不被切成四份。

儿童 / 家庭

共同看见、指认、比较；互动帮助一起观察，不制造任务压力。

青年 / 探索者

允许简化空间判断、取景、追踪关系；内容更深但仍可跳过。

成人 / 深读者

景观先成立，再主动进入地方故事、关系解释与来源。

长者 / 低体力

恢复、短停、路线确定性与 Return 优先于任何深读。

R13 / 同一通过，不同人仍共享一个优先级

空间变窄时，
所有人的第一任务都是通过。

R13 不因为“人群差异”增加游戏层。低体力、儿童家庭或陌生游客只会进一步提高身体、安全与回程信息权重。
