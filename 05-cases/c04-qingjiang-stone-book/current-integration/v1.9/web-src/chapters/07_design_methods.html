CH07 / 设计方法

方法不是流程图，
必须能生成一个具体设计结果。

每个方法都写明输入、操作、输出与使用位置。没有实际设计输出的方法不进入主展示。

M01证据转设计证据 → 空间发现 → 设计后果

用于场地、路线、R06/R13 等来源约束下的设计判断。

M02场景设计游客情境 → 动作 → 内容/游戏模式 → 载体 → 价值 → 退路

避免从功能清单直接跳到装置或界面。

M03注意力设计场景 × 注意力密度 × 人群深度

决定哪里可以读深、哪里必须减负。

M04景观优先完整景观 → 关系揭示 → 可选解释

R06 已冻结的核心表达方式。

M05介入选择现状 → 分布式最小介入 → 单一强装置

通过方案比较而不是直觉决定实体强度。

M06降级与退场NORMAL / DEGRADED / CLOSED / UNKNOWN × FULL / LIGHT / OFF

把状态逻辑转成可见行为，而不是后台矩阵。

M07多通道冗余实体 + 数字 + 纸图 + 人工服务

保证手机退出后路线、服务与回程仍然完整。

M08细节深化设计决定 → 身体/体验效果 → 细节/技术证明 → 现场开放项

技术图只证明已经设计的东西，不替代设计。
