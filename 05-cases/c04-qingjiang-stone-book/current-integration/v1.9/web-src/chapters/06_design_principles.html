CH06 / 设计原理

不是一套视觉风格，
而是一套控制“何时出现”的规则。

这些原理同时约束空间、内容、App、实体设施、服务和记忆系统。每条原理都必须能回到具体清江场景。

01

真实清江优先

景观与身体关系先成立，解释后进入。

R06：完整河谷 → 关系揭示
02

服务 / 回程优先

确定性先于完成任务和内容消费。

UNKNOWN / CLOSED：Return 提权
03

三种观看尺度

游船看江域，索道看关系，步行看身体与细节。

同一清江，不同尺度
04

内容可选，不设十三站

十三印可以读、玩、跳过，不改变路线权力。

ROUTE ≠ CONTENT ORDER
05

注意力密度随场景变化

开阔处可以深读，收束处必须减负。

R06 ↑ / R13 ↓
06

数字可退场

界面只在需要方向、阅读和记忆时出现。

FULL / LIGHT / OFF
07

最小必要实体介入

只有身体和服务真的需要时才增加物。

Existing → Minimal → Hero
08

同场景，不同深度

不同人不是复制四套产品，而是改变负担与内容深度。

R06 audience depth
09

景观 → 关系 → 解释

说明不能抢在空间理解之前。

Landscape First
10

回程 + 记忆闭合

项目以再次认出清江结束，而不是13/13。
