CH01 / 项目问题与机会

不是再做十三个景点，
而是重新设计一次完整游程。

清江本身已经足够强。设计介入的任务，是让游客更清楚地进入、移动、观察、停留、恢复、返回，并在需要时读懂一页清江，而不是用更多装置和任务覆盖景观。

01

景观很强，阅读很弱

山水关系足够鲜明，但游客仍需要方向、观看层级和停留判断。

机会：把“怎么看”设计出来。
02

空间是网络，不是十三站

公开导览显示分支与回环；十三印如果变成线性任务，会反过来扭曲真实游程。

机会：路线主权与内容主权分离。
03

三种移动尺度彼此割裂

江面、索道、山路分别建立水上、空中、身体尺度，但缺少连续体验逻辑。

机会：把移动本身变成认知结构。
04

内容越多，越可能遮住清江

故事、知识、互动和数字界面都有价值，但不同空间允许的注意力密度不同。

机会：按场景控制内容强度。
05

游览不仅是“到达景点”

疲劳、休息、天气、退路、无手机和回程都属于体验本身。

机会：Service / Return 前置。
06

离开以后不需要完成率

真正值得保留的是个人路线、一次观察、一段书写和对同一条江的再次识别。

机会：用记忆闭合，而不是13/13。
