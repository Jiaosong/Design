CH08 / 总体策略与体验系统

一条清江，
四类设计载体共同工作。

总体策略不把路线、十三印、App、实体和记忆拆成彼此竞争的产品。它们围绕同一次游程分工：空间负责发生，内容负责理解，载体负责支持，回程负责确定性。

01

真实清江 / 空间主层

江、两岸、峰林、索道与步行网络决定第一阅读和身体行动。

02

路线 / 服务 / 回程

ROUTE-03、纸图、人工服务和识别系统决定方向与退路。

03

十三印 / 内容互动

在合适场景中提供 CULTURE / WISDOM / PLAY / WELLBEING 的可选阅读。

04

数字 / 实体 / 记忆载体

App、身体支持、感官介入、清江旅记与我的石书按需出现，不拥有路线主权。

始终可退出数字关闭 → 纸图 / 标识 / 人工服务仍成立内容跳过 → 路线与回程不受影响状态未知 → 不画成正常开放
