032 / CH07 / P01METHOD / EVIDENCE → FINDING → CONSEQUENCE
方法一 / Evidence-led design

证据不能直接
跳到形式。

每一次设计介入都先把“我们知道什么”和“因此能决定什么”拆开。事实、推理、假设和设计决定保持不同层级。

01

真实路线是分支 / 回环网络

空间 / 行为发现
十三印不能拥有路线主权，也不能被画成一条强制完成链。

设计后果
ROUTE 与 CONTENT 分离；阅读挂接路线，但不重新定义拓扑。

02

R06 现场数据仍开放

空间 / 行为发现
可以建立景观—关系的阅读顺序，但不能伪造精确现场几何。

设计后果
Landscape First → short Relation Reveal → Withdraw；R06 保持冻结。

03

R13 的核心是身体收束

空间 / 行为发现
通过压力高于解释欲望；安全、方向与出口必须先成立。

设计后果
Content / Digital / Play OFF；身体、路线、Return 获得优先级。

04

短暂停留 ≠ 新建主装置

空间 / 行为发现
恢复、倚靠、再出发是行为需求，不自动等价于 Hero object。

设计后果
先比较 Existing / Minimum Support / Enhanced / Hero，再决定是否介入。

034 / CH07 / P03LANDSCAPE FIRST → RELATION REVEAL → OPTIONAL EXPLANATION
方法三 / Landscape-first reveal

先把清江看完整，
再让关系短暂出现。

R06 的方法不是把信息叠到风景上，而是控制解释出现的时机：景观先读、自主观察、关系揭示、可选解释，然后界面退场。

  1. 01完整景观

    没有解释层挡住江、两岸和峰林。

  2. 02自主观察

    先让人自己辨认尺度与空间关系。

  3. 03Relation Reveal

    只揭示当前证据能够支持的关系。

  4. 04Optional Explanation

    内容是邀请，不是任务或进度。

  5. 05Withdraw

    阅读完成后重新把第一视觉还给景观。

SAME-SOURCE PAIR GATE · 关系层必须与同一真实场景对得上；R06 不重新设计。
035 / CH07 / P04INTERVENTION LADDER / 0 → 3
方法四 / Intervention competition

不是所有问题，
都需要一个设计物。

每个候选从“不新增”开始竞争。只有当访问价值、场地适配、运维与证据风险共同支持时，介入才向更强一级升级。

0 / EXISTING

不新增

利用现有景观、路线、行为与服务完成目标。它不是“没设计”，而是一个必须参与比较的方案。

1 / MINIMUM SUPPORT

最小支持

只补足身体、方向、恢复或阅读真正缺失的部分；默认优先检验这一层是否足够。

2 / ENHANCED

增强介入

当最小支持无法解决明确关系问题时，才增加载体、结构或信息强度。

3 / HERO

强介入

必须证明其体验收益显著高于景观竞争、维护、证据和实施风险；否则退回前级。

036 / CH08 / P01MASTER STRATEGY / CORRECT ABSENCE
总体策略 / First-read hierarchy

完整不是全部出现，
而是该退场时能退场。

清江石书不是把内容、数字、品牌和文创堆进同一段旅程，而是为每一层规定主权、时机与退出条件。

01真实清江 / ROUTE / BODY

第一阅读与身体现实。任何系统不得覆盖真实山水、路线选择和通过需求。

02SERVICE / RETURN

在异常、疲劳、不确定或结束阶段升为最高功能层。

03OPTIONAL READING

十三印属于内容层；可开启、可跳过、可只读一部分。

04DIGITAL / BRAND

负责提示、关系揭示与一致识别，但必须能变轻、关闭和退场。

05MEMORY

发生在经历之后；不反向把旅程变成收集进度。

REAL QINGJIANG / ROUTE / BODY > SERVICE / RETURN > OPTIONAL READING > DIGITAL / BRAND > MEMORY

同一条江，
被看见三次。

交通不是三个功能按钮，而是三次观看尺度改变：水上先看整体，空中看两岸关系，山中用身体进入局部。

BOAT

视点跨越江面，南北岸、路径与峰林关系变得可辨；移动中不设置强制 UI。

每个系统，
只做它真正擅长的事。

系统完整性来自边界清楚，而不是每一层都覆盖每一件事。尤其不能让品牌、内容或 App 反向升级为路线、地理与安全权威。

044 / CH09 / P03CABLE / VIEWPOINT TRANSFORMATION
索道 / Moving viewpoint

空中看清江，
不是空中做任务。

跨江移动真正有价值的是视点转换。设计只帮助人在移动前建立方向、移动中观察、落地后重新认出关系。

BEFOREORIENT — 先知道江、两岸与落点关系。
DURINGOBSERVE — 把注意力留给移动中的真实视域变化。
AFTERRECOGNIZE — 落地后重新认出刚才看见的关系。
NO FORCED UI · NO FORCED AR · NO LONG READ · R01 MOVING VIEW REMAINS LIGHT
CABLE = VIEWPOINT TRANSFORMATION / RELATION · DIGITAL MUST NOT COMPETE WITH MOVING LANDSCAPE
045 / CH09 / P04WALK / CHOICE + BODY + DISCOVERY
步行 / Network exploration

山中探索可以自由，
路线权必须稳定。

步行阶段允许分支、回环和可选发现，但所有探索都挂接在同一个 ROUTE-03 骨架上。内容可以出现，不能创造第二条“更好看”的路线。

MAIN主游程

保持方向与关键转换连续。

EXPLORE可选探索

内容 / 节点挂接，不拥有拓扑。

RETURN恢复 / 回程

与探索并行存在，不等结束才出现。

  1. 01CHOICE

    在真正需要选择的位置出现信息。

  2. 02BODY

    坡度、疲劳、安全等精确量化保持 FIELD OPEN。

  3. 03DISCOVERY

    可选阅读只在注意力允许时出现。

GAME MAP = REAL ROUTE SKELETON + OPTIONAL DISCOVERY + PARTIAL REVEAL · NOT A SECOND TOPOLOGY
046 / CH09 / P05RETURN / SERVICE / NO-PHONE SUBSTRATE
Return / Safety substrate

Return 不是终点，
而是整条路线的底层。

探索自由成立的前提，是游客始终知道自己可以怎么回来。手机关闭、网络下降、状态未知时，系统仍通过多通道冗余保持可读。

01 / LANDSCAPE景观识别

江面、两岸、索道与关键空间关系帮助重新建立方位。

02 / SIGNAGE路径标识

只在选择与风险真正发生的位置说明继续 / 返回。

03 / PAPER纸图

无登录、定位、电量与网络也能理解关系。

04 / HUMAN人工服务

异常、询问、关闭与恢复仍保留人。

05 / DIGITAL数字辅助

补充状态和内容，但不能成为唯一承重结构。
