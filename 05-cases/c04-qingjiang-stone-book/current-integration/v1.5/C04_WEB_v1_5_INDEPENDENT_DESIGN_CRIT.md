## What materially improved

The four-frame `BEFORE / INSIDE / EXIT / BACK-LOOK` board is no longer the first-read carrier. The Web now reads as one spatial act: dark compression → body passage → Qingjiang reopening. `BODY FIRST / PLAY OFF / RETURN ON` is subordinate and the memory instruction is deferred until after exit. The previous board-in-Web failure is resolved.

### Fluid Rest — KEEP_AFTER_REVISION / SUPPORT
Real Qingjiang is restored as the first field; body/object geometry is visible in the same frame instead of being isolated on a beige object crop. The object remains visibly a relation study rather than a resolved site insertion, and `LOCATION OPEN` stays adjacent. This resolves the v1.4 regression while preserving the upstream limit that Fluid Rest is Physical/Technical support, not landscape Hero.

### 清风吟 — KEEP_AFTER_REVISION / SENSORY SUPPORT
The first read is again landscape + wind. The object is secondary, low-density and non-task-like. Wind lines act as a restrained perceptual cue rather than decorative UI. The v1.4 object-only first read is resolved. Exact response mechanism, ecology and mounting remain open.

### Motion Web carrier — KEEP_AFTER_REVISION
All six states now have independent finished visual carriers: ARRIVE / CROSS / OPEN / PASS / REMEMBER / RETURN. PASS uses the body corridor rather than the R13 review board. REMEMBER is a paper-memory field rather than another scene thumbnail. The sequence now has meaningful perceptual contraction/expansion rather than a contact-sheet rhythm.

### 390px first viewport — KEEP_AFTER_REVISION
For the repaired R13, Fluid Rest and 清风吟 beats, the scene/proof appears before the long explanatory copy. No horizontal overflow was observed in the changed-fragment 390px render. The prior failure where a giant title consumed the first viewport is materially reduced.

2. Fluid Rest and 清风吟 are deliberately composite relation studies. Their `LOCATION OPEN` / `MOUNTING OPEN` labels must remain visible so the montage is not read as verified placement.
3. R13 compression remains a remote conceptual visualization; it does not establish real clearance, width, surface, safety or field geometry.
