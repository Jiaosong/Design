## Independent pairing review
The model is **not** accepted as a Landscape Hero or a public-facing primary visual.

1. `standing → sitting → leaning` as one continuous body interface;
2. separation of `warm-touch strip / shell / hidden subframe` as an assembly relationship.

It does **not** prove:
- final site placement;
- terrain attachment;
- drainage;
- edge/fall protection;
- foundations;
- construction readiness.
