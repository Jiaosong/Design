07 / AUDIENCE DEPTH · 同场景不同深度

不是给不同人换一套界面，
而是让同一片河谷保持不同读取深度。

家庭、探索者、深读者、低体力、低数字与重复到访者共享同一场景；差异来自身体负担、注意力与主动深读程度，不来自 persona 卡片。

真正的差异，
发生在动作里。

家庭

LOOK / COMPARE / POINT：一起找、一起说，而不是把孩子交给任务系统。

探索者

TRACE / FRAME：更愿意做简化空间判断与观察比较。

深读者

LISTEN / WAIT / READ：主动进入更深来源与文化解释。

低体力 / 低数字

RECOVER / RETURN：先恢复、先确认路线，也可以完全不用手机。
