## KEEP / KEEP_AFTER_REVISION

### Culture Journey — KEEP_AFTER_REVISION
The page now reads as a Web-native Qingjiang scene rather than a board embedded inside the Web. The route/culture hierarchy is clear: landscape first, then culture. The left image and right editorial field establish a credible first read. The remaining weakness is that the image source is soft and the large-title editorial pattern is still familiar from other sections.

### Culture R06 — KEEP
This is the strongest v1.4 repair. R06 is carried by one real valley image with LOOK / COMPARE / EXPLAIN as subordinate annotations rather than a separate method panel. The claim is visually legible without relying on explanatory prose.

### Audience — KEEP_AFTER_REVISION
The same-scene / different-depth logic now works as a genuine Web composition. The scene remains dominant and the depth ladder is secondary. This is materially stronger than the embedded Audience board. On mobile, however, the headline becomes so large that the actual scene evidence is pushed below the first viewport; this should be reduced in the next pass.

### P01 — KEEP_AFTER_REVISION AS WEB SUPPORT ONLY
`PASS → GLOW → FADE` communicates transient low-intensity behavior without falsely promoting the upstream HOLD presentation. This is a valid carrier for the interaction principle. It is still an abstract timing diagram rather than a convincing place/body first-read, so it must not become the Physical Hero or substitute for a mature P01 spatial pixel.

### Technical — KEEP_AFTER_REVISION
The namespace is correct and the BODY → LAYER → ATTACH → OPEN ladder is useful. The lightbox is the first point at which the drawing becomes genuinely readable at near distance; once opened, the plan/section/elevation/layer relationship is clear enough for support proof. The initial page still places most of the actual drawing below the first viewport, so the first technical read remains more editorial than technical.

## REVISE / REGRESSION

### Culture R13 — REVISE
The v1.4 claim that Culture R13 moved from board framing to a Web-native carrier is not fully true in the finished pixels. The `R13 | BEFORE / INSIDE / EXIT / BACK-LOOK` board remains visibly embedded as a rectangular presentation artifact. The surrounding Web typography is cleaner, but the main evidence is still a board inside a page. This is an inherited-board residue, not a completed repair.

### Fluid Rest — REVISE / REGRESSION FROM v1.3
Removing the review-board chrome cleaned the frame, but the crop also removed the strongest useful context: real Qingjiang first-read and the relation between object, body and landscape. The remaining isolated schematic looks small, generic and under-resolved against a large empty field. It reads more like a cropped process illustration than a professional physical design outcome. v1.4 should not replace the stronger v1.3 scene-pairing logic here.

### 清风吟 — REVISE / REGRESSION FROM v1.3
The crop isolates a vertical device-like fragment but no longer makes wind, landscape or sensory relation legible. The object is too weak to carry the page alone and the large typography amplifies the mismatch between claim and proof. Keep the concept, but revert this public pixel or rebuild it from real Qingjiang + one clear response mechanism.

### Motion — REVISE
The scroll-driven state mechanism is a real behavioral improvement, but the finished visual sequence is not yet professionally coherent.

- ARRIVE works: real Qingjiang dominates and the stage language is legible.
- RETURN works as a cinematic closure, although the imagery is visually close to ARRIVE.
- PASS fails the first-visual gate: it uses the R13 four-frame board as the full motion carrier, then overlays a very large `PASS` label across that board. The motion stage therefore returns to the exact “board inside Web” problem v1.4 was intended to remove.
- Only ARRIVE / PASS / RETURN have independent finished-pixel readback in the review evidence. CROSS / OPEN / REMEMBER are not independently demonstrated as finished states, so six-stage visual continuity is not proven.

Motion may remain an interaction experiment, but it is not a MAIN-quality visual replacement for the v1.3 Motion carrier yet.

## Cross-page design findings

1. **v1.4 improves presentation cleanliness but over-crops some evidence.** Removing review-board chrome is not automatically an upgrade when the crop also removes the spatial relation that made the object credible.
2. **Real Qingjiang First is weaker specifically in Physical.** Culture/Audience improve, while Fluid Rest and 清风吟 become more detached from place.
3. **Large editorial headlines still dominate too many first viewports.** This is controlled on desktop but aggressive on 390px, where evidence is often pushed below the fold.
4. **Behavioral Motion improvement is not the same as Motion design finish.** State switching works, but finished visual carriers must be redesigned as cinematic states, not imported boards.
5. **Truth boundaries remain strong.** No field/engineering status was falsely closed and R05 was correctly left unresolved instead of being filled with generic imagery.

Required next gate: repair only these bounded deltas, then rerender the changed desktop + 390px states and rerun independent finished-pixel Crit.
