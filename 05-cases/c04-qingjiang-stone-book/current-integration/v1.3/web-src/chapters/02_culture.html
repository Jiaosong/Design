01 / CULTURE · 地域文化

文化不是背景说明，
而是一种观看方式。

地方故事、地名、山水经验与传统景观看法，不单独变成“知识页”。它们被嵌回 BOAT / CABLE / WALK 的真实游程，决定游客何时看、何时比较、何时听、何时停下。

CULTURE / JOURNEY

先看清江，
再让文化进入。

文化层不抢夺路线主权。游客先获得“我在哪里、怎么走、能不能回来”的确定性，再决定是否进入更深的地方知识。

看先让山水自身成为第一视觉证据。
辨把地名、形态、来源放在需要判断的瞬间。
听地方故事作为可选进入，不制造强制停留。
记把真正改变判断的片段留到旅记与我的石书。
PLACE NAME / LOCAL STORY

一个名字，
改变一次观看。

命名不是“答案”，而是观看的入口。R07 继续保留“仓禀峰／仓廪峰”的来源冲突；不把远程资料中的单一写法伪装成现场最终结论。

R06 / WISDOM

先看完整河谷，
再决定解释多少。

在开阔场景里，解释可以短暂出现；但它不能把景观变成“教学屏”。游客先比较两岸、江面与地形关系，再选择是否进入更深阅读。

R13 / WITHDRAW + RETURN

真正成熟的文化体验，
也知道什么时候不说话。

空间收窄时，身体、路线和回程优先。内容退后，记忆在通过以后形成，而不是在最需要注意脚下的时候继续加信息。

MEMORY / CULTURE

文化最终留下的，
不是“学完了什么”。

它成为一条路线、一段手写、一张自己留下的观察，或者一个以后还会想起的清江片段。
