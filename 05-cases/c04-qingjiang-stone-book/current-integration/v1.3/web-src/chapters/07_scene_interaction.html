06 / SCENE INTERACTION · 场景游戏

同一个系统，
不使用同一种强度。

开阔场景可以比较、揭示和停留；收窄场景让游戏关闭、身体接管。场景本身决定数字、实体、文化和 Return 的权重。

R06 / ACTION SEQUENCE

LOOK → RECOVER → OPTIONAL REVEAL → CONTINUE / RETURN

LOOK

先让视野和河谷关系自己成立。

RECOVER

短休息、倚靠或降低信息密度。

REVEAL

只在游客主动需要时出现简短关系解释。

RETREAT

读完就退，或者直接 Return。

R13 / ACTION SEQUENCE

BODY → PASSAGE → EXIT VIEW → RETURN

BODY

身体感受空间收窄，界面主动减弱。

PASSAGE

通过本身是体验，不添加扫码或任务。

EXIT

出口重新打开视野，才允许记忆层回归。

RETURN

继续、返回或休息的判断始终清楚。
