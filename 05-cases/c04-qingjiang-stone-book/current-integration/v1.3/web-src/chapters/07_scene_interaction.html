需要时再读。

先让完整河谷和身体位置成立。短恢复降低疲劳，数字层只在主动需要时出现；继续与 Return 都不被内容门槛阻挡。

LOOK真实河谷先读。

R13 / COMPRESSED ATTENTION

空间收窄，
身体接管。

进入一线天后 PLAY OFF。身体、脚下、出口与 Return 是第一层；通过之后，景观重新打开，记忆才回来。

BODY注意力回到通过本身。
EXIT出口重新打开视野。
RETURN继续、返回或休息始终清楚。
