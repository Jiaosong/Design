08 / PHYSICAL + BODY + SENSORY

实体不是一组产品，
而是一组身体支持。

它们服务不同停留时长与身体状态。景观、身体使用与技术证明各自承担不同层级；模型和效果图不拥有景观主权。

P01 / 步步生光

概念保留，
但不抢夺第一视觉。

步过时产生短暂低强度反馈，再自然消退。它仍是重要的身体互动方向，但现阶段首先保留交互逻辑与场地适配问题，不让表现图盖过清江。

这一方向继续保留；在场地、供电、防滑、排水与昼夜可读性进一步校核前，不作为主要场景装置展示。
P02 / SHORT RECOVERY

站 → 倚 → 短坐，
不制造新的停留负担。

栏杆式可拆卸倚靠 / 休息界面只解决短恢复、短读与身体支撑。它不是唯一防坠栏杆，也不替代完整结构安全体系。

P03 / FLUID REST

只在它真的增加身体价值时，
才值得出现。

它承担更长停留与坐 / 倚关系。当前模型只用于理解 standing → sitting → leaning 与材料层级，不证明选址、基础、排水、边缘安全或施工可行。

P05 / 清风吟

风先发生，
装置只把它变得可感。

清风吟保持低密度、低噪声、低占地。当前不继续建模，先锁定单一响应机制；它不能退化成愿望墙或景区打卡装置。
