## Remaining revision / bounded limits

1. **Inherited-board residue remains in a few support assets.** Culture R06, Audience v4 and some Physical/Technical carriers still visibly contain their upstream board typography. This is no longer a first-read failure, but a later polish pass could further detach evidence graphics from their original review-board framing.
2. **Physical remains the least visually resolved design family.** P02 is credible and readable; P01 correctly remains non-Hero/process-bound, and Fluid Rest remains location-open. This limits the Physical chapter from becoming a fully locked project MAIN section, but it is correctly represented without false promotion.
3. **R05 is intentionally incomplete at pixel level.** The authoritative Honghua Stone Forest landscape source is still unresolved; keeping the gap is preferable to a generic or AI substitute.
4. **Motion Web carrier is acceptable; final Motion artifact is not closed.** The six-stage sequence now reads as travel/body rhythm, but the separate final film still requires re-edit and independent motion review.
5. **Field and engineering validation remain open.** The Web correctly presents this boundary and does not visually imply measured/site/implementation certainty.
