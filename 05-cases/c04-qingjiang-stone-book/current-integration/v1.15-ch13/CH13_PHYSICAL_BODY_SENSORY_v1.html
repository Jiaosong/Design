P04 / STEP LIGHT

步步生光只做一件事：
脚步被看见，然后消失。

不是打卡、积分、连续任务，也不要求游客停下来操作。运动语法固定为 STEP → RESPONSE → FADE；关闭动效后信息仍然成立。

LIVE WEB BEHAVIOR / NATIVE CSS + POINTER

不是“点亮一条路”，
而是让一次经过留下极短的余波。

点击 / 触摸左侧区域模拟脚步。每次反馈独立出现并在约 1.45 秒内消退；没有得分、没有累计、没有完成率。
