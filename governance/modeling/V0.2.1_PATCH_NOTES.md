# OLEANDER Modeling Contract｜v0.2.1 Patch Notes

## Fixed
1. `<REQUIRED...>` placeholders no longer count as real project values in strict validation.
2. JSON Schema is now executed by the canonical validator.
3. `applicable=true` with empty Hard Point / Envelope / Section items fails strict validation.
4. Added global semantic-ID uniqueness and dependency-reference validation.
5. Added component-parent and primary-section reference validation.
6. Added Authority ↔ editable-source consistency.
7. Added M4/M6/M9 stage minimums for Primary Geometry / Semantic Components / Material Bindings.
8. Added QA completeness checks.
9. Added cache and Promotion-only persistence safety checks.
10. Added explicit `template` vs `strict` validation modes.
11. Added negative self-test logic locally to prevent regression to false-positive PASS.

## Non-breaking boundary
- `contract_version` remains `v0.2`.
- M0–M10 methodology is unchanged.
- Existing valid v0.2 contracts remain compatible.
- `spec_patch: v0.2.1` is optional metadata.

## Expected validation behavior
- Blank Template: `template = PASS`, `strict = FAIL`.
- Filled Automotive F0→F1 example: `strict = PASS`.
- Known invalid false-pass fixture: `strict = FAIL`.
