# OLEANDER Training — Cross-screen Visual Grammar

## Trigger
Recent Qingjiang digital review exposed a family-level inconsistency: ROUTE had a stronger spatial/game-like identity while TODAY and MY BOOK read as weaker, different product families.

## Existing-first
- Reused `oleander-story-and-board` as the owner for cross-surface narrative/visual cohesion.
- Checked recent training to avoid repeating responsive recomposition, long-form orientation, joint legibility, physical wayfinding, brand intensity, route-state and material-identity work.
- No parallel Skill created.

## External calibration
Apple Human Interface Guidelines (2026) are used only as a general primary-source precedent: maintain consistent visuals/interactions once established, preserve context, and use hierarchy intentionally. This training does not claim Apple-platform conformance.

## Practice
Three task surfaces are compared as one product family:
- ROUTE — path decision / world field
- TODAY — current recommendation / daylight decision plane
- MY BOOK — collected memory / paper-memory folio

### v1 — REJECT
Each screen is locally plausible but uses unrelated typography, material, color, status, and spatial grammars. The product reads as three separate products.

### v2 — REVISE
Shared family invariants become strong, but task differentiation is over-corrected: TODAY and MY BOOK feel like ROUTE skins.

### v3 — REVISE
Task-specific material roles are introduced, but rendered reopen finds TODAY secondary copy colliding with the dark-header/light-field boundary.

### v4 — KEEP FOR TRAINING
TODAY hierarchy is repaired. Shared invariants remain visible while task-specific first-read differs.

## Reusable rule
`SCREEN PURPOSE → FAMILY INVARIANTS → TASK VARIATION → SIDE-BY-SIDE FAMILY READ → DISTANCE READ → NEAR READ → CROSS-SURFACE SEMANTIC CHECK`

Consistency is not cloned layout. Variation is not visual reset.

## Design quality boundary
KEEP applies only to the synthetic training artifact. It does not prove final C04 UI, game feel, usability, browser runtime, accessibility, user comprehension, field truth, or MAIN promotion.
